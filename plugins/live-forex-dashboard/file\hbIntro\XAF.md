中非金融合作法郎（Central African Franc，简称CFA），是中部非洲经济与货币共同体（CEMAC）成员国使用的法定货币。该货币的代码为XAF，通常以CFA franc 或称为F CFA表示。

中非金融合作法郎基于法国法郎，并与欧元挂钩。1 欧元 = 655.957 XAF。中非金融合作法郎由中非国家银行负责发行和管理，其流通范围包括喀麦隆、中非共和国、乍得、刚果（布）、刚果（金）和赤道几内亚等国。

中非金融合作法郎的使用旨在促进地区贸易，增强成员国之间的经济合作，同时也为各国提供了货币稳定性。CFA法郎的历史可追溯至1945年，至今已历经多次货币和经济体制的调整。

需要注意的是，CFA加入的国家须遵循由西非国家中央银行或中非国家银行制定的相关货币政策，以确保区域经济的稳定与发展。
