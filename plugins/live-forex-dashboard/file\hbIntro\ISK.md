冰岛克朗（Icelandic króna，缩写为ISK）是冰岛的官方货币。它由冰岛中央银行（Seðlabanki Íslands）发行和管理，使用符号“kr”表示。克朗的名称源于古诺尔斯语中的“krón”一词，意为“冠”。

冰岛克朗的分币单位为音哥（aurar），其中1克朗等于100音哥。由于通货膨胀及经济波动，音哥的实际使用越来越少，主要在价格标识中出现。

冰岛克朗经历了多次汇率波动，因其经济受到各种外部因素的影响，如全球金融市场波动、旅游业发展等。在2008年金融危机期间，克朗实施了暂时性资本管制，随后逐步放宽。

通常，冰岛克朗与其他货币的汇率由市场供求关系决定，同时也受到冰岛经济状况、利率政策及国际经济形势变化的影响。

在外汇市场上，冰岛克朗被视为较小型的货币，流动性相对较低，但在特定情况下，具有一定的投资吸引力，尤其是在寻求多样化投资组合的情境下。

总体而言，冰岛克朗是一个稳定但具有一定风险的货币，其价值反映了冰岛国家经济的健康和发展态势。
