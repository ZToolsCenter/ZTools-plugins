厄立特里亚纳克法（Eritrean Nakfa）是厄立特里亚的官方货币，符号为"ERN"。其名称源自厄立特里亚的一个城市——纳克法。厄立特里亚纳克法于1997年第一次发行，取代了之前的苏丹镑。

纳克法的分币单位为分，1纳克法等于100分。其货币设计和硬币材料均具有一定的地方特色，通常会展示国家的历史、文化和自然资源。纳克法在促进国内经济活动及与邻国的贸易中发挥了重要作用。

在国际市场上，厄立特里亚纳克法相对较少交易，因此其汇率可能不如主要货币稳定。市场交易通常以美金或其它主要货币为主，尤其在外汇市场上对纳克法的需求较低。

此外，厄立特里亚的金融体系相对封闭和受限制，外汇管制使得本国居民在进行国际交易时面临一定的挑战。

总体而言，厄立特里亚纳克法在提升国家经济自主权方面发挥了作用，但因其流通性和国际认可度的限制，可能对投资者及旅行者在该地区的活动产生影响。
