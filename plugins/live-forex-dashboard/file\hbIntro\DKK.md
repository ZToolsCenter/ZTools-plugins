丹麦克朗（Danish Krone，货币符号：DKK）是丹麦的法定货币，官方单位为克朗（Krone，单数形式）和Øre（分，100 Øre = 1 克朗）。丹麦克朗自1875年采用金本位制以来，已成为丹麦的主要流通货币。

丹麦克朗的发行由丹麦国家银行（Danmarks Nationalbank）负责，该银行亦负责货币政策的制定与实施。丹麦克朗目前不使用欧元，而是参与欧洲汇率机制（ERM II），与欧元维持一定的兑换范围。

丹麦克朗在国际外汇市场上的汇率波动受多种因素影响，包括经济指标、利率水平和全球市场动态等。该货币以其金融稳定性和低通胀率著称，因此在北欧地区被广泛接受并使用。

丹麦克朗的货币符号是在国际标准化组织中分配的代码为“DKK”，在金融交易中常被引入用于价格表示。
