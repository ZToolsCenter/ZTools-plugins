柬埔寨瑞尔（Cambodian Riel，符号：₫，ISO 4217代码：KHR）是柬埔寨的官方货币。瑞尔分为100分（-santim），尽管分并未广泛流通。该货币由柬埔寨国家银行发行，成立于1953年，随后在20世纪90年代经历了多次改版。

汇率方面，柬埔寨瑞尔对其他主要货币的价值通常不稳定，尤其是对美元的汇率。美元在柬埔寨经济中被广泛接受，许多商业往来及交易以美元结算，导致瑞尔处于相对较弱的地位。 

流通方面，虽然瑞尔是法定货币，但在实际交易中，美元占据了相当大的份额。柬埔寨的许多商店、餐厅及服务行业都直接接受美元。在熊市时期，瑞尔的使用更为减少。

作为一种法定货币，瑞尔的使用受到柬埔寨法律的保护。柬埔寨国家银行负责货币的设计、印制和管理，以保持相对的财政稳定和经济发展。 

在选择货币进行交易时，投资者和游客应留意汇率波动，并考虑在计划旅行或投资前咨询相关的金融机构以获取最新的信息。
