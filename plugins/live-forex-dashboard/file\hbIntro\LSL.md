巴索托洛蒂（Basotho Loti，符号：LSL）是莱索托的官方货币。它的ISO 4217代码是LSL。巴索托洛蒂的名称来自于该国的主要民族巴索托人（Basotho），也是该货币的历史和文化背景的体现。

巴索托洛蒂的汇率与南非兰特（ZAR）挂钩，1巴索托洛蒂的价值通常等于1南非兰特。这是因为莱索托是南非的一个内陆国家，经济在很大程度上依赖南非。巴索托洛蒂可分为单位"兰特"和"先令"（1巴索托洛蒂=100先令），并发行不同面额的纸币和硬币。

在莱索托，巴索托洛蒂广泛用于日常交易，并且接受南非兰特作为法定货币。由于莱索托的经济结构和贸易关系，巴索托洛蒂在国际市场上的流通相对有限，主要用于国内经济活动。

值得注意的是，巴索托洛蒂的设计和印刷由南非储备银行负责。因此，使用巴索托洛蒂的交易和金融操作通常会受到南非货币政策的影响。
