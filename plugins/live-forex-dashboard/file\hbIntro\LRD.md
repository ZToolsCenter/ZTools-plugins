利比里亚元（Liberian Dollar，简称L$或LD）是利比里亚的官方货币。其货币符号为L$，而国际标准化组织（ISO）代码为LRD。利比里亚元分为100分。 

利比里亚元在1986年首次引入，替代了之前的利比里亚英镑。当前流通的利比里亚元纸币由利比里亚中央银行发行，包括多种面值的纸币，如5、10、20、50、100、500元。硬币则有1分、5分、10分、25分和50分等不同面值。

利比里亚元的兑换率受多重因素影响，包括经济形势、国际市场动态以及政府政策。利比里亚经济主要依赖农业与矿业，经济波动可能会影响货币的汇率稳定性。

值得注意的是，利比里亚元在国际市场上流通性较差，通常采用美元进行国际交易和结算。此种情况导致在利比里亚本国，美元与利比里亚元往往是同等流通的状态，公众在日常交易中使用美元的情况较为普遍。利比里亚的货币政策旨在保持价格稳定及促进经济增长。
