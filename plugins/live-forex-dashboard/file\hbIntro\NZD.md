新西兰元（New Zealand Dollar，NZD）是新西兰的法定货币，也是库克群岛、尼乌以及托克劳的官方货币之一。新西兰元的货币符号为“$”，通常用“NZD”来表示。新西兰元于1967年正式取代了新西兰镑（New Zealand Pound），并与其他一些美元货币采取浮动汇率制。

新西兰元分为100分（cents），其纸币面额包括5元、10元、20元、50元和100元，硬币面额则为10分、20分、50分、一元和二元。新西兰元的钞票采用了先进的聚合物材料，具有较好的耐用性和防伪特性。

新西兰元在国际外汇市场上的交易量相对较小，但广泛用于国际贸易，尤其是与澳大利亚、美国和中国等主要经济体的贸易关系中。新西兰元的汇率受多种因素影响，包括国际商品价格、新西兰的经济表现、利率政策及其与其他国家货币的相对强弱等。

在金融市场，新西兰元被认为是一种风险敏感货币，其价值通常受全球经济形势变化的影响。同时，新西兰元也是外汇交易中的一种活跃货币，受到投资者的广泛关注。
