德意志马克（Deutsche Mark，缩写为DM）是德国在1948年至2002年间使用的货币单位，直到欧元（EUR）取代其地位。德意志马克曾是德国联邦共和国及其继承国的官方货币，其符号为“DM”。 

德意志马克的废弃标志着德国从传统的国家货币转向更广泛的欧洲货币体系。这一转变发生在1999年1月1日，欧元作为电子货币正式推出，2002年1月1日起，欧元纸币和硬币开始流通，德意志马克的流通被正式停止。

在其存在期间，德意志马克曾经历多个兑换率变化，并在全球经济中扮演了重要角色。其作为一种安全的货币，受到投资者和存款人的高度信赖。在德意志马克废弃后，欧元成为了德国及其他欧盟国家的共同货币。

某些未流通的德意志马克货币仍然可以在一些银行进行兑换，不过大多数情况下，这一过程的兑换时效性和必要手续需根据具体银行政策而定。数据显示，德意志马克在货币历史上、经济的稳定性和德国经济模式上均有重要影响。
