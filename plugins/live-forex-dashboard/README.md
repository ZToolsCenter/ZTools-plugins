
# 汇率计算器


## 介绍
根据实时汇率，计算各货币之间折算金额。在插件中可以添加任意货币进行批量转换，也可以一键添加全部货币进行排序对比。
在这里还可以了解到各货币的科普知识，并且会优先使用本地缓存内容，减少重复加载。


## 使用
1. 插件选择 **人民币`CNY`** 作为默认货币
2. 你可以在【**选择货币**】下拉框中搜索想要计算的货币，点击下拉数据即可将货币添加到计算表格中
3. 你可以一键添加所有的货币到计算表格中，也可以一键移除所有货币 恢复到初始状态
4. 你可以切换【**已废弃**】的货币开关，使得已废弃的货币可以选中参加计算（“已废弃”货币默认不显示）
5. 你可以修改货币显示小数位数（0~20位）
6. 你可以在计算表格中拖拽货币实现自定义排序
7. 你可以点击【**实时汇率**】【**折算金额**】列头切换排序
8. 你可以点击【**折算金额**】单元格 来编辑换算金额，其他参与计算的货币将统一按该货币的汇率进行折算
9. 被选中的货币 会替换掉顶部的固定货币，同样 固定货币的【**折算金额**】单元格 也可以修改换算金额。
10. 你可以双击【**移除**】按钮来取消相关货币的计算
11. 你可以点击右上角的【**汇率刷新**】按钮来获取最新的汇率信息，刷新成功后将重新计算已在计算表格中的所有货币
12. 你可以点击【**国家名称**】单元格 弹出货币介绍信息（货币知识摘抄自chatGPT）
13. 你可以按下`F3`或`Ctrl+F`直接定位并选中【**货币选择**】下拉框，直接输入货币名称或代码搜索货币，再使用`↑`/`↓`光标键选择货币，回车添加到计算表格中
## 说明

汇率信息来自 [https://www.xe.com/](https://www.xe.com/)
