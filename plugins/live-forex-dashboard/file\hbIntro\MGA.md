马尔加什阿里亚（Ariary）是马达加斯加的法定货币。其符号为“Ar”，通常使用的代码为“MGA”。马尔加什阿里亚的引入是在2005年，替代了此前的货币单位“法郎（Malagasy franc）”，兑换率为1阿里亚等于5,000法郎。

阿里亚分为两种：硬币和纸币。硬币的面值包括1、5、10、20、50和100阿里亚，而纸币的面值则有100、200、500、1,000、2,000、5,000、10,000、20,000、50,000以及100,000阿里亚。

马尔加什阿里亚的发行由马达加斯加中央银行（Banque Centrale de Madagascar）负责。该货币在国际外汇市场上的流通性相对较低，主要在国内交易使用。在外汇市场上，汇率受多种因素影响，包括经济状况、通货膨胀及国际商品价格波动等。

在进行货币兑换时，应关注市场汇率及相关手续费，以确保交易的有效性及经济性。
