欧洲货币单位（European Currency Unit，简称ECU）是欧洲经济共同体（EEC）于1970年至1998年之间使用的一种账面货币单位。ECU最初是设立用于商定成员国货币间的相对价值，以促进贸易和金融稳定。

ECU的计算基于一篮子成员国货币的加权平均，其权重依据每种货币在欧共体内的相对经济规模设定。其目的在于提供一种稳定、统一的参考货币，便于成员国之间的货币政策协调与汇率稳定。

1999年，ECU被欧元（Euro）取代。虽然ECU在法律上仍被保留为一种参考单位，但在实际交易中已经不再使用。欧元的发行及其广泛接受，标志着欧洲货币一体化的重要里程碑。

当前，ECU不再是流通中的货币单位，其历史影响主要体现在欧元的形成及欧洲经济合作的基础上。
