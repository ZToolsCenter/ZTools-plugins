银（盎司）是指以盎司为单位测量的银的重量。银是一种贵金属，通常用于投资、工业用途及珠宝制造。常用的衡量单位包括：

1. **托拉盎司**（Troy Ounce）：这是贵金属（包括银）交易的标准单位。1托拉盎司等于约31.1035克。
2. **普通盎司**（Avoirdupois Ounce）：主要用于日常商品计量，1普通盎司约等于28.3495克。但在贵金属交易中通常使用托拉盎司。

银的市场价格通常以每盎司价格表示，这一价格受多种因素影响，包括供需关系、经济形势、市场投机及通货膨胀等。银的交易主要通过期货合约、交易所交易基金（ETFs）和现货市场进行。

作为投资者，可以通过购买实物银、银矿股票或银ETF等方式进行投资。银在全球范围内的供应链、市场流通及投资需求都在不断变化，因此投资者应密切关注相关市场动态及分析报告。
