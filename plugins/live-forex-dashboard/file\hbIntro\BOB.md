玻利维亚诺（Boliviano，缩写为BOB）是玻利维亚的法定货币，分为100个分币（centavos）。该货币于1987年正式发行，取代了之前的货币单位“玻利维亚元”，并以“玻利维亚诺”的名字代替。

玻利维亚诺的发行和管理由玻利维亚中央银行（Banco Central de Bolivia）负责。发行的纸币有多个面值，通常包括10、20、50、100和200玻利维亚诺，硬币则有0.10、0.20、0.50、1、2、5及10玻利维亚诺等面值。

玻利维亚诺的汇率会随着市场供需变化而波动，通常与美元等其他主要货币的汇率密切相关。在国际市场上，玻利维亚诺的流通范围较小，主要在玻利维亚国内使用。

对经济影响方面，玻利维亚诺的汇率波动可以影响进口和出口的成本，进而影响国家的贸易平衡和经济稳定性。金融机构和投资者需要关注该货币的国际汇率及其国内通货膨胀率，以便做出相应的经济决策。
