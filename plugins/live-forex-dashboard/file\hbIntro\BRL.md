巴西雷亚尔（Brazilian Real，货币代码：BRL）是巴西的法定货币。自1994年7月1日起启用，取代原有的克鲁扎多（Cruzeiro）。雷亚尔的分币为分雷亚尔（Centavo），1雷亚尔等于100分雷亚尔。

雷亚尔的符号为“R$”，在国际金融市场上，雷亚尔的汇率受多种因素影响，包括巴西的经济表现、通货膨胀率、利率水平及国际市场对巴西商品的需求等。巴西中央银行负责雷亚尔的发行及管理。

雷亚尔的纸币面额包括2、5、10、20、50和100雷亚尔，硬币面额包括0.01、0.05、0.10、0.25、0.50和1雷亚尔。

自其引入以来，雷亚尔经历了一系列的汇率波动，反映了巴西经济的变化。作为新兴市场货币，雷亚尔在外汇市场上也受到投资者及投机者的关注。
