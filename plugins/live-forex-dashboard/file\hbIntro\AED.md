阿联酋迪拉姆（United Arab Emirates Dirham，简称AED）是阿拉伯联合酋长国的官方货币。迪拉姆的ISO 4217代码为AED，其符号为"د.إ"或"DH"。一迪拉姆被细分为100菲尔斯（Fils）。

阿联酋迪拉姆于1973年首次发行，取代了之前使用的巴林第纳尔和其他货币。其名字“迪拉姆”源自于古希腊的“德拉克马”（Drachma）。在国际外汇市场中，迪拉姆通常与美元挂钩，汇率为1 USD ≈ 3.67 AED，为此提供了相对稳定的货币环境。

迪拉姆的纸币面额包括5、10、20、50、100、200、500和1000迪拉姆，硬币则有1、5、10、25、50菲尔斯和1迪拉姆。阿联酋中央银行负责迪拉姆的发行与管理。

在国际上，阿联酋迪拉姆被广泛接受，尤其是在中东地区，是贸易和旅行中常用的货币。该货币的稳定性有效支持了阿联酋的经济发展，尤其是在旅游、金融和房地产领域。
