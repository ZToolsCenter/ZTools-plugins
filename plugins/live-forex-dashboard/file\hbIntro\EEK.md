爱沙尼亚克朗（Estonian Kroon，货币代码：EEK）是爱沙尼亚在2002年1月1日之前使用的官方货币。根据国际标准化组织（ISO）代码，爱沙尼亚克朗被标识为EEK。

爱沙尼亚克朗的历史可以追溯到1918年，当时爱沙尼亚独立后发行了第一版克朗。1992年，在恢复独立后，爱沙尼亚重新引入克朗作为法定货币。克朗与欧元之间的汇率固定在1欧元=15.6466克朗。

在爱沙尼亚于2011年1月1日正式采用欧元（货币代码：EUR）作为其法定货币后，克朗不再流通，其兑换期限已于2017年结束，至此，所有爱沙尼亚克朗的面额均已停止使用。此后，任何持有克朗的个人或机构可以通过国家银行进行兑换。

爱沙尼亚克朗的面值曾包括纸币和硬币，包括1、5、10、50克朗的硬币以及10、25、50、100、500克朗的纸币。由于其历史与爱沙尼亚财政政策的演变有密切联系，克朗的引入与否决也反映了国家经济不断发展的轨迹。
