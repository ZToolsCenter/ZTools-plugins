美元（USD）是美国的法定货币，通常被称为“美金”。美元以分（cent）为单位，构成体系为1美元等于100分。美元是全球最重要的储备货币之一，同时也是国际贸易和金融交易中最广泛使用的货币。

美元的发行由美国财政部的“铸币局”和联邦储备系统管理。美元在国际市场上作为主要的计价和结算货币，广泛用于国际贸易合同、外汇交易以及商品定价，尤其是在石油、黄金等大宗商品交易中。

美元的符号为“$”，在国际标准ISO 4217中，其代码为“USD”。美元在全球外汇市场的流通量巨大，流动性强，且美元汇率受到多种因素的影响，包括美国的经济数据、利率变化、地缘政治事件等。

此外，美元也存在多种形式，包括纸币和硬币。美国的纸币有多个面值，常见的有1美元、5美元、10美元、20美元、50美元和100美元。硬币则有1美分、5美分、10美分、25美分、50美分和1美元等面值。

美元作为一个重要的全球货币，其稳定性和可信赖性使其成为国际投资者与资金流动的首选工具。
