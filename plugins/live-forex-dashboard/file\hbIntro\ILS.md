以色列谢克尔（Israeli New Shekel，代码：ILS）是以色列的法定货币。谢克尔于1985年作为新货币替代老谢克尔，旨在应对国内的高通货膨胀。新谢克尔的符号为 ₪，之前的旧谢克尔已不再使用。

新谢克尔的发行和管理由以色列银行（Bank of Israel）负责。以色列谢克尔分为小额单位，1谢克尔等于100个阿戈拉（agorot）。流通中的纸币面额包括20、50、100和200新谢克尔，硬币面额则有1阿戈拉、5阿戈拉、10阿戈拉、0.5谢克尔、1谢克尔、2谢克尔和5谢克尔。

以色列谢克尔在国际外汇市场上可自由交易，并且在中东地区的经济交易中逐渐增强其影响力。它也是一些国际机构的储备货币，反映以色列经济的相对稳定性和发展潜力。近年来，谢克尔兑美元及其他主要货币的汇率受到多种因素的影响，包括以色列的经济增长、政策变化以及全球市场的动荡。

需要注意的是，以色列谢克尔的货币政策旨在维护稳定的经济增长和价格稳定，以应对国内外经济环境的变化。
