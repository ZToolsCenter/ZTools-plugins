捷克克朗（Czech koruna，符号为 Kč，国际标准化组织代码 CZK）是捷克共和国的法定货币。捷克克朗于1993年1月1日正式启用，随着捷克共和国独立于斯洛伐克而成为国家的货币替代品，之前与斯洛伐克共同使用的是捷克斯洛伐克克朗。

捷克克朗的基本单位为1克朗，进一步划分为100哈洛（haléř）。然而，哈洛硬币已经在2011年停止发行，几乎不再使用。

捷克克朗由捷克国家银行（Česká národní banka, ČNB）负责发行和管理。该银行实施货币政策以维持价格稳定，控制通货膨胀，以及作为国家的宏观经济调控工具。

在国际外汇市场上，捷克克朗相对其他主要货币如欧元、美元等的汇率会受到多种因素影响，包括经济指标、政治稳定性和市场情绪等。由于捷克尚未加入欧元区，克朗的稳定性和汇率波动在一定程度上取决于捷克的经济表现及外部经济环境。

捷克克朗在国内和国际交易中广泛使用，尤其是在捷克共和国境内的商品和服务交易中，在欧洲中部及东欧国家的经济交流中也有所体现。
