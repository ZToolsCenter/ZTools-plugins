苏丹镑（Sudanese Pound，ISO 4217代码为SDG）是苏丹的官方货币。自2011年南苏丹独立以来，旧苏丹镑（SDP）被替代，正式引入新的苏丹镑。 

1. **历史背景**：在2011年之前，苏丹镑的变化经历了多次货币重组。2011年6月，新的苏丹镑被引入，为1新苏丹镑等于100旧苏丹镑。

2. **货币单位**：苏丹镑的最小单位为“皮阿斯特”（piastre），1苏丹镑等于100皮阿斯特。

3. **纸币与硬币**：苏丹央行发行的纸币面额包括1、5、10、20、50和100苏丹镑。硬币面额较小，通常为1、5、10、25及50皮阿斯特。

4. **汇率**：苏丹镑的汇率波动较大，受到国内经济状况、外汇储备以及国际市场动态的影响。建议通过正规渠道查看实时汇率信息。

5. **经济影响**：苏丹长期面临经济挑战，包括通货膨胀、货币贬值以及政治不稳定。这些因素对苏丹镑的购买力和国际信誉产生了深远影响。

6. **货币政策**：苏丹央行负责货币政策的制定与实施，其目标包括维持价格稳定、促进经济增长及保障金融系统的稳定。
