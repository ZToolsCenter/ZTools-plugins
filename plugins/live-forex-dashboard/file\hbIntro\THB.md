泰铢（Thai Baht，符号：฿，ISO代码：THB）是泰王国的官方货币。泰铢的分为100个萨滕（satang），其中1泰铢等于100萨滕。泰铢的发行和管理由泰国中央银行（Bank of Thailand）负责。

泰铢的纸币面额包括20、50、100、500和1000泰铢，硬币面额则包括1、2、5和10泰铢以及1、5、10萨滕。泰铢的颜色、图案和质量设计反映了泰国的文化和历史。

泰铢在国际外汇市场上被交易，同时也作为亚太地区的一种主要货币。汇率会受到多种因素的影响，包括经济增长率、贸易平衡、通货膨胀率以及泰国的政治稳定性。

投资者和旅行者在进行汇兑时需关注汇率变动以及相关的交易费用，了解泰铢的使用情况和法律规定是进行合法交易的重要前提。此外，注意泰国的货币限制法规对大额现金交易的规范。
