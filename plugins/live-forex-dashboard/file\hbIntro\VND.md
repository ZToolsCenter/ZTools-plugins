越南盾（Vietnamese Dong，符号：₫，国际标准代码：VND）是越南的法定货币。越南央行即越南国家银行负责其发行和管理。越南盾于3万多年前由金属制成的币和后来的纸币演变而成，随着经济的发展，越南盾的种类不断增多。

越南盾的汇率受到多重因素的影响，包括经济增长、通货膨胀、国际投资流动等。近年来，越南的外汇市场相对稳定，但汇率波动仍然存在。越南盾存在多个面额的纸币和硬币，纸币分为1,000、2,000、5,000、10,000、20,000、50,000、100,000、200,000和500,000盾等面额，硬币较少流通。

在国际贸易中，越南盾并未广泛使用，交易大多数以美元或其他主要货币进行。越南的货币政策旨在保持币值的稳定，以促进经济增长和吸引外资。同时，越南政府致力于深化货币市场改革和金融体系建设，以提高越南盾的国际竞争力。
