爱尔兰镑（Irish Pound）是爱尔兰在2002年之前使用的货币单位，简称IES。该币种于1971年到2002年期间作为爱尔兰的法定货币，其后被欧元（EUR）取代。爱尔兰镑在1970年代进行过几次贬值，汇率波动较大。2002年1月1日起，爱尔兰正式采用欧元，爱尔兰镑的所有面值货币在此期间被逐步替换并于2002年2月28日完全停止流通。

爱尔兰镑的符号为£，与英国镑符号相同，但其设计和印刷样式有所不同。该币种的汇率与其他货币挂钩，例如美元和英镑。随着欧元的实施，爱尔兰镑的官方兑换汇率被确立为1欧元=0.787564爱尔兰镑。在停止流通后，目前爱尔兰镑仍可在特定条件下进行兑换，具体时间和兑换方式需向相关金融机构查询。
