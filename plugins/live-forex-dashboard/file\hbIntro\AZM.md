阿塞拜疆马纳特（Azerbaijani Manat，AZN）是阿塞拜疆的法定货币。马纳特的首次引入是在1992年，取代了苏联卢布。马纳特经历了多次货币改革和重估，以应对经济状况变化。

值得注意的是，"废弃"的标记可能指代的是某个特定时期后的货币状况。根据历史信息，阿塞拜疆曾在2006年进行了货币重置，旧马纳特（旧AZM）被新马纳特（AZN）所取代，兑换比例为1新马纳特等于5000旧马纳特。因此，使用过程中需关注具体的货币版本及其有效性。

目前，马纳特的发行和管理由阿塞拜疆中央银行负责。马纳特在阿塞拜疆境内被广泛接受，并在全国范围内的金融交易中使用。兑换汇率通常受到市场供求、国家经济政策及国际经济形势的影响。
