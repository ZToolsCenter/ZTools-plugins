牙买加元（Jamaican Dollar，货币代码：JMD）是牙买加的法定货币，分为100个分币（Cent）。它由牙买加中央银行发行和管理。

牙买加元的历史可以追溯到1969年，取代了之前的牙买加镑（Jamaican Pound）。牙买加元的符号为“$”，在国际上通常以“J$”表示以区分其他国家的美元。

货币的汇率受多种经济因素的影响，包括通货膨胀率、利率、经济增长以及国际市场的需求与供给。目前，牙买加元为浮动汇率制，其汇率会随着市场条件的变化而波动。

牙买加元的钞票面额包括100、200、500和1000元，硬币则包括1、5、10、20和50分及1、5元等面额。钞票和硬币的设计包含了国家的文化、历史和重要人物，同时采用了防伪技术以提高货币的安全性。

整体上，牙买加元在国际外汇市场上的使用较为有限，主要在牙买加境内使用。对于外汇交易或国际旅游，建议在使用前了解最新汇率及相关兑换政策。
