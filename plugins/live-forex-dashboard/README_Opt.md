
# 货币汇率换算器

## 概述
利用最新的实时汇率，本换算器能够精确计算不同货币之间的金额转换。用户可以在插件中自由添加多种货币进行批量转换，同时支持一键排序和对比，让您对货币价值一目了然。此外，您还可以通过本工具深入了解各种货币的相关知识，并优先从本地缓存读取已保存内容。

## 使用指南
1. 插件默认以 **人民币`CNY`** 作为基础货币。
2. 通过【**选择货币**】下拉菜单搜索并选择您需要计算的货币，点击即可添加至换算表格。
3. 支持一键添加所有货币至换算表格，或一键清除所有货币，恢复至初始状态。
4. 切换【**已废弃**】货币选项，可将已废弃货币纳入计算范围（默认情况下不显示）。
5. 调整货币显示的小数位数，范围从0到20位。
6. 通过拖拽操作，自定义货币在换算表格中的排序。
7. 点击【**实时汇率**】【**折算金额**】列标题，可切换该列的排序方式。
8. 点击【**折算金额**】单元格，输入或修改换算金额，其他货币将根据所选货币的汇率进行相应折算。
9. 选中的货币将替代顶部的固定货币，同时固定货币的【**折算金额**】单元格 也可以进行自定义修改。
10. 双击【**移除**】按钮，可取消选定货币的换算。
11. 点击右上角的【**汇率刷新**】按钮，获取最新的汇率数据，刷新后自动更新换算结果。
12. 点击【**国家名称**】单元格，可弹出对应货币的详细介绍（货币知识来源于chatGPT）。
13. 按下`F3`或`Ctrl+F`快捷键，快速定位到【**货币选中**】下拉框，输入货币名称或代码进行搜索，使用`↑`/`↓`方向键选择并回车以添加至兑换表格。
