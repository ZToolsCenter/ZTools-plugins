朝鲜元（North Korean Won）是朝鲜民主主义人民共和国的法定货币，其符号为KPW，货币代码为KPW。朝鲜元的发行和管理由朝鲜中央银行负责。

朝鲜元首次发行于1947年，主要分为纸币和硬币两种形式。纸币面额包括1元、5元、10元、50元、100元等，而硬币则相对较少，主要有1元和5元等面额。

朝鲜元的汇率在国际市场上并不透明，受到国家政策和外汇管制的严格限制。在朝鲜的经济体制中，朝鲜元主要用于国内贸易和政府用途，而外国货币在某些情况下也被接受和流通，特别是在特定的经济区或面向外国游客的场所。

需要注意的是，朝鲜元的实际购买力和汇率可能与官方公布的价格存在较大差异，国内的市场价格通常受到多种经济因素的影响，包括限制、黑市交易等。
