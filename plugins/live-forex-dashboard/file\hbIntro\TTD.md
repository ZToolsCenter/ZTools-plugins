特立尼达元（Trinidad and Tobago Dollar，简称TTD）是特立尼达和多巴哥的法定货币。其符号为TT$，通常用以区分其他国家的元（如加拿大元、美金等）。特立尼达元由特立尼达和多巴哥中央银行发行，分为100分（cents）。

汇率：特立尼达元与其他主要货币的汇率会波动，受经济状况、政策调整及国际市场影响。请参考最新汇率以获取实时信息。

纸币和硬币：特立尼达元的纸币面额包括1、5、10、20、50和100元。硬币面额包括1、5、10、25分和1、2、5元。

使用场景：特立尼达元广泛用于国内交易，适用于日常消费、企业活动和投资。重要的经济部门包括石油和天然气、旅游及制造业。

经济政策：特立尼达和多巴哥中央银行负责货币政策和汇率稳定，旨在促进经济增长及保持通货膨胀在合理范围内。

在国际贸易和外汇市场中，特立尼达元的流通性相对较低，但在加勒比地区具有一定的影响力。
