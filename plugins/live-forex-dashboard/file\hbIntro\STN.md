圣多美多布拉（Dobra de São Tomé）是圣多美和普林西比的官方货币，简称为STN。该货币的分币为分多布拉（cêntimos de dobra），其中1多布拉等于100分多布拉。

圣多美和普林西比是位于非洲西部的岛国，经济主要依赖农业和石油产业。多布拉自1977年起成为该国的法定货币，取代了此前使用的葡萄牙埃斯库多。在汇率方面，多布拉对其他主要货币，如美元和欧元，存在波动。该国央行负责货币政策及货币发行。

当前，市场上多布拉的流通主要由纸币和硬币组成，纸币的面值包括1、5、10、20、50和100多布拉，而硬币则主要有1、5、10、20和50分多布拉的面值。由于该国相对较小的经济规模，多布拉在国际市场上的流通性有限。

投资者在考虑与圣多美多布拉的交易时，需关注该国的经济状况、政治稳定性，以及国际市场对其货币价值的影响因素。
