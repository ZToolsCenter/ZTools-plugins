赞比亚克瓦查（Zambian Kwacha，符号：ZMW）是赞比亚的官方货币，分为100个戈比（Ngwee）。克瓦查于1968年首次发行，取代了以前的赞比亚镑。该货币的名称源于本地方言“kwacha”，意为“日出”，象征着新开始。

克瓦查的发行和管理由赞比亚中央银行（Bank of Zambia）负责。货币的流通包括纸币和硬币，纸币的面额有2、5、10、20、50、100、200克瓦查，硬币则有1、5、10、20、50戈比及1、2、5、10克瓦查。

自2011年起，克瓦查的汇率经历了显著波动，受到外部经济因素（如铜价和国际贸易状况）影响。作为一个以铜矿业为主的国家，赞比亚的货币稳定性与全球市场的变化密切相关。

目前，赞比亚克瓦查在国际外汇市场上的地位相对较低，主要在地区交易中使用。针对投资者而言，了解克瓦查及其汇率变动对于评估赞比亚的经济环境及投资机会至关重要。
