卢森堡法郎（Luxembourg Franc）是卢森堡的前国家货币，符号为LUF。该货币在平欧元之前于1980年被引入并用于卢森堡的国内交易。卢森堡法郎于1999年被欧元（EUR）取代，作为卢森堡的法定货币。

在欧元引入之前，卢森堡法郎的价值与比利时法郎（BEF）挂钩，因为两国共享了货币政策。这使得卢森堡法郎在国际市场上相对稳定。

自2002年起，卢森堡法郎正式停止流通，所有法郎票据和硬币的兑换业务在全球范围内已终止。根据欧洲中央银行的规定，卢森堡法郎的纸币和硬币的兑换在法律上不再有效，尽管在某些情况下可能仍可以在特定机构进行兑换。

现行货币为欧元，卢森堡法郎不再用于任何金融交易，且其历史亦主要作为经济研究和历史分析的对象。
