马耳他里拉（Maltese Lira）是马耳他的法定货币，直到2008年被欧元取代。马耳他里拉的ISO 4217代码为MTL，其符号通常表示为₤或Lm。马耳他里拉分为100分（cents），并在其使用期间发行了多种面额的纸币和硬币。

马耳他里拉的历史可以追溯到19世纪30年代，当时马耳他是英国的殖民地，这种货币逐渐取代了之前的各种地方货币。里拉的设计中常包含了马耳他的国家象征、历史人物及标志性建筑。

2005年，马耳他决定加入欧元区，最终于2008年1月1日起正式停止使用里拉，过渡成为欧元。在过渡期间，马耳他公众和商户必须接受两种货币，里拉和欧元，有一定的换算比率。

在此后，马耳他里拉不再流通，所有未使用的货币将改变为欧元。该货币目前已经被废弃，现阶段无法再在市场上交易和兑换。有关马耳他里拉的任何实物货币仍可能在收藏市场中存在，但不具备法定货币的流通和支付功能。
