巴布亚新几内亚基那（Kina）是巴布亚新几内亚的官方货币。其符号为“K”，ISO 4217代码为“PGK”。基那的名称源于当地一种盐塘贝壳的名称，具有本地文化的象征意义。

基那主要分为纸币和硬币两种形式。纸币分为多个面额，包括2、5、10、20、50和100基那。硬币则包括1、2、5、10、20、50分以及1和2基那的面额。基那于1975年首次发行，以替代原来的澳大利亚元，成为独立后巴布亚新几内亚的法定货币。

基那的汇率受多种因素影响，包括经济数据、政治稳定性、国际商品价格（尤其是矿产和农业产品）以及美元等主要货币的走势。作为发展中经济体，巴布亚新几内亚的金融体系与货币政策面临特定的挑战和机遇。
