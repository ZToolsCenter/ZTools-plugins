加纳塞地（Ghanaian Cedi），货币代码是GHS，是加纳的法定货币。塞地在2023年进行过两次主要的货币重定，以应对通货膨胀和经济挑战。

1. **历史背景**：最初的塞地于1965年首次引入，作为替代旧的加纳镑。2007年，第一代塞地被重新评估，1新塞地等于10000旧塞地。新塞地的符号为₵。

2. **发行机构**：加纳中央银行（Bank of Ghana）是加纳塞地的唯一发行机构，负责货币政策的制定和实施。

3. **货币结构**：加纳塞地的纸币面额有1、2、5、10、20、50和100塞地，硬币面额包括1和5戈呼（Ghanaian Gonna）以及相应的小面额塞地硬币。

4. **汇率**：加纳塞地的价值与其他主要货币（如美元、欧元等）存在波动，汇率受多种因素影响，包括经济状况、贸易平衡和市场供求。

5. **使用情况**：在加纳，塞地被广泛接受用于商业交易，银行服务以及国内和国际的金融交易。

6. **经济影响**：加纳政府和中央银行采取了多项措施来稳定塞地，力求提高其国际信用和经济稳定性，并促进外资流入。

7. **金融科技**：近年来，加纳在数字支付和移动支付领域取得了显著进展，促进了塞地的使用和流通。
