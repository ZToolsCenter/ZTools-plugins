土耳其里拉（Turkish Lira, TRY）是土耳其的法定货币。历史上，里拉的汇率经历了多次波动和重估，现在使用的是新土耳其里拉（Yeni Türk Lirası），其主要是为了抑制通货膨胀及改善货币稳定性。

里拉符号为₺，ISO 4217代码为TRY。土耳其里拉分为100库鲁ş（Kuruş）。当前发行的纸币有5、10、20、50、100和200里拉，硬币包括1里拉，以及更小面额的硬币如1、5、10、25、50库鲁ş和1库鲁ş。

土耳其中央银行（Türkiye Cumhuriyet Merkez Bankası）负责里拉的发行和货币政策。自2000年代以来，土耳其里拉经历了相对较大的通货膨胀，影响了其国际汇率，并在全球经济波动时表现出较高的波动性。

在外汇市场上，土耳其里拉通常被视为新兴市场货币，其价值受到国内经济政策、国际贸易条件、地缘政治因素以及市场投资者信心的影响。投资者在考虑交易或投资土耳其资产时，必须对里拉的兑换率持谨慎态度。
