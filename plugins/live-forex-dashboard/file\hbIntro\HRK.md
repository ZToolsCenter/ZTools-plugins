克罗地亚库纳（Croatian Kuna，简称HRK）是克罗地亚在1994年至2023年间的法定货币。其名字来源于一种小动物“库纳”，这是一种在克罗地亚及其他地区常见的貂类动物。库纳的符号为“kuna”，且通常以“HRK”作为其国际标准代码。

克罗地亚库纳分为100个利帕（lipa），后者是其辅币种。自1994年起，库纳替代了原有的克罗地亚第纳尔（Croatian Dinar），成为新的法定货币。在其流通期间，克罗地亚库纳经历了多次货币改革，并且与欧元保持了一定的汇率稳定。

2023年，克罗地亚正式采纳欧元，成为欧元区的成员国，因此库纳作为法定货币被废弃，所有交易和支付转向了欧元。在转换期间，克罗地亚政府实施了较为宽松的货币兑换政策，以确保居民和企事业单位顺利过渡至新货币体系。在此之后，库纳不再被广泛使用，其流通也逐渐结束。
