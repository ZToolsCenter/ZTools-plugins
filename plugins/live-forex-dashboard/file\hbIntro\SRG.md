苏里南古尔德（Surinamese Guilder）是曾经用于苏里南的货币单位，其国际货币代码为SRG。该货币在1986年被苏里南元（Surinamese Dollar, SRD）所取代，后者是苏里南目前的法定货币。

苏里南古尔德的历史可以追溯到19世纪，其最早的版本与荷兰的荷兰古尔德有密切关系。在1980年代，由于经济情况和政治局势的变化，苏里南古尔德经历了严重的贬值，导致了货币体系的动荡。

1990年代后，苏里南元的引入旨在稳定经济并促进国际贸易。然而，苏里南古尔德在历史上仍然具有重要的文化和经济意义，现已成为收藏爱好者和货币历史研究者关注的对象。当前，苏里南古尔德不再流通，其兑换也已停止。
