叙利亚镑（Syrian Pound，货币代码：SYP）是叙利亚的法定货币。发行和管理叙利亚镑的机构为叙利亚中央银行。叙利亚镑分为100个松（qirsh），但松在日常交易中不再使用。

叙利亚镑的历史可以追溯到其在20世纪初期的引入，作为对抗奥斯曼帝国货币的一种手段。自叙利亚独立以来，叙利亚镑经历了多次贬值，受诸多因素的影响，包括政治动荡、经济制裁和内战等。

叙利亚镑当前的币值和汇率受到国际市场和当地经济状况的影响，通常波动较大。由于叙利亚的经济形势复杂，叙利亚镑在近些年里贬值显著，汇率波动常常反映出国家经济健康状况的变化。

在流通方面，叙利亚镑的纸币有多种面值，包括但不限于1、5、10、20、50、100、200和500镑。硬币则主要为1、2、5、10和25镑。

总体而言，叙利亚镑作为一个国家的货币，不仅是经济交易的工具，也是揭示该国经济形势和社会稳定的重要标志。
