保加利亚列弗（Bulgarian Lev，ISO 4217代码：BGN）是保加利亚的法定货币。1列弗分为100斯特唐卡（stotinki）。列弗的名称源于拉丁文的“levis”，意为“轻的”。

保加利亚列弗于1880年首次引入，经历了多次改革和重估。现代列弗的引入是自1999年7月1日，由于经济改革和稳定的需要，旧列弗被新的列弗替代，其汇率为1新列弗等于1000旧列弗。

保加利亚列弗受到保加利亚国家银行的监管，采用浮动汇率制并与欧元实行钉住汇率政策，为未来加入欧元区做准备。该货币在国际外汇市场上交易，利率、经济状况及政治稳定性等因素均可能对其汇率产生影响。

在国内，列弗以纸币和硬币两种形式流通，纸币面额包括2、5、10、20、50、100和200列弗，硬币则有1、2、5、10、20和50斯特唐卡及1、2、5列弗的面额。

保加利亚列弗的国际汇率波动，根据市场需求、经济指标和华尔街市场等多种因素而变化。获取最新汇率信息及其他相关金融数据可参考专业金融服务平台或保加利亚国家银行的官方网站。
