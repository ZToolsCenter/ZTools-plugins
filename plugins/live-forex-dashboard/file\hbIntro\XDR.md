特别提款权（Special Drawing Rights，简称SDR）是国际货币基金组织（IMF）创设的一种国际储备资产，它并非一种货币，而是一种补充成员国官方储备的资产。特别提款权的分配基于成员国在IMF中的份额，目的是为了增强成员国的流动性，帮助其应对国际支付困难。

特别提款权的价值基于一篮子主要货币的兑换率，当前包括美元、欧元、人民币、日元和英镑。这一篮子的组成和权重会定期调整以反映全球经济的发展。

特别提款权可用于IMF成员国之间的交换，成员国可以将其SDR出售给其他国家以获得硬通货，或将其用于支付IMF的费用。此外，SDR还可用于IMF的成员国之间的交易和资金汇总，是一种国际援助和流动性机制。

值得注意的是，特别提款权的分配并不等同于外汇收入，且使用特别提款权不需支付利息，但将来使用时需要按IMF的规则归还相应的金额或其它货币。特别提款权的发行通常发生在全球流动性不足的情况下，以便提供必要的资金支持。
