新台币（新台湾元，货币符号：NT$，国际标准代码：TWD）是中华民国（台湾）官方通用的法定货币。新台币于1949年推出，取代了旧台币，旨在稳定经济和控制通货膨胀。

新台币的发行和管理由中央银行负责。纸币的面额有100元、200元、500元、1000元和2000元，硬币的面额有1元、5元、10元、20元、50元、100元和500元。

新台币在国际外汇市场上具有一定的流通性，其汇率相对于其他主要货币（如美元、欧元、日元等）会随着市场供需关系而波动。新台币的汇率政策为浮动汇率制，因而受到全球经济动态、贸易状况及市场预期的影响。

台湾政府在货币政策上采取相对宽松的立场，通过利率调整和外汇干预等手段，以保持经济稳定增长和防止过度波动。

总之，新台币是台湾经济的重要组成部分，其稳定性和流通性对于维持经济健康发展具有重要意义。
