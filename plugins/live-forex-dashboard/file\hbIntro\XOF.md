CFA法郎是由非洲多个国家使用的货币，分为两种不同的版本：西非CFA法郎（XOF）和中非CFA法郎（XAF）。这两种货币虽然名称相同，但其使用地区和汇率机制有所不同。

西非CFA法郎（XOF）是由西非经济货币联盟（UEMOA）成员国使用，包括贝尔基、布基纳法索、科特迪瓦、几内亚比绍、马里、尼日尔、塞内加尔和托戈。该货币的发行机构为西非中央银行（BCEAO）。

中非CFA法郎（XAF）则由中非经济和货币共同体（CEMAC）成员国使用，涵盖喀麦隆、中非共和国、乍得、刚果共和国、刚果民主共和国和赤道几内亚。中非CFA法郎的发行机构为中非国家银行（BEAC）。

这两种CFA法郎都以欧元为固定汇率基础进行锚定，汇率机制规定1欧元等于655.957法郎，这一机制帮助这两种货币保持相对稳定，促进了区域经济的一体化。

需要注意的是，尽管CFA法郎在不同地区被广泛接受，但它并不属于所使用国家的主权货币，因此某些国家可能对其使用和流通持有不同的看法和政策。
