荷兰盾（Dutch Guilder），通常指荷兰在2002年前使用的货币单位，其国际标准ISO代码为NLG。荷兰盾于1816年正式成为荷兰的法定货币，并作为荷兰及其殖民地和一些海外领土的官方货币长期流通。

在其历史过程中，荷兰盾经历了多次的货币改革和版本更替，用以适应经济和金融发展的需求。到20世纪中期，荷兰盾的兑换率经历了不同的变动，并在1980年代和1990年代初期受到通货膨胀等经济因素的影响。

随着欧元的引入，荷兰盾在2002年被欧元（EUR）取代，成为不再流通的废弃货币。欧元的引入旨在实现更深层次的欧洲经济一体化，促进成员国间的贸易及资本流动。

虽然荷兰盾已不再作为流通货币，但在某些场合，仍可能遇到以该货币计价的历史遗留问题和收藏市场的需求。根据相关规定，荷兰盾的纸币和硬币在央行仍可兑换成为欧元，但这一服务自2014年5月后已停止，民众需要在特定时间内完成兑换。
