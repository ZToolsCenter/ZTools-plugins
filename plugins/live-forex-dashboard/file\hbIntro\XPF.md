CFP法郎（CFP Franc，法语为Franc Pacifique）是一种用于法属波利尼西亚、新喀里多尼亚和法属南部和南极领土的货币。其官方代码为XPF，且与欧元（EUR）和其他货币不同，CFP法郎是由法郎的硬币和银行票据组成。CFP法郎与欧元的汇率固定为1欧元=119.33 CFP法郎。

CFP法郎的主权发行机构是法属南方和南极领土的中央银行，其货币政策受到法国国家银行的监管。CFP法郎是一个非独立货币，在时值波动性较小，旨在为当地经济提供相对稳定的货币环境。由于其固定汇率制度，CFP法郎的通货膨胀率通常较低。

CFP法郎分为硬币和纸币两种形式。硬币有1、2、5、10、20、50、100 和 500 法郎，纸币有500、1000、5000 和 10000 法郎。CFP法郎的使用主要限于上述地区，且在全球交易中不被广泛接受。
