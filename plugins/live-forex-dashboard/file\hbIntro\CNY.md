中国人民币（CNY）是中华人民共和国的法定货币，主要由中国人民银行发行。人民币的符号为“¥”，其iso代码为CNY。人民币的单位包括元、角、分，1元等于10角，1角等于10分。

人民币的流通形式包括纸币和硬币，纸币面额有1元、5元、10元、20元、50元、100元等，而硬币面额有1分、2分、5分、1角、2角、5角、1元等。

人民币在国际金融市场上逐渐被广泛接受，并在2016年正式纳入国际货币基金组织的特别提款权（SDR）篮子，标志着其国际化程度的提高。人民币的汇率由市场供求关系决定，但中国人民银行会在必要时采取措施予以调控，以维护汇率稳定。

人民币的国际使用正在增加，尤其是在“一带一路”倡议下，越来越多的国家和地区开始接受人民币作为贸易结算货币。此外，中国政府也在推动人民币的跨境使用，促进人民币国际化进程。
