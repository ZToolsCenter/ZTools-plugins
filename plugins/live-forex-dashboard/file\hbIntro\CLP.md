智利比索（Chilean Peso，简称CLP）是智利的法定货币，其符号为“$”或“CLP”。智利比索的单位分为100分（centavos），通常以“¢”符号表示。智利比索在1975年取代了原先的智利货币“智利埃斯库多”，成为智利中央银行发行的主要货币。

智利比索的汇率受到多种因素的影响，包括经济指标、通货膨胀率、国际商品价格以及外部经济环境等。智利是一个以矿业为主的国家，尤其是铜的生产，这使得智利比索受到全球金属市场波动的影响。

智利比索在外汇市场上交易，投资者和贸易商可以通过主要金融机构和外汇交易平台进行买卖。从1999年至今，智利政府采取了一系列经济政策，努力促进宏观经济的稳定，从而在一定程度上保持了智利比索的稳定性。

对于持有智利比索的海外投资者而言，汇率波动可能影响其投资回报，因此在进行与智利相关的金融交易时，应时刻关注相关的经济和市场动态。
