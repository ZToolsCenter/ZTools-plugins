Bitcoin是一种去中心化的数字货币，首次于2009年由化名为中本聪的个人或团体引入。它基于区块链技术，这是一种分布式账本，可以在不依赖中央银行或单个管理机构的情况下记录交易。

主要特征包括：

1. **去中心化**：没有中央管理机构或金融机构控制，比特币网络由用户参与者共同维护。
   
2. **有限供给**：比特币总供应量被限制在2100万枚，预计将在2140年达到此上限。这一特性使其具备稀缺性。

3. **匿名性与透明性**：尽管交易在公共区块链上记录，但用户身份可以匿名。交易信息是透明的，接受者和发送者的地址可被任何人查看，但无法直接与个人身份关联。

4. **挖矿机制**：比特币通过一种称为“工作量证明”（Proof of Work）的算法进行挖矿。参与者通过解决复杂数学问题来验证交易并增加新区块。

5. **流通与交易**：比特币可以在各大交易所买卖，还可用于某些商家消费。其价格高度波动，受市场需求和供给、政策法规、技术发展等多重因素影响。

6. **安全性**：比特币交易通过加密技术确保安全，用户必须使用私钥来控制和转移其比特币。

比特币的使用和合法性在各国各地区存在不同的监管政策，投资者应谨慎评估相关风险。
