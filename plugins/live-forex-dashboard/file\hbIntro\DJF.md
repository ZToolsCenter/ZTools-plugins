吉布提法郎（DJF）是吉布提的官方货币，分为100个分。其货币符号为“Fdj”。吉布提法郎于1949年首次发行，曾与法国法郎挂钩，汇率为1吉布提法郎等于0.186法郎。1997年，吉布提法郎与美元形成了新的固定汇率关系，1美元约等于177.72吉布提法郎。

吉布提法郎由吉布提中央银行负责发行和管理，其流通及使用主要集中在国内的商业交易和财政活动。由于吉布提是一个相对小型的经济体，其货币流动性和国际接受度有限。由于区域经济背景与国际货币市场的变化，吉布提法郎的汇率相对波动较小，稳定性较强。

在国际外汇市场上，吉布提法郎通常不直接参与交易，更多地是通过多边贸易等形式与其他主要货币进行兑换。其使用范围主要限于吉布提境内，以及与吉布提的经济活动相关的区域贸易。
