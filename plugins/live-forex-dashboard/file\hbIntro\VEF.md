委内瑞拉玻利瓦尔（Bolívar）是委内瑞拉的官方货币。该币种历史悠久，经历了多次货币改革和价值崩溃。最初于1879年引入，以纪念南美独立战争领袖西蒙·玻利瓦尔。然而，受经济困境、高通胀和政策失误影响，玻利瓦尔的实际购买力大幅下降。

为应对极端通货膨胀，政府在2018年进行了货币重组，将原有的玻利瓦尔货币单位改为玻利瓦尔主权（Bolívar Soberano），并废弃了5个零，以此试图稳定经济。然而，该措施未能有效遏制通货膨胀，导致玻利瓦尔主权同样面临贬值压力。

截至2023年，委内瑞拉经济仍然受到高通胀、货币不稳定等问题困扰，市场上普遍使用美元等外币进行交易，玻利瓦尔逐渐被边缘化。政府对于货币政策的调整往往缺乏透明度，导致对市场信心不足。整体来看，委内瑞拉玻利瓦尔的经济现实及其废弃状态反映了该国面临的重大经济挑战。
