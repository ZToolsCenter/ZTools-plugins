赞比亚克瓦查（Zambian Kwacha，代码：ZMW）是赞比亚共和国的法定货币。克瓦查的名称源于当地语言中的“闪电”，反映了其文化背景。以下为克瓦查的详细信息：

1. **汇率**：克瓦查的汇率相对其他主要货币（如美元、欧元等）会有所波动，受到经济指标、政治稳定性及外部经济环境的影响。

2. **面额**：克瓦查目前发行有纸币和硬币两种形式。纸币面额包括2、5、10、20、50及100克瓦查，而硬币则包括1、5、10、50和100克瓦查。

3. **历史**：克瓦查于1968年正式推出，取代了赞比亚旧货币—赞比亚英镑（Zambian Pound）。克瓦查在经济历程中曾经历过多次贬值与重估，特别是在1985年进行了大规模重估，推出兑换新旧克瓦查的政策。

4. **中央银行**：赞比亚中央银行（Bank of Zambia）负责克瓦查的发行与管理，并且通过货币政策来控制通货膨胀和保持经济稳定。

5. **使用范围**：克瓦查主要在赞比亚国内使用，对于国际交易，通常需要转换为其他主要货币。外币交易受到一定的管制，建议在进行大额交易时咨询相关金融机构。

6. **经济影响**：克瓦查的价值受到赞比亚经济状况的直接影响，包括矿业、农业及旅游业等主要产业的表现。

此货币信息是以截至2023年10月的数据为基础，具体汇率及政策可能会因市场动态而有所变化。建议在进行实际交易前，查阅最新的汇率信息及相关政策。
