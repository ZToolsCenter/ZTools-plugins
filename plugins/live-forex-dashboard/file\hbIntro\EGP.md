埃及镑（Egyptian Pound，货币代码：EGP）是埃及的法定货币，分为100个皮阿斯特（Piastre）。埃及镑由埃及中央银行发行，其货币符号为£E或E£。 

埃及镑的历史可以追溯到19世纪，最初作为埃及的金属货币和银币流通。自此之后经历了多次货币改革和重估。当前的埃及镑自2003年起实施新的浮动汇率制度，此后汇兑率波动较大。

在国际货币市场上，埃及镑通常与其他主要货币（如美元、欧元）进行交易。埃及经济在2020年代面临多项挑战，包括通货膨胀、外汇储备压力及国际贸易波动，这些因素都对埃及镑的汇率产生了影响。

使用埃及镑的纸币面额包括1、5、10、20、50、100和200镑，硬币面额则通常为25和50皮阿斯特，以及1镑。当前币制上，100皮阿斯特相当于1镑。埃及镑的流通和使用受到埃及中央银行的严格监控与管理。
