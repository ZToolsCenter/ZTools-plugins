日元（Japanese Yen，货币符号：¥，ISO 4217 代码：JPY）是日本的官方货币。日元由日本银行（Bank of Japan）发行，是全球第三大交易量的货币，仅次于美元和欧元。自1871年正式发行以来，日元已成为国际金融市场中重要的储备货币之一。

日元的主要特点包括：

1. **货币形式**：日元以纸钞和硬币两种形式存在。纸钞有千元、五千元和一万元三种面值，硬币则有1元、5元、10元、50元、100元和500元几种面值。

2. **汇率**：日元的汇率通常相较于美元和欧元波动频繁，受多种因素影响，包括日本的经济数据、国际市场动态及地缘政治风险。

3. **利率政策**：日本银行通过调整利率和实施量化宽松政策来影响日元的价值，通常目的是促进经济增长和实现物价稳定。

4. **国际使用**：日元作为全球贸易及金融交易的主要货币之一，在外汇市场、国际投资及海外任意交易中广泛应用。

5. **货币安全性**：日元被认为是一种避险货币，在全球经济不确定性增加时，投资者往往会选择转换为日元以保值。

了解日元的基本特性，有助于评估它在国际交易及投资组合中的重要性。
