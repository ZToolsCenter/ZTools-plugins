巴林第纳尔（Bahraini Dinar，BHD）是巴林王国的官方货币。它的ISO 4217代码为BHD。巴林第纳尔最初在1965年推出，取代了之前的巴林镑。

巴林第纳尔的分为1000个哈拉尔（hilar），是中东地区价值较高的货币之一。根据目前的汇率，1巴林第纳尔约等于2.65美元，具体汇率会根据国际市场变化而波动。

巴林第纳尔的发行由巴林中央银行负责，该银行也负责制定货币政策和监管金融系统。巴林第纳尔通常在巴林及周边国家被广泛接受，且由于其稳定性，常被视为国际贸易和投资的一种安全选择。

在货币设计方面，巴林第纳尔的钞票上印有巴林的历史人物及重要文化遗产的图案。流通的钞票面值有1、5、10、20、50及100第纳尔，而硬币则包括0.5、1、5、10、25和50哈拉尔等不同面值。
