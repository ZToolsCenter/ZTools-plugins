约旦第纳尔（Jordanian Dinar，JOD）是约旦的法定货币，分为1000个菲尔斯。该货币的符号为JD，而货币代码为JOD。约旦第纳尔于1949年首次引入，取代了在英国托管时期使用的巴勒斯坦磅。

约旦第纳尔的汇率通常与美元挂钩，其汇率稳定，旨在维护国内经济的稳定性和吸引外资。中央银行负责约旦第纳尔的发行和管理，其主要职责包括货币政策的制定、金融系统的监管以及外汇储备的管理。

在国际市场上，约旦第纳尔被认为是相对稳定的货币，主要由于约旦的地理位置、经济状况以及与其他国家的贸易关系影响。尽管约旦面临一些经济挑战，包括失业率较高和公共债务水平增加，但约旦第纳尔的相对稳定性使其在地区内被广泛接受。
