港币（Hong Kong Dollar，简称HKD）是中华人民共和国香港特别行政区的法定货币，通常以符号“$”或“HK$”表示。港币分为100分，流通领域包括纸币和硬币。

**历史背景**  
港币的起源可以追溯到19世纪中期，最初作为银元的一种替代品。1972年，香港实行了与外汇挂钩的联系汇率制度，港币与美元之间的汇率被固定在7.8比1。

**发行机构**  
港币的发行由香港金融管理局（Hong Kong Monetary Authority, HKMA）负责，港币的纸币由多家授权银行发行，包括香港上海银行、国泰银行等。

**流通状态**  
港币在全球市场上广泛被接受，尤其是在与人民币的交流中扮演重要角色。它在国际货币市场上的流通性较高，通常被认为是一种安全稳定的货币。

**汇率**  
港币的汇率受多种因素影响，包括国际经济形势、利率水平及市场供需等。在计算汇率时，通常与美元、人民币等主要货币进行对比。

**使用领域**  
港币广泛应用于日常消费、商业交易以及金融投资等领域。香港的储蓄、投资和信贷产品大多数也以港币计价。

**金融工具**  
港币可用于外汇交易、金融衍生品、债券市场等，这使其在全球金融体系中占有一席之地。

总结而言，港币是香港经济体系中核心的货币，它不仅反映了香港的经济状态，也在国际金融体系中发挥着重要作用。
