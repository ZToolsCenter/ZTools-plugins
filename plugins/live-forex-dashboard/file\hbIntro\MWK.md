马拉维克瓦查（Malawi Kwacha，代码：MWK）是马拉维的法定货币。马拉维克瓦查的名称来源于当地一种传统的货币单位“kwacha”，在尺量价值上有特定的历史背景。

马拉维克瓦查于1971年首次发行，取代了以前的货币单位“马拉维英镑”。马拉维中央银行负责其发行和管理。货币的分单位为"戈比"（ngwee），1马拉维克瓦查等于100戈比。

马拉维克瓦查的汇率受到多种经济因素的影响，包括国内经济状况、通货膨胀率、国际贸易和外汇市场的波动。近年来，马拉维经济面临挑战，货币贬值加剧，影响了日常交易及外贸。

马拉维克瓦查以多种面值的纸币和硬币形式存在，常见的纸币面值有20、50、100、200、500及1000克瓦查等。硬币一般为1、2、5、10和20戈比。

在国际外汇市场上，马拉维克瓦查的流动性相对较低，主要在地方市场和邻近国家的交易中使用。
