土库曼斯坦马纳特（Turkmenistani Manat）是土库曼斯坦的官方货币，其货币符号为“M”或“ТМ”以土库曼斯坦语表示。该货币分为100个图曼（Tenge）。土库曼斯坦马纳特的国际货币代码为TMT。

土库曼斯坦马纳特经历了多次贬值和重估。1993年首次发行时，1马纳特等于1000苏曼（旧货币单位），在2009年，进行了货币改革，进行了重估，1马纳特兑换5000苏曼。到2023年，土库曼斯坦马克持续稳定在1美元兑约35马纳特左右的汇率。

该国中央银行负责发行和管理马纳特。土库曼斯坦马纳特的纸币现有1、5、10、20、50、100和500马纳特，硬币通常面额较小，包括1、2、5、10、20、50图曼。

土库曼斯坦的经济依赖于天然气和石油资源，货币政策受到国际能源市场波动的影响。外汇市场受到一定程度的管制，政府通过官方汇率和市场汇率进行调节。
