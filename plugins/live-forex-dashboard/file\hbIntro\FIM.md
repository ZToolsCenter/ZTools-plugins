芬兰马克（Finnish Markka）是芬兰的前国家货币，国际代码为FIM。在2002年，芬兰马克正式被欧元（EUR）取代，标志着芬兰加入了欧元区。芬兰马克的使用历史可以追溯到1860年，当时为芬兰大公国的货币。

芬兰马克的纸币和硬币有多个面额，纸币面额包括1、5、10、20、50、100、200和500马克，硬币面额包括1、2、5马克以及10、20、50芬兰芬尼（芬兰马克的分币）。在流通的早期阶段，芬兰马克与其他货币如俄国卢布等有过兑换，但随着全球经济的发展和欧盟的货币统一，芬兰选择采用欧元。

虽然芬兰马克已经不再作为法定货币流通，但在某些情况下，历史学家和收藏家仍对其产生兴趣，并有足够的收藏价值。一般而言，芬兰马克在所有的金融交易体系中已无实际影响力，且相关的兑换也已不再可行。最终，芬兰中央银行于2016年停止了芬兰马克的所有交易活动和兑换服务。
