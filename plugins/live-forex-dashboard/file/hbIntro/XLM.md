Stellar Lumen (XLM) 是一种数字货币，旨在促进跨境支付和资金转移的效率。它是 Stellar 协议的原生代币，Stellar 是一个去中心化的开放网络，支持各种货币进行快速而便宜的交易。

Stellar 的主要特点包括：

1. **快速交易**：Stellar 网络的交易确认时间通常在 3 到 5 秒之间，这相比于传统银行系统显著提升了交易速度。

2. **低费用**：交易费用非常低，通常在千分之一 XLM 以下，这使得小额交易也能具备经济性。

3. **去中心化**：Stellar 协议是开源的，由全球社区持续改进，旨在提升金融服务的可达性。

4. **跨境支付**：Stellar 允许用户在不同货币之间无缝转移资产，解决了传统金融系统中的高昂费用和处理时间问题。

5. **支持多种资产**：用户可以在 Stellar 网络上创建和交易不同类型的资产，包括法定货币和其他数字资产。

6. **金融包容性**：Stellar 的目标是通过提供低成本的金融服务，促进全球范围内的金融包容性，尤其是服务那些传统银行无法覆盖的人群。

Lumen 的产生采用了“分发”的方式，最初通过空投和其他形式向用户提供，以推动网络的使用和参与。目前，XLM 已被多种交易所支持，并可用于多种钱包中进行存储和交易。
