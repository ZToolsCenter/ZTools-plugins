蒙古图格里克（Mongolian Tögrög，常用符号为MNT）是蒙古国的法定货币。图格里克的历史可以追溯到1925年，当时以“图格里克”名称开始流通，成为替代此前的货币单位“蒙古卢布”的新货币。 

图格里克的货币单位分为100个蒙戈（Möngö）。在流通中，主要的货币面额包括纸币和硬币，纸币的面额有1, 5, 10, 20, 50, 100, 500, 1000, 5000和10000图格里克，而硬币的面额则为1, 5, 10, 20, 50蒙戈及1, 5, 10图格里克。 

蒙古图格里克的汇率受到多种因素的影响，包括国家经济状况、通货膨胀率、国际市场的供需状况等。蒙古国以矿产资源和畜牧业为主要经济支柱，这些因素也直接影响到图格里克的价值。近年来，蒙古国经济逐渐多元化，图格里克的国际交换和使用范围也在不断扩展。 

在货币政策上，蒙古中央银行（Bank of Mongolia）负责制定和执行相关政策，以维护图格里克的稳定性和购买力。
