罗马尼亚新列伊（Romanian Leu，符号：RON）是罗马尼亚的官方货币。新列伊于2005年7月1日正式启用，取代了旧列伊（ROL），汇率为1新列伊=10,000旧列伊。新列伊的引入旨在简化货币单位并减轻通货膨胀的影响。

罗马尼亚新列伊由罗马尼亚国家银行（Banca Națională a României）发行，并为法定货币。新列伊分为100个分币，称为“巴尼”（bani）。流通中有多种面额的纸币和硬币，包括1、5、10、50、100、200和500列伊纸币，以及1、5、10、50分的硬币。

罗马尼亚新列伊的汇率在国际市场上波动，受多种因素影响，包括经济表现、通货膨胀率、利率以及全球金融环境。该货币在区域内与欧元和其他中东欧货币存在一定的浮动关系。

罗马尼亚新列伊在国际贸易中逐渐发挥作用，虽然罗马尼亚尚未加入欧元区，但其货币与欧元交易的流动性相对较强。在进行货币交易或相关金融业务时，建议参考最新的外汇报价和市场动态。
