铂（Platinum）是一种贵金属，化学元素符号为Pt，原子序数78。铂的物理特性包括高密度、高熔点和优良的抗腐蚀性。其在自然界中主要以矿石的形式存在，通常与镍、铜等金属共生。

铂的价格通常以盎司（troy ounce）为单位进行报价，1盎司等于约31.1035克。铂的市场价格波动较大，受到供需关系、工业需求（尤其是汽车催化剂、电子产品和首饰等领域）及地缘政治因素的影响。

铂金具有较高的投资价值和稀缺性，常被用作对冲通货膨胀和市场波动的工具。与其他贵金属（如黄金和白银）相比，铂的市场交易量相对较小，因此其价格波动性可能更大。

铂的标准单位也包括克，但在国际金融市场上，盎司单位更为常见。铂的买卖通常通过交易所进行，其中如纽约商品交易所（COMEX）和伦敦金属交易所（LME）是主要的交易平台。
