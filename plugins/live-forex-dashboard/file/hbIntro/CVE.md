佛得角埃斯库多（Cape Verdean Escudo，货币代码：CVE）是佛得角（Cape Verde）的官方货币。它分为100个欧分（Centavos）。该货币自1977年起首次发行，取代了之前的佛得角克鲁泽罗（Cape Verdean Cruzado）。 

佛得角埃斯库多的汇率通常与欧元相关，因为佛得角在2002年实现了货币的固定汇率模式。尽管该货币在国际市场上的流通量有限，但其在佛得角国内的使用非常广泛。 

硬币的面额包括1、2、5、10、20、50埃斯库多，以及1、2、5、10、20、50欧分。纸币的面额则包括200、500、1000和2000埃斯库多。 

佛得角埃斯库多的设计通常体现了国家的历史、文化和自然景观，反映了该国的独特身份。
