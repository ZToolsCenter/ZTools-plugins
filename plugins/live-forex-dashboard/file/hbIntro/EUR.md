欧元（EUR）是欧元区内使用的官方货币。欧元是欧洲联盟（EU）成员国中18个国家的法定货币，形成了欧洲经济与货币联盟（EMU）。

欧元的标志是“€”，其货币代码为EUR。欧元的发行机构为欧洲央行（ECB），其总部位于德国法兰克福。欧元自2002年起正式流通，取代了先前各国的本国货币，如德国马克、法郎等。

欧元的使用旨在促进区域内的经济一体化，简化跨国交易，降低汇率风险，并提供更大的价格透明度。欧元区国家间的经济和货币政策相互关联，由欧洲央行负责制定货币政策。欧元是全球第二大最活跃的交易货币，仅次于美元。

欧元的结构包括纸币和硬币，现行纸币面额有5、10、20、50、100、200和500欧元，硬币面额则包括1、2、5、10、20和50分以及1和2欧元。

在国际金融市场中，欧元被广泛用作储备货币，承担着全球贸易和投资的重要角色。
