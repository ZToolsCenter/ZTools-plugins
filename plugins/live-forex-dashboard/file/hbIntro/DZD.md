阿尔及利亚第纳尔（DZD）是阿尔及利亚的法定货币。其国际标准化组织（ISO）代码为DZD。阿尔及利亚第纳尔分为100个更小单位，称为分（"centime"），但由于通货膨胀，分的流通逐渐减少。

阿尔及利亚第纳尔最初在1964年引入，取代了旧的货币——阿尔及利亚法郎（ALF）。阿尔及利亚第纳尔在市场上的兑换率受到国际油价、外汇市场波动和阿尔及利亚经济状况等多种因素的影响。

阿尔及利亚第纳尔的货币符号通常为"د.ج"。流通中的纸币面额包括500、1000、2000和5000第纳尔，硬币面额则有1、5、10、20和50第纳尔等。阿尔及利亚银行是国家的中央银行，负责货币发行及相关政策的制定。
