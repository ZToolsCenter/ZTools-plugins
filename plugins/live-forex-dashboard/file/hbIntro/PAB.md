巴拿马巴波亚（Balboa）是巴拿马的货币单位。其名称源于西班牙探险家瓦斯科·努涅斯·巴尔博亚（Vasco Núñez de Balboa），该货币于1904年首次引入，并且以1巴波亚等于100分为单位。巴波亚在日常交易中使用较少，主要是与美国美元并行流通。

巴波亚直接与美元挂钩，1巴波亚等于1美元。虽然巴波亚是法定货币，但实际上，大多数交易都是使用美元进行的。巴波亚纸币由巴拿马中央银行发行，而巴波亚硬币则与美元硬币同样设计，并被广泛接受。

在巴拿马国内，巴波亚的主要用途是作为法定货币，尤其是在一些特定场合或政府交易中，但经济活动主要依赖于美元进行。整体而言，巴波亚的存在对巴拿马经济稳定性具有重要意义，尤其在与国际市场的交易中。
