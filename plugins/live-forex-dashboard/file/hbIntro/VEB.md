委内瑞拉玻利瓦尔是委内瑞拉的法定货币，曾经历多次重命名和货币贬值。最初的玻利瓦尔于1879年引入，取名自南美独立斗士西蒙·玻利瓦尔。由于经济危机导致高通货膨胀，2008年，委内瑞拉政府在老玻利瓦尔的基础上推出了新玻利瓦尔，汇率为1新玻利瓦尔兑换100000旧玻利瓦尔。 

然而，尽管更换了货币，经济问题依然严重，导致新的高通货膨胀。2018年，政府再次进行了货币重估，推出了第二版玻利瓦尔（称为“加密玻利瓦尔”或“主权玻利瓦尔”），其单位为1主权玻利瓦尔等于100000旧玻利瓦尔。

随着这系列的货币改革与贬值，委内瑞拉玻利瓦尔逐渐失去了其作为稳定法定货币的有效性，最终导致实际经济交易中更倾向于使用外币如美元。至2023年，旧版和新版的玻利瓦尔都已被广泛认为在经济中逐渐被淘汰，尤其是在市场交易和日常消费中。
