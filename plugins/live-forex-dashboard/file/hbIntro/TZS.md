坦桑尼亚先令（Tanzanian Shilling，TZS）是坦桑尼亚联合共和国的法定货币。其货币符号为“Sh”或“TSh”。坦桑尼亚先令的分为100个分币（Cents），但由于通货膨胀，分币的流通较少。

历史上，坦桑尼亚先令于1966年于独立后产生，取代了此前的东非先令。货币由坦桑尼亚央行（Bank of Tanzania）发行和管理。坦桑尼亚先令的汇率受多种因素影响，包括国内经济状况、国际贸易、通货膨胀率及货币政策等。

目前，坦桑尼亚先令的纸币面额包括1,000、2,000、5,000、10,000、20,000等。硬币面额有50、100、200、500先令。由于坦桑尼亚的经济与农业、旅游业、和矿业密切相关，货币的稳定性随经济形势的变动而变化。

在进行国际交易及外汇兑换时，了解坦桑尼亚先令的当前汇率及经济背景尤为重要。交易者和投资者需密切关注国际市场变化，以确保能有效应对汇率波动。
