塔吉克斯坦索莫尼（Tajikistani Somoni，货币符号为TJS）是塔吉克斯坦的法定货币。其名称源于波斯语的“苏门”，历史上是中亚地区的一种古老货币单位。索莫尼于1999年10月发行，取代了先前的塔吉克斯坦鲁布（TJS）。

索莫尼分为100分（也称为“迪尔汉”）。目前流通的纸币面额包括1、3、5、10、20、50、100、200和500索莫尼，而硬币则包括1、3、5、10、20、50分和1、3、5索莫尼。

塔吉克斯坦索莫尼的汇率受到多种经济因素影响，包括国内生产总值（GDP）、通货膨胀、国际市场价格等。汇率波动可能影响外汇交易和国际投资。

索莫尼的符号通常被表示为“SM”或“TJS”。在国际金融市场上，塔吉克斯坦索莫尼的流通性相对较低，主要在国内使用，外部世界对其认知度不高。
