莫桑比克梅蒂卡尔（Mozambican Metical，简称MZN）是莫桑比克的法定货币。梅蒂卡尔的货币符号为"MT"或"MZN"。该货币由莫桑比克银行发行，并于1980年首次引入，取代了之前的货币“莫桑比克斯科特”（Mozambican Escudo）。 

梅蒂卡尔分为100个分币，分币有面值1、2、5、10、20、50、100及200梅蒂卡尔的纸币和硬币。由于经济波动和通货膨胀，莫桑比克梅蒂卡尔经历了几次重新定值，最新一轮是在2016年，以提高其对外交易的稳定性。

在外汇市场上，梅蒂卡尔的汇率受多种因素影响，包括国内经济状况、国际市场动向以及与主要贸易伙伴国货币的兑值情况。尽管梅蒂卡尔在国内广泛使用，但其国际接受度相对较低，常常需要与美元、欧元等主要货币进行兑换以适应国际交易。

近年来，莫桑比克经济受益于自然资源的开发和外国投资，但也面临挑战，包括政治不稳定、基础设施不足以及高通货膨胀。因此，对梅蒂卡尔的长期稳定性和价值仍需持续关注。
