瑞士法郎（Swiss Franc, CHF）是瑞士及列支敦士登的法定货币。其符号为“CHF”，分为100个拉皮（Rappen）或加分（Centimes）。瑞士法郎在国际金融市场上被认为是一种相对稳定的货币，因其强劲的经济基础和稳健的货币政策而受到投资者的青睐。

瑞士法郎的历史可以追溯到19世纪中叶，其标准铸造的硬币和纸币经过多个版本的演变，均由瑞士国家银行（Swiss National Bank, SNB）负责发行。该银行在货币政策上追求价格稳定，并且通常采取低通胀的策略。

在外汇市场上，瑞士法郎通常作为避险资产，尤其是在全球经济不确定性加剧时。其汇率受多种因素影响，包括经济数据、国际局势、利率变化等。

瑞士法郎还以其高标准的安全性和先进的金融系统而知名，这使得其在全球范围内被广泛接受。在国际贸易及投资领域，瑞士法郎也扮演着重要的角色。
