东加勒比元（East Caribbean Dollar，缩写为XCD）是东加勒比国家和地区的官方货币。它由东加勒比中央银行（Eastern Caribbean Central Bank，ECCB）发行，服务于东加勒比货币联盟的成员国和地区。该货币于1983年正式引入，以替代原有的货币，并实现区域内的货币稳定与经济一体化。

东加勒比元的汇率固定，对美元的汇率为1 USD = 2.7 XCD。东加勒比元的面额包括纸币和硬币，纸币的面额有：5、10、20、50和100元；而硬币则有1、2、5、10、25分及1和2元的面额。

东加勒比元的使用国家和地区包括安提瓜和巴布达、圣基茨和尼维斯、圣卢西亚、多米尼克、格林纳达、巴哈马、圣文森特和格林纳丁斯等。这种货币的设计旨在促进区域经济合作与一体化，增强成员国之间的货币稳定性和政策协调。

东加勒比元在国际外汇市场的流通性相对较低，主要在该货币联盟内部流通。在该地区的经济活动中，东加勒比元在交易、投资和国际贸易中发挥着重要作用。
