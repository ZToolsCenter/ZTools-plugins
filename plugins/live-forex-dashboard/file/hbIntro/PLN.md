波兰兹罗提（Polish Zloty，缩写为 PLN）是波兰的法定货币。兹罗提分为100个格尔德（Grosz）。它的符号为zł。波兰兹罗提的名称源于中世纪的波兰语，意为“金子”。

波兰兹罗提自1995年以来以新兹罗提（新波兰兹罗提）出现，替代了之前的旧兹罗提（1新兹罗提等于10000旧兹罗提）。兹罗提的发行由波兰国家银行（Narodowy Bank Polski）负责。

波兰兹罗提在国际市场上被广泛使用，并在外汇市场上流通。波兰是欧盟成员国，但尚未采用欧元作为其法定货币，兹罗提依然是其主要的流通货币。

汇率波动受多种因素影响，包括经济指标、政治因素及市场供需关系等。截至最后一次记录，波兰兹罗提表现出相对稳定性，但汇率详情需根据外汇市场的实时数据进行查询。
