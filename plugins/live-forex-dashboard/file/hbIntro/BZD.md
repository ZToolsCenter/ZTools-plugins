伯利兹元（Belize Dollar，货币符号：BZD）是伯利兹的法定货币。其货币代码为BZD，由伯利兹中央银行发行。伯利兹元的分币为分（cent），1 伯利兹元等于100 分。

伯利兹元与美元的固定汇率为2:BZ=1:USD。此汇率常被广泛使用，适用于日常交易和国际商业活动。

伯利兹元的纸钞面额包括2、5、10、20、50和100元，而硬币则包括1分、5分、10分、25分以及1元。

由于伯利兹的经济与邻国和国际市场的紧密联系，伯利兹元在国际交易中也时常会受到美元的影响。作为一种较小规模的货币，其流通和使用主要集中在当地市场。伯利兹元的价值稳定性比起某些更强的国际货币相对较低，故在汇率方面也需特别注意。
