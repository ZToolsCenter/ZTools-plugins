瓦努阿图瓦图（Vanuatu Vatu），是瓦努阿图的官方货币，代码为VUV。瓦图的分币为“希尔”（Sente），1瓦图等于100希尔。

瓦图于1981年开始流通，取代了之前的货币——澳大利亚元。瓦图的名称来源于“瓦努阿图”这个国家的威望与文化，具有一定的地方象征意义。

瓦图的纸币和硬币的面额多样，常见的有：1、2、5、10、20、50、100、200、500瓦图的纸币，以及5、10、20、50瓦图的硬币。纸币上通常印有瓦努阿图的文化、历史和自然景观的图案，反映了该国的民族特色与身份。

汇率方面，瓦图与其他外币的汇率会有所波动，受多种因素影响，包括经济状况、国际市场动荡以及旅游等行业的表现。投资者和旅行者在关注瓦图时，应定期查看相关金融机构提供的最新汇率信息。

总体而言，瓦努阿图瓦图在国际市场上的流通性较低，主要在国内使用。在进行货币兑换时，需考虑到相关手续费和汇率差异。对于国际贸易或旅行，建议提前了解瓦图的汇率及其对其他主要货币（如美元、欧元等）的兑换情况。
