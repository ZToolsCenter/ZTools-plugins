吉尔吉斯斯坦索姆（Kyrgyz Som，ISO 4217代码：KGS）是吉尔吉斯斯坦的法定货币。该货币于1993年首次发行，旨在取代苏联卢布（RUB）。索姆的基本单位为1索姆，分为100提利（Tiyin）。

吉尔吉斯斯坦索姆的发行由吉尔吉斯斯坦国家银行负责，主要用于国内的商品和服务交易。在国际市场上，吉尔吉斯斯坦索姆的流通性相对较低，通常限制在与主要货币（如美元、欧元和俄罗斯卢布）的兑换中。索姆的汇率受多种因素的影响，如经济状况、通货膨胀率以及国际市场的变化。

在设计方面，索姆的纸币和硬币上印有吉尔吉斯斯坦的国家象征、历史人物和文化遗产，体现了该国的民族特色和历史渊源。当前流通的纸币面额包括1、5、10、20、50、100、200、500、1000和5000索姆。

在进行货币兑换时，请注意关注汇率波动，并了解可能产生的手续费，以确保交易的经济性和安全性。
