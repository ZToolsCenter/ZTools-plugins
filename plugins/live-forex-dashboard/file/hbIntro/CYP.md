Cypriot Pound（CYP）是原为塞浦路斯的官方货币，使用于1972年至2008年。Cypriot Pound与英镑的联系较为紧密，自1862年开始作为塞浦路斯的法定货币，直到2008年停止流通并被欧元（EUR）取代。 

在2008年1月1日，塞浦路斯正式采用欧元为法定货币，Cypriot Pound在新的货币系统中不再被接受。Cypriot Pound的兑换率为1欧元等于0.585274 Cypriot Pound。当前的货币主要用于纪念和收藏，并且已经停止生产和流通。 

Cypriot Pound的国际代码为CYP，之前的分币单位为“米利”（milli），通常表示为1/100的汇率单位。由于其退市，当前不再进行任何新交易，历史货币的价值主要基于收藏者的市场需求。
