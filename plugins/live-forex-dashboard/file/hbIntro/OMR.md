阿曼里亚尔（Omani Rial，ISO代码：OMR）是阿曼苏丹国的官方货币。它于1973年首次引入，取代了之前的阿曼镑（Oman Pound）。阿曼里亚尔分为1000比萨（Baisa），流通的硬币有1、5、10、25、50比萨以及1里亚尔的面额，纸币面额包括1、5、10、20和50里亚尔。

阿曼里亚尔是一种高度稳定的货币，通常与美元挂钩。其汇率在国际市场上相对稳定，利率政策由阿曼中央银行制定，以促进经济稳定及可持续发展。

阿曼里亚尔的设计体现了阿曼的文化和历史，纸币上通常会印有国家的标志性建筑、历史人物以及自然景观。金融机构通常提供阿曼里亚尔的兑换服务，适用的汇率依据市场动向和交易成本变化而定。

在国际贸易及旅游中，阿曼里亚尔的使用范围有限，因此在外部交易中，部分情况下可能需要先兑换成更广泛接受的货币，如美元或欧元。
