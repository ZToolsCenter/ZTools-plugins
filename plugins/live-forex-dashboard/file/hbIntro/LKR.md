斯里兰卡卢比（LKR）是斯里兰卡的官方货币，通常以符号“Rs”或“SLRs”表示。卢比被划分为100分（ cents）。斯里兰卡中央银行是卢比的发行机构，负责货币政策和金融稳定。

卢比在国际外汇市场上较为活跃，但相对于主要货币，如美元、欧元和英镑，其流动性较低。根据经济状况和外部因素，如贸易平衡、外汇储备和国际油价，卢比的汇率会波动。

卢比的历史可以追溯到19世纪，其面值纸币和硬币的设计通常会反映斯里兰卡的文化和历史，包含佛教图案、自然景观等元素。

近年来，由于经济挑战，特别是与债务和通货膨胀相关的问题，斯里兰卡卢比经历了一定程度的贬值。外汇管制措施和国际援助可能会对卢比的未来走势产生影响。

在进行任何货币交易时，建议考虑实时汇率信息以及可能影响汇率的宏观经济因素。
