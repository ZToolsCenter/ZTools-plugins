孟加拉国塔卡（Bangladeshi Taka，缩写为BDT）为孟加拉国的法定货币。其国际标准代码为BDT，符号为৳。塔卡分为100个波卡（Paisa），尽管由于通货膨胀，波卡的实际使用逐渐减少。

历史上，塔卡在1972年作为独立后的新货币开始流通，取代了之前的巴基斯坦卢比。由孟加拉国央行（Bangladesh Bank）负责发行和管理。

孟加拉国塔卡的面额发行包括纸币和硬币，纸币常见面额有2、5、10、20、50、100、500及1000塔卡；硬币面额通常包括1、2、5及10塔卡，以及不同的波卡面额。

在国际市场上，塔卡的汇率会因多种经济因素而波动，包括经济增长、通货膨胀、外汇储备及国际贸易状况等。为了获取当前的汇率信息，建议查询相关金融服务平台或银行的信息。

总体而言，孟加拉国塔卡在国内的流通和使用非常广泛，是该国经济活动的基础。
