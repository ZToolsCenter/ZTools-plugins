委内瑞拉玻利瓦尔（Venezuelan Bolívar）是委内瑞拉的法定货币，其货币代码为VES。其历史可以追溯到19世纪初，但现行的玻利瓦尔版本是2018年以“新玻利瓦尔”的形式发行的，旨在应对高通货膨胀和货币贬值。

1. **货币改革背景**：由于委内瑞拉长期的经济危机和高通货膨胀率，旧版玻利瓦尔（VEF）在2018年被换成了新玻利瓦尔，汇率为1新玻利瓦尔等于1,000,000旧玻利瓦尔。该改革旨在简化交易流程和货币单位。

2. **货币面值**：新玻利瓦尔的面值包括纸币和硬币，纸币的面值从2玻利瓦尔到100玻利瓦尔不等，硬币的使用较为有限。

3. **通货膨胀**：近年来，委内瑞拉经历了世界上最高的通货膨胀率，导致货币贬值显著，这也促使中央银行采取多项政策来控制通胀及保护经济。

4. **使用限制**：由于内外经济恶化以及外汇管制，外汇市场受到严格监管，因此在国际市场上，新玻利瓦尔的交易和接受程度相对较低。

5. **当前状态**：鉴于持续的经济不稳定，央行和政府推动了一系列货币政策来稳定经济，但面临重重压力，导致对新玻利瓦尔的信心不足。
