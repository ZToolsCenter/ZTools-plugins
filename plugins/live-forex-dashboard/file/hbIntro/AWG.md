阿鲁巴盾（Aruban Florin, AWG）是阿鲁巴的官方货币。它的分币为分，而荷兰盾（Dutch Guilder, NLG）是荷兰在2002年前使用的官方货币，现已被欧元（EUR）所取代。

阿鲁巴盾在阿鲁巴国内流通，1阿鲁巴盾通常等于100分。阿鲁巴盾与美国美元（USD）有稳定的汇率关系，通常被广泛接受，尤其在旅游业发达的地区。

荷兰盾自17世纪以来一直是荷兰的法定货币，但在2002年欧元正式引入后，荷兰盾停止流通。根据汇率转换，1欧元大约等于2.20371荷兰盾。在停止使用前，荷兰盾的分币为分。

当前，对于需要使用阿鲁巴盾或历史上的荷兰盾的相关信息，建议参考最新的汇率和金融政策，以获取准确的金融数据。
