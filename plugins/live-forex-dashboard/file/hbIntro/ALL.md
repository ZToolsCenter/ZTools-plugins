阿尔巴尼列克（Albanian Lek，货币代码：ALL）是阿尔巴尼亚的法定货币。其历史可以追溯到1926年，当时首次发行。阿尔巴尼列克的名称源于阿尔巴尼亚的传统货币单位“列克”。 

阿尔巴尼列克的符号为“L”，且通常以分（Qindarka）为辅币单位，1列克等于100分。阿尔巴尼列克由阿尔巴尼亚中央银行（Bank of Albania）负责发行和管理。 

在国际外汇市场上，阿尔巴尼列克相对较少交易，其汇率受到阿尔巴尼亚经济状况、通货膨胀率和国际市场流动性的影响。阿尔巴尼亚维持相对浮动的汇率制，具体汇率常与主要货币如欧元（EUR）和美元（USD）等挂钩。

阿尔巴尼列克在日常交易中广泛使用，纸币面额包括200、500、1000、2000、5000列克，同时硬币面额有1、5、10、20、50和100列克。近年来，阿尔巴尼亚政府和中央银行加大了对金融体系的改革力度，推进电子支付和数字货币的相关发展。
