危地马拉格查尔（Guatemalan Quetzal，ISO代码：GTQ）是危地马拉的法定货币。该货币以危地马拉的国鸟“格查尔鸟”命名，象征着自由与独立。格查尔的基本单位分为100分（ centavos）。

历史上，格查尔于1925年开始流通，取代了之前的危地马拉比索。格查尔在国际外汇市场上的交易通常受到影响，受到政治稳定、经济政策及全球市场动态等因素的制约。

格查尔的纸币面额包括1、5、10、20、50、100和200格查尔，而硬币则包括1、5、10、25、50格查尔及更小的分币。纸币和硬币上印有危地马拉的历史人物、文化和自然景观，反映了国家的民族特色。

在危地马拉，格查尔广泛用于国内交易。尽管美金在某些商业领域被接受，但官方交易仍以格查尔为主。使用格查尔进行国际交易时，通常会通过外汇市场进行兑换。对于外汇业务，银行和交易所提供格查尔与其他主要货币的汇率信息。
