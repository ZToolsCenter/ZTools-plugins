斯威士兰的法定货币是斯威士兰兰吉尼（Lilangeni），其国际货币代码为SZL。兰吉尼于1974年首次引入，并与南非兰特（ZAR）挂钩，汇率为1:1。兰吉尼的分币单位为埃米兰吉尼（Emalangeni），1兰吉尼等于100埃米兰吉尼。

斯威士兰兰吉尼以希腊神话中的图案及当地文化元素为设计特色，流通纸币的面额包括20、50、100和200兰吉尼。硬币则有1、2、5、10、20和50埃米兰吉尼等面额。

兰吉尼是斯威士兰经济的重要组成部分，主要受到农业、制造业和服务业等行业的驱动。由于地理位置和经济结构的限制，斯威士兰的经济对南非经济的波动较为敏感，这也使得兰吉尼在国际市场上面临一定的风险。

总之，斯威士兰兰吉尼是该国官方货币，在国内外交易中被广泛接受，并与南非兰特密切关联。
