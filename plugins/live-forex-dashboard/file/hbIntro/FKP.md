福克兰群岛镑（Falkland Islands pound，代码为FKP）是福克兰群岛的官方货币。它与英镑（GBP）等值，因此在实际运用中，福克兰群岛镑可以直接与英镑互换。福克兰群岛镑的分币单位为便士（pence），1福克兰群岛镑等于100便士。

福克兰群岛镑的发行和管理由福克兰群岛政府及其授权的管理机构负责。尽管当地流通的主要货币是福克兰群岛镑，但英镑在该地区也被广泛接受且流通。

福克兰群岛镑的纸币和硬币设计通常反映该地区的文化、历史以及自然景观。硬币的面值包括1便士、2便士、5便士、10便士、20便士、50便士以及1镑和2镑的硬币。纸币的面值则通常有5镑、10镑、20镑、50镑等。

福克兰群岛镑的兑换率与英镑相对稳定，但与其他货币的汇率会受到国际市场波动的影响。由于福克兰群岛地理位置偏远，货币流通量较低，因此在进行国际交易时，需关注相关的外汇市场动态与服务费用。
