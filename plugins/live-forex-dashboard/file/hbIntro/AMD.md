亚美尼亚德拉姆（Armenian Dram，简写为AMD）是亚美尼亚的法定货币。德拉姆的历史可追溯至1993年，当时亚美尼亚在独立后引入该货币，以替代苏联卢布。德拉姆进一步分为100个拉尔（Luma），虽然拉尔在流通中已不再常见。

亚美尼亚德拉姆的货币符号为֏，国际标准化组织（ISO）代码为AMD。自推出以来，德拉姆经历了多次货币贬值和升值，受到多种经济因素的影响，包括国内生产总值（GDP）、通货膨胀率和国际贸易情况等。

中央银行是亚美尼亚德拉姆的发行机构，负责货币政策和金融监管。德拉姆与其他主要货币（如美元、欧元）之间的汇率会受到国际市场供需、地缘政治和经济数据的影响，进行常规交易。然而，作为一个小型经济体的货币，德拉姆的汇率波动性可能较大。

在国际市场上，德拉姆的流通相对有限，因此其使用主要集中在亚美尼亚境内。对于国际旅行者和投资者而言，了解德拉姆的汇率及其经济背景对于制定财务决策具有重要意义。
