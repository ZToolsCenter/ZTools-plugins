博茨瓦纳普拉（Botswana Pula）是博茨瓦纳的法定货币，货币代码为BWP，符号为"P"。根据国际标准化组织（ISO）定义，BWP于1976年首次引入，取代了之前使用的南非兰特。

博茨瓦纳普拉的名称来源于当地的一种草，象征着繁荣和富饶。其货币单位分为100个蒂卡（Thebe）。博茨瓦纳中央银行负责普拉的发行和管理。

普拉的纸币面额有10、20、50、100及200普拉，硬币则有1、2、5、10、25、50分及1、2、5普拉的不同面额。博茨瓦纳普拉的设计彰显了国家文化和自然特色，包括野生动物和保护区等元素。

博茨瓦纳的经济以矿业（尤其是钻石）、农业和旅游业为主，普拉在国际金融市场上具有相对稳定的地位。近年来，其汇率通常与南非兰特相挂钩，波动性相对较小。为维护货币稳定，博茨瓦纳中央银行在必要时进行市场干预。

在进行外汇交易时，博茨瓦纳普拉的可兑换性有限，主要与地区货币进行交易，其国际使用和流通性相对较低。
