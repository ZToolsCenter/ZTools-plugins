沙特里亚尔（Saudi Riyal，简写为SAR）是沙特阿拉伯的法定货币。沙特里亚尔的货币符号为ر.س（阿拉伯文符号），以及SAR的国际标准化组织ISO代码。

以下是沙特里亚尔的详细信息：

1. **汇率与兑换**：沙特里亚尔与美元的汇率是固定的，通常为1美元兑换3.75沙特里亚尔。具体汇率可能因市场波动而略有变化。

2. **分币单位**：1沙特里亚尔可细分为100哈拉拉（halalah）。

3. **纸币与硬币**：沙特里亚尔的纸币面额包括1、5、10、20、50、100和500里亚尔。此外，硬币的面额包括1、5、10、25、50哈拉拉和1、2、5沙特里亚尔。

4. **发行机构**：沙特阿拉伯央行（Saudi Arabian Monetary Authority，SAMA）负责沙特里亚尔的发行与管理。

5. **经济背景**：沙特里亚尔作为主要的中东货币之一，其价值受到国家经济、石油价格以及国际市场动态的影响。

6. **金融交易与接受度**：沙特里亚尔广泛用于国内交易，亦在全球一些金融市场进行交易，对国际投资者和商人来说具有一定的流通性。
