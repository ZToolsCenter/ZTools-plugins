马尔代夫拉菲亚（Maldivian Rufiyaa，ISO 4217代码：MVR）是马尔代夫的法定货币。拉菲亚的分币单位为拉菲亚的分（Laari），其中1拉菲亚等于100拉里。拉菲亚的国际货币代码是MVR，通常以符号MVR表示。

该货币自1981年起开始流通，取代了之前使用的英镑。马尔代夫拉菲亚由马尔代夫中央银行（Maldives Monetary Authority）发行和管理。

马尔代夫拉菲亚的纸币面额包括1、5、10、20、50、100、500和1000拉菲亚，硬币面额包括1、2、5、10、25、50拉里和1、2、5拉菲亚。拉菲亚的汇率受到多种因素的影响，包括经济状况、旅游业的繁荣程度及全球市场情况。

在马尔代夫，通常接受美元作为主要的外币，但对于正式交易，使用拉菲亚更为普遍。游客在使用拉菲亚之前，建议了解当前的汇率以及相关的货币兑换规则。
