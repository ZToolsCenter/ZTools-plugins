巴基斯坦卢比（Pakistani Rupee，符号为PKR）是巴基斯坦的法定货币，分为100个比索（Paisa）。巴基斯坦卢比由巴基斯坦中央银行负责发行和管理。卢比在国际金融市场上通常以“PKR”缩写来标识。

自1948年引入以来，巴基斯坦卢比经历了多次重估和贬值，受多种因素影响，如通货膨胀、财政政策及外部经济环境。国家经济状况、贸易平衡、外汇储备水平及国际投资环境均对其汇率产生重要影响。

巴基斯坦卢比流通的纸币面额包括20、50、100、500、1000卢比，硬币面额有1、2、5、10、25、50比索。货币设计及防伪技术已得到加强，以防止伪造。

在国际交流中，巴基斯坦卢比的汇率波动经常与美元、欧元、人民币等主要货币对比，并受到全球经济形势及地缘政治的影响。
