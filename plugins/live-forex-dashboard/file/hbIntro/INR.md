印度卢比（Indian Rupee），符号为₹，是印度的法定货币，由印度储备银行（Reserve Bank of India）发行和管理。其ISO 4217代码为INR。

1. **历史背景**：卢比的起源可以追溯到古代印度，最早的卢比是在16世纪由穆斯林统治者发行。现代卢比的建立可以追溯到1861年，当时英国东印度公司首次发行统一的纸币。

2. **汇率**：印度卢比相对其他货币的汇率波动受多个因素影响，包括经济指标、政治稳定性、国际投资流动及市场情绪。汇率每天都会在外汇市场上进行交易和调整。

3. **货币结构**：印度卢比可以分为纸币和硬币。纸币面额包括₹2、₹5、₹10、₹20、₹50、₹100、₹200、₹500和₹2000，硬币面额则包括₹1、₹2、₹5和₹10。各面额的设计具有文化和历史象征意义。

4. **经济指标**：人民币的稳定对于印度经济至关重要。经济增长、通货膨胀、国际贸易和财政政策等因素都会直接影响卢比的价值。

5. **使用范围**：卢比不仅在印度使用，还在巴基斯坦、尼泊尔和印度一些邻国的交易中被接受。印度卢比的国际化程度逐渐提高，尤其是在南亚地区。

6. **支付手段**：随着金融科技的发展，数字支付在印度已逐渐普及。各种数字钱包和在线支付平台使得卢比的使用更加便利。

总体而言，印度卢比是印度经济中重要的组成部分，其稳定性和兑换能力对国家的经济发展有着深远的影响。
