摩洛哥迪拉姆（Moroccan Dirham，符号：MAD）是摩洛哥王国的法定货币。迪拉姆划分为100分哈拉（centimes）。摩洛哥中央银行（Bank Al-Maghrib）负责该货币的发行与管理。

摩洛哥迪拉姆的汇率通常会受到国际货币市场的影响，具体汇率表现取决于多个因素，包括投资者情绪、经济数据、政治稳定性及外部经济环境等。

摩洛哥地处北非，其货币政策和经济状况均与区域和全球经济动态密切相关。摩洛哥政府致力于维护货币的稳定性，以促进改革、小型企业和外贸的发展。

在国际市场上，摩洛哥迪拉姆并不具备广泛的兑换性，相比于主要货币（如美元、欧元）会更少被用于国际贸易。通常在摩洛哥境内可通过银行、货币兑换处等渠道进行兑换和使用。

在使用摩洛哥迪拉姆时，请注意至关重要的是遵循当地法律和金融规定，以确保合法和有效的金融交易。
