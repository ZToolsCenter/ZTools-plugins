安哥拉宽扎（Angolan Kwanza，ISO 4217代码：AOA）是安哥拉的法定货币。它由安哥拉中央银行（Banco Nacional de Angola）发行和管理。宽扎的名称来源于当地一种传统的货币单位，具有历史和文化的意义。

宽扎分为100个分币，最初发行的系列包括纸币和硬币。当前的纸币面额包括200、500、1,000、2,000、5,000、10,000、20,000和50,000宽扎。硬币面额通常较小，包括了1、5、10、50、100、200、500宽扎等。

安哥拉宽扎的汇率受到多种因素的影响，包括国际油价，因为安哥拉经济在很大程度上依赖于石油出口。近年来，宽扎经历了贬值和波动的情况，货币政策及外汇管理对其稳定性至关重要。

安哥拉政府定期进行货币改革以应对通货膨胀问题，改善经济状况。在进行国际交易或投资时，了解宽扎的汇率及其对主要货币（如美元、欧元）的兑换情况非常重要。
