意大利利拉（Italian Lira）是意大利的法定货币，简称“Lira”，其国际货币代码为“ITL”。利拉最终于2002年被欧元（EUR）替代，标志着意大利从传统货币转向欧元区的共同货币体系。

历史上，意大利利拉的使用可以追溯到1861年，当时意大利王国成立，利拉成为统一后国家的官方货币。利拉的名称源自拉丁语“Libra”，意思为“磅”，在货币的历史发展中经历了多个版本和发行系列。

意大利政府在1999年确定了欧元的使用时间表，并于2002年正式停止流通利拉，将所有流通中的利拉在一定时间内兑换为欧元。法律上，2002年1月1日起，利拉不再作为法定货币。从此，欧元取代了曾经在意大利乃至更广泛地区流通的利拉。

虽然意大利利拉已经不再使用，但在历史上其在经济、文化及商业活动中占据了重要地位，留下了丰富的遗产和文物。此外，现今仍可以在市场上找到一些流通和收藏的旧利拉币种，其收藏价值可能因稀缺性而有所不同。
