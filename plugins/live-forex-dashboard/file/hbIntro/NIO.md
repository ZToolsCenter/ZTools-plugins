尼加拉瓜科多巴（Nicaraguan Córdoba，ISO货币代码为NIO）是尼加拉瓜的法定货币。科多巴以尼加拉瓜独立国父弗朗西斯科·赫梅斯的名字命名，分为100分（Centavos）。科多巴经历过几次重估，当前使用的科多巴是自1991年起的版本。现行的科多巴纸币面额包括10、20、50、100和200科多巴，而硬币则有1、5、10、25、50分及1、5科多巴。

货币发行由尼加拉瓜央行（Banco Central de Nicaragua）负责，该机构也负责货币政策和金融稳定。科多巴的汇率受到多种因素影响，包括国际市场上美元的波动，因为美元在尼加拉瓜经济中扮演着重要角色。这意味着科多巴的汇率可能会出现波动，反映了全球经济状况和国内经济政策。

在国际市场上，科多巴的流通性较低，主要在尼加拉瓜境内使用，外部交易主要使用美元或其他主要货币。因此，在进行国际贸易或投资时，了解科多巴的汇率变动及其经济背景至关重要。
