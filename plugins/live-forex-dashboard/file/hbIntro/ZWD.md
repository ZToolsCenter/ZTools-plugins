津巴布韦元（Zimbabwean Dollar，简称ZWD）曾是津巴布韦的法定货币。初次发行于1980年，之后经历了多次的重估和重新发行。由于津巴布韦在21世纪初经历严重的经济危机和超高通货膨胀，津巴布韦元的购买力急剧下降，最终在2009年被废弃。

2009年，津巴布韦政府宣布停止发行本国元，转而使用外币，如美国美元（USD）和南非兰特（ZAR）作为主要交易货币。此举旨在稳定经济和恢复信任。在此之后，津巴布韦元在实际流通中不再被接受。

2019年，津巴布韦元重新被引入作为官方货币，称作“新津巴布韦元”，并继续受到严格的控制和管理。 当前的经济形势仍然复杂，因此需关注津巴布韦政府和中央银行的政策动态。
