汤加潘加（Tongan Paʻanga，货币代码：TOP）是汤加的法定货币。该货币由汤加中央银行发行，用于国内的所有经济交易。

1. **基本信息**：
   - 货币符号：T$（通常在金额前使用）
   - 货币分为更小单位，1潘加等于100仙（seniti）。

2. **汇率**：
   - 汤加潘加的汇率相对其他主要货币（如美元、澳元和新西兰元）会有波动，具体汇率需参考最新的外汇市场信息。

3. **流通与纸币**：
   - 汤加潘加纸币的面额包括2、5、10、20、50以及100潘加，硬币的面额包括1、2、5、10、20仙和1、2潘加。

4. **经济背景**：
   - 汤加是南太平洋的岛国，经济主要依赖农业、渔业和外援，潘加的稳定性与国家经济状况密切相关。

5. **国际使用**：
   - 汤加潘加主要在汤加境内使用，在国际交易中的接受度较低。

6. **运输及汇款**：
   - 由于汤加地理位置较为偏远，国际汇款通常依赖于汇款服务提供商，汇款成本可能较高且需注意汇率差异。
