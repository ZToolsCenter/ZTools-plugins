南非兰特（South African Rand，符号：R，ISO 4217代码：ZAR）是南非的法定货币，广泛用于南非及部分相邻国家。兰特的历史可以追溯到1961年，当时被引入以替代南非先前的货币——南非镑。名称“兰特”源于“威尔特水兰特”（Witwatersrand），即南非重要的金矿区。

兰特的基本单位为分（Cent，符号：c），1兰特等于100分。南非兰特的货币符号为“R”，在书写时通常位于金额的前面，例如：R100。

南非央行，即南非储备银行（South African Reserve Bank），负责兰特的发行和管理。为了维护货币的稳定，南非储备银行实施了一系列货币政策，包括利率调整和外汇干预。

兰特在国际市场上被广泛交易，并且因其在大宗商品市场（如黄金和白银）中的使用而受到关注。由于南非的经济结构较为多元和发达，因此兰特的汇率受到诸多因素的影响，包括国际市场的商品价格、国内经济数据以及政治稳定性。

南非兰特的汇率可以通过外汇市场波动，其价值对其他主要货币（如美元、欧元和英镑）存在一定的波动性。投资者在进行国际交易或投资时需要关注兰特汇率的风险。同时，兰特也是南部非洲发展共同体（SADC）国家的一部分，部分国家以兰特为参考货币进行交易。
