格鲁吉亚拉里（GEL，Georgian Lari）是格鲁吉亚的法定货币。其名字源于拉里的古典含义，意为“金币”或“货币”。拉里的符号为₾，国际货币代码为GEL。

拉里于1995年正式引入，以取代之前的苏联卢布。根据中央银行的规定，格鲁吉亚拉里被分为100戈比（Guri），戈比是拉里的辅币单位。

格鲁吉亚拉里的汇率受到多种因素的影响，包括国内经济状况、国际市场的供需关系以及外汇储备情况。格鲁吉亚国家银行负责拉里的发行与管理，其货币政策旨在确保价格稳定和金融系统的稳定性。

在国际贸易中，格鲁吉亚拉里相对常见的交易对象包括美元（USD）和欧元（EUR）。此外，拉里也可以在一些阿塞拜疆、亚美尼亚和土耳其的边境地区用于交易，但通常还是以主要货币为主。

对于投资者而言，格鲁吉亚拉里的流动性相对较低，因此在考虑相关投资时需要充分评估风险因素。
