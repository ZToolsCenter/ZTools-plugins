比利时法郎（Belgian Franc, BEF）是比利时在2002年1月1日前使用的官方货币。它的符号为"BF"或"フ"（日文“フ”通常用于表示法郎）。

历史上，比利时法郎的起源可以追溯到1832年，当时它被引入作为比利时独立后的一种货币单位。比利时法郎包含100个分（centimes），并且在其使用期间曾经历过多次汇率调整和重估。

2002年，比利时法郎被欧元（EUR）取代，成为欧洲经济和货币联盟的一部分。自此以后，它不再作为法定货币流通。法郎与欧元的兑换率为40.3399比利时法郎等于1欧元。在2002年后，比利时法郎已经停止发行和流通，但在某些情况下仍可在中央银行进行兑换。

法郎的废弃不仅标志着比利时货币政策的重大转变，也反映了欧洲经济一体化进程中的重要一步。在欧元区成立后，比利时不再单独使用自己的货币，而是统一使用欧元，方便了跨国界的商业和金融交易。
