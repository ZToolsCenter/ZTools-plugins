索马里先令（Somali Shilling，ISO 4217货币代码为SOS）是索马里共和国的法定货币。该货币自1962年开始发行，取代了先前的索马里盾。索马里先令的符号通常表示为“Sh.so”或“S/.”。

索马里先令分为100中心（cent）。目前流通的货币版本包含纸币和硬币。纸币的面值通常有1,000、500、100、50、10先令等，而硬币则主要为1、5、10、25、50中心及更高面值。

由于索马里的经济和政治不稳定，先令近年来遭遇了严重贬值。外部经济条件、政府政策以及内战等因素对其价值产生了重大影响。因此，其汇率通常在国际市场上波动较大。

索马里中央银行负责发行索马里先令并管理国家的货币政策。尽管形式上存在官方货币，实际交易中现金与非现金支付方式并存，且美元和其他外币在国民经济中也具有重要地位。
