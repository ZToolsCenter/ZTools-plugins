所罗门群岛元（Solomon Islands dollar）是所罗门群岛的法定货币，代码为SBD。其分为100个分币，主要采用纸币和硬币两种形式进行流通。

所罗门群岛元于1977年替代了原先的所罗门群岛英镑，成为该国的官方货币。纸币的面额包括$1、$2、$5、$10、$20、$50和$100，硬币的面额包括1、2、5、10、20和50分以及$1和$2。

所罗门群岛元的发行由所罗门群岛中央银行负责，该银行负责维持币值的稳定与货币政策的实施。所罗门群岛元的汇率受国际市场波动影响，通常与主要外国货币（如美元、澳元等）进行一定程度的挂钩。

在国际交易中，所罗门群岛元的使用范围有限，主要在国内进行流通和交易。对于外部投资者和国际贸易商而言，了解所罗门群岛元的汇率波动及市场环境十分重要。
