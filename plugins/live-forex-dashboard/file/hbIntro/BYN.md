白俄罗斯卢布（Belarusian Ruble），简称BYN，是白俄罗斯的法定货币。白俄罗斯卢布的符号为“Br”，并以其分单位“戈尔德”（groszy）表示，1卢布等于100戈尔德。

白俄罗斯卢布的历史可以追溯到1992年，当时作为苏联解体后白俄罗斯独立的标志之一，它替代了前苏联卢布。自那时起，卢布经历了多次贬值和货币重组。2016年，白俄罗斯政府进行了货币改革，重设了卢布的面值，以应对经济挑战。

白俄罗斯卢布由白俄罗斯国家银行发行和管理，其汇率受到多种经济因素的影响，包括通货膨胀、外部贸易、投资流动以及政治局势等。该货币的流通也受到国家货币政策的严格管理。

在国际外汇市场上，白俄罗斯卢布的流通性相对较低，主要使用于国内贸易和消费。在国外，白俄罗斯卢布的接受度有限，因此对于国际旅行者而言，建议事先了解汇率并准备好可广泛使用的硬通货如欧元或美元。
