葡萄牙埃斯库多（Portuguese Escudo）是葡萄牙的一种法定货币，直到2002年被欧元（Euro, EUR）所取代。埃斯库多的汇率在1999年被固定为200.482 escudos = 1 euro。在其流通周期中，埃斯库多经历了多次货币改革和历史变迁。

埃斯库多的符号为“Esc.”，并分为100个分币，称为“centavos”。在其流通的历史中，葡萄牙中央银行负责发行和管理埃斯库多。同时，埃斯库多在1990年代经历了通货膨胀和货币贬值，其购买力不断下降。

尽管埃斯库多目前不再作为法定货币，但在某些情况下，依然可以在集市或特殊场合被视为收藏品。尽管其法律地位已经废止，依然对研究葡萄牙经济历史和货币政策具有一定的学术价值。
