离岸人民币，通常称为CNH，是在中国境外市场交易的人民币（CNY）版本。离岸人民币的概念建立是为了促进国际贸易和投资，允许非居民使用人民币与中国企业进行交易，而不受在岸市场所施加的限制。

CNH的关键特点包括：

1. **市场可及性**：CNH可以自由交易，并且受到与中国政府严格控制的CNY不同的监管。这种灵活性允许中国以外的投资者和企业参与以人民币计价的交易。

2. **汇率动态**：由于香港等离岸中心的市场力量，CNH的汇率可能与CNY不同。这可能导致基于供求以及地缘政治和经济因素的波动。

3. **使用情况**：CNH主要用于国际贸易结算、外国投资，以及作为外汇储备的货币。它还被用于各种金融工具，包括债券（点心债券）和衍生品。

4. **监管**：尽管CNH的运作比CNY的监管要宽松，但仍有监管框架来促进贸易并维持离岸市场的稳定。

5. **全球化**：CNH的引入是中国使人民币国际化的更广泛战略的一部分，使其成为全球金融和贸易中更突出的货币。

6. **市场发展**：离岸人民币市场不断发展，交易量增加，外国银行和公司的接受度提高，增强了其作为国际金融中主要货币的角色。

总体而言，离岸人民币（CNH）在全球金融体系中扮演着重要角色，反映了中国经济影响力的增长，并为外国投资者更容易地进入中国市场提供了便利。
