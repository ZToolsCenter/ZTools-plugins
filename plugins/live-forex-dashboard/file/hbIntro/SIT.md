斯洛文尼亚托拉尔（Slovenian Tolar）是斯洛文尼亚在2007年1月1日之前的官方货币。托拉尔的国际标准货币代码为SIT，常用符号为TOL。托拉尔于1991年独立后正式投入流通，最初设计为替代前南斯拉夫第纳尔（Yugoslav dinar）。

托拉尔的货币单位分为100个分币（stotin），其钞票和硬币均由中央银行设计发行。常见面额的硬币有1、2、5、10、20和50托拉尔，而钞票的面额为100、200、500、1,000和5,000托拉尔。

2007年，斯洛文尼亚正式加入欧元区，托拉尔被欧元（EUR）所取代，汇率为1欧元等于239.640托拉尔。随之，托拉尔的法定货币地位被取消，所有托拉尔在法定流通中消失，消费者、商家与金融机构被要求逐步转换为欧元。

托拉尔在退出流通时，允许在一定期限内换回欧元，之后托拉尔不再被接受为支付手段。随着时间的推移，托拉尔成为历史货币，未在日常交易中使用。
