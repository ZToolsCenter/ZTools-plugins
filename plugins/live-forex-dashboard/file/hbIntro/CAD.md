加拿大元（CAD）是加拿大的法定货币，采用符号“$”或“C$”来标识以区别于其他国家的元（例如美国美元）。加拿大元的基本单位是分，1加元等于100分。

加拿大元是由加拿大银行（Bank of Canada）发行，并且在国际上被广泛使用。其货币代码为CAD，属于G10货币之一，常在外汇市场上进行交易。加拿大元的汇率受到多种因素的影响，包括经济指标、国际油价、政治事件和市场心理等。作为大宗商品货币，加拿大元特别受到能源价格波动的影响。

加元的纸币在2001年进行了重大的 redesign，采用聚合物材料，使其更加耐用，并增强了防伪特性。纸币的面值包括5加元、10加元、20加元、50加元和100加元。硬币则包括1分（已停止铸造）、5分、10分、25分、1加元和2加元。

加拿大元在国际贸易和投资中扮演重要角色，许多非加拿大全球被广泛接受作为交易货币。
