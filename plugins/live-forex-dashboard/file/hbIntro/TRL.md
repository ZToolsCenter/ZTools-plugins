土耳其里拉（Turkish Lira，通常以TRY为代码）是土耳其的官方货币。土耳其里拉经历了多次货币改革，并且在历史上曾先后使用了几种不同的里拉，直到2005年进行了重置，1新里拉（Yeni Türk Lirası）等于1,000,000旧里拉。2005年的改革在货币符号和单位上进行了更新，推出了新的货币符号₺。

土耳其里拉的价值受到多种因素的影响，包括土耳其的经济政策、通货膨胀率、外部经济环境及地缘政治风险。近年来，里拉经历了显著的贬值，其汇率波动受到国际市场及投资者信心的强烈影响。

土耳其里拉在国际金融市场上的流通相对有限，其主要用途为国内交易及投资。鉴于经济波动及汇率不稳定，投资者在考虑使用或投资土耳其里拉时需进行谨慎的市场分析。
