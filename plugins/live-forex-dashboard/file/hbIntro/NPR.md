尼泊尔卢比（Nepalese Rupee，符号：Rs，货币代码：NPR）是尼泊尔的法定货币。它由尼泊尔中央银行（Nepal Rastra Bank）发行和管理。尼泊尔卢比的分为100个比索（ paisa），尽管因通货膨胀，较小面额的比索硬币在日常交易中已不常使用。

尼泊尔卢比的面额通常包括纸币和硬币。纸币的面额包括Rs 1, Rs 2, Rs 5, Rs 10, Rs 20, Rs 50, Rs 100, Rs 500 和 Rs 1000等，硬币的面额包括1、2、5、10、25和50比索等。

该货币在国际外汇市场的流通较为有限，汇率受到多种因素影响，包括经济状况、贸易平衡、外资流入流出等。与其他货币的汇率波动需要关注尼泊尔的经济与政治环境、以及印尼、印度等邻国的经济状况，因为这些因素可能会对卢比的价值造成重大影响。

尼泊尔卢比主要与印度卢比（INR）实行一种固定汇率制度，历史上印尼卢比在尼泊尔经济中占据重要地位，导致尼泊尔的货币政策受到印度经济影响。需要注意的是，境外对尼泊尔卢比的接受程度相对有限，因此国际支付通常需要通过其他主要货币进行。

总体而言，尼泊尔卢比的使用受到该国社会经济发展的推动，有助于支持尼泊尔的国内交易与外部经济活动。
