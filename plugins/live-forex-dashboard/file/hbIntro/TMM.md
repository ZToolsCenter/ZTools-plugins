土库曼斯坦马纳特（Turkmenistani Manat）是土库曼斯坦于1993年开始使用的货币单位。它的代码为TMM。马纳特的发行旨在取代苏联卢布，成为独立后的国家货币象征。

土库曼斯坦马纳特经历了多次货币改革。第一次重大改革发生于2000年，伴随着货币贬值，新的马纳特（TMT）于2009年被引入，以降低高面额货币的使用。2009年的改革将原有的马纳特以1:5000的比例进行兑换，新的马纳特代替了旧马纳特成为土库曼斯坦的法定货币。

土库曼斯坦马纳特的设计主要体现了土库曼民族文化及历史，货币背面常常印有国家的标志性建筑和自然景观。

如今，土库曼斯坦马纳特（TMT）仍在流通，并且是由土库曼斯坦中央银行负责发行和管理。

需要注意的是，货币的稳定性和流通性可能受到多种因素的影响，包括国家的经济政策、国际油价波动及其对土库曼斯坦经济的影响。使用土库曼斯坦马纳特进行国际交易可能面临困难，主要因其流动性有限。

货币的价值和兑换率会受到市场供需关系的直接影响，建议在进行相关货币交易或投资前，咨询具体的金融专业人士。
