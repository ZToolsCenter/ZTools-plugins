科摩罗法郎（Comorian franc，货币符号：KMF）是科摩罗联邦的法定货币。其最初发行于1970年，取代了原有的法郎。科摩罗法郎的分币单位为塞尔（cent）1法郎等于100塞尔。 

科摩罗法郎由科摩罗中央银行（Banque Centrale des Comores）负责发行和管理。该货币的汇率与其他货币之间的浮动相对较大，常受市场供需、经济状况及外汇市场波动的影响。

在流通时，科摩罗法郎的纸币面额包括500、1,000、2,000、5,000和10,000法郎，而硬币面额则包括1、5、10、20、50、100和200法郎。在国际贸易中，科摩罗法郎的使用较为有限，主要用于国内交易。 

需要注意的是，因经济、政治因素，科摩罗法郎的稳定性相对较低，且通货膨胀可能会影响其购买力。因此，在进行货币兑换或投资时，应充分考虑相关风险。
