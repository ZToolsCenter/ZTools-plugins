乌干达先令（Ugandan Shilling，代码：UGX）是乌干达的法定货币，采用符号“Sh”或“UGX”。乌干达先令由乌干达中央银行发行，首次引入于1987年，取代了此前的乌干达镑。

乌干达先令分为100分（Cent）。纸币的面额有1,000先令、2,000先令、5,000先令、10,000先令、20,000先令、50,000先令和100,000先令。硬币的面额包括50分、100分、200分、500分和1,000先令。

汇率浮动受多种因素影响，包括国内经济状况、国际市场波动、货币政策及政治稳定性等。乌干达先令在国际外汇市场上的流动性相对较低，主要用于区域内交易。

乌干达先令的主要应用场景包括个人消费、商业交易以及各类形式的储蓄。此外，乌干达政府通过主权债券和其他金融工具使用先令进行融资。
