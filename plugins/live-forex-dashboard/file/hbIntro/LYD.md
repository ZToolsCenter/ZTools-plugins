利比亚第纳尔（Libyan Dinar，代码：LYD）是利比亚的官方货币。该货币于1971年首次发行，取代了前使用的利比亚镑。利比亚第纳尔的符号为"ل.د"，其中1第纳尔划分为1000大比尔。

自发行以来，利比亚第纳尔经历了多次汇率变动和经济政策调整。根据利比亚中央银行的规定，第纳尔的发行和流通受到严格监管。货币的形态包括纸币和硬币，纸币的面额通常有1、5、10、20和50第纳尔，而硬币通常有1、5、10、25和50大比尔。

在国际外汇市场上，利比亚第纳尔被视为相对不稳定的货币，受到利比亚经济状况及国内政治环境的影响。利比亚的经济主要依赖石油出口，因此，国际油价变动对第纳尔的汇率有直接影响。

需要注意的是，由于2011年阿拉伯之春以及后续的内战，利比亚的金融体系和货币政策经历了重大变化，造成第纳尔汇率波动加大，国际贸易和外汇兑换的可预见性降低。在进行货币兑换时，建议关注最新的市场汇率及相关经济动态。
