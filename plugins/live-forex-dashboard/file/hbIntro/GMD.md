冈比亚达拉西（Gambian Dalasi，简称GMD）是冈比亚的官方货币。它由冈比亚中央银行发行，是按十进制体系设计的，1达拉西等于100分（Butut）。达拉西的名称源于当地语言，意为“货币”。

冈比亚达拉西最初于1971年推出，取代旧的货币单位——冈比亚镑。该货币以纸币和硬币两种形式流通。纸币面额包括5达拉西、10达拉西、20达拉西、50达拉西、100达拉西和200达拉西。硬币则有1分、5分、10分、25分、50分和1达拉西的面额。

冈比亚经济主要依赖农业和旅游业，达拉西的汇率受这些因素的显著影响，因此在国际汇率市场中，冈比亚达拉西相对其他主要货币的波动性较大。近年来，为了应对经济挑战，冈比亚中央银行采取了一系列货币政策，旨在稳定达拉西的价值。
