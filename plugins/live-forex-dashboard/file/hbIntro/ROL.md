罗曼尼亚列伊（Romanian Leu，货币符号：RON）是罗马尼亚的法定货币。列伊的历史可以追溯到19世纪，其名称源于历史上的“雄狮”（leu），这是一个在区域内广泛使用的货币象征。

然而，罗马尼亚在2005年前已经经历了货币改革，将旧列伊（ROL）转换为新列伊（RON），实行了1新列伊等于10,000旧列伊的转换率。新列伊是由国家中央银行（罗马尼亚国家银行）发行并监管的，分为100个分勒伊（ban）。

从1989年起，罗马尼亚逐步向市场经济转型，基础设施和金融系统经历了重大改革。这些改革导致列伊汇率的波动以及与其他主要货币（如欧元、美元等）的相对稳定性提高。

目前，罗马尼亚列伊在国内用于日常交易，接受其作为现金支付的商户众多。虽然罗马尼亚于2007年加入欧盟，但尚未采用欧元，未来何时过渡到欧元仍有待进一步政策决定。
