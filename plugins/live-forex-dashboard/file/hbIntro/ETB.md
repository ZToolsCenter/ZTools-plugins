埃塞俄比亚比尔（Ethiopian Birr，代码：ETB）是埃塞俄比亚的法定货币。比尔的名字源于埃塞俄比亚的传统货币“比尔”，并在1976年被正式作为国家货币推出。比尔分为100个青尼罗（cent）。

当前聚焦于埃塞俄比亚比尔的主要特点如下：

1. **货币符号**：比尔通常以“ብር”表示。

2. **发行机构**：埃塞俄比亚国央行（National Bank of Ethiopia）负责比尔的发行和监管。

3. **汇率**：比尔的汇率受到多种因素的影响，包括经济政策、通货膨胀、外汇储备等。汇率会因市场波动而有所变化。

4. **纸币与硬币**：埃塞俄比亚比尔的纸币面额包括1、5、10、50、100比尔。硬币则包括1、5、10、25、50青尼罗和1比尔。

5. **经济状况**：埃塞俄比亚经济结构较为特殊，农业占据主导地位，近年在工业和服务业方面也有所发展，对比尔的价值产生一定影响。

6. **国际使用**：埃塞俄比亚比尔主要在国内流通，国际上接受程度较低，通常需通过外汇交易转换为其他货币进行国际交易或旅游活动。
