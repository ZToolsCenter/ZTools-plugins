伊拉克第纳尔（Iraqi dinar，ISO 4217代码为IQD）是伊拉克的法定货币。伊拉克第纳尔首次发行于1932年，取代了之前的伊拉克镑。第纳尔的分币单位包括菲尔斯（fils），1第纳尔等于1,000菲尔斯。

伊拉克第纳尔的货币符号为"ع.د"，通常在国际市场上以IQD表示。该货币受到伊拉克中央银行的监管。近年来，因经济、政治及安全形势的复杂性，第纳尔的汇率受到较大的波动。官方汇率和黑市汇率之间通常存在显著差异，影响了第纳尔的国际购买力。

伊拉克第纳尔的现行纸币面额包括250、第500、第1,000、第5,000、第10,000、第25,000和第50,000第四代纸币，设计上体现了伊拉克的文化、历史和自然景观。由于其汇率的不稳定性及其他经济因素，持有伊拉克第纳尔的风险相对较高，投资者应谨慎评估相关风险。
