立陶宛立特（Litas，符号：Lt，ISO代码：LTL）是立陶宛的法定货币，直至2015年1月1日被欧元（EUR）替代。立特的历史可以追溯到1922年，当时被引入以替代占领期间的外国货币。立特在1990年代恢复独立后重新被采用，并成为国内经济的重要组成部分。

立特的分币单位为“阿尔法”（cent，符号：cnt），1立特等于100阿尔法。在使用立特期间，中央银行发布了不同面额的纸币和硬币，其中纸币的面额通常为10、20、50、100、200和500立特，而硬币则包括1、2、5、10、20和50阿尔法以及1、2和5立特。

在立陶宛正式加入欧元区后，立特的放弃和欧元的采用旨在促进经济稳定和发展，提高国际竞争力。立特的历史和过渡至欧元的过程，反映了立陶宛在金融领域的演变及其与欧盟的整合。
