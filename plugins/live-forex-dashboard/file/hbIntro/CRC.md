哥斯达黎加科朗（Costa Rican Colón，ISO 4217代码：CRC）是哥斯达黎加的官方货币。该币种的名称“科朗”源于西班牙语，意为“圈”，其货币符号为₡。哥斯达黎加科朗分为100分（céntimos）。 

历史背景：
科朗于1896年首次发行，取代了当时的哥斯达黎加比索。货币发行由哥斯达黎加中央银行（Banco Central de Costa Rica）负责，其主要职责是维护国家货币的稳定和微观经济的健康运行。

流通及面值：
科朗的流通有纸币和硬币两种形式。纸币通常包括1000、2000、5000、10000、20000和50000科朗的面值。硬币的面值包括5、10、25、50、100和500科朗。

汇率：
科朗的汇率受到多个因素的影响，包括经济状况、国际市场波动及货币政策。消费者和投资者在进行货币兑换和国际交易时需关注当前的汇率动态。

经济地位：
哥斯达黎加科朗在国际外汇市场的利用率相对有限。此外，该国经济以农业、旅游和服务业为主，货币政策及其稳定性在一定程度上影响着外资流入和经济增长。
