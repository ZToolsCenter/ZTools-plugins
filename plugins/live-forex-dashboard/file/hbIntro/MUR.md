毛里求斯卢比（Mauritian Rupee，简称MUR）是毛里求斯的法定货币。它由毛里求斯中央银行发行，符号为"Rs"或"₨"。毛里求斯卢比可分为100分（cents）。

**汇率**：毛里求斯卢比的汇率对其他主要货币如美元、欧元及英镑等会有所波动，受到国际市场因素、经济政策及外汇市场的影响。

**纸币与硬币**：毛里求斯卢比的纸币面额包括20、50、100、200、500和1000卢比。硬币则通常包括1、5、10和20卢比，以及一些分币如1、5、10和20分。

**经济背景**：毛里求斯是一个多元化的经济体，主要依靠旅游、农业（尤其是甘蔗）与制造业。货币政策旨在保持通货膨胀在可控范围内，促进经济稳定与可持续发展。

**国际使用**：毛里求斯卢比在国际贸易中相对不常用，主要在国内使用。对于计划进行货币兑换或投资毛里求斯市场的客户，建议关注最新的汇率信息和经济政策，确保作出明智的财务决策。
