津巴布韦元（Zimbabwe Dollar, ZWD）是津巴布韦的法定货币，但其历史上经历了多次变迁。最初于1980年引入，此后由于经济危机、超高通货膨胀和货币贬值，津巴布韦元于2009年停止使用，国家转而采用外币（如美元和南非兰特）进行交易。

2019年，津巴布韦政府重新引入新津巴布韦元（RTGS Dollar, ZWL$），旨在恢复国内货币体系。然而，新津巴布韦元的稳定性面临挑战，目前仍受通货膨胀和经济政策的影响。

新津巴布韦元以RTGS为基础，成为津巴布韦国内交易的主要媒介。需要注意的是，由于经济状况及政策变化，津巴布韦元的汇率波动较大。此外，津巴布韦央行也可能会采取不同的货币政策以应对宏观经济情况。

在进行国际交易或投资有关津巴布韦的金融产品时，需格外关注其货币政策及市场动态。
