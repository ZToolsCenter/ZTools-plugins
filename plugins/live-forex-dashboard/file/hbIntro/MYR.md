马来西亚林吉特（Malaysian Ringgit，符号：RM，货币代码：MYR）是马来西亚的法定货币。林吉特的历史可以追溯到1967年，当时作为马来西亚独立后的货币单位正式引入。林吉特的币值分为100仙（sen）。

马来西亚林吉特由马来西亚中央银行（Bank Negara Malaysia）发行与管理。该银行负责制定货币政策，维护货币的稳定性及金融系统的稳定。林吉特在国际货币市场上被交易，与多种主要货币（如美元、欧元和英镑）进行兑换。

林吉特在流通中有多种纸币和硬币，纸币面额包括1、5、10、20、50和100林吉特；硬币面额则有1、5、10、20和50仙以及1林吉特。林吉特的价值受多种因素影响，包括经济数据（如通货膨胀与国内生产总值）、国际市场的供求关系、政治稳定性及货币政策等。

近期，马来西亚林吉特相对稳定，尽管在全球经济环境变动及区域性经济波动中，其兑换率可能出现波动。林吉特在东南亚区域内的交易和流通较为广泛，也是该地区的重要经济指标之一。
