印度尼西亚卢比（Indonesian Rupiah，货币符号为IDR）是印度尼西亚的法定货币。其主要特点和相关信息如下：

1. **货币代码**：IDR
2. **发行机构**：印度尼西亚央行（Bank Indonesia）负责卢比的发行和管理。
3. **历史背景**：卢比最早于1946年发行，替代了在殖民时期使用的荷兰货币。经过多次贬值和重新设计，现代卢比的前身为1965年引入的新卢比。
4. **面值**：卢比的纸币面值包括1000、2000、5000、10000、20000、50000及100000等不同面额。硬币面值有100、200、500及1000等。
5. **汇率**：卢比对其他货币的汇率浮动较大，受经济、政治及国际市场变化影响。汇率在需要时应通过合法渠道查询最新情况。
6. **通货膨胀**：印度尼西亚历史上曾经历较高的通货膨胀，政府和央行采取了一系列措施以控制物价稳定。
7. **国际使用**：尽管卢比主要在印度尼西亚境内使用，但在某些情况下，如旅游或商品交易中，可能会接受其他货币。卢比在国际外汇市场的流通性较低。

投资者和外汇交易者在进行相关交易时，需关注卢比的市场动态、经济指标以及政治稳定性，这些因素都会影响其汇率及投资价值。
