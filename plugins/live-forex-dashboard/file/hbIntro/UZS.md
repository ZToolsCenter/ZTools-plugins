乌兹别克斯坦索姆（Uzbekistani Som，ISO 4217代码：UZS）是乌兹别克斯坦的法定货币。索姆的符号为 "сум"（在当地书写）或 "so'm"（拉丁字母）。其历史可以追溯到1994年，当时为了替代原先的货币系统而被引入。

货币单位的分单位为“蒂金”（tiyin），价值为1/100索姆。需要注意的是，由于通货膨胀等因素，蒂金在日常交易中已几乎不被使用。乌兹别克斯坦中央银行负责索姆的发行与管理，并通过货币政策维护货币稳定。

索姆在流通中有多种面值的纸币和硬币。纸币面值通常涵盖1, 5, 10, 50, 100, 200, 500, 1,000, 5,000, 10,000和50,000索姆。硬币则包括1、5、10和50索姆。

乌兹别克斯坦索姆在国际市场上的流通性较低，主要用于国内经济活动。对于外汇交易和国际支付，通常需进行货币兑换。索姆的汇率可能会受到经济政策、市场供需及国际环境的影响。

了解具体的汇率信息和金融产品建议，应咨询相关金融机构或访问乌兹别克斯坦中央银行官方网站。
