挪威克朗（Norwegian Krone，币符：NOK）是挪威的法定货币。克朗的名称源于古诺尔斯语中的“克朗”，意为“王冠”。挪威克朗的分币单位为“耳尔”（øre），在当前使用中1克朗等于100耳尔。

挪威克朗是由挪威中央银行（Norges Bank）发行和管理。挪威中央银行的主要职责包括货币政策的制定、金融稳定的维护以及对银行体系的监管。克朗在外汇市场上交易，受多种因素影响，包括挪威的经济表现、油价波动、利率政策等。

挪威是一个拥有丰富自然资源的国家，尤其是石油和天然气，这些资源在国际贸易中占有重要地位。挪威克朗常常被视为与商品市场紧密相关的货币，其汇率波动可能受到全球市场动态的显著影响。

在挪威，纸币和硬币的面额包括：纸币有1、5、10、20、50、100、200和500克朗的面额，硬币则有1、5、10、20克朗和5、10、20耳尔的面额。设计上，挪威克朗的纸币展现了挪威文化、历史和自然风光。

总的来说，挪威克朗是一个稳定性较高的货币，且根据经济形势和政策的变化，其国际市场表现较为活跃。
