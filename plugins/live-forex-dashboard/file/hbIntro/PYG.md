巴拉圭瓜拉尼（Guaraní）是巴拉圭的法定货币，货币代码为PYG。它以巴拉圭的原住民语言命名，反映了该地区的文化遗产。瓜拉尼被分为100分（céntimos）。

巴拉圭瓜拉尼的历史可以追溯到1944年，当时它取代了旧的货币单位“巴拉圭瓜拉尼”。该货币主要由巴拉圭中央银行发行。设计上，瓜拉尼的纸币和硬币上通常印有国家的历史人物、文化象征和自然景观。

巴拉圭瓜拉尼的汇率受多种因素影响，包括经济状况、国际市场情况以及通货膨胀率等。在国际市场上，瓜拉尼的流动性相对较低，主要在巴拉圭国内交易。

适用场景包括日常消费、商业交易及各类金融活动。对于外籍人士而言，通常建议在当地进行货币兑换，使用信用卡或旅行支票作为替代支付方式。

请注意，货币的实际使用和流通情况可能因时间和市场变化而有所不同，因此建议在涉及金融交易时，参考最新的市场信息和汇率。
