法郎（Franc）是曾经使用于法国及其一些附属国的货币单位。法郎的历史可追溯至中世纪，最初用作金币的名称，后逐渐演变为银币和纸币。

法郎在20世纪经历了几次重要的变化。1945年后，法国实施了货币改革，推出了“新法郎”（nouveau franc），其值为旧法郎的100倍。新法郎在2002年被欧元取代，法国正式加入欧元区，法郎在市场上结束流通。

法郎的废弃使法国在货币政策、经济管理及国际金融市场上步入了一个新的阶段。自2002年起，法郎的所有银行券和硬币都无法再在商业交易中使用，官方也不再以法郎进行任何经济交易。

此后，法郎作为一种货币单位的象征价值逐渐降低，但在集邮、历史收藏及文化研究中仍然保持了一定的历史地位。
