毛里塔尼亚乌吉亚（Mauritanian Ouguiya），符号为MRU，是毛里塔尼亚的法定货币。乌吉亚的历史可以追溯到1973年，当时替代了之前的货币——西非法郎。毛里塔尼亚乌吉亚分为100个古吉亚（khoums）。

在2020年，毛里塔尼亚政府进行了货币重估，将旧乌吉亚与新乌吉亚的比率设定为1新乌吉亚（MRU）等于100旧乌吉亚。新乌吉亚的纸币和硬币面额包括5、10、20、50、100、200、500和1000乌吉亚，不同面额的纸币和硬币在流通中被广泛使用。

毛里塔尼亚央行负责乌吉亚的发行和管理。该货币在国际交易中的接受度较低，通常在毛里塔尼亚国内市场和相关的地区贸易中使用，汇率波动受到市场供求、经济政策及国际经济环境的影响。
