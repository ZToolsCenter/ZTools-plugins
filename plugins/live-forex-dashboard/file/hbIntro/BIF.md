布隆迪法郎（Burundian franc，缩写为BIF）是布隆迪的官方货币。布隆迪法郎分为100个法郎分（centimes），但法郎分在实际交易中已不再流通。布隆迪法郎自1970年起作为正式货币使用，取代了之前的布隆迪基尔。

布隆迪法郎的汇率相对不稳定，受到布隆迪经济、政治局势、国际市场和货币政策等多种因素的影响。目前，其与主要国际货币的汇率信息可以通过各大金融机构和外汇市场查询。

布隆迪法郎的主要面额包括纸币和硬币。纸币面额有1,000法郎、5,000法郎、10,000法郎等，硬币则有50法郎、100法郎等。

需要注意的是，布隆迪的经济状况较为脆弱，货币贬值现象较为严重，通货膨胀也时有发生，这对布隆迪法郎的稳定性构成了挑战。
