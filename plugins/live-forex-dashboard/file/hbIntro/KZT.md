哈萨克斯坦坚戈（Kazakhstani Tenge，符号：₸，ISO 4217代码：KZT）是哈萨克斯坦的法定货币。坚戈于1993年11月15日首次发行，取代了之前的苏联卢布。

坚戈分为100个提延（tiyin），但提延的流通量较少，日常交易中常以坚戈进行结算。坚戈的发行和管理由哈萨克斯坦国家银行负责，该行负责维持货币政策和金融稳定。

坚戈的汇率受到市场供求关系、国际油价、地缘政治及经济形势等多种因素的影响。在国际市场上，坚戈通常与美元和欧元等主要货币进行兑换。

在哈萨克斯坦的经济中，坚戈被用于所有的商品和服务交易，是国内经济活动的基础。了解坚戈的走势和相关经济指标对于投资者和经济分析师至关重要。
