圣赫勒拿镑（Saint Helena pound）是南大西洋圣赫勒拿岛的官方货币。其符号为SHP，属于英镑的一个分支，与英镑的汇率固定为1:1。圣赫勒拿镑与英镑的流通是相互承认的，即在圣赫勒拿岛可以使用英镑，而在英国也可以使用圣赫勒拿镑。

圣赫勒拿镑的纸币和硬币由圣赫勒拿岛的金融管理部门发行，设计上常常体现该岛的自然景观、历史和文化元素。尽管圣赫勒拿镑主要在岛上流通，它在国际市场上的流通性相对较低，主要因为这是一种小型经济体系的货币，大多数国际交易通常使用更为常见的货币，如美元或欧元。

圣赫勒拿岛的经济主要依赖于农业、旅游和外汇收入，其货币政策也受到英国央行的影响，确保经济稳定及适度通货膨胀的控制。由于其金融市场的规模较小，圣赫勒拿镑并不具备与大型货币相比的流动性。
