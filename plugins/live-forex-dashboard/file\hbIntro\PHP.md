菲律宾比索（Philippine Peso，货币符号：₱，ISO 4217代码：PHP）是菲律宾的法定货币。比索分为100分（centavos），其货币单位的简称为“P”或“PHP”。菲律宾比索由菲律宾中央银行（Bangko Sentral ng Pilipinas，BSP）负责发行和管理。

菲律宾比索的纸币目前的常见面值包括20、50、100、200、500和1000比索，各面值纸币的设计包括国家重要人物、文化景观及历史事件的图案。硬币面值包括1、5、10、25分和1、5、10比索。

汇率方面，菲律宾比索对其他主要货币（如美元、欧元等）的汇率会受多种因素影响，包括经济基本面、国际金融市场动态以及菲律宾的政治经济稳定性。因此，如需进行投资或外汇交易，建议及时查阅最新的汇率信息和市场动态。
