澳大利亚元（Australian Dollar，符号：AUD）是澳大利亚的法定货币。它于1966年新元制度改革时引入，替代了旧的澳大利亚英镑。澳大利亚元的汇率与世界主要货币如美元、欧元和日元等有较强的流动性。 

澳大利亚元由澳大利亚皇家铸币厂铸造，根据国际标准分为硬币和纸币两种形式。硬币面值包括5分、10分、20分、50分，以及1元和2元；纸币则有5元、10元、20元、50元和100元，纸币材质为聚合物，具有更高的耐用性和防伪特性。

澳大利亚元不仅在澳大利亚使用，还是一些太平洋岛国（如基里巴斯、图瓦卢和瓦努阿图等）的官方货币之一。根据国际标准化组织的ISO 4217编码，澳大利亚元的代码是AUD。

作为一种储备货币，澳大利亚元在国际市场上具有重要地位，其汇率受多种经济因素影响，包括但不限于澳大利亚的经济指标、利率政策、国际贸易状况以及全球市场的风险情绪等。此外，澳大利亚作为资源丰富的国家，其出口商品（如矿产、农产品）对澳大利亚元的价值亦有显著影响。
