斯洛伐克克朗（Slovak Koruna，代码：SKK）曾是斯洛伐克共和国的官方货币，直到2009年1月1日被欧元（EUR）取代。斯洛伐克克朗在1993年1月1日成为独立货币，随着捷克斯洛伐克的分裂而开始流通。

斯洛伐克克朗的分为100哈洛特（halier），并发行了包括纸币和硬币在内的多种面额。纸币面额包括：20、50、100、500、1000和5000克朗，硬币则包括：1、2、5、10、20、50哈洛特以及1、2、5、10、20、50克朗。

随着斯洛伐克于2009年加入欧元区，克朗被淘汰，政府实施了货币转换政策，按1欧元=30.1260克朗的固定汇率进行兑换。废弃后，斯洛伐克克朗不再具有货币流通价值，但仍可在特定情况下进行兑换，具体政策由斯洛伐克国家银行规定。
