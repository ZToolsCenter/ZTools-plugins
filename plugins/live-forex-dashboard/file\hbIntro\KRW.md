韩元（KRW）是韩国的法定货币，属于货币单位。其符号为"₩"，ISO 4217代码为"KRW"。韩元最早于1902年发行，经过多次调整与改革，目前采用的是2007年进行的小额面额更替政策。韩元分为不同面额的纸币和硬币，最常见的纸币面额包括1,000元、5,000元、10,000元和50,000元，硬币则有1元、5元、10元、50元、100元和500元。

韩元的汇率受到多种因素影响，包括经济发展、国际贸易、外汇市场投机以及政策变化等。韩国中央银行—韩国银行负责韩元的发行和管理，并实施货币政策以稳定物价和促进经济发展。韩元通常在国际外汇市场上与其他主要货币进行交易。

在国际贸易中，韩元的使用范围较广，尤其是在与中国、美国及其他亚洲国家的贸易往来中。尽管韩元在国际市场上的流通性相对较低，但随着韩国经济的发展和全球化进程的加快，其国际化程度正在逐步提高。
