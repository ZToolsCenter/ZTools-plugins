圣多美多布拉（Dobra）是圣多美和普林西比（São Tomé and Príncipe）曾使用的货币单位。在1997年之前，该国的官方货币是多布拉，分为100分。在此之后，货币被废弃并替换为圣多美多布拉（New Dobra），以应对经济通货膨胀和货币贬值等问题。

1. **历史背景**：多布拉的名称源于葡萄牙语“dobra”，意为“折叠”，在1990年代以来，该货币经历了多次贬值，政府在1997年首先进行货币改革，推出了新多布拉，其与旧多布拉的汇率为1新多布拉=1,000旧多布拉。

2. **货币符号与代码**：新多布拉（STN）是圣多美多布拉的货币代码，常用的符号是“Db”。

3. **流通情况**：新多布拉在1997年后成为该国的法定货币，但由于经济条件的变化和外汇市场的影响，货币的流通和流动性受到限制。当前，新多布拉在国际市场上的接受程度较低，主要用于国内交易。

4. **汇率**：新多布拉的汇率波动可能较大，受多种经济因素影响，包括通货膨胀率、国际市场对咖啡和可可等主要出口商品的需求等。

5. **当前状态**：目前该货币仍在使用中，但由于经济挑战，圣多美和普林西比的金融稳定性整体较弱，国际投资者对该国充满谨慎态度。

总体而言，圣多美多布拉在国际金融市场的地位较为微弱，主要用于国内交易，外部经济环境对其价值的影响较大。
