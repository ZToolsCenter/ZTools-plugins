波斯尼亚可兑换马尔卡（Bosnia and Herzegovina Convertible Mark，简称BAM）是波斯尼亚和黑塞哥维那的法定货币。该货币于1998年引入，以替代之前的波斯尼亚和黑塞哥维那丁（BHD）。波斯尼亚可兑换马尔卡与欧元的汇率是固定的，1 BAM 大约等于 0.51129 欧元。 

BAM 采用可兑换的机制，旨在促进国内外的经济交易。该货币的符号为"КМ"（拉丁字母"C"和"M"），并以硬币和纸币的形式存在，硬币面值包括 5, 10, 20, 50 分马尔卡及 1、2、5 马尔卡，纸币面值则包括 1、5、10、20、50、100 和 200 马尔卡。 

通货膨胀和汇率波动通常受到国家经济政策、国际市场条件以及地区经济状况的影响。在进行跨境交易和投资时，了解 BAM 的汇率动态是十分重要的。
