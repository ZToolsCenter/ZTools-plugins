苏丹第纳尔（Sudanese Dinar）曾是苏丹使用的货币单位，发行于1992年，替代了以前的苏丹镑。该货币分为100个吉尔（giro）。然而，由于经济不稳定、通货膨胀及货币贬值等原因，苏丹第纳尔在2007年被苏丹镑（Sudanese Pound）取代。

苏丹第纳尔的流通时间短暂，其在国际市场上并未形成广泛的稳定性和认可度。在该货币存在的期间，其兑换率也经历了显著的波动。因此，对于历史研究或经济分析而言，苏丹第纳尔的相关数据可能具有一定的参考价值，但其实际使用价值已归于历史。

苏丹目前的法定货币为苏丹镑（SDG），持续受到经济政策和国际市场动态的影响。有关苏丹货币政策、汇率及其他经济指标的信息，建议参考中央银行发布的官方数据。
