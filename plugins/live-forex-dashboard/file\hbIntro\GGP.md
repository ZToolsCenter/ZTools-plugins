根西岛镑（Guernsey Pound，简称GUP）是根西岛（Guernsey）使用的法定货币。其汇率与英镑（GBP）持平，因此1根西岛镑等于1英镑。根西岛镑由根西岛政府发行，通常用于该岛的流通。

根西岛镑的纸币和硬币设计上明显区别于英镑，具有当地特色的图案，例如岛上的风景、动物以及历史人物等。根西岛镑的纸币主要由5镑、10镑、20镑和50镑等面值构成，而硬币则包括1便士到1镑的各个面值。

在国际交易中，根西岛镑通常不被广泛接受，因此在离开根西岛时，持有的根西岛镑应当在离开时兑换成英镑或其他国际货币。根西岛与英国之间的关系使得这种货币得以在该区域内发挥作用，但根西岛镑并非英格兰的一部分，因此其货币政策独立于英格兰银行。
