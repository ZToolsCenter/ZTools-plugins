巴巴多斯元（Barbadian Dollar，货币符号：BDS$或$）是巴巴多斯的法定货币。它的国际标准ISO 4217代码为BBD。巴巴多斯元的分币为分（cent），1巴巴多斯元等于100分。

巴巴多斯元的汇率通常与美元挂钩，1巴巴多斯元约等于0.50美元（United States Dollar, USD），具体汇率可能随着市场波动而变化。巴巴多斯元由巴巴多斯中央银行发行，该银行负责货币政策的制定和货币的稳定。

巴巴多斯元的纸币面额包括2、5、10、20、50以及100元，硬币面额包括1分、2分、5分、10分、25分和1元。该货币的设计上通常会采用巴巴多斯的历史和文化元素，如国家的标志性建筑、著名人物和自然景观。

在国际贸易和旅游中，巴巴多斯元的使用受到广泛认可，但对于国际交易，通常会建议使用美元或其他主要货币。巴巴多斯元在一些加勒比地区国家也可流通，具体取决于各国的货币政策和经济状况。
