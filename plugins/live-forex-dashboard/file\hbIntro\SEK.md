瑞典克朗（Swedish Krona），国际标准代码为SEK，是瑞典的官方货币。其名称“克朗”源于中世纪时期使用的“克朗币”，而“瑞典克朗”则是指瑞典的货币单位。瑞典克朗分为100厄瑞克（öre），尽管自2020年起厄瑞克不再实际流通。

瑞典克朗由瑞典国家银行（Sveriges Riksbank）发行，其现行纸钞和硬币系列包括不同面额的纸币（20克朗、50克朗、100克朗、200克朗、500克朗和1000克朗）以及硬币（1克朗、2克朗、5克朗、10克朗和20克朗）。瑞典克朗的设计注重国家文化和历史，纸币上通常印有著名瑞典人物的肖像和具有文化价值的图案。

作为一种货币，瑞典克朗在国际金融市场上具有流动性，其汇率受多种经济因素影响，包括瑞典的经济表现、利率政策以及国际市场的波动。瑞典克朗在外汇交易中被看作是一种稳定的货币，且瑞典政府维持着较低的通货膨胀率，使其在全球货币体系中具有一定的信用度。

目前，瑞典已决定不加入欧元区，未来的货币政策将继续根据国内经济状况进行调整。瑞典国家银行致力于保持价格稳定和促进金融系统的稳定。
