马达加斯加法郎（Malagasy Franc）是一种已废弃的货币单位，曾用于马达加斯加。该货币在1973年之前有效，后来被马达加斯加阿里亚里（Malagasy Ariary）取代，后者于1976年正式投入使用。

马达加斯加法郎的货币代码为MGF，分为100个分币（centimes）。在1970年代之前，马达加斯加在与法国的货币联系中使用法郎，随后的货币改革旨在创造一个更加独立的经济体系。

马达加斯加阿里亚里的引入标志着国家货币政策的重大转变，并为了适应当时经济的发展需求。现今，马达加斯加阿里亚里为马达加斯加的法定货币，1阿里亚里分为5个分币（iraimbilanja）。马达加斯加法郎现已失去流通和法律地位，成为历史遗留货币。
