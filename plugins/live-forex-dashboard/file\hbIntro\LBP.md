黎巴嫩镑（Lebanese Pound, ISO 4217代码：LBP）是黎巴嫩的法定货币。根据历史背景，黎巴嫩镑在1939年首次被引入，取代了先前使用的法郎。其货币符号为“ل.ل.”，通常以“LBP”或“ليرة”表示。

黎巴嫩中央银行是负责发行和管理黎巴嫩镑的机构。自2020年起，黎巴嫩经济经历了严重的货币危机，导致镑汇率大幅波动，政府采取了一系列措施应对经济挑战和货币贬值。

黎巴嫩镑的面值包括纸币和硬币，纸币的面额从1,000镑到100,000镑不等，硬币则主要有1镑、5镑、10镑、25镑、50镑和100镑等面值。尽管官方汇率存在，实际市场汇率可能因经济环境而显著不同。

对于进行货币交易或投资，需留意黎巴嫩镑的汇率变化和相关的市场风险。
