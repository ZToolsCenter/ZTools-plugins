古巴可兑换比索（Cuban Convertible Peso，简称CUC）是古巴曾经使用的一种货币，主要用于外国游客和一些特定的商业交易。自2011年起，古巴政府逐步实施了一系列货币改革，以减少对双重货币体系的依赖。2021年1月1日，古巴正式宣布停止可兑换比索的使用，将其替换为古巴比索（Cuban Peso，CUP）。

可兑换比索在流通时与美国美元相对接，通常被视为一个较为稳定的货币。然而，由于古巴的经济政策和市场环境，CUC的价值并不完全反映真实的市场交易价值。改革后，古巴比索成为主要流通货币，任何相关交易及金融活动现以古巴比索进行。

请注意，关于古巴的经济和货币政策的信息可能会随着政策调整而变化，建议随时保持关注最新的官方公告及新闻报道。
