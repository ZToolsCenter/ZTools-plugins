澳门元（澳门元，符号：MOP或MOP$）是澳门特别行政区的法定货币，通常用“元”为单位。澳门元的汇率通常与港元（HKD）挂钩，1澳门元大致等于1港元，但由于市场波动，汇率可能会有所变化。

澳门元的发行由澳门金融管理局（AMCM）负责，该局是澳门的中央银行。澳门元纸币分为多种面值，包括10元、20元、50元、100元、500元和1,000元，而硬币则有1角、5角、1元、2元、5元和10元的面值。

澳门元可在澳门的商店、酒店和赌场广泛接受。在国际市场上，澳门元的流通程度较低，通常无法直接用于其他国家或区域的交易。

汇兑方面，澳门元可以在澳门地区的银行和货币兑换机构进行兑换，以港元、美元及其他主要外币。持有澳门元的人士应留意其真实性，避免伪币问题，特别是在私人交易或不明场所。
