卡塔尔里亚尔（Qatari Riyal，符号：QAR），是卡塔尔的官方货币。它由卡塔尔中央银行（Qatar Central Bank）发行和管理。卡塔尔里亚尔的分币为德纳尔（Dirham），1里亚尔等于100德纳尔。

卡塔尔里亚尔与美元之间有固定的汇率，通常为1美元约等于3.64里亚尔。此货币于1973年取代了之前的货币——卡塔尔和杜哈里亚尔。

卡塔尔里亚尔的纸币面额包括1、5、10、50、100、200里亚尔，硬币面额则有1、5、10、25、50和100德纳尔。卡塔尔里亚尔在国际外汇交易中通常以QAR表示。该货币主要用于卡塔尔国内的商业交易和国际贸易。

卡塔尔经济以其丰富的石油和天然气资源为基础，外汇储备充足，经济稳定，因此卡塔尔里亚尔被认为是一种相对稳定的货币。
