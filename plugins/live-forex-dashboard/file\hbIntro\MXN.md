墨西哥比索（Mexican Peso，符号：$, ISO 4217 代码：MXN）是墨西哥的法定货币。其历史可以追溯到16世纪，最初以西班牙银元为基础，现行的比索自1993年进行了一次重估，称为新比索（Nuevo Peso），以区分于先前的版本。1 新比索等于1000 老比索。

墨西哥比索的发行由墨西哥中央银行（Banco de México）管理，其采纳自浮动汇率制，因此其汇率受市场供求的影响。比索不仅在墨西哥国内流通，也在一些中美洲国家及美国的部分地区使用，特别是在边境地区。由于其相对稳定性和逐渐增强的国际化，墨西哥比索逐步成为在拉丁美洲较为广泛接受的货币之一。

墨西哥比索的纸币面额包括20, 50, 100, 200, 500 和1000比索，而硬币则包括5、10、20、50、1、2、5比索以及一些纪念币。设计上，纸币上通常印有著名的历史人物、文化遗产，以及自然景观，体现了墨西哥的历史与文化。

值得注意的是，墨西哥比索在外汇市场的波动受到多种因素的影响，包括但不限于经济指标、国际商品价格、政治稳定性及与美国的经济关系等。因此，投资者在交易比索时应充分考虑市场动态及相关风险。
