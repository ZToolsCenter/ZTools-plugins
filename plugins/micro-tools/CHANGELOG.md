# 更新记录

## v1.6.13（2026-10-24）

- 科研英语首页整合为内置素材库、自建素材库、错题与收藏、单词本、主页与设置五个入口；渐变标题区只显示今日学习摘要，设置页采用分类侧栏。
- 学习足迹改为完整月历，支持翻月和每日明细；记录有效学习时间、已学句数与连续打卡，保留原有累计时长。
- 错题与收藏内置「我的收藏」「我的错题」，支持新建收藏夹；旧收藏与练习记录继续使用。
- 单词本支持本机 XLS / XLSX / JSON 预览导入及导出；内置 152 词生物基础词表，提供 3290 词 Monash 中英词表的可选下载，重复导入或下载素材包保留已有进度。
- 单词打字练习使用独立界面，支持顺序 / 随机、词典详情、暂停与继续；与句子练习共用可配置键盘和答题音效，朗读与录音期间静音。
- 补齐并细化 24 道基础入门题的结构拆分；默认自动播放、下一句预览、紧凑底部操作栏及快捷设置均可持久配置。
- 答案支持单击查词、拖选短语及收藏；增加词性、词形、例句和英美发音，修复翻译代理识别与 HTTP 429 限流处理。
- 最近删除的题库支持确认后永久删除，并清理对应进度与本机录音；题库备份、独立词表和打卡记录保留。
- 科研英语与投稿助手共用 AI 连接检测，明确区分插件模型与外部 AI Agent；统一状态提示并保留无需插件模型的 Agent 路线。
