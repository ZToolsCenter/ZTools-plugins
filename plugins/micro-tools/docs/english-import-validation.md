# 手动导入：校验并预览素材

本页说明“导入 AI 返回的素材”中的手动校验流程。校验本身不调用 AI，不查询专业词典，也不判断科学结论是否正确。

## 流程

1. **读取 JSON**：读取粘贴内容中的课程 JSON 对象，或读取选择的 `.json` 文件。文件最大 2 MB；不把普通散文、表格或截断 JSON 自动改写成课程。
2. **基本结构校验**：检查课程标题、1–120 句非空英文、字段与数组类型、各字段长度上限及来源链接。标题和英文句子是必要内容；可选字段按现有素材契约补默认值。来源链接若填写，必须是无凭据的 HTTPS URL。违反这些规则会阻止导入。
3. **有原文才做的检查**：如果建库表单里有原文，先在本机创建素材会话，要求首次导入句数等于目标句数；每句必须有有效 `source_id` 或可匹配的 `quote`。只容忍排版差异，如空格、换行、连字、排版引号与断行连字符，匹配后回填真实原文片段。句数不符、引用不存在或会话过期会阻止保存。没有原文时不做这些检查，也不能声称引用已经核实。
4. **教学建议**：按下表生成警告。警告不会阻止手动预览或保存，也不会改写术语、数字、否定或引用。
5. **选择句子**：显示全部句子及其警告，默认全部保留。可逐句取消勾选，或批量剔除所有带句子级警告的句子；“恢复全部句子”可恢复当前预览的完整草稿。课程简介警告不是某一句的问题，不会触发批量剔除。
6. **保存**：只保存勾选保留的句子，至少保留一句。主动剔除后允许保存比原目标更少的句子，原文引用仍必须通过校验。原始返回 JSON 与已保存题库不会因勾选而被删除。修改“编辑课程 JSON”后应重新校验，预览会以当前编辑内容为准重新建立。

原文匹配只能证明引用片段存在，不能证明英文改写忠实、翻译准确或科学推断成立。

## 哪些是警告

| 规则 | 判定方式 |
| --- | --- |
| 简介不完整 | `description` 为空、少于 10 个字符，或等于标题 |
| 句子偏长 | `en` 超过 22 词；8–16 词只是生成时的优先目标，不是硬下限 |
| 数字或特殊符号 | `en` 含英文字母、空白、普通句读标点、撇号和连字符以外的字符 |
| 疑似专用标识 | 下述大小写模式命中，且不在常见缩写名单中 |
| 缺少解析 | `chunks` 为空 |
| 句法块偏长或为空 | 某块不含可识别词，或超过 6 词 |
| 词块覆盖不一致 | 各 `chunks.en` 的词按顺序拼接，不能与 `en` 的词逐一对应；此比较忽略大小写和标点，不能检验语法角色是否正确 |

词数由现有英文分词正则计算：字母/数字序列算词，内部撇号或连字符可连接为一个词。因此 `scRNA-seq` 在词数统计中算一个词；符号会单独触发学习建议。

## osmB、RNAs 为什么曾被提示

从 `en` 提取候选词：

```regex
\b[A-Za-z]+(?:-[A-Za-z]+)*\b
```

满足任一模式就产生“疑似”提示，再检查白名单：

```regex
[A-Z]{2}      # 连续两个大写字母
[a-z][A-Z]    # 小写字母后紧接大写字母
```

- `osmB`：命中 `mB`，且不在白名单中。只能说明写法类似专用标识，不能据此判定它是否规范、冷僻或适合某位用户。
- `RNAs`：命中连续大写字母；旧版仅对白名单中的 `RNA` 做精确匹配，因此误报。现在同时放行白名单词后加 `s` 的复数形式，所以 `RNAs`、`DNAs`、`mRNAs` 不再因此报警。
- `rpoS`、`scRNA-seq`：同样命中大小写模式，手动导入中只提示，由用户决定保留。

白名单为：`DNA`、`RNA`、`PCR`、`AI`、`MRI`、`CT`、`HIV`、`AIDS`、`ATP`、`ADP`、`COVID`、`mRNA`、`rRNA`、`tRNA`，以及上述写法后加 `s`。

这是简单启发式，可能误报人名、机构名或未列入白名单的常见术语，不是术语识别模型。

## 与自动 AI 建库的区别

“使用已配置的 AI”仍把教学要求作为自动生成的约束，触发批次修订。MCP 保存工具也维持原有严格教学校验。手动导入增加警告和用户选择，不绕过 JSON 结构、原文引用或来源链接检查。
