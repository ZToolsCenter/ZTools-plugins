# MFA Authenticator

TOTP/HOTP/Steam 验证码生成器，基于 RFC 6238 (TOTP) / RFC 4226 (HOTP) 标准，为你的在线账户提供安全的两步验证。

## 功能特性

- **TOTP 验证码生成** — 支持 SHA1/SHA256/SHA512 算法，6/8 位验证码，可自定义刷新周期
- **HOTP 验证码支持** — 基于计数器的一次性密码，手动点击刷新生成下一个验证码
- **Steam 令牌** — 支持 Steam Guard 5 位字母数字验证码，兼容 Steam 移动端令牌
- **智能填充** — 输入发行方名称时自动匹配预设参数（算法/位数/周期），支持 GitHub、Google、AWS、Steam 等 17+ 常见服务
- **实时倒计时** — 环形/条形指示器可切换，验证码自动刷新
- **下一周期预览** — TOTP 倒计时结束前提前显示下一周期验证码，点击可直接复制
- **一键复制** — 点击即复制验证码到剪贴板，自动隐藏窗口
- **主密码保护** — 所有密钥使用 AES-256-GCM 加密存储，PBKDF2 密钥派生
- **自动解锁** — 可选"记住密码"，下次打开自动解锁，无需重复输入主密码
- **密钥查看保护** — 编辑账户时查看密钥需二次验证主密码，防止密钥泄露
- **修改主密码** — 支持在线修改主密码，自动重新加密所有账户数据
- **拼音搜索** — 支持中文拼音模糊匹配，含双拼方案（自然码/小鹤/拼音加加/微软/搜狗）
- **置顶排序** — 常用账户可置顶，快速访问
- **拖拽排序** — 拖拽调整账户顺序

## 账户导入

- **手动添加** — 填写发行方、账户名、密钥等信息，支持 TOTP / HOTP / Steam 三种协议
- **URI 导入** — 粘贴 `otpauth://totp/` 或 `otpauth://hotp/` 格式链接，或在 ZTools 搜索框直接粘贴自动识别
- **二维码图片识别** — 选择包含 OTP 二维码的截图或照片，自动识别并导入账户
- **批量文本导入** — 每行一条，支持 `发行方:账户名:密钥` 格式或 `otpauth://` URI
- **文件导入** — 支持 TXT、CSV、JSON、Excel (.xlsx) 文件，以及加密的 .mfa 文件

## 文件导出

- **4 种格式** — TXT、CSV、JSON、Excel 可选
- **加密导出** — 使用独立导出密码加密，生成 `.mfa` 文件，用于本插件跨设备数据同步
- **明文导出** — 不加密，直接导出原始格式文件，兼容其他 Authenticator 平台导入
- **安全验证** — 导出前需验证主密码
