# Changelog

## 1.3.0

### Added
- Steam Guard 令牌支持（5 位字母数字验证码）
- 智能填充：输入发行方自动匹配预设参数（GitHub、Google、AWS、Steam 等 17+ 服务）
- 条形倒计时指示器，可与环形指示器一键切换
- 双拼搜索：支持自然码、小鹤、拼音加加、微软、搜狗 5 种方案
- 二维码图片识别导入

### Changed
- 倒计时指示器支持环形/条形切换，偏好自动保存
- 搜索支持全拼与双拼混合匹配

## 1.2.0

### Added
- HOTP (RFC 4226) 验证码支持
- 文件导入导出（TXT/CSV/JSON/Excel/加密 .mfa）
- 加密导出与导入，支持跨设备数据同步
- 批量文本导入
- otpauth:// URI 导入（含搜索框自动识别）

## 1.1.0

### Added
- 自动解锁（记住密码）
- 密钥查看保护（二次验证主密码）
- 修改主密码功能
- 拼音搜索
- 置顶排序与拖拽排序
- 下一周期验证码预览

## 1.0.0

### Added
- TOTP (RFC 6238) 验证码生成（SHA1/SHA256/SHA512，6/8 位）
- AES-256-GCM 加密存储，PBKDF2 密钥派生
- 主密码保护
- 一键复制验证码
- 实时倒计时进度环
