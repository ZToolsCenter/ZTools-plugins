# Changelog

## 1.0.2 - 2026-11-05

- 原始数据新增查找与替换，支持匹配计数、前后跳转、区分大小写、单个替换及全部替换。
- 所有匹配内容持续高亮，当前项使用橙色背景与边框，切换时自动滚动定位。
- 支持 Ctrl + F / Ctrl + H 打开查找替换，替换后自动更新格式化结果；查找过程中编辑文本保持光标位置。

## 1.0.1 - 2026-10-10

- 树形、文本及底部节点值区域支持字符串中的 JSON 反转义显示，包括根节点中的嵌套字符串。
- 复制完整结果和根节点值保留必要转义，复制子节点值使用反转义后的内容。
- 支持直接编辑反转义后的节点内容，应用修改时保留原有字符串类型。

## 1.0.0 - 2026-08-26

- 首次发布 JSON/JSON5 格式化与树形浏览功能。
- 支持节点查看、复制、编辑和 Key 排序。
- 支持自适应窗口与全屏布局，格式化统一使用 2 空格缩进。
