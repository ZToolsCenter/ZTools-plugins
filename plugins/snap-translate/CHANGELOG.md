## 1.0.0 - 2026-09-30

### Added
- 贴图 OCR 结果弹窗内展示翻译：贴图 OCR 唤起的结果小窗中点击「翻译」按钮，直接在该弹窗内展示翻译结果（自适应调整弹窗高度，原位平滑刷新），不再覆盖桌面悬浮贴图
- 相同语言自动跳过翻译：识别文本与目标语言一致时（如识别为中文且目标语言为中文），自动跳过翻译 API 调用，直接展示原文并轻提示，避免二次翻译导致乱码
- 混合文本多行局部翻译：多行混合文本中逐行识别语言，仅对非目标语言行发起翻译请求，目标语言行原样保留并原位拼装回填
- OCR 识别后智能推断目标语言：贴图 OCR 识别完成后，根据主体语言智能预设互补的目标翻译语言（如检测为中文默认目标设为英文，检测为英文默认目标设为中文）

### Changed
- 弹窗翻译模式下失败时提供清晰 Toast 反馈，避免静默失败无感知

## 0.9.0 - 2026-09-17

### Added
- 通用设置「翻译按钮结果」：贴图点翻译后可选**弹窗**（默认）或**原文覆盖**
- 结果弹窗 / 主窗 OCR 结果底部低调展示实际使用的 OCR、翻译引擎
- 贴图翻译结果覆盖后，按钮变为「原文」，点击可还原、不重新翻译

### Changed
- OCR / 翻译优先走**宿主默认提供商**；OCR 失败再回退微信明细 / Paddle，翻译失败再回退微软 / 谷歌等
- 覆盖模式下 OCR 优先取带检测框的引擎（微信 / Paddle）
- 贴图打开时**保持截图原始尺寸**（DIP），不再自动缩小；大小只靠滚轮调节
- 贴图打开在**截图原处**（使用 `screenCapture` 的 `bounds`），不再跟光标乱跳
- 设置页引擎目录只展示「存放目录 + 打开目录」
- 按钮改为实心底实字色，提高对比度

### Fixed
- 贴图**首次移动后被延迟 inject 拉回原位**：用户拖动后不再被打开时的初始坐标覆盖
- 同一张图重复 inject 不再清掉 OCR 结果与译文覆盖
- 市场 CI：声明 `platform: ["win32"]` 以构建 Windows 包

### Removed
- 公式 / LaTeX 识别相关功能与设置
