# 更新日志

## v1.0.0 (2026-09-02)

### 新增
- **极简拖拽画质增强**：无需配置 Python 与复杂环境，拖入本地视频即可一键启动 AI 超分辨率高清修复。
- **本地与云端双引擎架构**：
  - 本地离线引擎：一键自动安装部署 `realesrgan-ncnn-vulkan` 与 `ffmpeg` 绿色静态二进制，离线执行，数据 100% 隐私安全；
  - 云端托管引擎：支持填入 Replicate API Key，利用云端 A100 算力免显卡极速超分。
- **全场景智能去水印 (Universal Delogo)**：
  - 覆盖单角标（右下角/右上角/左下角/左上角）；
  - 支持 **🔥 双角标 (右上+右下)** 级联连续擦除；
  - 支持 **📜 底部通栏 (字幕与广告栏)** 与 **📰 顶部通栏** 平滑擦除；
  - 底层基于 FFmpeg `delogo` 平滑擦除 + Real-ESRGAN 超分纹理重绘融合，彻底还原纯净高清画面。
- **3 秒快速对比试看**：一键截取前 3 秒视频极速渲染，弹窗内嵌 Before/After 双屏滑杆实时对比视口，所见即所得。

### 优化
- **默认满血多线程流式并发加速**：
  - 采用多 Worker 分块切片并发流水线；
  - 线程池优化为 `-j 1:1:1` 流式直通模式，彻底消除高频抢占 Metal / Vulkan 命令队列的锁颠簸，基准渲染跑满 6.4 FPS。
- **全平台四级硬件自适应 (Tier 0 ~ Tier 3)**：
  - 深度识别 Apple Silicon 统一内存、Windows 独显/核显及 Linux 显卡规格；
  - 动态分配 Worker 并发进程数与瓦片尺寸（Tile 0 / 100 / 200）；
  - 内置防爆显存与防 OOM 动态熔断保护，规避轻薄核显本卡顿或崩溃。
- **设置弹窗弹性视口布局**：采用 Flex 弹性视口布局（`max-height: 85vh` + `overflow-y: auto`），吸顶标签与吸底操作，彻底解决高度截断无法滚动问题。
- **主界面参数栏排版与防挤压重构**：
  - 针对窄窗或长选项场景，将“基础倍率”与“去水印选项”重构为左右双分组弹性流式布局；
  - 为全部选项标签强制施加 `white-space: nowrap` 防断行保护，彻底根治“全场景智能去水印”汉字被纵向挤压折成四行的排版缺陷；
  - 优化胶囊倍率按钮与去水印下拉框的最大宽度和间距，使整个主界面视觉通透、整洁自然。
- **全屏透光穿透与按钮折行断裂彻底根治**：
  - **100% 实体不透明背景**：全面重构 `html`、`body`、`#app`、`.error-container` 与 `.rescue-card`，消除任何导致系统毛玻璃/透明窗口透出底层桌面窗口与无关文字的微透明度泄漏；
  - **杜绝任何按钮文字换行**：为全局 `button`、操作区按钮全面施加 `white-space: nowrap !important;` 与独立自适应宽度，解除原本 `flex: 1` vs `flex: 2` 导致的“💳 前往 Replicate 充”换行“值”以及“返回重”换行“试”的不良排版缺陷。
- **仪表盘真实联动**：运行状态栏实时动态展示当前真实工作进程数与线程池配置，消除硬编码。

### 修复与安全
- **云端欠费/异常智能感知与降级自愈**：
  - 针对 Replicate API 额度耗尽（`insufficient credit`）或 Token 认证失败，将原始晦涩英文错误中文化；
  - 错误页面新增专属「💡 智能降级推荐卡片」，并提供 **「⚡ 立即切换为本地 GPU 运行」** 核心按钮，实现自动切模式并一键重新触发或引导离线安装，避免用户陷入死胡同；
  - 增加 **「💳 前往 Replicate 充值」** 外链直达，操作体验无缝闭环。
- **参数防注入安全加固**：探查视频元数据全面改用无 Shell 解释器的 `spawnSync` 纯数组传参，彻底免疫特殊文件名注入。
- **孤儿临时文件自动垃圾回收 (GC)**：插件初始化时自动巡检并清理超过 2 小时的非正常中断残留帧目录，防止磁盘撑爆。
- **音频流自适应容错**：Phase 3 音频复用采用 `-map 1:a?`，彻底消除静音视频或纯画面动画在无音轨时 FFmpeg 报错退出的隐患。
