# Changelog


## 0.1.0 - 2026-08-19

- 初次发布，将插件提交至 ZTools 插件仓库。
- 适配 ZTools 插件清单及宿主接口。
- 完善快速取码、验证码粘贴、拖拽排序和网格/列表视图切换。
- 修复构建和依赖配置问题；原有按日期维护的功能记录保留在下方。

### 原有日期记录

### 2026-07-31

#### 倒计时动效优化

🌈 本次更新重点：验证码倒计时现在会连续流动，剩余时间变化更自然；进入新周期时会立即回满，不再出现反向缓慢拉伸。

🪐 优化

• 账户卡片、账户详情和快速取码中的直线进度条与圆形倒计时统一为平滑线性变化。

🐛 修复

• 修复倒计时进度按整秒一截一截跳动的问题。

#### 界面与 MCP 更新

🌈 本次更新重点：界面升级为更清晰的黑白基调，并支持按喜好选择强调色；还新增了安全的本地 MCP 查询能力，方便在不暴露验证码和密钥的前提下查看账户概况。

✨ 新功能

• 现在可在设置中选择黑白、海蓝、松绿等 8 种强调色，选择会自动记住并适配明暗主题。
• 新增本地只读 MCP 服务，可按账户名、发行方或分组查询脱敏账户信息，或查看保险库汇总；种子、otpauth 链接和动态验证码始终不会返回。

🪐 优化

• 账户详情把分组和添加时间并排展示，分组选择控件、输入控件与各类按钮的悬停和按下反馈更统一。
• 列表、导入导出、回收站与快速取码等页面统一为新的视觉层级，窄窗口下更易扫描和操作。

🐛 修复

• 新建账户未填写名称或密钥时会给出明确的字段级错误提示，避免不完整信息被误认为已保存。

### 2026-07-22

🌈 本次更新重点：修复分组信息丢失，并让分组与账户走同一套可同步存储。

✨ 新功能

• 分组信息现在可随 uTools 账号同步到其他设备。

🪐 优化

• 移除不再维护的原生桌面打包链路，项目运行面收敛为 uTools 与 Web 开发环境。

🐛 修复

• 分组定义不再只写在浏览器 localStorage；uTools 下改为 dbStorage，可随账号跨设备同步。
• 启动时自动迁移旧 localStorage 分组到平台存储，避免升级后分组莫名消失。
• 加载账户时以平台存储中的分组为准，避免不同设备/会话读取到脏的本地筛选状态。

### 2026-07-20

🌈 本次更新重点：账户分组回归清晰的一级结构，并完善跨分组整理、uTools 入口和顶部界面体验。

✨ 新功能

• 账户卡片支持直接拖到其他一级分组，也可以拖回“未分组”。

🪐 优化

• 移除发行方二级分组与收起操作，账户直接平铺在当前一级分组中。
• 顶部分组栏移除冗余标题并压缩高度，长名称支持截断、提示和安全滚动。
• 调整分组菜单位置、标签左右留白和拖动反馈，统一移除输入控件聚焦时的额外边框。

🐛 修复

• 修复通过 uTools 主快捷键进入时误带搜索内容、无法进入设置界面的问题。
• 修复拖动结束后偶发出现突兀焦点圆圈，以及无效分组移动可能产生错误归属的问题。

### 2026-07-19

🌈 本次更新重点：完善账户分组和 uTools 快速取码，并系统提升数据可靠性、窄窗体验与 Chrome 108 兼容性。

✨ 新功能

- 新增自定义账户分组，支持创建、重命名、排序、删除和详情页归档。
- 新增 uTools 快速取码模式，支持搜索、方向键选择、回车粘贴和 HOTP 安全递增。
- 备份升级为 v2，可完整恢复分组、账户归属、备注与自定义名称，并继续兼容 v1。

🪐 优化

- 优化紧凑、网格和列表视图，完善 320px 窄窗布局、明暗主题、键盘焦点和低动态模式。
- 验证码刷新改为共享时钟，移除持续 WebGL 背景，减少多账户场景下的计时器与渲染开销。
- 导入、复制、加载和保存均增加明确的成功或失败反馈，避免未读取完成时覆盖本地数据。

🐛 修复

- 修复页面状态切换可能触发的 Hook 顺序崩溃、普通 Base32 二维码误报和复制失败仍显示成功。
- 加强 TOTP、HOTP、otpauth URI 与 Google Authenticator 迁移数据校验，避免无效或不完整数据静默导入。
- 修复删除分组后回收站账户残留失效归属，以及批量导入内部重复账户未被过滤。
- 清除 uTools 构建产物中的 `color-mix()`、`oklch()`、`lab()` 和 `lch()`，保证 Chromium 108 关键样式可用。

### 2026-06-07

🌈 本次更新重点：账户列表现在支持拖拽排序，还新增了网格/列表两种视图可随时切换。

✨ 新功能
• 账户卡片可以直接拖住左侧把手拖动换位，松手即保存新顺序
• 顶部新增视图切换按钮，一键在"网格两栏"和"紧凑列表"之间自由切换，视图偏好自动记忆

🪐 优化
• 列表模式下每行更紧凑，倒计时圆圈直接显示在右侧，信息一眼扫完
• "跟随系统 / 锁定主题"从折叠按钮独立出来，变成菜单里单独一项，更容易点到
• 从 uTools 带关键字进入时，搜索框会自动展开并显示当前过滤词，方便一键清除

### 2026-05-28

🌈 本次更新重点：新增「快速取码」模式，在 uTools 搜索框输入关键字即可一键粘贴验证码到当前窗口

✨ 新功能
• 在 uTools 主搜索框输入 `2fa github` / `otp 谷歌` 等组合，自动匹配账户并展示验证码列表，按回车直接粘贴到上一个窗口
• 快速取码面板支持上下键选择账户、回车粘贴、Esc 退出，全程不离开键盘
• uTools 新增三个入口：「2FA / OTP / 验证码」查看列表、正则模式快速取码、「管理鹅的验证」进入管理面板

🪐 优化
• 快速取码面板支持按账户名、发行方、备注、笔记多字段搜索，多个关键字之间为 AND 关系
• 账户列表每行显示头像首字母、验证码倒计时进度环、HOTP 计数器标签

### 2026-05-26（晚）

✨ uTools 主搜索框直出验证码
• 输入「2FA / OTP / 验证码 / 二步验证」→ 直接看账户列表，回车自动粘贴到刚才的窗口
• 输入「2fa github」（关键词带空格）→ 一步搜索 + 粘贴，无需进入插件
• 输入「管理鹅的验证」→ 打开管理面板添加/编辑账户

### 2026-05-26

🌈 本次更新重点：账号详情页可以添加备注了，名称太长时也能看到完整内容

✨ 新功能
• 打开任意账号详情页，名称下方新增「备注」栏，点击即可添加自定义备注信息

🪐 优化
• 名称太长被截断时，鼠标悬停会弹出完整名称提示
• 点击编辑名称时，文字会自动全选，方便直接修改

🐛 修复
• 账号详情页的输入框组件内部完善，确保 ref 引用可以正常传递
