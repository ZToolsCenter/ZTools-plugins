# 退休倒计时

ZTools 插件：显示距离法定退休日的倒计时。

## 功能

- 触发词：`退休` / `退休倒计时` / `retire` / `tx`
- 支持男职工 / 女职工 / 女干部的渐进式延迟退休估算（自 2025-01-01）
- 也可自定义退休年龄或精确退休日期
- 显示年 / 天 / 时 / 分，以及职业生涯进度条
- 配置通过 `dbStorage` 持久化

## 使用

插件已放在 ZTools 本地插件目录。在 ZTools 中输入 `退休` 即可打开。首次使用先填写出生日期并保存。

## 说明

政策估算仅供参考，实际退休年龄以当地社保部门核定为准。
