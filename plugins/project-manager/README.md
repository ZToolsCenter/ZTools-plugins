# Project Manager

当前版本：`v1.7.0`

一个现代化的跨平台项目管理工具，聚合了项目运行、Git 管理、Node 版本管理、项目文件整理与系统集成功能。  
桌面端基于 `Tauri v2 + Vue 3 + TypeScript` 构建，同时提供 `uTools` / `ZTools` 插件版本。

---

## 核心能力

### 1. 项目管理与命令运行

- 统一管理多个前端或通用项目
- 支持单个或批量添加项目，也支持拖拽目录导入
- 批量导入和手动导入均可自动扫描目录中的子项目，形成可钻取的多级项目工作区
- 项目包含子项目时，子项目列表会显示同级父项目入口，父子项目分别使用各自的命令、Git、环境、文件和备忘录数据
- 父子项目钻取提供方向动画，返回时自动恢复此前浏览和滚动位置
- 子项目仅在自身目录为 Git 仓库根目录时显示 Git 状态，不会继承父级仓库
- 自动识别 `package.json` 脚本，并支持自定义命令
- 支持识别 Maven / Gradle Java 项目，并自动提供构建、运行和测试命令
- 子项目支持独立拖拽排序、置顶和收藏，运行状态会向父项目聚合
- 一键在编辑器、终端、资源管理器中打开项目
- 统一的亮色 / 暗色主题体系，主工作台、设置、Git、文件管理等高频区域风格一致
- 支持选择本地图片作为全局背景，并调节背景显示强度
- 命令运行采用 Run Session：清晰显示 Starting、Running、Success、Failed、Stopped
- Session 显示 exit code、耗时和当前项目 Node Runtime 环境
- 命令运行日志支持持续输出，并在高频日志场景下自动跟随到底部
- 支持一键停止、重新运行和清空当前 Session 输出；同一命令保持一个 Console 标签
- 已完成的运行会保留轻量 Run History，可按当前命令或项目查看最近结果、失败原因、耗时和执行环境
- Console 日志支持 stdout、stderr、Runner 筛选，内存日志可搜索、复制全部和导出；完整日志不会写入运行历史
- 智能排序：根据使用频率自动排列项目，新项目优先显示

项目总览提供分组、标签、收藏、置顶、最近使用、运行状态、Git 改动、健康异常和路径缺失等筛选维度，并支持保存常用视图与启动组。

![项目总览](docs/images/project-dashboard.png)

父项目可以展开为独立的多级项目工作区。子项目分别使用自身的命令、Git、Node 环境、文件和备忘录数据，返回上级时会恢复此前的浏览位置。

![多级项目工作区](docs/images/project-workspace.png)

命令面板会自动识别项目脚本和内置安装依赖命令，适合统一运行开发、构建、检查与测试任务。每次执行都会创建独立的 Run Session，命令可以从 Starting 进入 Running，最终明确落在 Success、Failed 或 Stopped；历史结果可以直接按当前项目配置重新运行。

![命令运行](docs/images/command-runner.png)

### 2. Git 管理

- 内置 Git 图形界面，支持状态、差异、提交、历史、分支、远程仓库等操作
- 支持文件级与 hunk 级暂存 / 取消暂存 / 丢弃
- 文件状态支持 Ctrl+Click 多选和 Shift+Click 范围选择，批量暂存 / 取消暂存 / 丢弃
- 无暂存文件时可自动暂存后提交；支持 amend、撤销上次提交
- 冲突时禁用提交，并在合并进行中提供继续 / 中止操作
- 工具栏根据 ahead / behind 智能突出 Push / Pull，支持 pull 策略
- 提交历史支持搜索筛选，右键可复制、建分支、cherry-pick、revert、reset
- 仓库中心统一管理贮藏、标签、远程与分支
- 支持并排 / 行内差异视图
- 支持提交历史查看、文件变更查看与区块回滚
- Git Diff 选中状态按项目隔离，切换项目后不会串用其他项目的差异内容
- Git 工作区多处分栏支持拖拽调整，以百分比存储布局，窗口缩放自动适配

![Git 管理](docs/images/git-panel.png)

### 3. 项目备忘录与文件管理

- 每个项目都可以维护 Markdown 备忘录
- 支持编辑 / 预览 / 分屏模式
- 可关联常用文件或文件夹，支持快速预览图片与文本
- 文件和备忘录与命令、Git 位于同一项目工作区，切换项目或子项目时自动使用对应数据

### 4. Node 版本管理

- Project Manager Managed Node Runtime：由 Project Manager 统一管理应用内命令使用的 Node Runtime
- 兼容扫描已有 NVM Runtime，NVM 作为外部 Runtime 来源，不改变 NVM 自身管理方式
- 支持安装、卸载 Runtime，并由 Project Manager 统一管理系统 Node 切换
- 支持识别系统已有 Node，或手动添加自定义 Node 可执行路径
- 项目可以绑定具体 Runtime/version，运行命令时使用项目当前配置

![Node 版本管理](docs/images/node-manager.png)

### 5. 端口管理

桌面端新增端口管理能力，适合排查本地开发时的端口占用问题。

- 查看当前正在占用的 TCP / UDP 端口
- 查看端口对应的 PID、进程名、程序路径与命令行
- 支持按进程结束占用端口的程序

![端口管理](docs/images/port-manager.png)

说明：

- 当前端口管理为桌面端功能
- `uTools` / `ZTools` 插件环境下不提供端口管理

### 6. AI 提交信息生成

- 基于暂存区差异自动生成提交信息
- 支持 OpenAI 兼容接口
- 可配置 Base URL、API Key、模型和提示词模板
- 支持单渠道多模型或多渠道回退，单次请求失败时自动尝试备用槽位
- 默认遵循 Conventional Commits 风格

![AI 提交信息生成](docs/images/ai-commit-settings.png)

> 截图中的服务地址、模型和密钥等演示配置已隐藏。

### 7. 系统集成

- 支持多编辑器配置，项目可单独指定编辑器
- 自动检测系统终端，也支持自定义终端
- 支持托盘、关闭行为、自启动、右键菜单等系统能力
- 桌面端项目数据保存到系统用户数据目录，自动迁移旧版数据并采用原子写入保护
- 桌面端使用签名校验的原生更新器，自动匹配 Windows、macOS、Ubuntu deb 与 AppImage 安装包；下载可后台进行，安装前会保护未保存的数据
- 支持配置聚焦搜索、新建项目、刷新项目和 Ctrl+1~5 侧边菜单快捷键
- 设置页提供固定的分区目录，可点击跳转并随内容滚动自动高亮
- 提供设置导入导出，支持一键应用全部当前或导入数据，便于迁移与备份

![设置页面](docs/images/settings.png)

## 快速开始

开发命令要求 Node.js `20.19+` 或 `22+`，推荐使用 Node.js 22 LTS。当前 Vite 6 依赖链不支持 Node.js 16 或 21。

```bash
# 安装依赖
npm install

# 启动桌面端开发环境
npm run tauri dev

# 构建桌面端
npm run tauri build

# 构建 uTools 插件
npm run build:utools

# 构建 ZTools 插件
npm run build:ztools

# 发布前检查（不修改版本、不创建 tag、不推送）
npm run release:preflight

# 准备本地版本提交和 tag（不推送）
npm run release:prepare -- 1.7.0

# 发布已准备好的提交和 tag
npm run release:publish -- 1.7.0
```

发布前请按 [`docs/release-checklist.md`](docs/release-checklist.md) 执行自动检查与各平台手工 QA。`release:prepare` 和 `release:publish` 均支持 `--dry-run`；本轮不会创建正式 tag、GitHub Release 或发布插件。

## 更新日志

### v1.6.2

**新功能与优化**

- **签名自动更新**：桌面端迁移到 Tauri 官方 updater。更新包经过签名验证后再安装，Windows、macOS、Ubuntu deb 与 AppImage 会匹配各自的原生安装方式。
- **Ubuntu 安装体验**：deb 更新会请求系统认证后覆盖安装；AppImage 自动替换原文件并重启，不再把下载的安装包作为普通可执行文件直接启动。
- **远端分支同步**：新建远程项目会保留全部远端分支引用；旧版单分支克隆项目点击获取后会自动修复引用范围。
- **Ubuntu 软件中心元数据**：补齐项目图标、作者、MIT 许可证、主页、简介、分类和关键词，改善软件中心的详情展示。

**升级说明**

从 `v1.6.1` 升级到 `v1.6.2` 的 Ubuntu deb 用户，请在下载目录执行一次：

```bash
sudo apt install ./Project.Manager_1.6.2_amd64.deb
```

后续版本可直接在应用内完成更新，无需通过 Ubuntu 软件中心打开本地 deb。

**新功能**

- **仓库中心**：工具栏新增仓库中心入口，统一管理贮藏（stash）、标签、远程仓库与本地分支

- **文件状态分栏**：左侧文件列表默认占容器 50%，拖拽按百分比保存，窗口缩放按比例重算，避免大窗写死像素、小窗挤占右侧 Diff
- **Git 错误详情**：较长失败信息可展开查看原始 Git 输出
- **后端能力打通**：注册并暴露 stash / merge / rebase / tags / amend / reset / cherry-pick / revert，Tauri 与 uTools / ZTools 适配器同步

**修复**

- **分支弹窗定位**：分支、仓库设置、仓库中心弹窗改为挂到 `body` 并相对整页居中，不再只在右侧 Git 面板内居中
