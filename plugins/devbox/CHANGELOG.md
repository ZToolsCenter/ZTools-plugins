# Changelog

本文件记录 ZTools 开发百宝箱插件的版本变更历史。

## 3.0.1 - 2026-09-24

### 修复

- **修复再次进入插件时不切换到对应标签页的问题**（插件隐藏到后台后重进，只会停留在上次的标签页）
  - 根因：宿主在插件隐藏时会重载开发插件视图（重跑 preload 并替换 `window.ztools`），已注册的 `onPluginEnter` 回调随之失效，后续进入事件被宿主缓冲、无法送达页面。现定时将 enter 回调重新注册到最新的宿主接口对象上，缓冲的进入事件会在重注册时回放，重进插件即可正确激活对应工具标签（多标签与首页状态保留逻辑不受影响）
  - 同时修正指令触发判定：图标点击伪装只会回传第一个 feature 的 code，因此其余 feature 的 text 进入（含拼音/模糊搜索词，如输入「suiji」进随机数字）不再要求搜索词命中指令关键词，避免被误判为图标点击而保持原状
  - 配套调整：plugin.json 首位新增 `home` 入口 feature（搜索词 `devbox`）承接宿主图标点击伪装回传的 code，指令触发判定简化为「action.code 命中工具注册表即切换」，不再比对 payload 与 cmds；`tools.ts` 中各工具的 `cmds` 字段随之一并移除，触发指令以 `plugin.json` 为唯一事实来源。至此随机身份等所有工具的历史记录 / 最近使用 / 快捷键 / 拼音搜索进入均可正确切换标签

## 3.0.0 - 2026-09-22

### 新增

- **多标签页**：右侧内容区支持同时打开多个工具页签，点击左侧菜单即可新开 / 激活对应标签，多个工具可配合使用（如边看 JSON 边转 Base64）
  - 同一工具只开一个标签，重复点击直接激活已有标签
  - 标签可关闭（×），关闭激活标签时自动激活右侧邻位标签（末尾则左侧），全部关完回到插件首页
  - 标签条用 Element Plus `el-tabs` 实现，高度压缩至 26px（调节 `--el-tabs-header-height`），超出宽度自动出现滚动箭头，明暗主题均已适配
- **插件首页**：进入插件不再默认打开「随机身份」，未开任何标签时展示首页——上方「常用」区按工具打开/激活次数自动统计 Top 8（数据持久化到 ZTools dbStorage，无使用数据时该区隐藏），下方为按分类分组的全部工具网格，点击任意工具即新开/激活对应标签
- **工具状态保留**：切换标签不销毁组件（KeepAlive），每个工具的输入内容、生成结果在标签间来回切换后依然保留

### 变更

- 插件描述改为表达产品理念——只做实际开发中会用到的工具、每个工具都解决真实开发场景的具体问题，不再罗列工具清单
- 页面框架调整：内容区由单页显示改为「标签条 + 内容区」结构（`App.vue` 多标签状态模型 + `ToolboxLayout.vue` 标签条），工具组件通过 KeepAlive 统一渲染
- 插件隐藏到后台（onPluginOut）不再卸载页面：标签与工具状态跨「退出-进入」完整保留，同时修复重进时因页面卸载与 enter 时序错位导致的黑屏；enter 事件未到达时也兜底渲染上次状态，不再出现空窗
- 入口行为区分：关键词触发进入插件时打开 / 激活对应工具标签（不再重置页面，已开标签保留）；**快捷键进入直达绑定的工具标签**；点击插件图标进入时保持现状，未开标签则显示首页。宿主把各入口都包装成 feature 触发形态（图标=首个 feature + 搜索词、快捷键=绑定 feature + 空 payload），按「type / payload 命中 cmds / code 是否首个 feature」三层区分
- 二维码、时间转换、JSON 工具、HTML 预览四个组件的全局副作用（paste 监听、时钟定时器、主题监听、防抖刷新）适配 KeepAlive 生命周期（onActivated / onDeactivated）：非激活标签停止监听与计时，切回自动恢复，避免后台标签抢占粘贴事件或空转

## 2.7.2 - 2026-09-17

### 修复

- **JSON 工具**：修复粘贴「无外层引号、内部全是 `\"` 转义」的 JSON 文本（如从日志或字符串字面量复制后丢了外层引号，形如 `[{\"a\":\"1\"}]`）时报 `Expected property name or '}' in JSON` 且无法格式化 / 去转义的问题
  - 智能解析新增转义还原兜底：直接解析失败时，按 JSON 字符串字面量规则逐层还原转义（最多 3 层）后再解析，成功即自动去转义并格式化
  - 还原实现优先用「包一层引号 + JSON.parse」处理标准转义（含 `\\` `\n` 等）；存在裸引号、字面换行等非标准形态时降级为逐转义对消费，只还原 `\"` 与 `\\`，避免误伤内容
  - 「去转义」按钮复用同一套还原逻辑，对这类输入同样可用；普通 JSON、带外层引号的二次编码字符串等原有行为不受影响
- **JSON 工具**：修复「多个对象/数组用逗号拼接、缺外层 `[]`」的文本（形如 `{...},{...},{...}`，转义与否均可）无法格式化的问题——网上工具单纯去转义后仍是非法 JSON（报 `Unexpected non-whitespace character after JSON`）
  - 直接解析与去转义均失败时，检测首尾为配对 `{}` / `[]` 的碎片形态，自动补全外层数组后解析，状态栏提示「已补全外层数组」明确内容被结构性修改
  - 覆盖转义 + 缺括号叠加形态（`{\"a\":\"1\"},{\"b\":\"2\"}` 一键得到格式化数组）与数组拼接形态（`[1,2],[3,4]`）；真坏 JSON 仍正常报错不误判
  - 进一步支持**无逗号拼接**（`{...}{...}{...}`，含带 `\"` 转义与数组混排形态）：在相邻值之间自动补逗号后再包数组；补逗号前先隔离字符串字面量，对象字符串值内恰好含 `}{` 不会被误伤，嵌套对象边界不受影响
- **JSON 工具**：状态栏改为三态显示，避免自动修复掩盖输入不标准的事实——直接解析成功显示「✓ 有效 JSON」（绿色）；靠去转义/补全数组才解析成功的显示「⚠ 非标准 JSON（可自动修复）」（黄色）；完全解析失败显示「✗ 无效 JSON」（红色）。执行格式化/压缩/去转义后内容变为标准 JSON，标签自动转绿

## 2.7.0 - 2026-09-14

### 新增

- **URL 编解码工具** — percent-encoding 编码与解码，双栏实时互转
  - 编码支持三种范围：整段转义（encodeURIComponent，把整段输入当作一个值全部转义）/ 仅不安全字符（encodeURI，保留 : / ? & = 等结构字符）/ 仅参数值（解析 URL 结构，只转义各查询参数的值，协议/主机/路径与参数名原样保留，输入不是 URL 时自动降级为「整段转义」并提示）
  - 「仅参数值」对每个参数值先解码再编码做归一化，避免已编码内容被二次转义成 %25；空格输出 %20、字面 + 输出 %2B，与解码方向「+ 还原为空格」的语义保持一致
  - 解码支持「+ 还原为空格」开关（x-www-form-urlencoded 语义），默认开启
  - 非法转义序列（%zz、孤立 %、截断的 UTF-8）给出内联错误提示并定位出错位置
  - 解码方向自动解析 URL 结构：协议 / 主机 / 路径 / 锚点分段展示，路径逐段解码
  - 查询参数逐个拆解为「参数名 → 参数值」表格，先按 & 和 = 拆分再逐段解码，避免值内含 &/= 时错误切分
  - 结构解析在原始输入上做；原始输入不含未转义的结构字符时（如「整段转义」回填后的 `http%3A%2F%2F…`，`: / ? & =` 已全被吃掉），回退到在解码结果上解析，并标注「基于解码结果」区分来源。回退链路上 `+` 不再当作空格——第一遍解码已消费掉 form-urlencoded 语义，否则会把 `%2B` 还原出的字面 `+` 二次解成空格
  - 输入看起来已编码时提示一键切到解码
  - 结构行与参数行点击即复制；超长结果截断展示（前 8000 字符），复制为完整内容

## 2.6.0 - 2026-09-14

### 新增

- **Base64 编解码工具** — 文本与 Base64 双栏实时互转
  - 编码 / 解码双方向切换，输入即出结果
  - 支持标准与 URL-safe 字符集（JWT 场景），可去除 `=` 填充

  - 支持将文件、图片转为 dataURL 输出（含 MIME 前缀），并支持拖拽文件到输入区
  - Base64 解码后可识别 PNG/JPEG/GIF/WebP/BMP/ICO 并直接预览，或下载为二进制文件
  - 解码结果非 UTF-8 时降级为 Hex 视图，不输出乱码
  - 超长结果仅截断展示（前 8000 字符），复制与下载始终为完整内容
