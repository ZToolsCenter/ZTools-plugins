# Changelog


## 1.2.0 - 2026-05-01

- 新增「内置数据 / 自定义」选项卡切换
- 自定义选项卡：支持任意「指令 → 固定文本」配对，触发时直接填充到当前输入框
- 「全开 / 全关」改为分段控件，作用范围跟随当前选项卡
- 修复设置保存未等待数据落盘可能导致丢失的问题

## 1.1.0 - 2026-04-29

- 支持在设置页按项目开启或关闭随机数据项
- 支持自定义每个随机数据项的触发指令
- 支持在设置页直接预览生成结果
- 优化设置页布局与显示顺序
- 首次使用改为先打开一次设置页完成指令注册

### 根据提交记录补充

- 修复设置页自动保存与复制交互问题
- 忽略本地归档文件避免阻塞发布

## 1.0.0 - 2026-04-27

- 初次发布，将插件提交至 ZTools 插件仓库。
- 初始化随机数据插件
- 优化地址和金额随机生成
- 对齐 ZTools 粘贴 API 并优化生成逻辑
- 移除社交账号生成并改为直接输入
