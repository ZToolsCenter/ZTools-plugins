# Changelog


本项目的所有重要更改都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)

## 1.0.3 - 2026-07-27

### 新增功能

- **剪贴板导入**：支持通过 `Ctrl+V` 导入系统文件管理器中复制的文件和文件夹
- **批量复制**：支持将文件路径或文件名复制为纯文本或 JSON
- **目录浏览**：导入文件夹时保留目录节点，支持逐层查看子目录内容

### 优化

- **响应式操作栏**：优化窄窗口下的按钮布局与图标按钮可访问性
- **代码结构**：拆分文件队列、路径处理及拖放/粘贴逻辑

## 1.0.2 - 2026-04-28

### 新增功能

- **文件夹支持**：支持重命名文件夹功能

### 修改问题

- **拖拽文件路径问题**：修复无法通过拖动获取文件绝对路径而导致的无法重命名的bug

### 根据提交记录补充

- 优化文件导入和复制。

## 1.0.1 - 2026-04-27

### 新增功能

- **删除字符**：支持按字符、类型、位置或去重删除文件名中的字符

## 1.0.0 - 2026-04-15

- 初次发布，将插件提交至 ZTools 插件仓库。
- 初始化 FR 文件重命名工具并完善插件化规则系统
- 添加i18n国际化支持系统
- 完成文件批量重命名插件配置和文档
- 添加Toast通知系统和文件状态重构
