# 文件智能重命名 V1 使用说明

## 安装与启动

1. 在项目根目录运行 `pnpm install`，然后运行 `pnpm build`。
2. 运行 `.\scripts\package-probe.ps1`。默认生成 `outputs/file-smart-rename-v<版本号>.zip`；也可以传入 `-OutputPath <ZIP绝对路径>` 指定位置。
3. 在 ZTools 插件管理中选择“本地安装”，安装生成的 ZIP。
4. 插件也可从 ZTools 普通搜索入口打开。普通入口不读取 Explorer 当前选择；插件进程仍保留任务时会继续显示该任务。

## 导入文件

- **文件上下文入口：** 在 Explorer 选中文件，通过 ZTools 文件上下文打开“文件智能重命名”。收到新文件任务后，列表会替换为所选文件，默认进入“查找替换”并按名称升序排列，同时清除旧任务的撤销记录。
- **添加文件：** 点击“添加文件”并多选文件。新文件追加到列表，重复绝对路径会去重。取消文件选择不会清空已有任务。
- **扫描文件夹：** 点击“扫描文件夹”并选择目录。插件递归扫描普通文件，不把文件夹加入改名列表；扫描遇到错误时会保留可读取文件并提示错误。最多处理 10,000 个文件。
- **移除和清空：** 每行的“移除”只移除该项。点击“清空”会清除文件、预览和当前撤销记录。

## 编辑目标名称

列表显示当前文件名、目标文件名和状态。状态包括“无变化”“待改名”“错误”和执行后的“已完成”；错误行会显示原因，点击错误标签可查看完整原因。修改规则、排序或编辑值后，目标名称会重新预览，并检查目标名冲突。顶部搜索框只筛选可见文件，执行仍针对当前任务中的全部文件。

四个可执行功能模块分别保存自己的规则：

- **查找替换：** 可添加多条规则并按顺序应用。支持普通替换、前 N 位、后 N 位、指定区间、定位字符前后及定位字符前后的 N 位。默认不处理扩展名；勾选后才将扩展名纳入替换。
- **自动编号：** 可设置前缀、开始序号、序号类型、阿拉伯数字固定位数和后缀。支持阿拉伯数字、中文大小写数字和英文字母大小写。固定位数只对阿拉伯数字生效。序号根据当前显示顺序计算，原扩展名保留。
- **插入内容：** 可插入固定文本、序号或文件信息，并选择文件名开头、指定位置或扩展名前。文件信息包括创建时间、修改时间、文件大小、图片尺寸和拍摄时间；缺少所需元数据的文件会显示错误。
- **手动编辑：** 可逐项填写目标名，也可从表格或电子表格复制多行后粘贴。粘贴按当前排序顺序填写；多余行忽略，少于文件数时其余项保留原值，空白行对应的目标名会标错。
- **智能重命名：** 在 ZTools 设置中配置 AI 模型后，选择模型、填写重命名要求并点击“生成预览”。插件仅发送文件名、大小和时间元数据，由 ZTools 调用已配置的模型；检查候选名称后再点击“执行重命名”。每次最多处理 500 个文件，内部按每批 50 个请求；模型返回无效结果时不会执行改名。模型配置变更后可点击“刷新模型”。

## 排序与执行

排序菜单提供名称、大小、修改时间和创建时间的升序、降序。排序会更新显示顺序及编号预览；相同值保持原相对顺序，缺失的数值排在末尾。

点击“执行重命名”后，插件会再次检查文件和目标名称。非法名称、同目录目标重名、已被外部文件占用的目标会被拒绝。互换或循环改名会作为关联操作安全执行。互不相关的文件逐项处理；部分失败时，其余文件仍可继续。执行完成后停留在当前功能页，右上角提示成功和失败数量；成功项更新为实际文件名，失败项显示原因。修改规则或切换功能页后，才会从新的文件名生成下一轮预览。

## 撤销与限制

- “撤销”只恢复最近一次执行中成功改名的文件，逐项检查文件是否仍是原文件，并且不会覆盖已被占用的名称。
- 撤销记录只存在于当前 ZTools / 插件进程内：关闭插件窗口但 ZTools 未退出时应保留；完全退出 ZTools 后清除。它不支持多级撤销，也不写入数据库。
- 通过文件上下文进入的新任务会清除上一任务的撤销记录。普通入口重入会保留当前任务。
- V1 面向 Windows / ZTools。其他操作系统和宿主版本未经实测的行为，请参见 [V1 验收记录](v1-acceptance.md)，不得据此视为已验收。
- 所在文件系统若不支持安全建立硬链接，相关改名会报错并保留源文件。
