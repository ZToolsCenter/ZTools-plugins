# Changelog

- 整合房贷与通用贷款计算器，支持年、月、日利率切换，以及等额本息、等额本金、先息后本还款方式。
- 整合方案对比、提前还款、浮动利率模拟、真实利率反算和历史记录批量管理。
- 统一开发者为 Samson，调整功能描述与版本号，完成 2.0.0 整合发布。
