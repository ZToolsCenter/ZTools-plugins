# Changelog


## 0.3.0 - 2026-08-31

### 新增

- **暗夜紫硬件工况仪表盘**：重构仪表盘核心视觉为专业暗夜紫电竞/服务器工况风格，提供 CPU 多核架构与实时利用率环形图、GPU 显卡与统一显存检测、物理内存多阶深度压力（Active/Wired/Compressed/Free）、macOS/Linux/Windows 磁盘与多挂载卷容量分布、以及当前系统资源消耗最高的 Top 5 进程实时动态排行。
- **压缩包安全工作台（Archive Workbench）**：
  - **多级层级树状展开预览**：重组线性压缩包条目为结构化树形节点，支持逐层展开/收起、子项数量与递归容量自动统计、一键全部展开/全部收起；根据代码、文本、媒体、归档等类型智能映射专属文件图标与 CRC-32 十六进制标签。
  - **ZIP 流式分片按需解析引擎**：纯前端新增基于 `file.slice()` 的轻量二进制解析引擎，通过按需截取文件末尾 65KB 快速索引 EOCD 与 Central Directory，面对数十 GB 大型镜像压缩包秒级展开，内存开销严格低于 100KB。
  - **视口自适应与全屏拖拽保护**：未上传状态下拖拽释放区域自适应占满视口，干掉右上角冗余按钮，支持点击任意区域秒开原生文件选择器，增加全局窗口防拖拽漏失拦截。
- **ZTools 插件安全体检中心（Plugin Guard）**：
  - **检索作用域聚焦**：默认仅对 `~/.ztools/plugins` 目录下的真实已安装插件进行深度体检，彻底排除开发环境杂乱源码目录的干扰。
  - **独立外部目录体检入口**：支持手动选取任意本地插件工程目录并置顶单独体检，无缝审查第三方开发插件。
  - **静态合规与安全审计**：深度扫描 `plugin.json` 清单结构、权限声明与高危 API 调用，综合输出健康评分（Health Score）、风险等级与合规建议。
- **扩展 3 项全新 MCP 工具能力（工具集扩充至 25 项）**：
  - `get_hardware_metrics`：只读获取实时 CPU/GPU/内存压力/磁盘分布/Top 5 资源消耗进程。
  - `inspect_archive_safety`：只读解析 ZIP 目录树结构并执行 Zip Slip 目录穿越安全判定。
  - `audit_installed_plugin`：只读审查 ZTools 本地已安装插件清单权限与高危调用并输出体检报告。
- **分层图标解析引擎**：各子模块统一引入 `icon-helper.cjs`，实现跨平台分层 Bundle 递归回退提取 App 图标与系统图标。

### 优化

- **应用深度卸载（Application Uninstaller）**：重构 UI 交互体验，支持高保真应用图标呈现、全选/反选与多维筛选交互、空状态插画及关联残留文件树形展开。
- **开机启动项管护（Startup Manager）**：新增 `useStartupGrouping` 分组管理引擎，按登录项、系统守护进程、用户代理、Windows 计划任务/系统服务清晰分类呈现，重构启停卡片交互与状态标签。
- **系统垃圾清理（System Cleaner）**：修复深色模式下复选框与文本重叠对齐问题，优化 warnings 错误信息安全字符串序列化，改进空间占用可视化。
- **硬件看板后台休眠节能**：集成 Page Visibility API（`document.hidden`），插件窗口最小化或切入后台时毫秒级挂起 1 秒高频采集子进程命令，切回前台时即刻唤醒刷新，杜绝后台无效 CPU 与电池消耗。
- **子页面受信任路由体系**：在 `router.cjs` 中注册 `archive-workbench` 与 `plugin-guard` 为受信任白名单子页面，保障跨模块跳转的安全性。

### 修复

- **系统级 5 级原生对话框平滑降级（`safeShowOpenDialog`）**：在宿主 API 缺失或子页面环境未完成桥接时，按优先级平滑回退至 `hostApi` $\to$ 全局 API $\to$ `remote.dialog` $\to$ macOS `osascript` $\to$ Windows PowerShell $\to$ DOM 选择器，彻底根除“当前宿主环境不提供目录选择对话框”报错。
- **拖拽文件交互修复（Path Masking）**：针对 Electron 28+ 拖拽文件物理路径抹除（置空字符串）的沙箱安全策略，构建物理路径与纯内存 ArrayBuffer 二进制流双轨互补解析引擎，杜绝拖入无响应现象。
- **脚本语法阻断修复**：排查并清理压缩包工作台交互脚本中遗留的多余语法字符，确保页面生命周期与 DOM 事件监听 100% 正常初始化。
- **自动化单测与契约同步**：更新全套测试套件断言，主工程 62 项独立单测及 5 个内置子模块 160+ 项深度单测全绿通过（共计 220+ 项自动化测试通过）。

### 安全

- **底层解压 Zip-Slip 目录穿越安全防御**：在 `extractZipArchive` 执行解压前强制预检 `safeFromTraversal`，一旦发现 `../`、`..\` 或绝对根路径条目立即安全熔断并拒绝解压，回退解压前严格核验目标目录归属性。
- **环境隐私与敏感路径脱敏**：彻底移除代码中残留的开发机个人绝对路径（`/Users/harris/...`），全量改为标准相对路径探针与内嵌静态分析回退，防止开发环境私密信息外泄。
- **MCP Schema 严格受控**：全部 25 个 MCP 工具的输入与输出对象严格锁定 `additionalProperties: false`，字符串皆有限定 `maxLength`，数组皆有限定 `maxItems`，杜绝未受审数据注入。

## 0.2.1 - 2026-08-03

### 修复

- 监听 ZTools 插件退出生命周期，运行中升级时拒绝新的副作用请求，并等待当前 Agent journal 在有限窗口内收敛。
- 为应用卸载与启动项变更增加受限、原子写入的本地恢复记录；重新进入时核对未完成批次，不自动重试系统写操作。
- 恢复跨会话启动项撤销记录到根 MCP runtime，确保新会话仍可安全调用 `undo_startup_change`。
- 将 Linux CNI、容器、虚拟化和 VPN 接口识别为受限网络接口；无法确认类型的非典型接口默认要求用户确认。
- 要求 Agent 在 `prepare_lan_scan` 中显式确认受限接口，防止执行阶段绕过虚拟/VPN/未知接口的二次确认。

### 优化

- 接入 ZTools 3.0.2 注入的 `--plugin-primary-color`，保持警告、危险和成功状态颜色的语义独立。
- 补充运行中升级、恢复记录、虚拟接口确认和主题色变量测试与安全说明。

## 0.2.0 - 2026-07-31

### 新增

- 将系统诊断报告融合为第五个系统管家模块，集中展示操作系统、处理器、内存、存储、显卡、电池与运行环境摘要。
- 为 ZTools 2.4 及以上版本注册 22 个 Agent 工具，覆盖诊断、应用处理、启动项、垃圾清理和局域网发现。
- 增加 Dashboard 短时授权，可按报告导出、应用处理、启动项变更、系统清理和局域网扫描五个范围独立授权。

### 优化

- 统一 Dashboard、SuiteBar、模块图标、状态标签和窄屏布局，并更新插件及模块截图。
- 业务服务保持按需加载；可信 Dashboard 与五个模块页注册工具，未知文件页和网络页面不获得特权能力。

### 安全

- 有副作用调用采用 90 秒单次 action、执行前复验、幂等键和当前 renderer 会话内的操作记录。
- 默认移除绝对路径、命令参数、设备标识等敏感信息；清理与应用处理仅移动复验通过的项目到系统废纸篓。
- 系统诊断探测在受控 helper 子进程中执行，限制并发、输出与清理时限，并锁定 `systeminformation@5.33.1` 的包完整性。
- 局域网扫描限制为选定本机接口、最多 `/24`、每 15 秒一次，不执行端口、公网或漏洞扫描。
