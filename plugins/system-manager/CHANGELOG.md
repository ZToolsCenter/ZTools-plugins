# Changelog


## 0.3.0 - 2026-08-31

### 新增

- **暗夜紫硬件工况仪表盘**：重构仪表盘核心视觉为专业暗夜紫电竞/服务器看板风格，提供 CPU 架构与实时利用率、统一显存/独立 GPU、物理内存多阶压力（Active/Wired/Compressed）、macOS/Linux 磁盘与挂载卷容量分布、以及消耗最高的 Top 5 进程实时排行。
- **压缩包安全工作台多级层级树展开预览**：重组平铺 entries 为结构化目录树，支持逐层展开/折叠、文件夹子项与递归大小统计、一键全部展开/全部收起、以及常见开发与媒体文件的智能图标映射。
- **ZIP 流式分片按需解析引擎**：纯前端新增基于 `file.slice()` 的轻量二进制解析器，通过按需截取末尾 65KB 索引 EOCD 与 Central Directory，数十 GB 超大压缩包秒开且内存开销小于 100KB。
- **插件安全体检聚焦已安装插件**：默认仅对 `~/.ztools/plugins` 目录下的真实已安装插件进行深度合规与安全审计，提供独立的【选择外部目录】置顶体检通道。
- **扩展 3 项全新 MCP 工具能力（工具集扩充至 25 项）**：新增只读 MCP 工具 `get_hardware_metrics`（实时 CPU/GPU/内存压力/磁盘分布/Top5进程）、`inspect_archive_safety`（ZIP 目录树结构与 Zip Slip 穿越风险分析）与 `audit_installed_plugin`（ZTools 本地已安装插件权限与高危调用体检报告），使 AI Agent 具备全方位的系统与插件安全审计能力。

### 修复

- **系统级 5 级原生对话框平滑降级**：实现 `safeShowOpenDialog`，在宿主 API 缺失或子页面未桥接环境下，平滑回退至 macOS `osascript`、Windows PowerShell 与浏览器 DOM 选择器，彻底解决“当前宿主环境不提供目录选择对话框”异常。
- **拖拽解析语法阻断与交互优化**：移除多余语法字符并修复 Electron 28+ 拖拽文件路径抹除（Path Masking）导致的无响应问题，实现物理路径与内存流双轨互补。
- **底层解压 Zip-Slip 目录穿越防御**：在 `extractZipArchive` 执行解压前强制实行 `safeFromTraversal` 穿越校验，自动熔断恶意相对路径覆盖。
- **彻底清理环境敏感路径残留**：移除 preload 服务层残留的本地开发机个人绝对路径，全量改为标准相对路径与内嵌静态分析回退。

### 优化

- **硬件看板后台休眠节能**：结合 Page Visibility API，在窗口最小化或后台切出时自动挂起 1 秒高频硬件采集子进程命令，前台切回时即刻唤醒刷新，显著降低待机能耗。
- **拖拽区视口高度自适应**：未上传状态下拖拽上传区域自适应占满窗口，干掉右上角冗余按钮，强化点击即选与全局防拖拽丢失保护。

## 0.2.1 - 2026-08-03

### 修复

- 监听 ZTools 插件退出生命周期，运行中升级时拒绝新的副作用请求，并等待当前 Agent journal 在有限窗口内收敛。
- 为应用卸载与启动项变更增加受限、原子写入的本地恢复记录；重新进入时核对未完成批次，不自动重试系统写操作。
- 恢复跨会话启动项撤销记录到根 MCP runtime，确保新会话仍可安全调用 `undo_startup_change`。
- 将 Linux CNI、容器、虚拟化和 VPN 接口识别为受限网络接口；无法确认类型的非典型接口默认要求用户确认。
- 要求 Agent 在 `prepare_lan_scan` 中显式确认受限接口，防止执行阶段绕过虚拟/VPN/未知接口的二次确认。

### 优化

- 接入 ZTools 3.0.2 注入的 `--plugin-primary-color`，保持警告、危险和成功状态颜色的语义独立。
- 补充运行中升级、恢复记录、虚拟接口确认和主题色变量测试与安全说明。

## 0.2.0 - 2026-07-31

### 新增

- 将系统诊断报告融合为第五个系统管家模块，集中展示操作系统、处理器、内存、存储、显卡、电池与运行环境摘要。
- 为 ZTools 2.4 及以上版本注册 22 个 Agent 工具，覆盖诊断、应用处理、启动项、垃圾清理和局域网发现。
- 增加 Dashboard 短时授权，可按报告导出、应用处理、启动项变更、系统清理和局域网扫描五个范围独立授权。

### 优化

- 统一 Dashboard、SuiteBar、模块图标、状态标签和窄屏布局，并更新插件及模块截图。
- 业务服务保持按需加载；可信 Dashboard 与五个模块页注册工具，未知文件页和网络页面不获得特权能力。

### 安全

- 有副作用调用采用 90 秒单次 action、执行前复验、幂等键和当前 renderer 会话内的操作记录。
- 默认移除绝对路径、命令参数、设备标识等敏感信息；清理与应用处理仅移动复验通过的项目到系统废纸篓。
- 系统诊断探测在受控 helper 子进程中执行，限制并发、输出与清理时限，并锁定 `systeminformation@5.33.1` 的包完整性。
- 局域网扫描限制为选定本机接口、最多 `/24`、每 15 秒一次，不执行端口、公网或漏洞扫描。

## 0.1.0 - 2026-07-31

- 初次发布，将插件提交至 ZTools 插件仓库。
- 新增跨平台系统管家套件
- 整合应用卸载、启动项管理、垃圾清理和局域网发现，补充跨平台安全边界、自动化测试及可复现发布打包。
- 融合系统诊断报告
- 新增第五个系统诊断模块，隔离软硬件探测进程，并锁定运行时依赖与发布校验。
- 统一套件界面与导航
- 重整 Dashboard 与四个维护模块的视觉层级、响应式布局和 SuiteBar 导航，并同步更新界面测试与截图。
- 接入 ZTools Agent 工具
- 注册 22 个本地工具，并加入短时授权、两阶段执行、幂等记录、结果脱敏与受限局域网扫描。
- 记录五项套件能力、Agent 工具调用方式、短时授权模型、诊断隐私边界及发布校验流程。
