# 收货地址智能解析

面向电商、客服、行政和物流场景的 ZTools 插件。把聊天消息、订单备注或收货清单粘贴进来，即可批量提取姓名、电话、省、市、区县和详细地址，检查缺失项，并导出 Excel/WPS 可直接打开的 CSV 表格。

## ZTools 兼容性

- ZTools 3.2.0：导出的 CSV 可从“拖出 CSV”按钮拖至外部应用。
- ZTools 2.4–3.1：保留保存对话框导出流程。
- 低于 2.4.0，或真实 ZTools 宿主无法提供可比较版本号：显示升级提示。仅未注入 `window.ztools` 的浏览器开发预览放行。

## 功能

- 本地规则解析：支持中国大陆手机号（含 `+86` 和空格/连字符）、常见座机、34 个省级行政区、地级市/自治州/地区/盟以及区县。
- 两种批量方式：每行一条，或用空行分隔多行记录。
- 稳定批处理：单次最多 1000 条，结果每页显示 100 条，避免大批量输入阻塞界面。
- 缺失字段检查：逐条标出姓名、电话、省、市、区县、详细地址中的缺失项。
- 表格内修正：解析后可以直接修改任何字段，完整状态随修改自动更新。
- 安全导出：输出带 UTF-8 BOM 的 CSV，使用 CRLF 行结束符，兼容 Excel 与 WPS，保留电话前导零，并防止用户内容触发公式注入。
- 隐私优先：解析过程完全离线，不上传或持久化地址数据。

## 使用方法

1. 在 ZTools 搜索“收货地址解析”“地址解析”或“批量地址”。选中包含手机号的文本也可直接触发。
2. 粘贴原始地址。默认每个非空行是一条记录；如果一条记录本身占多行，选择“空行分组”，并在记录之间留一个空行。
3. 点击“开始解析”或按 `Cmd/Ctrl + Enter`。
4. 用“待补充”筛选需要人工确认的记录，在表格中直接补全。
5. 点击“导出全部 CSV”，选择保存位置。

示例：

```text
张三 13800138000 广东省深圳市南山区粤海街道科技园科苑路 15 号
收件人：李晓明 电话：139-1234-5678 地址：北京市朝阳区望京街道阜通东大街 6 号
```

## 导出字段

`序号、姓名、电话、省、市、区县、详细地址、完整原文、缺失字段`

CSV 使用 UTF-8 BOM 和 CRLF，可直接由 Windows/macOS 上的 Excel、WPS，以及 Linux 上的 LibreOffice 打开。数字电话会输出为经过严格校验的固定文本单元格，因此座机 `021...` 的前导零不会被 Excel 删除；其他用户输入仍执行公式注入防护。

## 解析边界

插件使用可审计的确定性规则，不调用在线地图或 AI。规范地址（带“省/市/区/县”等后缀）的识别效果最佳；以下情况会保留在“待补充”列表中供人工修正：

- 省市区完全使用简称且没有行政区后缀；
- 地址存在同名区县或行政区划已变更；
- 只有门牌地址，没有姓名或电话；
- 海外地址和非中国行政区地址。

规则不会凭空补全无法可靠判断的字段，以避免把错误地址当成完整结果导出。

## 开发与自测

插件没有第三方运行依赖，要求 Node.js 16.17 或更高版本。

```bash
npm test
npm run check
```

测试覆盖：34 个省级行政区、姓名与省份简称冲突、长订单号手机号误判、字段标签、直辖市、自治区、全角数字、`+86` 手机号、座机、缺失字段、两种批量模式、1000 条批处理与分页上限、人工补全、CSV 转义/注入防护、取消导出，以及 Windows/POSIX 路径行为。

安装 Python Playwright 后，还可以启动静态服务器执行真实浏览器流程测试：

```bash
python3 /path/to/with_server.py \
  --server "python3 -m http.server 4173 --bind 127.0.0.1 --directory ." \
  --port 4173 -- python3 tests/ui_flow.py
```

脚本会自动寻找 Playwright Chromium、Chrome 或 Edge，并验证桌面端解析/补全/下载流程、移动端布局和控制台错误。

## 跨平台兼容性

| 平台 | 状态 | 依据 |
|---|---|---|
| Windows | 支持 | `path.win32` 导出路径测试；无原生依赖；CRLF + BOM CSV |
| macOS | 支持 | POSIX 导出路径测试；通过 ZTools 保存对话框选择路径 |
| Linux | 支持 | POSIX 导出路径测试；无平台专属 API 或二进制模块 |

插件不设置 `feature.platform`，使用 Node.js 标准 `fs/path` 和 `window.ztools.showSaveDialog`。所有路径都由保存对话框返回，不拼接硬编码分隔符。

## 隐私与安全

- 不发送网络请求，不保存输入历史。
- preload 仅暴露 `saveCsv(content, suggestedName)`，不向页面暴露 `fs` 或任意文件写入能力。
- 导出内容限制为 20 MB，保存位置必须由用户在系统对话框中选择。
- 文件外拖仅接受最近 5 分钟内由插件成功保存的 CSV，校验真实普通文件后单次授权，不能拖出任意绝对路径。
- CSV 对以 `= + - @` 开头的单元格增加文本前缀，降低表格软件公式注入风险。
