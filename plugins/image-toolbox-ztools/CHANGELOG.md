# 更新日志

## 3.0.1 - 2026-11-25

- 新增账号自动登录：打开插件自动恢复登录状态，登录过期自动续期，网络不稳时不再被误登出
- 修复保存或复制图片后分辨率与原图不一致的问题
- 修复画笔光标跟随有时不显示、绘制及缩放后不跟随的问题，光标改为单个圆圈

## 3.0.0 - 2026-11-08

- 新增 AI 配置与指令编辑，可接入多个 OpenAI 兼容服务商并用一句话自动调色
- 新增 PSD 工程文件导入/导出，支持保留图层
- 新增历史记录面板，可查看每一步参数变更并回到该步骤
- 调色新增中间调、色温、棕褐与灰度强度参数
- 新增大量滤镜预设，按基础/复古/黑白分类
- 修复画布缩放或平移后图层对齐与分布位置偏移的问题
- 修复选择滤镜后其他滤镜预览不准确的问题
- 修复连续裁剪或切换工具后图层被裁掉的问题
- 修复保存图片或 ORA 工程文件时默认位置可能带出常用目录的问题
- 修复 uTools 启动时控制台反复输出报错信息的问题
- 优化 AI「编辑当前图层」：效果先生成预览，确认后才替换原图
