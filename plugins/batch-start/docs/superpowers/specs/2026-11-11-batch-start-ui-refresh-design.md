# BatchStart UI 焕新设计

日期：2026-11-11  
状态：已确认，直接实施

## 目标

在不改变核心流程（扫描 → 选应用 → 启动组 → 试跑/指令启动）的前提下：

1. **跟随 ZTools 宿主主题**（亮暗 + 主色），插件不抢戏  
2. **保留三栏**，强化中间应用区为主工作面  
3. **分类弱化**：默认收起为窄轨，可展开；数据与 API 保留  

## 布局

| 区域 | 默认 | 说明 |
|------|------|------|
| 顶栏 | 全宽 | 标题 + 扫描(主)/加目录/试跑 + 上次扫描 |
| 左：分类 | 收起 ~48px | 展开 ~168px；状态持久化 |
| 中：应用 | flex:1 | 主表面、搜索、来源筛选、列表 |
| 右：启动组 | ~280px | 可折叠窄条；空状态轻量 CTA |

## 主题 Token

- `ztools.getThemeInfo()` / `onThemeChange` → CSS 变量  
- `--bg` `--surface` `--surface-2` `--text` `--muted` `--border` `--accent` `--selected` `--danger`  
- 无宿主 API 时浅色中性降级  
- 主色优先用宿主注入的 `--plugin-primary-color`（若有）或 themeInfo 解析  

## 视觉

- 平面 + 1px 分割，少阴影；圆角 6–8px  
- 系统字体栈；动效 150–200ms；`prefers-reduced-motion`  
- 列表选中：`--selected` + 左侧 accent 细条  
- 分段筛选低调，不大胶囊堆  

## 空状态 / 反馈

- 无应用：整页扫描 CTA  
- 有应用无组：右栏空状态  
- 筛选无结果：列表内提示  
- busy 防连点；试跑 toast；保存错误行内  

## 非目标

- 移除分类数据模型、拖拽排序、新手引导、自建主题页
