# Changelog

## 0.1.1 - 2026-09-17

- 扫描时合并已安装插件的 **ZTools 文本指令** 到应用列表（排除 setting / system / batch-start）
- 同时排除 batch-start 管理指令（`批量启动` / `应用启动组`）及其启动组动态注册的指令
- 指令扫描优先使用 ZTools 已安装插件注册表，避免把卸载残留 / 旧版 `.asar` 扫进来
- 启动组对指令成员通过 `redirect([插件标题, 指令])` 打开；指令消失后重新扫描会清理失效项
- 列表展示名称为指令词，副标题为所属插件；标签为「指令」
- 应用列表支持按「全部 / 系统应用 / 指令」筛选（默认全部）

## 0.1.0 - 2026-09-14

- 初次可用版本：应用扫描、手动分类、启动组动态 Feature、批量启动
- Windows 扫描支持 `.exe` / `.bat` / `.cmd` / `.lnk`；忽略卸载类快捷方式
- 中文显示名修复（Node 路径名 + UTF-8 批量解析 .lnk）
- 扫描性能：批量 PowerShell、`withFileTypes`、入库 bulk/并行
- 对齐官方 Vue 模板目录：`src-ztools/` + `base: './'`
- 更换插件 Logo
- 退出时 `outPlugin(true)`，仅在唤起时运行、不常驻后台
