# Changelog

本文件用于插件版本管理。每次发布新版时，在顶部新增一条记录，并同步修改 `plugin.json` 中的 `version`（语义化版本：主版本.次版本.修订号）。

## 1.2.0 - 2026-08-26

### 新增
- 输入即匹配：在 Ztools 搜索框输入含汉字内容时自动匹配，进入后带入文本
- 配置记忆：自动保存并恢复上次使用的模式与各项配置（localStorage）
- 深色模式：右上角太阳 / 月亮切换按钮，偏好持久化

### 优化
- 无

## 1.1.0 - 2026-08-25

### 新增
- 输入框清空按钮
- 界面字号统一调整为 14px

### 优化
- 配置项改为下拉菜单，默认窗口无需滚动
- 更新插件图标为圆角四格（pīn / yīn / 拼 / 音）

## 1.0.0 - 2026-08-21

### 初始版本
- 标准模式：大小写 / 音调 / 结果类型 / 非汉字处理 / 间隔换行 / ü→v / 姓氏
- 变量命名模式：10 种命名格式
- 基于 pinyin-pro 的纯前端实现
