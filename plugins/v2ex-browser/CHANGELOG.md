# Changelog

## 0.1.5 - 2026-09-30

- 将最新帖子列表缓存时长调整为 2 分钟；热门帖子继续缓存 10 分钟。

## 0.1.4 - 2026-09-30

- 热门和最新列表分别缓存 10 分钟，手动刷新立即更新当前列表缓存。
- 启动指令精简为 `v2ex` 和 `v2`，默认打开热门列表。
- 修复用户头像通过系统代理加载，以及原帖跳转按钮的显示样式。

## 0.1.3 - 2026-09-30

- 通过 Node 系统代理下载并缓存用户头像，修复 ZTools 页面无法直连头像 CDN 的问题。

## 0.1.2 - 2026-09-30

- 使用 Node HTTPS 代理 Agent 通过 macOS 系统代理请求 V2EX，修复 ZTools 未继承代理导致的连接失败。

## 0.1.1 - 2026-09-30

- 通过 ZTools Preload 请求 V2EX，避开浏览器跨域限制。

## 0.0.1 - 2026-09-30

- 初次发布，将插件提交至 ZTools 插件仓库。
