# Changelog

## 0.1.8 - 2026-10-26

- 支持帖子正文和评论富文本渲染，展示标题、列表、引用、代码、链接与图片。
- 评论按回复关系展示平级和多级嵌套内容，并保留楼层、时间及楼主标识。
- 单独识别表情与正文图片，避免表情换行或普通图片被误缩小。
- 链接统一经安全过滤后交由系统浏览器打开，并提供纯文本回退。
- 补全正文与评论中图片和链接的 HTTPS 地址，修复本地插件误用 file 协议导致图片无法显示。

## 0.1.7 - 2026-10-23

- 列表和详情页工具栏吸附顶部，滚动后仍可切换列表、搜索、刷新、返回列表和打开原帖，适配深色主题与窄窗口。
- 热门和最新列表分别记住滚动位置，切换后恢复各自上次阅读的位置。
- 详情刷新时保留正文、回复和滚动位置；刷新失败时保留已加载内容并显示错误提示。
- 补充插件作者的 GitHub 主页链接。

## 0.1.6 - 2026-10-17

- 修复 macOS 和 Windows 系统代理开关读取，关闭代理时正确直连，并在每次请求时使用最新配置。
- 明确提示不支持的自动代理配置，避免沿用已关闭或不适用的代理地址。

## 0.1.5 - 2026-09-30

- 将最新帖子列表缓存时长调整为 2 分钟；热门帖子继续缓存 10 分钟。

## 0.1.4 - 2026-09-30

- 热门和最新列表分别缓存 10 分钟，手动刷新立即更新当前列表缓存。
- 启动指令精简为 `v2ex` 和 `v2`，默认打开热门列表。
- 修复用户头像通过系统代理加载，以及原帖跳转按钮的显示样式。

## 0.1.3 - 2026-09-30

- 通过 Node 系统代理下载并缓存用户头像，修复 ZTools 页面无法直连头像 CDN 的问题。

## 0.1.2 - 2026-09-30

- 使用 Node HTTPS 代理 Agent 通过 macOS 系统代理请求 V2EX，修复 ZTools 未继承代理导致的连接失败。

## 0.1.1 - 2026-09-30

- 通过 ZTools Preload 请求 V2EX，避开浏览器跨域限制。

## 0.0.1 - 2026-09-30

- 初次发布，将插件提交至 ZTools 插件仓库。
