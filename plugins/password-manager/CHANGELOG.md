# Changelog


密码管理器 ZTools 插件（本地自用，纯 JS 重写）。

## [Unreleased]

### Changed
- 数据库文件 `passwords.db` 从插件目录内移到用户 `.ztools/password-manager/` 下，兼容市场 asar 安装（只读目录无法写库）。新增 `pmApi.getDbInfo()` 查看落盘位置；旧位置有库时自动迁移。
- 导入格式改为「首列 IP、其余皆字段列」，移除名称字段（按需自行加列）。
- 复制状态文案由「已复制 ✓」改为「已复制」；顶栏按钮高度对齐。
- 密码掩码固定为 8 个点 `••••••••`，不再按真实长度，避免泄露长度。

### Added
- 复制 IPv4 到剪贴板时自动填入搜索框（剪贴板联动）。
- 目录式安装支持（直接放置于 `.ztools/plugins/password-manager/`，改完重载即生效）。

### Fixed
- Excel 中以 `=` 开头的密码导入后为空：先关闭公式求值，再处理「值缺失但有公式残留」的单元格，正确按原文导入（含真实文件验证）。
- 空值字段显示为 `—`，与未揭示的掩码区分。
- 连续复制多台主机时，复制状态互斥，上一个自动复位。

### Removed
- 删除「显示本页」一键揭示整页明文按钮（改为单格点击按需揭示，更安全）。

## 0.1.0 - 2026-07-29

### Added
- 主密码登录/解锁，AES-256-GCM 逐字段加密 + PBKDF2-HMAC-SHA256(100k) 派生 + 设备绑定。
- 主机凭据表格展示（一行一台主机、一列一个字段），分页（50/100/200）与懒加载解密。
- 搜索（IP / 字段名）、复制（30s 自动清除）、新增、删除、明暗主题。
- CSV / Excel 导入（正则指令输 IP 直达、粘贴文件唤起）。
- 剪贴板 IP 联动搜索、空值识别、复制互斥等体验优化。
