## 一、已有功能

### 1. 空间首页（SpaceView）— 提示词快速检索与调用

| 功能 | 具体用途 | 适用场景 |
|---|---|---|
| **多视图切换** | 全部 / 最近 / 收藏 / 项目 / 资产 / 历史 / 回收站 七个视图一键切换 | 快速定位目标提示词范围 |
| **Fuse.js 模糊搜索** | 容错匹配、权重排序（标题 0.5 > 正文 0.3 > 标签 0.2），threshold 0.4 | 记忆模糊时仍能搜到，支持拼音/英文混合输入 |
| **键盘快捷键** | `↑↓` 选择、`Enter` 复制/填写、`E` 编辑、`Ctrl+N` 新建、`Esc` 返回 | 纯键盘操作，无需鼠标，提升效率 |
| **标签/项目筛选** | 按标签或所属项目过滤列表 | 按分类缩小范围 |
| **排序切换** | 按创建时间 / 更新时间 / 名称 / 使用次数排序，升降序可切换 | 找最新、最常用或按字母查找 |
| **自动聚焦** | 打开插件后输入框自动获得焦点（可配置开关） | 开箱即用，输入即搜 |
| **右键菜单** | 卡片右键：复制、编辑、收藏/取消、删除 | 快捷操作不离开当前视图 |

### 2. 变量填写面板（FillPanel）— 动态提示词填写

| 功能 | 具体用途 | 适用场景 |
|---|---|---|
| **变量自动识别** | 正文中用 `{{变量名}}` 声明变量，自动提取并生成输入框 | 代码审查模板中填入项目名、语言等 |
| **实时预览** | 左侧填写变量，右侧实时渲染替换后的最终文本 | 确认最终效果再复制 |
| **默认值填充** | 每个变量可设定默认值，减少重复输入 | 高频固定参数无需每次都填 |
| **必填/可选** | 无默认值的变量标记为必填，有默认值可选填 | 防止遗漏关键参数 |
| **一键复制** | 填写完成后一键复制渲染结果到剪贴板 | 粘贴到 AI 对话窗口 |
| **使用记录** | 复制后自动记录使用次数（usageCount）和最后使用时间 | 追踪提示词使用频率 |

### 3. 快速保存（QuickSaveView）— 从外部快速捕获提示词

| 功能 | 具体用途 | 适用场景 |
|---|---|---|
| **剪贴板保存** | 从剪贴板读取内容直接保存为提示词 | 在浏览器/文档中复制优质提示词后一键存入 |
| **选中文本保存** | 通过 ZTools 唤起栏选中文本后触发保存 | 选中长文本直接保存，无需复制 |
| **自动检测变量** | 正则 `\{\{(.+?)\}\}` 从文本中自动提取变量 | 无需手动声明变量 |
| **标题自动推断** | 取正文第一行作为标题，截取前 50 字 | 快速入库，减少填写 |

### 类别 D：架构与工程化

| 序号 | 功能名称 | 功能描述 | 预期效果 |

## 三、优先级建议

按"投入产出比"排序，建议优先落地以下 5 项：

1. **D4 持久化 Debounce** — 改动最小（约 20 行），直接提升性能体验
2. **A4 搜索高亮** — 改动集中在 PromptList 组件，用户感知明显
3. **B1 版本差异对比** — 补全版本管理闭环，让快照功能真正有价值
4. **A1 全局快捷键面板** — 一次性投入，长期降低用户学习成本
5. **D2 组件拆分重构** — 为后续所有功能开发铺平道路，降低维护成本
