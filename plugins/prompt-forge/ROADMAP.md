# PromptForge（词匠）开发路线图

> 本文档统一维护：已实现功能、已修复问题、未来待实现功能。
> 当前版本：v1.1.0（2026-08）

---

## 一、已实现功能

### 1. 空间首页（SpaceView）
- 七个视图切换：全部 / 最近 / 收藏 / 项目 / 资产 / 历史 / 回收站
- Fuse.js 模糊搜索（标题 0.5 / 正文 0.3 / 标签 0.2 权重）
- 搜索关键词高亮（`<mark>` 标签，深浅色主题）
- 键盘快捷键：`↑↓` 选择、`Enter` 复制/填写、`E` 编辑、`Ctrl+N` 新建、`?` 快捷键面板
- 标签 / 项目筛选，按创建时间 / 更新时间 / 名称 / 使用次数排序
- 自动聚焦搜索框（可配置），右键菜单快捷操作

### 2. 变量填写面板（FillPanel）
- `{{变量名}}` 自动识别并生成输入框
- 实时预览渲染结果，默认值填充，必填/可选校验
- 一键复制，自动记录使用次数

### 3. 快速保存（QuickSaveView）
- 剪贴板 / 选中文本保存（`pfs` 指令、`保存提示词`、正则匹配、over 模式）
- 自动检测变量、标题自动推断（首行前 50 字）
- 重复度检测（精确匹配 + 二元组 Jaccard 相似度 ≥ 0.8 提示）

### 4. 新建向导（WizardView）
- 三步引导：正文 → 基本信息 → 变量配置
- 变量实时提取，类型选择（prompt / snippet / template / constraint）

### 5. 库管理（ManageView）
- 左右分栏编辑器，五个标签页（正文 / 属性 / 变量 / 版本 / 统计）
- 正文变更自动递增版本并保存快照
- 版本查看、**版本差异对比（LCS-based diff）**、版本恢复
- 多选批量操作（删除 / 移入项目），类型 / 归属筛选

### 6. 组合拼接（ComposeView）
- 三栏布局：基础提示词选择 → 画布 → 片段/约束
- 前置 + 基础 + 后置拼接，实时合成预览，一键复制

### 7. 项目管理
- 创建 / 编辑 / 删除项目，5 个固定分组（开发 / 学习 / 写作 / 研究 / 其他）
- 项目内提示词筛选，删除项目后提示词自动转为"资产"

### 8. 回收站
- 软删除（`deleted=true`），恢复，永久删除

### 9. 使用历史记录
- 自动记录（含变量渲染后文本），按时间排序
- 重新复制、跳转原始提示词、上限可配置（50-500）、一键清空

### 10. 收藏功能
- 收藏 / 取消收藏，独立视图

### 11. 设置（SettingsView）
- 复制后关闭窗口、自动聚焦、历史上限
- 浅色 / 深色主题，JSON 导入导出（按 ID 去重），清空数据

### 12. 数据持久化架构
- LMDB KV 存储（prompts / projects / settings 三文档）
- Preload（`window.kvStorage`）+ Fallback（`ztools.dbStorage`）双路径
- 300ms Debounce 合并写入，Fuse 索引懒加载
