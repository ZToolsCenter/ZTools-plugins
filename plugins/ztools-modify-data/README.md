# ZTools 插件数据编辑器

用于浏览和修改已安装 ZTools 插件的 `ztools.db` / `ztools.dbStorage` 数据。界面为中文，无前端构建步骤。

## 安装和使用

1. 把 `dist/ztools-modify-data-1.1.1-win-x64.zip` 拖入 ZTools，选择安装；也可在插件管理页通过「导入插件」选择该 ZIP。
2. 搜索 `插件数据`、`修改插件数据`、`数据编辑器` 或 `modifydata` 打开。
3. 先退出需要修改的目标插件，避免其内存缓存覆盖新值。
4. 在列表页选择插件，再点击记录进入二级编辑页面。编辑区默认占满页面；dbStorage 默认只编辑 `value`，普通文档编辑自定义字段。
5. 修改 JSON，点击「检查并保存」或按 Ctrl+S，检查原值和新值后确认。
6. 重新打开目标插件以读取新数据。如果插件常驻后台，在 ZTools 插件管理中结束该插件再打开。

自动连接 `%USERPROFILE%/.ztools`，也会读取宿主进程的 `ZTOOLS_DATA_ROOT`。数据空间自动跟随 ZTools 当前登录账号；账号切换后需刷新重新连接。

开发运行：在 ZTools 开发者工具中导入此目录的 `plugin.json`。请先执行 `npm install`。

1.0.1 修复了 Electron 插件预加载环境下 LMDB 原生模块定位错误的问题。开发版更新源文件后，请在插件管理中结束该插件再打开；普通刷新页面可能仍保留旧模块缓存。

## 大数据编辑（1.1.0）

1.1.1 起，「数据空间」仅显示当前账号下拥有数据库记录的插件；无数据的插件不显示，也不计入空间数量和搜索结果。保存了 `false`、`0` 或 `null` 的记录仍属于有数据。

- 两级页面：先浏览插件和数据记录，点击记录进入宽幅编辑页面，通过「返回数据列表」返回；未保存的修改会提示确认。
- 「大窗口编辑」打开 1400 × 900 的独立窗口，可拖动调整尺寸或最大化。当前记录、未保存草稿、选区及滚动位置会一起带入；原窗口中的内容也保留。
- 「专注编辑」隐藏非编辑信息，进一步扩大编辑区，快捷键 Ctrl+Shift+F。
- 插件、记录列表可单独开关，拖动分隔线调整宽度。
- 提供行号、光标位置、12–20 的字号和自动换行；字号、换行及列表宽度会记住。
- Ctrl+F 查找文本，Enter / Shift+Enter 定位下一处 / 上一处。
- 大段 JSON 的校验采用短暂延迟，减少连续输入时反复解析。1 MB 限制按实际 JSON 数据计算，排版空白不会影响编辑器校验；保存仍以 ZTools 文档大小上限为准。
- 历史备份默认折叠，保存按钮一直位于页面底部，不需要滚动整个页面才能保存。

大窗口以本地一次性临时文件传递草稿，读取后删除，不写入原插件数据库。两个窗口分别编辑同一条记录时，后保存的窗口仍会执行版本冲突检查。

## 备份和恢复

每次写入前会把原始文档保存到数据根目录中的 `data-editor-backups/<插件名的 SHA-256>/`。备份成功后才提交数据库事务，备份失败则不写入。备份包含原始插件数据，请自行保管。

选中记录后，在「历史备份」选择一次备份，点击「回填到编辑器」，检查并保存即可恢复自定义字段。恢复会生成新版本，并再次备份恢复前的数据。回填不会立即修改数据库。附件内容始终保留当前版本，不包含在 JSON 导出或恢复范围内。

「导出插件 JSON」导出该插件全部 JSON 文档及版本字段；导出不是完整数据库备份，不包含附件二进制内容。
