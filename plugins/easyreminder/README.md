## 功能

### 三种提醒模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **间隔提醒** | 在指定时间段内，每隔 X 分钟提醒一次 | 久坐提醒、喝水提醒、眼保健操 |
| **每日提醒** | 每天固定时间提醒（可指定星期几） | 起床、吃药、会议提醒 |
| **一次性提醒** | 在指定日期时间触发一次，触发后自动禁用 | 倒计时、临时事项提醒 |

### 后台运行

调度器运行在 ZTools preload 层，插件窗口关闭或隐藏到后台时，定时器依然正常运行，到点自动弹出系统通知。

**开机自启后仍要提醒（重要）**：ZTools 只在「创建插件视图」时才执行 preload.js —— 即用户打开插件，或勾选了「跟随主程序同时启动运行」。所以电脑重启、ZTools 随系统自启之后，本插件也需要自启，否则提醒任务不会开始调度：

1. 在 ZTools 搜索框输入 `提醒` 打开本插件
2. 点右上角设置按钮 → **插件设置** → 勾选 **跟随主程序同时启动运行**

勾选后 ZTools 启动时会在后台预加载本插件（`plugin.json` 已声明 `backgroundRunning`，后台视图不会被节流），提醒任务随之启动。首页底部的「调度中 · 下次 …」可确认调度器已就绪，「系统日志」里也会有一条 `[启动]` 记录。

### 法定工作日 / 节假日触发

新建或编辑提醒时可选择「触发日」：**不限 / 仅工作日 / 仅节假日**。判断依据国家法定节假日安排（含调休补班），数据来自 [timor.tech](https://timor.tech) 节假日 API：

- 进入插件时检查本地缓存，缺哪年就自动拉取一次（当年全年数据；12 月起顺带补次年），已有数据则不发起请求
- 断网时使用本地缓存判断；缓存也未获取到时退化为按自然周（周一至周五为工作日）近似

### 触发对齐（间隔提醒）

间隔提醒可选择触发点的计算方式：

| 对齐方式 | 行为 | 示例（09:00–18:00，每小时） |
|---------|------|--------------------------|
| **按开始时间对齐** | 触发点 = 开始时间 + N × 间隔，与创建时刻无关，错过自动回到下一格 | 10:30 创建 → 11:00、12:00…准点触发 |
| **按创建时间起算** | 从创建时刻起每隔一个间隔触发 | 10:30 创建 → 11:30、12:30… |

### 通知格式

- 标题：提醒任务名称
- 内容：提醒描述文字

### 分组管理

新建或编辑提醒时可在「分组」下拉里选择分组，也可以直接输入新组名创建分组。一个提醒最多归属一个分组，未选择即为未分组。

列表默认只显示分组入口（组名 + 当前分类下的任务数）和未分组任务，点击分组向下展开组内任务，再次点击收起。组头提供四个操作：

| 操作 | 行为 |
|------|------|
| **启动** | 批量启用组内全部任务 |
| **停止** | 批量停用组内全部任务 |
| **解散** | 只移除分组，组内任务保留并转为未分组 |
| **删除** | 连同组内全部任务一起删除（确认框会提示任务数） |

### 多选批量操作

多选工具栏固定显示在状态 Tab 上方，不会随勾选出现/消失：

| 操作 | 行为 |
|------|------|
| **全选** | 选中/取消当前可见的任务（未分组任务 + 已展开分组内的任务） |
| **移入分组** | 选择已有分组，或直接输入新组名 |
| **移出分组** | 将所选任务转为未分组（仅有已分组任务时显示） |
| **启用 / 停用** | 批量切换启用状态 |
| **删除** | 批量删除所选任务，弹窗确认 |

未选中任务时工具栏只显示「全选」；选中后才出现上述操作按钮。切换状态分类、收起分组（该组内已勾选的任务会从选择中移除）、完成一次批量操作后，选中状态会相应清理。

### 拖拽排序

- **分组排序**：拖动组名左侧的六点手柄，放到另一分组的上/下半区即可调整分组顺序。
- **任务排序**：拖动任务左侧的六点手柄，可在同一列表内上下调整顺序。
- **改分组**：把任务拖到其他分组行上，会移入该组并自动展开；拖到其他分组的任务上，会按落点位置插入；拖到未分组任务上则移出分组。

### 复制提醒

列表项右侧的复制按钮可一键复制任务。副本的配置、启用状态和所属分组与原任务一致，标题追加「（副本）」，触发记录重置，相当于一条全新的任务。

## 使用方式

### 触发

在 ZTools 搜索框输入以下指令之一：

- `提醒`
- `定时提醒`

### 新建提醒

1. 点击 **+ 新建** 按钮
2. 选择提醒类型（间隔 / 每日 / 一次性）
3. 填写提醒标题和内容
4. 按需选择分组（可选已有分组，或直接输入新组名）
5. 配置具体时间参数
6. 按需选择触发日（不限 / 仅工作日 / 仅节假日）
7. 点击 **保存**

### 管理提醒

- **开关**：列表右侧开关可随时启用/禁用提醒
- **复制**：点击复制图标得到配置、状态、分组一致的新任务
- **编辑**：点击编辑图标修改提醒参数，包括调整所属分组
- **删除**：点击删除图标移除提醒
- **分组**：点击分组行展开/收起组内任务；组头可批量启动/停止、解散或删除整个分组
- **多选**：Tab 上方的工具栏常驻显示，支持全选；选中后批量移入/移出分组、启停、删除
- **拖拽**：拖动六点手柄可调整分组或任务顺序，任务拖到其他分组即改变归属

## 常见问题

### 后台不提醒？

确认 ZTools 系统通知权限已开启。调度器运行在 preload 层，窗口隐藏后仍会触发。

### 重启电脑后不提醒？

需要勾选「跟随主程序同时启动运行」（见上文[后台运行](#后台运行)）。ZTools 只在创建插件视图时执行 preload.js；未勾选自启时，重启后必须手动打开一次插件，调度器才会开始工作。打开插件后可在底部看到「调度中 · 下次 …」，或在「系统日志」里确认 `[启动]` 记录。

### 通知不显示？

检查系统通知权限是否允许 ZTools 发送通知。

### 数据会丢失吗？

提醒数据存储在 ZTools 云端，开启数据同步后不会丢失。
