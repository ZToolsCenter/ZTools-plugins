# Changelog

## 1.0.1 - 2026-08-27

### 修复
- 修复安装编译包后打开白屏问题：feature code 与前端 route 判断不一致，导致主界面不渲染

## 1.0.0 - 2026-08-27

### 新增
- 三种提醒模式：间隔提醒、每日定点提醒、一次性定时提醒
- 调度器运行在 preload 层，插件后台运行也能稳定触发通知
- 支持自定义提醒标题和内容
- 间隔提醒支持多时间段、自定义间隔（分钟）
- 每日提醒支持选择星期几和具体时间
- 一次性提醒支持选择日期和时间，触发后自动禁用
- 提醒列表支持启用/禁用开关
- 调试日志面板（默认关闭），方便排查问题

### 优化
- 动态调度算法：精确计算下次触发时间，偏差 < 20ms
- 系统通知：标题显示任务名，内容显示描述
- 数据持久化：使用 ZTools dbStorage，数据随账号同步

### 技术
- 基于 Vue 3 + TypeScript + Element Plus
- 调度逻辑在 preload 中运行，不受渲染进程节流影响
- 响应式数据流，操作即时反馈
