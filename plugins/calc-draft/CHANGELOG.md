# Changelog

## 1.0.0 - 2026-09-26

- **插件定位**: 类似`计算稿纸`插件，提供更加现代化的UI和交互设计以及更多的高级特性
- **公式行引用**: 编写计算公式时可以通过`#id`引用公式行，动态联动
- **跨草稿引用**: 可以通过`@id#id`引用其他草稿中的公式行，动态联动
- **多步计算**: 每行写一个表达式，自动出结果。支持四则运算、幂、取模、常用函数（sqrt/sin/cos/log/abs/round 等）和常量（pi/e）
- **快捷操作**: 几乎所有操作都可以通过键盘来编辑，例如`Ctrl + 单击`跳转引用位置符合`JB家族 Coder`的使用习惯
- **自动补全**: 草稿引用/公式引用都可以自动补全，并且支持备注搜索，拼音搜索，非常丝滑
