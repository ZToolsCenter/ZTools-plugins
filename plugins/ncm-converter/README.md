# 音频转 MP3（ZTools 插件）

> **作者**：一个成熟的剪辑猿


一键把任意音频文件转成 **无封面的 MP3**：

- **网易云 NCM** → 纯 JS 解密后输出 MP3（不带封面）
- **wav / ogg / flac / m4a / aac / wma / opus / mp3 / ape / caf / aiff / amr** 等 → 调用 ffmpeg 转码为 MP3（不带封面）

复刻 uTools 里「中键选文件 → 超级面板 → 一键转换」的体验，但**全程静默**：触发后主窗口立即隐藏，
转换完成用**右下角提示窗 + 提示音**告诉你结果。

## 特性

- **无界面 / 静默**：触发后立刻隐藏主窗口，转换过程不占用屏幕。
- **完成反馈**：转换结束后**右下角弹出自毁提示窗**（列出每个文件的成功/失败），同时**播放提示音**；
  另发一条 Windows 通知中心原生 toast（横幅消失后可在通知中心查历史）与宿主系统通知。
  三条通道互为兜底，任一失败都不影响其余。
- **输出位置**：与源文件同目录，文件名优先取「艺人 - 歌名」（NCM），否则用原文件名。
  同名自动追加序号（`xxx (1).mp3`），不会覆盖已有文件。
- **无封面**：所有输出 MP3 都带 `-vn`，不保留任何封面/图片流。
- **容错**：源目录不可写（网盘 / 只读 / 受保护目录）时自动回退到桌面，避免整单失败。
- **依赖**：NCM 解密纯本地完成；其他格式**优先调用系统已安装的 ffmpeg**（自动探测 PATH 与常见安装路径，含 `C:\Program Files\ffmpeg-2022-11-03\bin\ffmpeg.exe`），不触发 ZTools 的下载弹窗。仅当系统完全没有 ffmpeg 时，才回退到 ZTools 内置 `runFFmpeg`（需要联网下载集成，且 ZTools 下载节点可能不可达）。

## 安装到 ZTools

1. ZTools → 设置 → 插件 → 右上角「更多」→ **导入本地插件**
2. 选择 `zt-ncm-converter.zip`（注意 plugin.json 必须在 zip 根目录）
3. 预览页点 **安装插件** → 安全警告点 **已知风险，继续安装**
4. 旧版「NCM 转换」建议先删除再装，避免重复

## 用法

- **超级面板（推荐）**：在文件管理器里中键选中任意支持的音频文件 → 长按悬浮球 → 点「音频转 MP3」。
- **搜索框**：打开 ZTools，输入 `转mp3` / `tomp3` / `ncm` → 选文件（可多选）→ 转换。

转换完成后同目录会出现 `.mp3` 文件，右下角弹出结果提示窗。

## 文件说明

| 文件 | 作用 |
|------|------|
| `plugin.json` | 插件清单：定义 `files` 类型功能（覆盖常见音频扩展名）+ 搜索命令。 |
| `preload.js` | 核心逻辑：静默隐藏、提取路径、NCM 解密、ffmpeg 转码、完成提示（提示窗/提示音/通知）。 |
| `ncmdump.cjs` | vendored 的 NCM 解密库（来自 `ncmdump-js`，纯 JS，无外部依赖）。 |
| `index.html` | 占位页（headless 插件正常不显示）。 |
| `logo.png` | 插件图标。 |

## 开发者备注：plugin.json 的 `files` 指令写法

ZTools 客户端读取 `files` 类型指令时，**扩展名必须平铺在指令对象上**：

```jsonc
{
  "type": "files",
  "label": "音频转 MP3",
  "fileType": "file",
  "extensions": ["ncm", "wav", "mp3"]   // ← 平铺在这里
}
```

`cmd.extensions` 是客户端唯一读取扩展名的地方；`cmd.match` 则是**正则字符串**（如 `"/\\.ncm$/"`），
用于按文件名匹配。把扩展名塞进 `match: { ... }` 对象里会导致规则编译抛
`InvalidContextRuleError: 字段 match 应为 string`，指令整体失效（插件表现为「用不了」），
同时扩展名过滤也会失效（任意文件都能触发该指令）。

## 已知限制

- 转码依赖系统 ffmpeg（推荐安装到 PATH 或 `C:\Program Files\ffmpeg\bin\`）。插件会自动探测常见路径；若系统确实没有 ffmpeg，会提示安装，而不会反复弹 ZTools 的下载窗。
- 输出目录固定为源文件所在目录（不可写时回退桌面），暂不支持自定义。
- 提示窗属于插件进程，主程序在 `enter` 的 Promise 结束后才退出插件，因此转换完成后会有约 5 秒的停留等待提示窗自毁。
