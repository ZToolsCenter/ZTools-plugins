# Changelog

## 1.0.0 - 2026-10-26

### 新增

- 首次发布：Windows 环境变量可视化管理器
- 用户变量 / 系统变量双作用域查看，支持新增、编辑、删除
- 编辑值时可直接「选择文件 / 选择文件夹」填入路径，也可以手动输入（选中后按分号追加）
- 点击列表任意一行打开详情：完整值（点击即复制）、类型说明（悬浮显示）、`%引用%` 展开后的实际生效值
- 多路径变量（PATH 类）在详情里以表格展示，逐条给出展开值与「存在 / 缺失」状态（缺失行标红加底色）
- 列表精简为「变量名 / 值 / 操作」三列，类型改为在详情页里查看（悬浮出说明）
- 值本身是单条路径时支持「打开目录」（详情页底部、PATH 编辑器每条路径；列表里不显示），含 `%引用%` 的先展开，值是文件则定位并选中
- 类型不再直接暴露 `REG_SZ` 术语，界面显示「普通文本 / 可展开文本」，REG 全名放到悬浮提示里；悬浮说明按当前值给上下文（可展开但无引用 / 普通文本却含引用）
- PATH 专项编辑器：逐条拆分、拖动排序、置顶、去重、无效路径标红、`%引用%` 展开预览、选文件夹直接追加
- 系统变量批量提权写入：一次 UAC 完成本次全部系统变量改动；ZTools 以管理员运行时零弹窗
- 应用前的变更 Diff 预览（新增 / 修改 / 删除分类展示）
- 备选值 + 快速切换：同一个变量可存多个候选值（如多个 JDK）；列表里点「切换」就地换成下一个值（可以一直点循环），**不点「确认」不写入**；确认后只保存这一行并自动生成单项快照，系统变量弹一次 UAC；详情页点任意候选值同样先进待确认状态
- 循环里始终包含「原值」：原值不在备选列表中时也作为一环参与轮换（详情里显示为带「原值」标记的芯片），切走之后随时能切回来；切回原值等于取消待确认，不产生无意义写入
- 写入成功后自动把「改前值」补进该变量的备选列表（只对有备选值的变量生效），切换确认后原值不会丢，永远留在候选里
- 切换按钮的显示条件改为「去重后的候选 ≥ 2」（候选 = 当前生效值 + 备选值）：只剩一条与当前值相同的备选时按钮自动隐藏，不再出现点了没反应的切换
- 备选值芯片压缩显示：多路径值显示为「N 条路径」、超长值截断加省略号，完整值悬停查看，PATH 这类长值不再撑满整行
- 快照回滚加转圈提示：确认后按钮变「回滚中…」并禁用其它操作，避免等 UAC 期间重复点击
- 详情页固定展示「当前生效值」，未确认的新值单独一行提示，避免误以为已经改好；详情内容随待确认状态实时刷新
- 快照两种粒度：修改前的自动快照只记录本次被改动的那几项（diff 快照，约 200 字节 vs 全量约 4KB），回滚只影响这些变量、不覆盖之后对其它变量的改动；「立即快照」仍是整份备份
- 快照内容可查看：单项快照列出「变量名 / 改前 / 改后」，整份快照按用户 / 系统分页列出全部值，均支持搜索、导出与回滚
- 编辑弹窗对 `*_HOME` 类变量检测多值（含分号）并给出黄色警告：`_HOME` 只接受单个目录，多值被拼进 PATH 时会拆成两条、前段失效（典型「配了 jdk8 却跑 jdk17」）
- 写入后广播 `WM_SETTINGCHANGE`，资源管理器与新开终端立即生效
- 保留注册表值类型：`REG_EXPAND_SZ` 的 `%变量%` 引用不会被展开成死值
- 支持暗色模式（跟随系统主题）
