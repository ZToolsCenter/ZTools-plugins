# Changelog


## 1.2.0 - 2026-08-27

- 支持在资源管理器和选中文件夹中搜索。
- 支持 Tab 键切换分组，提升分组切换速度和运行健壮性。

## 1.1.1 - 2026-08-24

- 支持调整侧栏宽度和分类顺序。
- 优化图片原始比例拖动、缩放动画、排序菜单及侧栏布局。

## 1.1.0 - 2026-08-22

- 支持多选、原生拖拽和批量右键操作。
- 增加搜索结果与预览区域的宽度调整、图片透明棋盘背景及缩放按钮。
- 修复预览切换闪烁、下拉菜单和 ASAR 中的 Everything 路径问题。
- 增加 everything_search MCP 工具，优化主题与设置交互。

## 1.0.2 - 2026-07-19

- local-search-neo 兼容asar

## 1.0.1 - 2026-07-01

- 修复路径匹配相关的审查问题，更新依赖与版本配置。

## 1.0.0 - 2026-06-09

- 初次发布，将插件提交至 ZTools 插件仓库。
- 实现基于 Everything 的文件搜索、分类管理、分页与匹配高亮。
- 支持图片、代码、Markdown、PDF、目录树及归档等文件预览。
- 增加文件复制、图标缓存、图片缩放与预览复制。
- 完善内置 Everything 管理及原生模块构建，修复路径匹配、文本解码和初始化输入框问题。
