# 🔓 文件解锁器 (File Unlocker)

一款高性能 Windows 文件/文件夹占用解除插件。参考 **IObit Unlocker** 的核心设计，支持深度扫描锁定源、无损释放句柄、强制结束进程、安全移至回收站及批量处理。

![插件界面预览](logo.png)

---

## ✨ 核心功能

### 1. 📁 便捷添加待解锁目标
- **文件选择器**：点击「添加文件/文件夹」通过系统对话框多选添加；
- **拖拽支持**：直接将单个或多个文件/文件夹拖拽至窗口任意区域；
- **剪贴板粘贴**：复制本地路径后在插件界面直接 `Ctrl+V` 快速导入。

### 2. 🖱️ 进程精细化控制（右键菜单 & 双击）
在右侧占用列表中，针对具体占用进程提供全面的控制选项：
- 🔍 **查看进程详情**：弹出结构化详情面板，展示进程名、PID、可执行文件完整路径、占用类型（目录/文件/模块/系统）及句柄 Hex 列表；
- 📂 **打开程序位置**：在资源管理器中直接定位并高亮选中该程序的 `.exe` 文件（**支持双击进程行快速直达**）；
- 🛡️ **仅关闭句柄（无损解锁）**：基于 `DuplicateHandle(DUPLICATE_CLOSE_SOURCE)` 仅释放被占用的文件句柄，**无需关闭主程序**（如不关闭 IDE/编辑器即可解除某个文件的锁定）；
- ⚡ **强制结束进程**：调用 `taskkill /F /T` 结合底层 `TerminateProcess` 强制终止该进程树。

### 3. 🛠️ 丰富的解锁后处理
- 🔓 **一键解锁**：直接释放句柄或结束占用程序；
- 🗑️ **解锁并移至回收站**：解除占用后，将文件/文件夹安全移入 **Windows 系统回收站**（可随时还原，杜绝误删风险）；
- ✏️ **解锁并重命名**：解除占用后输入新文件名即时重命名；
- 📦 **解锁并移动**：解除占用后选择目标文件夹完成迁移；
- 📍 **定位文件**：一键在 Windows 资源管理器中高亮选中文件/文件夹。

### 4. 📚 批量处理
- 支持勾选多项或全部文件；
- 顶部工具栏一键 **「全部解锁」** 或 **「全部移至回收站」**。

## 🎨 快捷操作与交互指南

| 操作 | 对应功能 |
| :--- | :--- |
| **拖拽文件 / 文件夹到窗口** | 快速添加待解锁对象 |
| **点击文件项** | 选中文件并在右侧查看具体占用进程 |
| **右键占用进程** | 唤出菜单：查看详情 / 打开位置 / 仅关闭句柄 / 强制结束进程 |
| **双击占用进程** | 快速在资源管理器中打开该程序所在文件夹并高亮选中 |
| **`Esc`** | 关闭弹窗 / 取消操作  |

> 🌓 界面已完美适配系统 **深色模式 (Dark)** 与 **浅色模式 (Light)**。
