# 快速密码填充插件使用手册
> **通过长按鼠标中键呼起超级面板，实现就地极速自动填密**

---

## 🎯 核心使用理念

传统密码工具通常需要：
`切换窗口 ➔ 搜索密码 ➔ 复制 ➔ 切回目标窗口 ➔ 粘贴`。

本插件配合 ZTools 超级面板后，操作路径缩短为极致的 **“就地触发，无感回填”**：
```
光标在账号框(双填) 或 密码框(仅密码) ➔ 就地长按中键 0.5 秒 ➔ 点「填密码」 ➔ 选密回车 ➔ 严格保序自动填入并隐去
```

---

## ⚙️ 第一部分：首次使用配置指南（仅需一次）

### 步骤 1：在 ZTools 中开启「超级面板」
1. 按快捷键呼出 ZTools 主搜索框（默认快捷键为 `Alt + 空格`）；
2. 点击搜索框右上角的齿轮图标或头像进入 **「设置」**；
3. 在左侧菜单中选择 **「超级面板」**；
4. 勾选 **「开启超级面板」**；
5. 在弹出方式中选择 **「长按鼠标中键」**（推荐长按时长设定为 **400ms ~ 500ms**）。

### 步骤 2：将「快速填充密码」固定到超级面板
1. 在 ZTools 搜索栏输入指令：`填密码` 或 `pwd`；
2. 搜索结果列表中将出现带有蓝色锁图标的 **「快速填充密码」**；
3. **在该条目上单击鼠标右键**；
4. 在右键上下文菜单中点击 **「固定到超级面板」**；
5. 此时该条目右下角会出现一枚固定的图钉图标，表示已成功收录至超级面板。

## 🚀 第二部分：日常使用完整操作流

### 1. 就地长按唤起
- 在任意浏览器或客户端登录界面时，请先确认光标位置：
  - 若要使用 **「账号+密码」双填**：请用鼠标左键点入**账号/用户名输入框**；
  - 若只想 **单填「密码」**：请用鼠标左键点入**密码输入框**；
- 此时直接在当前光标位置，**长按鼠标中键约 0.5 秒**，鼠标指针旁将弹出 ZTools 超级面板。

### 2. 选取密码指令
- 在弹出的超级面板中，直接左键点击 **「快速选择并填充密码」** 图标（也可以直接按下图标对应的快捷数字键）。

### 3. 极速多词检索
- 屏幕将弹出轻量悬浮选密窗口；
- 支持**空格分隔多关键词**检索（同时匹配平台名称、账号与备注）及关键词高亮，未匹配时支持一键创建条目；
- 支持键盘 `↑`、`↓` 快速移动高亮条目，前 9 条支持 `Alt+1~9` 直接选中填充；
- 按 `Ctrl+C` 可直接复制当前选中密码（支持智能定时清理）。

### 4. 一键安全回填
- 顶部搜索栏右侧提供「回车: 双填 / 仅密码」切换胶囊，可随时切换默认 `Enter` 策略；
- 每个条目右侧提供三个独立按钮，按需点击：
  - **「账号+密码」**：填入账号 ➔ 等待消费并 `Tab` 切到密码框 ➔ 填入密码（需光标在账号框）；
  - **「账号」**：仅把账号填入当前光标所在输入框；
  - **「密码」**：仅把密码填入当前光标所在输入框（需光标在密码框）；
- 键盘快捷键：`Enter` 按当前默认策略填充、`Shift+Enter` 仅密码、`Alt+Enter` 仅账号；
- 插件悬浮窗瞬间隐去后，底层引擎严格串行等待焦点恢复并逐框落盘校验填充，彻底防止账号密码填反；
- 系统剪贴板将在设定秒数（默认 10 秒）后智能擦除密码残留（若期间已复制其他非密码内容，绝不会误清）。

## 💡 第三部分：常见场景与避坑指南

### 1. 遇到禁止粘贴的网页/系统（如网银、政企平台、安全终端）
- 某些前端页面屏蔽了键盘 `Ctrl+V` 或鼠标粘贴事件；
- **解决方案**：
  1. 呼出本插件的完整管理面板（搜索 `密码管理` 或点击设置图标）；
  2. 进入「首选项设置」；
  3. 将 **自动填充模式** 切换为 **「模拟键盘打字 (hideMainWindowTypeString)」**；
  4. 保存后，插件将使用底层 Unicode 虚拟键盘将密码逐字按键输入，彻底绕过网页端的一切粘贴拦截。

### 2. 目标应用程序以「管理员身份运行」
- **表现**：在网页和普通记事本里可以自动填充，但发现在某些终端（如管理员 PowerShell、以管理员身份运行的编辑器）中无法粘贴；
- **原因**：Windows 系统的 UIPI（用户界面特权隔离）机制，严禁普通权限软件向管理员权限窗口发送模拟按键；
- **解决方案**：将 **ZTools 也右键设置为「以管理员身份运行」**，权限对齐后即可全域畅通无阻。

### 3. 特殊 Win32 MDI 架构编辑器（如 Notepad++）
- Notepad++ 的文本区域是一个独立的 `Scintilla` 子窗口。长按鼠标中键唤起超级面板时，Scintilla 默认会响应中键进入滚动状态并暂时隐藏 Caret 光标；
- 插件现已内置 **450ms 焦点自愈与二次防丢保障**，彻底解决窗口恢复时的光标失焦与物理按键未弹起冲突；
- 若您的电脑安装了大量 Notepad++ 插件导致窗口恢复更慢，可在插件「设置」中将「前台焦点恢复等待时长」调至 **600ms**。

### 4. 首次使用与锁屏保护
- 每次系统重启或手动锁定时，插件处于零知识 AES-256-GCM 本地加密锁定状态；
- 此时长按中键触发会先展示 4 位 PIN 输入框，输完 PIN 后自动解锁并记忆内存，随后的多次填充均无须再次输密。
