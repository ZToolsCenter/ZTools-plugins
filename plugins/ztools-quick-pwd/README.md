# 快速密码填充 (ZTools 插件)

本地 AES-256-GCM 高度安全加密的密码存储与自动填充插件。支持长按鼠标中键或快捷指令一键将密码填入当前光标所在输入框，零额外依赖，纯本地运行。

![logo](logo.png)

## ✨ 核心特性

-  **高强度本地加密**：采用 PBKDF2 (SHA-256, 100,000次迭代) 派生主密钥，所有敏感数据均通过 **AES-256-GCM** 加密存储，密码永不离机。
-  **长按鼠标中键一键呼出**：在任意输入框内长按鼠标中键或唤出超级面板，即刻就地呼出快捷选密面板。
- ⚡ **严格保序无感填充**：选中条目后按 `Enter`，支持**极速粘贴**或**模拟键盘逐字键入**（支持防粘贴输入框），双框联动严格串行校验绝不串位，并智能定时清空剪贴板（仅清理敏感密码，不误清后续复制文本）。
- ⌨️ **全键盘流支持**：快捷模式支持空格多词即时检索与高亮，支持 `↑` `↓` 移动、`Enter` 回填、`Shift+Enter` 仅密码、`Alt+Enter` 仅账号、`Alt+1~9` 数字直选、`Ctrl+C` 复制密码、`Esc` 清空/关闭。
- 🎯 **三键分离与常用排序**：支持条目置顶与使用频率智能排序；每条记录提供「账号+密码」「账号」「密码」三个独立按钮，顶部可一键切换默认回车策略。
- 🔐 **完整安全与备份工具**：支持备注字段、16 位随机强密码生成器与强度评估、修改主密码、空闲自动锁定及加密备份导入导出。
-  **多平台完美兼容**：全面支持 Windows、macOS 和 Linux，原生调用各平台剪贴板与输入接口。
-  **自适应深浅主题**：现代毛玻璃界面风格，完美适配系统的浅色/深色模式。
-  **零构建 / 零第三方依赖**：仅使用 Node.js 核心内置模块与原生 Web 规范。

## 🛠️ 安装与使用

### 1. 安装方式
1. 打开 ZTools 设置中的 **插件管理** -> **开发者开发中插件**。
2. 点击 **添加开发插件**，选择当前插件根目录（包含 `plugin.json` 的目录）。
3. 安装完成后即可使用。

### 2. 初始化
首次启动时，插件会要求您设置一个 **主密码 PIN**（至少 4 位）：
- 该主密码将作为派生主密钥（MasterKey）的唯一凭借。
- 密码库完全本地加密存储在 ZTools 用户数据目录下的 `ztools-quick-pwd/vault.json` 中。
- 请妥善保管主密码，一旦遗忘，因零知识加密架构无法找回。

## 📖 超级面板使用指南（长按中键呼出极速填充）

这是日常使用本插件**最便捷、最高效**的使用姿势：在任何网页或客户端的密码框前，无需切出大窗口，就地长按鼠标中键即可呼出选单完成自动填入。

### ⚙️ 前置配置流程（仅需设置一次）

#### 步骤 1：在 ZTools 中启用超级面板
1. 按快捷键呼出 ZTools 主面板（默认 `Alt + 空格`）；
2. 点击右上角头像或齿轮图标进入 **「设置」 ➔ 「超级面板」**；
3. 勾选 **「开启超级面板」**；
4. 触发方式勾选 **「长按鼠标中键」**（推荐触发延迟设为 **400ms ~ 500ms**）。

#### 步骤 2：将「快速填充密码」固定到超级面板
1. 在 ZTools 搜索栏输入：`填密码` 或 `pwd`；
2. 在搜索结果列表中找到 **「快速填充密码」** 插件指令；
3. 在该条目上 **单击鼠标右键**；
4. 在弹出的右键菜单中点击 **「固定到超级面板」**（图标右下角将出现固定图钉标记）。

### 🚀 日常使用路径（工作流）

```
[1. 光标聚焦密码框] ➔ [2. 长按鼠标中键 0.5s 弹出超级面板] ➔ [3. 点击「填密码」图标]
                                                                ↓
[6. 密码自动安全填入] ⬅ [5. Enter 或点击目标条目] ⬅ [4. 极简选单检索选择]
```

1. **就地唤起**：
   若使用 **「账号+密码」双填**，请将光标点入登录页的**账号输入框**；若只想**单填密码**，请将光标点入**密码输入框**。随后直接**按住鼠标中键约 0.5 秒**；
2. **呼出快捷菜单**：
   光标旁将就地弹出 ZTools 超级面板，点击固定的 **「快速选择并填充密码」** 图标（或直接按对应的序号数字键）；
3. **即时筛选与直选**：
   屏幕就地弹出极简悬浮列表，支持空格分隔多关键词按名称/账号/备注即时搜索与高亮，支持键盘 `↑` `↓` 切换、`Alt+1~9` 直选或 `Ctrl+C` 复制密码；
4. **一键安全回填**：
   条目右侧提供三个按钮，按需点击即可：
   - **「账号+密码」**：填入账号 ➔ 等待页面消费并自动 `Tab` 切换 ➔ 填入密码（光标需放在**账号框**，默认回车同效）；
   - **「账号」**：只把账号粘贴到当前光标所在输入框（`Alt+Enter` 同效）；
   - **「密码」**：只把密码粘贴到当前光标所在输入框（光标需放在**密码框**，`Shift+Enter` 同效）；
   - 选密窗口瞬间自动隐去，目标输入框在恢复焦点后严格保序自动填入；
   - 10 秒后智能擦除系统剪贴板中的密码残留（若期间已复制其他内容则不会误清）。

### 💡 常见场景与避坑指南

1. **遇到禁止粘贴的输入框（如某些银行、政企内网网页、远程桌面）**：
   - 打开密码管理器主界面 ➔ 点击右上角 **「设置」**；
   - 将「自动填充模式」切换为 **「模拟键盘键入 (hideMainWindowTypeString)」**；
   - 插件将通过底层 Unicode 按键逐字打入，轻松绕过网页前端的复制粘贴拦截。
2. **目标应用以管理员身份运行（如某些环境下的 Notepad++ 或终端）**：
   - Windows 的 UIPI（用户界面特权隔离）机制会拦截普通权限向管理员权限窗口发送的模拟输入；
   - 如需在管理员权限应用中自动填入，建议将 **ZTools 也右键设置为「以管理员身份运行」**。
3. **锁屏或重启后首次使用**：
   - 首次触发时会弹出快速解锁界面，输入主密码 PIN 后立即进入选密流程。

## 🛡️ 安全架构设计

1. **零知识存储**：
   - 不存储用户的主密码明文，仅保存加盐派生后用于校验的 AES-GCM 令牌。
   - 每次加密均生成全新的 12 字节随机 IV，杜绝重放与模式推断攻击。
2. **敏感内存隔离**：
   - 主密钥仅在插件解锁期间驻留内存，插件锁定时或插件关闭时立即清空内存引用。
   - 监听 `ztools.onPluginOut`，插件退出时自动销毁后台监听与解密密钥。
3. **剪贴板防残留**：
   - 自动模拟粘贴后启动定时器，10 秒内自动清空系统剪贴板，避免密码泄露给其他应用程序。
4. **数据原子性持久化**：
   - 写入 `vault.json` 时采用临时文件 + `fs.renameSync` 原子写入，防止掉电或崩溃导致数据文件损坏。

##  跨平台适配说明 (Windows / macOS / Linux)

| 平台 | 呼出方式 | 自动填充机制 |
| :--- | :--- | :--- |
| **Windows** | 长按鼠标中键 (超级面板 / 全局 Hook) 或 全局快捷键 | `hideMainWindowPasteText` (Ctrl+V) 或 `hideMainWindowTypeString` |
| **macOS** | 长按鼠标中键 (ZTools 原生超级面板) 或 全局快捷键 (如 `⌥+Q`) | `hideMainWindowPasteText` (⌘+V) 或 `hideMainWindowTypeString` |
| **Linux (X11)** | 长按鼠标中键 (ZTools 超级面板 / xinput) 或 全局快捷键 | `hideMainWindowPasteText` (Ctrl+V) 或 `hideMainWindowTypeString` |

> **提示**：在 macOS 上因系统沙盒安全性要求，强烈推荐在 ZTools 搜索框搜 `填密码` ➔ 右键固定到「超级面板」，或在「全局快捷键」绑定热键，可获得最稳定流畅的无感填充体验。
