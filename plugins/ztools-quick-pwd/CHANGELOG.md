# 更新日志 (CHANGELOG)

## 0.0.1 - 2026-11-27

### 新增功能
- **初次发布至 ZTools 插件市场**：提供本地 AES-256-GCM 加密密码存储与极速自动填充能力，纯本地零依赖运行。
- **高强度加密与双模式解锁**：采用 PBKDF2 (SHA-256, 100,000 次迭代) + AES-256-GCM 加密保险库；支持主密码 PIN 保护、修改主密码全库重加密、空闲自动锁定，并支持免密模式开关及初始化跳过入口。
- **极简快捷选密与三键分离填充**：支持配合 ZTools 超级面板（长按鼠标中键）或快捷指令呼出；支持空格多词高亮检索、条目置顶与使用频率排序，提供「账号+密码」「账号」「密码」三键分离填充及 `Enter` / `Shift+Enter` / `Alt+Enter` / `Alt+1~9` / `Ctrl+C` 全键盘操作。
- **可靠保序回填与剪贴板防护**：支持快速粘贴与模拟键盘逐字键入双模式，单通道剪贴板落盘校验与可配置 Tab 切换等待，杜绝双框填反；自动定时智能清理剪贴板敏感密码残留。
- **完整管理台与数据备份**：内置 16 位随机强密码生成器与密码强度评估、备注字段、深浅色自适应主题、独立桌面窗口模式及加密备份导入导出（`.json`）。
- **跨平台支持**：全面适配 Windows、macOS 与 Linux。
