## 1.0.0 - 2026-10-06
- **五个页签**：已安装（筛选 / 更新 / 主页 / 目录 / 锁定 / 卸载）、
  可更新（单个 / 全部更新，异常包分组提示）、搜索安装（实时日志）、
  Bucket（快捷添加 / 手动添加 / 移除）、缓存（统计 / 清空 / 清理旧版本）。
- 已安装列表自动标注 `全局` / `已锁定` / `Install failed` 等状态标签；
  卸载两档确认（Alt+确认 = `scoop uninstall -p` 彻底卸载）。
- 所有写操作互斥执行，底部日志抽屉实时滚动、随时终止；深浅色跟随宿主。
- **环境自举**：未安装 scoop 时进入配置页，一键安装走官方脚本 + 社区反代镜像，
  强制 TLS 1.2、管理员自动 `-RunAsAdmin`、直连失败自动探测本机代理；
  也支持手动指定已有 shims 位置。
- **Bucket 国内直连源**：快捷添加预置 Gitee 镜像（main）与 GitHub 反代
  （extras / versions / apps），均经 `git ls-remote` 实测。
- **git 自动保障**：bucket 管理硬依赖 git，缺失时自动从 npmmirror
  的 git-for-windows 国内 CDN 静默安装。
- **软件下载镜像化**：安装/更新前把清单里的 GitHub 下载地址就地临时改写为反代地址
  （原始清单自动备份、装完字节级还原），镜像代理原字节流，hash 校验不受影响；
  更新失败自动回退镜像清单强制重装。
