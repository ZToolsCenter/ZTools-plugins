# Changelog

## 1.2.1 - 2026-09-13

本次更新新增 QQ 表情搜索源、本地/云端双版本预览与搜索结果缓存，并优化表情详情弹窗布局。

### Added
- 新增「QQ」表情搜索源，支持翻页加载更多
- 表情详情支持本地/云端版本切换预览，并展示添加时间、更新时间、配对状态与标识 ID

### Improved
- 表情详情弹窗改为「左侧预览、右侧信息」双栏布局
- 搜索结果加入缓存，切换搜索源后返回仍保留已加载内容与翻页进度
- 详情中的存储位置、配对状态与转换按钮随当前预览版本同步

### Removed
- 移除已失效的「糖豆子」搜索源

## 1.2.0

### Adjusted
- 将搜索框改为平台原生子输入框，提升搜索体验
- 重新设计搜索选项卡样式，采用药丸式设计更紧凑美观
- 将搜索选项卡与添加按钮合并为一行，节省页面空间

### Added
- 支持分别删除本地或云端的表情包，同时存在于两端时可选择仅删除其一或全部删除

### Improved
- 同一表情包同时存在于本地和云端时，列表中只展示一次，优先保留本地版本

## 1.1.2

### Added
- 增加了表情详情中点击图片放大查看的功能

## 1.1.1

### Fixed
- 修复了部分情况下添加表情包后自动跳转到"我的"页面
- 修复了首次启动或云端数据不存在时本地表情包被意外清空的问题
- 修复了首次保存云端表情包时因文档不存在导致的 404 错误
- 修复了首次保存设置时因文档不存在导致的 404 错误

### Removed
- 移除了部分不需要的文件

## 1.1.0

### Added

- 增加了遇见搜索接口功能

### Improved
- 优化了部分情况下网络请求超时、图片复制错误时的处理
- 优化了部分ui样式和交互细节
