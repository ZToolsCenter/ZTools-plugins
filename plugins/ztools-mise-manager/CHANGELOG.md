# Changelog

## 0.1.0 - 2026-10-28

### 新增功能
- 工具市场支持点击工具展开查看并选择安装具体远程版本，支持关键词实时过滤与快捷安装 latest
- 安装任务提升至全局管理，顶部常驻全局进度条 Banner，跨 Tab 页面无缝保持安装状态与实时日志
- 工具管理与切换 Node.js 版本时检测上一版本的全局 npm 包，弹出迁移确认弹窗，支持一键批量迁移安装
- 检测上一版本 Corepack 启用状态并在新版本自动执行 `corepack enable`
- 展示用户级 `~/.npmrc` 摘要与当前镜像源信息

### 优化与修复
- 修复 Tab 切换组件卸载导致的搜索关键字与滚动位置丢失问题

## 0.0.1 - 2026-09-03

- 初次发布，将插件提交至 ZTools 插件仓库。
