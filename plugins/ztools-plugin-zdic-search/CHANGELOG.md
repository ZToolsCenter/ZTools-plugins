# Changelog

本项目的所有重要变更将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 0.3.2 - 2026-09-04

### 变更

- 关闭调试日志开关（`DEBUG` 置为 `false`），正式发布不再向控制台输出 `[zdic]` 调试信息
- 修正源码注释中的引号规范（直角引号改为中文弯引号）
- `package.json` 与 `public/plugin.json` 版本号同步至 0.3.2

## 0.3.1 - 2026-08-19

### 修复

- 回归纯净版：移除诊断版遗留的可视化诊断时间线
- 修复滚动条样式闪烁：主文档导航开始即遮罩内容，滚动条样式注入完成后淡入，消除“原生滚动条 → 自定义滚动条”的视觉跳变

### 变更

- 构建产物剥离 `development` 字段，规避开发模式误加载 localhost 导致白屏

## 0.3.0 - 2026-08-19

### 变更

- 适配官方 ZTools v3.x（WebContentsView 架构），移除对个人魔改版 API（`onPluginKeyDown` 等）的依赖

## 0.2.1 - 2026-05-26

### 新增

- `onPluginKeyDown` 热键支持（Alt+I 聚焦 webview 搜索框、Enter 转焦、ESC 失焦）

## 0.2.0 - 2026-05-25

### 新增

- webview 内热键注入与自定义滚动条
- `/hans/<词>` 词条直达失败自动降级 `/search/?q=`，并以缓存记住降级结果
- 子输入框 800ms 防抖查询

### 修复

- 首次加载闪帧问题

## 0.1.0 - 2026-05-25

### 新增

- 汉典查询插件初始版本：`汉典`/`hd` 关键词打开汉典首页，over 全局匹配任意文本直达词条页
