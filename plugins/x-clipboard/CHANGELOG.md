# Changelog

## 1.3.0 - 2026-09-20

- 新增 图片文件的缩略图：单个 .png / .jpg 等图片文件，行首显示缩略图而不是文件图标
- 修改 「行尾操作」：行尾的 ☆ / 🗑 两颗按钮改成各开各的（此前一个「行尾按钮」总开关管两颗），两颗都关也行；
- 修改 面板里原来叫「行尾」的那一组跟着改叫「行尾显示」
- 新增 行内瞬时星：行尾没开收藏按钮时，按 `⌘K` 会在那一行闪一颗星（随后自动消失），补上一个"成功了"的回执
- 新增 翻页：`PageDown` / `PageUp` 和 `⌘↓` / `⌘↑` 一次跳一屏（上一屏的最后一行接着当新屏第一行，不会漏行）

## 1.2.1 - 2026-09-19

- 修改 图片缩略图：Windows 上也能正常显示（此前一律退成占位图标）

## 1.2.0 - 2026-09-18

- 新增 设置面板键盘操作：`↑↓` 换项、`←→` 换值、`Enter` 落值
- 新增 搜索命中高亮：命中的字显示高亮；命中落在长文靠后、本来会被省略号截掉时，那一行自动前移成 `…前文…命中…后文…`
- 新增 行尾「来源」：显示这条是在哪个应用里复制的。默认关
- 修改 面板里的「选中」：面板打开时列表收起选中（一屏只留一处），面板里"被选中"的那一颗跟随「选中项」的三档样式

## 1.1.0 - 2026-09-17

- 新增 `⌘1`–`⌘9`：直接粘贴列表第 1–9 条；行尾可显示对应序号作为参考
- `Backspace` 改为「收回搜索关键词」，不再可能误删内容；删除只剩 `Delete` 与 `⌘⌫`
- 删除单条不再弹确认框；清空历史仍然会确认
- 行尾一格三样可配：序号、类型标签、☆ / 🗑 按钮，各自独立开关；按钮在鼠标划过、或该行是当前行时出现
- 「底色」选中态加了左端一根竖条 —— 淡底在浅色主题下更容易定位到当前行
- 底色扩到 6 颗（默认 / 白 / 灰 / 实 / 暖 / 冷），前三个是一条明度阶梯
- 设置面板改为与列表并排、不再遮挡内容，并收成三组：色点、药丸、开关
- 设置项说明全部搬进 README 的「设置」一节，面板内不再放文字
- 行的悬停与选中改为 120ms 低幅度缓动；圆角统一为 4 / 8 / 999px 三档；灰度分为四档
- 改了搜索词之后，选中位置回到第一条并滚回顶部（此前会停在原地）

## 1.0.0 - 2026-09-17

- 首次发布：键盘优先的极简剪贴板，打开就是内容
- 五个平级分类（全部 / 文本 / 图像 / 文件 / 收藏），`Tab` / `⇧Tab` 循环切换
- 键盘：`↑↓` 选择、`Enter` 粘贴、`⌘K` 收藏、`Esc` 分步退出搜索
- 鼠标：单击选中、双击复制，行尾 ☆ / 🗑 收藏与删除
- 行尾一格承担类型标签与操作按钮，切换时不改变行宽
- 支持按当前分类清空历史；收藏独立管理，清空历史不影响收藏
- 设置面板可调选中态样式、浮层底色、底栏提示档位，强调色跟随宿主主题
- 不使用任何 UI 组件库，纯自写 CSS
