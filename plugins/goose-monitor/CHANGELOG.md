# Changelog


## 0.1.0 - 2026-08-19

- 初次发布，将插件提交至 ZTools 插件仓库。
- 适配 ZTools 插件清单及宿主接口。
- 完善进程搜索、分类列表、键盘提示和系统主题同步。
- 修复 Windows 图标提取与搜索排序问题，加强进程操作校验。
- 保留原有按日期维护的功能记录。

### 原有日期记录

### 2026-08-19

🌈 本次更新重点：可以按端口号搜索进程，列表里也能看到谁占用了哪些端口。

✨ 新功能
• 搜索框输入端口号（如 8101），就能找到占用它的应用
• 进程名称旁会显示正在使用的服务端口
• 设置里可开关「显示进程号」和「显示服务端口」

🪐 优化
• 后台服务尽量显示更好认的名称


### 2026-08-10

🌈 本次更新重点：离开一会儿再打开时，搜索会自动清空，直接看到全部进程。

🪐 优化
• 关掉插件超过 5 分钟再打开，顶部搜索会清空并显示全部；短时间内再开仍保留上次筛选。

### 2026-08-06

🌈 本次更新重点：深色模式更好认，结束应用更快，等待时也能看出还在加载。

🪐 优化
• 深色模式整体更亮、层次更清楚，分类标签和列表更好区分。
• 选中应用后按回车或点「关闭应用」会立刻结束，不再二次确认。
• 切换分类或刚打开时，用灰色占位条表示正在加载，不再只显示一句话。

### 2026-08-02

🌈 本次更新重点：进程列表的排序、分组切换和选中定位更稳定，指标布局与明暗主题下的图标也更加统一紧凑。

✨ 新功能
• 支持使用 Tab 和 Shift+Tab 在当前可用的进程分类间循环切换。
• 会分别记住普通分类与网络分类的排序方式，再次打开时无需重新设置。

🪐 优化
• 进程数、CPU 和内存统一右对齐并收紧间距，把更多横向空间留给进程名称。
• 系统进程与未知应用的兜底图标统一视觉重量，并分别适配浅色和深色主题。
• 选中行改为清晰的轻底色与左侧提示线，减少切换时的文字跳动。

🐛 修复
• 修复进程数据刷新或排序变化后，当前选中项可能跳到其他进程的问题。

### 2026-07-31

🌈 本次更新重点：鹅的监控现为专为 uTools 设计的紧凑进程管理插件，也可通过本地 MCP 安全诊断和结束进程。

✨ 新功能
• 支持方向键上下选择、左右展开和收起进程组。
• 支持按界面窗口和 macOS 实时网络速率查看进程；不可用的能力会自动隐藏。
• 新增本地 MCP 服务，可读取资源与进程；结束进程前必须确认并复核最新快照。

🪐 优化
• 正式插件只使用 uTools 顶部 subInput，内容区不再重复显示 Logo、标题和搜索框。
• 浏览器开发 mock 的搜索框收进工具栏右上角。

🧹 清理
• 移除独立应用、原生后端、托盘窗口和多平台安装包构建链路。

### 2026-07-19

🌈 本次更新重点：进程识别和退出操作增加了完整的安全校验，托盘、定时退出和清理线也完成了一轮交互与无障碍优化。

✨ 新功能
• 退出应用前会校验进程身份、启动时间和最新快照，避免 PID 复用或过期界面误伤新进程。
• 新增跨平台持续集成，自动检查前端类型、测试、uTools 产物以及 Rust 格式、测试和静态分析。

🪐 优化
• 独立启动的 Node、Python 等同名进程不再被错误合并；自动清理默认关闭，并只处理能够安全识别的应用。
• 托盘应用选择、定时退出、清理线和偏好设置补齐了返回路径、状态反馈、键盘操作、焦点管理和无障碍语义。
• uTools 构建会拒绝 Chromium 108 不支持的现代颜色语法，并统一校验版本和图标资源。

🐛 修复
• 修复部分终止失败仍被报告为成功、休眠后定时任务漂移、切换主题后页面状态不同步等问题。
• 修复发布流程可能删除既有正式版本、Linux 附件名称不匹配以及 uTools 安装包未进入发布产物的问题。

### 2026-07-18

🌈 本次更新重点：搜索结果会优先显示更相关的应用；Windows 版也能正常展示应用自己的图标了。

✨ 新功能
• 主窗口和托盘搜索会按匹配程度自动排序，更接近输入内容的应用会排在前面。

🪐 优化
• 英文和数字搜索改为优先匹配连续片段，减少输入零散字符时出现无关结果的情况。

🐛 修复
• 修复 Windows 版合并多进程应用后丢失真实应用图标的问题，现在会从对应的可执行文件读取图标。

### 2026-07-02

🌈 本次更新重点：现在在 uTools 搜索和托盘搜索里，输入关键片段也能快速找到目标进程。

✨ 新功能
• 主窗口和托盘搜索都支持按关键片段筛选进程，例如输入 `chr` 先筛出 Chrome。

🪐 优化
• 搜索结果匹配规则统一为更宽松方式，减少了“必须完整输入才能命中”的筛选摩擦。

🐛 修复
• 以前输入 `企微` 无法匹配“企业微信”，现在可按片段直接命中。

### 2026-06-29

🌈 本次更新重点：修复了主题色（强调色）在外观切换时不会跟着改变的问题，并为托盘和主窗增加了「跟随电脑主题」的选项。

✨ 新功能
• 在托盘「偏好设置」中新增了「外观」选择区，支持切换「跟随电脑」、「浅色」和「深色」

🪐 优化
• 主窗口右上角的主题按钮升级为三态循环，点击可直接在「跟随电脑 / 浅色 / 深色」模式之间循环切换
• 重构了外观主题的底层应用逻辑，使得切换深浅外观时，相应的陶土红强调色（如聚焦框、选区高亮）会在浅色（橘红）和深色（亮橘）两套色彩中自动同步更新

🐛 修复
• 修复了部分界面元素即使切换了深浅模式，其主强调色仍然残留旧外观配色、不会随之切换的问题

### 2026-06-18

🌈 本次更新重点：托盘新增「清理线」自动清理功能，uTools 里按 `/` 能直接跳回搜索框了

✨ 新功能
• 托盘里多了一条「清理线」，会把长时间没用、内存又高的应用列出来，到点自动退出帮你腾内存
• 「清理线」可以自己调闲置多久才算该清（15 分钟到 4 小时），还能把不想被关的应用加进白名单永久保留
• 自动清理只会在用户明确开启后执行，并会在「清理线」中显示候选和豁免状态

🪐 优化
• 在 uTools 里浏览列表时按 `/`，焦点会直接回到顶部搜索框（之前按了没反应）

### 2026-06-02

🌈 本次更新重点：分类快捷键提示更聪明，桌面版打包分平台更省心

✨ 新功能
• 左侧分类右边的快捷键提示平时隐藏，按住快捷键时才整排显示，不再一直占着视线
• Windows / Linux 上分类快捷键显示各自键盘上的「Ctrl」，Mac 上显示「⌘」，与手边的实际按键一致

🪐 优化
• 打包桌面版拆成「Mac 版 / Windows 版 / Linux 版」三个独立入口，在哪台电脑上就打哪个版本，用错系统会直接提示
• Windows 上抓取应用图标时不再一闪而过弹出黑色小窗
• Linux 上能认出更多来源的应用图标（系统自带、自己安装、商店安装的应用）
