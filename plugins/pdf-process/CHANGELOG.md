# Changelog


## 1.2.0 - 2026-08-02

- preload PPT 转换写盘并完善 PR 打包流程
- 支持无磁盘路径的浏览器文件加水印等本地处理

## 1.0.1 - 2026-08-01

- 更新插件版本与发布配置。

## 1.0.0 - 2026-07-31

- 初次发布，将插件提交至 ZTools 插件仓库。
- 实现 PDF 压缩、合并、拆分、加水印及转图片等处理入口。
- 完善 PDF 转 Word、Excel、PPT 的转换流程，支持 AI 转换及本地回退。
- 修复中文水印、字体与字符映射、扫描件识别及 Electron preload 兼容问题。
- 支持文件预览、选择、拖拽和超级面板导入。
- 完善输出目录处理、依赖安装与发布构建，移除未完成的 PDF 编辑入口。
