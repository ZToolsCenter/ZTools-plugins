# Changelog

## 0.8.2 - 2026-08-24

### Fixed

- 横向单行阅读会在后台提前缓存后续 3 页，到页尾时直接本地切换，不再显示空白加载间隔或无意义的 `1/1`。
- ZTools 主面板隐藏后继续执行正文预读，避免独立阅读条打开后后台翻页被暂停。
- 只读取 Canvas 最后一次完整绘制的正文，避免翻页动画期间前后两页文字交错。

## 0.8.1 - 2026-08-24

### Fixed

- 修复微信读书纵向 Canvas 正文被误识别为“上一章”或“下一章”的问题。
- 单行阅读到章末继续向下滚动时自动衔接下一章，在章首向上滚动时自动返回上一章。
- 等待新章节正文真正完成绘制后再更新单行窗口，避免标题已切换但正文仍停留在上一章。

## 0.8.0 - 2026-08-23

### Added

- 阅读菜单新增独立单行阅读窗口，从当前微信读书章节和可见位置开始阅读。
- 支持鼠标滚轮、方向键和 W/A/S/D 逐字或逐行移动，并支持自动滚动。
- 适配横向阅读的 Canvas 正文，读到页尾时自动衔接下一页。
- 将画布视觉换行合并为连续单行，并支持从阅读条任意非按钮区域拖动窗口。
- 背景色与字体色新增系统级屏幕取色，并避免原生目录入口被本地菜单遮挡。
- 移除单行窗口外部阴影；鼠标离开阅读条后自动隐去，移回原位置时恢复显示。
- 单行窗口支持长度、背景颜色与透明度、字体颜色与透明度、字体、字号和粗细设置。
- 单行窗口默认置顶、隐藏任务栏入口，支持拖动、快速隐藏和窗口复用。
- 项目采用 MIT License 开源。

## 0.7.3 - 2026-08-19

### Changed

- 浅色阅读正文固定为纯黑，深色阅读正文固定为纯白。
- 微信读书完成主题切换后再同步 ZTools 明暗模式，避免正文与背景错配。
- 右上角深色工具浮层中的文字和图标统一使用纯白色。
- 恢复并保留“浏览器打开”下方的微信读书原生目录入口。

### Removed

- 移除实验性的“传书到手机”入口及相关页面跳转处理。

### Fixed

- 修复横向阅读正文由 Canvas 绘制时普通 CSS 文字颜色规则不生效的问题。
- 修复翻页和冷启动后正文颜色重新变灰或变暗的问题。

## 0.7.2 - 2026-08-18

### Changed

- 阅读区改为透明背景，直接继承 ZTools 的 Acrylic 窗口材质。
- 阅读主题会根据微信读书页面的实际样式动态识别浅色或深色模式，并匹配高对比度文字。
- 右上角菜单按钮改为随 ZTools 明暗主题变化的半透明 Acrylic 样式。

### Fixed

- 移除导致阅读区域发灰的全屏遮罩与额外背景 tint。
- 隐藏阅读区域滚动条，同时保留鼠标、触控板和键盘滚动。
- 修复切换微信读书浅色或深色主题后背景与正文颜色不匹配的问题。
