# Changelog

## 1.0.7 - 2026-10-30

### Added

- 表设置新增字段约束：可给字段勾选「必填」「唯一」，新增、编辑、记一笔、导入、批量修改时统一校验，不再需要事后人工检查重复/空值；唯一按「去首尾空白 + 忽略大小写」比较，数字/日期按类型归一化后比较，空值不参与唯一判定（避免非必填的唯一字段被隐式变成必填）
- 新增/编辑记录与「记一笔」：命中约束时在对应字段下方标红错误并阻止保存，编辑记录时不会和自己比；必填字段标签带 `*`
- 表设置保存时检查已有数据：给旧表开启必填/唯一后若存量有空值或重复，会列出条数与示例，可选择「仍然保存」（只约束之后的新增/修改）或取消；改字段类型时按转换后的数据预检，转换造成的重复/空值也会先提示
- CSV/TSV 导入：解析后立即校验，预览里标红不合规行并给出必填缺失/重复的行数；导入时只写入通过校验的行，跳过多少行会在确认框和结果提示里说明
- 批量修改：唯一字段不能被多条记录改成同一个非空值，必填字段不能被清空，命中时直接提示原因
- 表头标记：必填字段名后带红色 `*`，唯一字段带「唯」角标，悬停可看说明

### Changed

- 空值判定统一为「null / 空串 / 空数组 / 只含空白」都算空，筛选的「为空 / 不为空」与必填校验共用同一判定，两处语义不再分叉（只含空白的单元格以前算「不为空」）

## 1.0.6 - 2026-10-19

### Added

- 批量修改：勾选若干记录后点「批量修改」，把某个字段统一改成同一个值；一个字段一条命令，改完只影响指定字段，其余内容不动
- 未勾选时视为全部：直接作用于当前列表里的所有记录（有筛选时就是筛选结果）；勾选过则只改勾选的记录，且只改当前列表内看得见的那些
- 两个入口：勾选后出现在勾选操作条上；「⋯ 更多」里常驻「批量修改字段…」，不勾选也能打开
- 值编辑器按字段类型给出对应控件（文本、长文本、列表、单选、多选、数字、日期、是否），留空即清空该字段；单选/多选的候选值包含已有数据里出现过的值，新值会自动收进字段选项
- 只写真正发生变化的记录并刷新它们的「修改时间」，值本来就相同的记录不动；执行前确认改为多少条、改成什么值，不可撤销

### Fixed

- 勾选后点「取消选择」没真的取消勾选：选择列开了跨页保留，原来只把内部计数置空，表格里的勾选框还留着 —— 在筛选条件下勾选、点「取消选择」、再清除筛选，那些行依然打着勾，此时再勾一行会把残留记录一起算进已选。改为调用表格自身的 clearSelection 真正清掉勾选；删除表格、清空表格、切换表格时的勾选清理也一并走同一处，不再留残留

### Changed

- 插件描述补充「批量修改」能力

## 1.0.5 - 2026-10-16

### Fixed

- 表设置里「是否」类型的字段没有默认值输入框（其他类型都有）：现在可选「是 / 否 / 无」，新增记录（含「记一笔」、导入）会按所选默认值预填；切换字段类型时默认值会按新类型重新转换，不会把编辑态文本 `yes` / `no` 当成字面量带到其他类型
- 高级筛选里「是否」字段的「为空 / 不为空」判定不准确（默认值为「否」时单元格显示为空，会被判成「为空」）：改为按「是 / 否」筛选，未填写的行一并计入「否」

## 1.0.4 - 2026-10-16

### Added

- 列宽按内容分配：默认列宽按「表头文字 + 已有内容」估算（长文本、多标签的列更宽，不再一律 110px），宽度夹在 96–360px 之间；估算只采样前 300 行，大表不必为算列宽整表扫描
- 列宽记忆：手动拖动列宽后按表保存，下次打开沿用（跟随 JSON 备份一起迁移）；「⋯ 更多」新增「列宽重置为自动」，随时恢复到按内容分配
- 单元格悬停提示：内容被列宽截断时，鼠标悬停弹出完整内容；多值字段按「、」连接，与复制/导出的文本一致

## 1.0.3 - 2026-09-30

### Added

- 字段类型改成「单选 / 多选」时自动收集已有取值：切换类型后弹确认框列出将加入的选项，选「加入」即写入选项，老数据的值当场就能在下拉框里选到
- 表设置的选项输入框下新增「从已有数据收集」：数据是后来导入或别处写入的，也能一键把新取值补进选项
- 单选 / 多选下拉一律显示「已配置选项 + 已有数据里出现过的值」——编辑记录、记一笔、筛选「属于选项」三个入口都不会再出现「值在表里、下拉里选不到」

### Fixed

- 改字段类型后已有数据没有按新类型转换（类型变更确认框写了「会尽量转换」，实际从未执行）：文本改多选/列表后单元格显示为空、改数字/日期后残留原字符串
- 「已回填 N 条记录」中的 N 是表内总行数，不是真正被回填的行数

## 1.0.2 - 2026-09-24

### Added

- 新增「行高样式」开关：「⋯ 更多」菜单里可选「固定行高（超出省略）」与「自适应行高（随内容撑高）」两种样式，当前样式带 ✓ 标记，选择即生效并持久保存（默认固定行高）
- 高级筛选：升级为 AND 条件组，可添加多条条件自由组合；每个字段支持「为空 / 不为空」，单选/多选支持「属于选项」，文本/链接/数字支持「包含关键词」
- 时间筛选：创建时间 / 修改时间 / 日期字段支持「今天 / 本周 / 本月」（周一起始）；筛选面板顶部提供「本周创建」「本月创建」「今天更新」「本周更新」快捷按钮（点击切换）
- 组合场景：如「复制本周创建的、链接为空的数据」——添加两条条件后，不勾选行直接「导出 → 复制到 Excel」即可复制筛选结果
- 字段默认值：表设置里可为每个字段配置默认值，新增/记一笔/导入时自动预填；新增字段设置了默认值时，可选择是否回填到已有记录（回填只补缺失行，不覆盖已有值）

### Changed

- 「新建表」从表切换下拉后的文字按钮改为工具栏左上角第一个按钮（primary plain 样式），更醒目、更好找
- 筛选面板加宽至 360px，显示激活条件数（筛选 · N）；切换表格时清空筛选条件

## 1.0.1 - 2026-09-22

### Added

- 「⋯ 更多」下拉新增「清空当前表（仅记录）」：清空数据但保留表定义（表名/字段不动）；走 preload bulkDocs 一次 IPC 提交
- 清空动作为两段确认：先提示建议导出 JSON 备份，再二次确认；执行期间全屏 loading

### Fixed

- 导入 400+ 条数据卡半分钟：preload 走 `promises.bulkDocs` 整表一次提交，IPC 数从 ~1680 降到 ~2，dbStorage 同步整包一次 setItem
- 导入对话框没有 loading 反馈：点击「导入 N 行」后按钮变 loading、dialog 不可关、控件全部 disabled，全程正面反馈
- 列表不能上下滚动：放手让 el-table 自己负责垂直滚动；外层 `.grid-wrap` 不再 `overflow: auto`、el-table 改用 `height="100%"`
- 导入 JSON 备份时整段加全屏 loading，含 1000+ 行也不会沉默

## 1.0.0 - 2026-09-22

### Added

- 首次发布「简单记录」：多表结构化记录，自定义字段（文本、长文本、列表、单选、多选/标签、链接、数字、日期、是否）
- 空启动：首次进入不预置「工作记录」表，界面为空引导新建
- 表切换改为工具栏下拉，去掉左侧表列表，主界面专注数据列表
- 快捷指令「记一笔」：弹窗直接记录，可选表并记住上次选择，不进入主页面
- 新建表：填表名后进入表设置配置字段（不提供模板向导）
- 行操作：新增、双击编辑、复制整行（按钮）、多选删除；链接可点开
- 复制为 TSV（含表头）到剪贴板，便于粘贴进 Excel
- 工具栏减负：搜索 + 新增为主，筛选/导入/导出/更多用轻量文本菜单；勾选后才显示批量操作
- 「导入」「导出」两个下拉菜单：
  - 导入：CSV / TSV 文本（粘贴 + 列映射）、JSON 备份（覆盖/合并）
  - 导出：复制到 Excel、TSV 文件、CSV 文件（UTF-8 BOM）、JSON 备份
- 多值/选项统一按「、 ， , |」拆分；导出展示默认顿号连接
- 表设置抽屉：表名 + 字段 + 系统列开关；筛选弹层内下拉不误关
- 系统列「创建时间」「修改时间」（只读、可排序、可导出）
- 列表分页（20/50/100/200 条/页），字段多时横向滚动
- 列排序三态：升序 → 降序 → 取消
- 数据持久化：dbStorage 存表定义，ztools.db 存行数据并双写回退
- 分类为「效率工具」；README 面向普通用户，开头附 index.png 预览
