# Changelog

## 1.0.0 - 2026-10-28

- 初次发布，将 Mermaid 图表工作室提交至 ZTools 插件仓库
- 支持 Mermaid 代码编辑与实时预览，内置流程图、时序图、类图、状态图、ER 图、甘特图、饼图、思维导图、时间线、Git 图、象限图、C4 架构共 12 种模板
- 支持 PNG（1x–4x 倍图）、SVG、PDF（A4/A3/Letter/自适应，可设横竖与页边距）导出
- 导出 SVG 时自动移除 foreignObject，保证第三方编辑器可正常显示文字
- 支持浅色、深色、森林、中性四种 Mermaid 主题，并适配 ZTools 深色模式
- 支持并排、仅编辑、仅预览三种布局与拖拽分栏
- 可通过 `mermaid`、`Mermaid 图表工作室`、`图表工作室` 触发；选中 Mermaid 代码后可用划词指令直接打开
