# Changelog

## 1.2.0 - 2026-09-06

### 新增
- 点对点私密共享：远程访问者可按来源 IP 向主机申请私密连接，插件端实时收到申请通知并可同意/拒绝；同意后双方建立私密对话
- 私密对话能力：文本消息、一次多文件发送（多文件合并为一条消息）、文件上传/下载/在线预览、离线消息与文件投递、实时消息通知（SSE + 系统通知）
- 消息与连接管理：双方均可删除单条消息（服务端留存同步删除、收到的文件同步清理）与删除整个私密连接，删除结果双方可见
- 本机/远程访问识别：Web 页面识别是否在插件宿主机浏览器访问，头部显示「本机访问 / 远程访问」标识
- 本机管理控制台：本机浏览器访问 Web 页面时，通过左侧「文件 / 消息」菜单切换到与插件端一致的点对点对话管理与查看；页面可查看下载/上传日志、管理 IP 白名单

### 根据提交记录补充

- 修复P2P聊天客户端刷新后历史消息丢失和主机端对话区域滚动问题

## 1.1.1 - 2026-08-18

### 新增
- Web UI 大图全屏查看：点击预览中的图片进入全屏 viewer，支持鼠标滚轮缩放（0.1x~20x）、拖拽平移、双击重置、ESC 退出
- 插件侧文件预览：在插件主窗口共享列表中点击预览按钮，可直接查看文件内容，支持图片、音频、视频、文本/代码/Markdown，与 Web UI 预览体验一致
- 插件侧图片全屏 viewer：预览弹窗中点击图片进入全屏，同样支持滚轮缩放、拖拽平移、双击重置、ESC 退出
- 预览文件大小限制：文本文件 ≤2MB，二进制文件（图片/音频/视频）≤20MB，超出时提示「文件过大」

### 修复
- 修复手动关闭共享服务后，关闭页面再重新进入（插件后台仍在运行）时服务被意外自动重启的问题：现通过内存标志区分「插件首次加载」与「用户手动关闭后重新进入」，手动关闭后重新进入页面保持关闭状态，插件彻底关闭再重新打开时恢复默认自动启动

### 根据提交记录补充

- 修复TypeScript 关键字识别失效

## 1.1.0 - 2026-08-13

### 安全修复
- 修复任意文件读取漏洞：`/api/file` 原先未校验路径是否在共享列表内，持有链接者可读取宿主机任意文件，现已强制校验（未共享/已关闭的条目一律 403）

### 新增
- 客户端上传：Web 页面支持按钮/拖拽上传文件，上传后自动加入共享列表，按来源 IP 分组展示，与主机共享文件互不混杂
- 上传去重：服务端对上传内容做 SHA-256 哈希比对——内容已存在则跳过并弹窗提示「已上传」；同名不同内容则弹窗选择「覆盖 / 重命名 / 跳过」（覆盖仅限本人此前上传，主机共享与他人上传不可覆盖；冲突文件挂起 10 分钟待决策，无需重新上传）
- 客户端删除上传：上传者可在 Web 页面删除自己上传的文件，严格按 socket 来源 IP 校验（其他 IP / 仅持有链接者无法删除），删除同时移除磁盘文件与共享条目
- 上传文件落盘至「下载/z-share-uploads」目录，文件名自动消毒与去重，单次请求上限 2GB
- 传输日志新增「类型」列：下载/上传分别记录，含 IP 与时间
- 目录 ZIP 打包下载：服务端流式打包（deflate + CRC32，不落临时文件、不占内存），目录行、多选、全部下载均走 ZIP 打包；目录内单文件仍可直接下载
- 端口可配置：主界面可直接修改端口，启动时检测端口占用并提示；支持一键自动选择空闲端口
- Web 端文件搜索：按文件名实时过滤，匹配目录自动保留父级结构
- 主界面按 IP 分组：插件主窗口共享列表同样按「主机共享 / 客户端上传·IP」分组展示，与 Web 端保持一致

### 修复
- 修复 Web UI 分组标题被列表渲染覆盖，导致客户端上传未按 IP 分组显示的问题
- 修复删除接口信任客户端可控的 `x-forwarded-for` 请求头导致 IP 可伪造、可删除他人上传的安全漏洞（IP 判定现仅信任 socket 实际来源）
- 修复插件窗口删除客户端上传条目时仅移除列表、磁盘文件残留导致磁盘膨胀的问题（现同步删除 `z-share-uploads` 磁盘拷贝；主机本地共享仍只移除引用，原文件不受影响）
- 修复下载日志中「上传/下载」标签列过窄导致文字竖排的问题（加宽列宽并禁止换行）
- 修复切换网卡时服务未运行也会被意外启动的问题
- 修复端口冲突时静默失败无任何提示的问题

### 优化
- 主界面工具栏改为单行布局：服务启动/停止后不再换行，网卡选择与错误提示自适应压缩
- Web 端弹窗统一为通用自定义组件（提示 / 确认 / 多选三种形态），替换浏览器原生 confirm 弹窗
- 上传文件哈希在保存成功时入库（dbStorage），后续去重比对直接取值、不再重复计算；仅主机共享文件首次比对时惰性计算并缓存（带 size+mtime 失效校验）

### 测试
- 新增 `test/smoke.cjs` 后端冒烟测试（`npm run test`），覆盖路径校验、上传、ZIP 结构、端口冲突等断言
- 删除接口用例：同 IP 可删、异 IP 拒绝、主机共享拒绝、`x-forwarded-for` 伪造拒绝、磁盘文件同步移除

## 1.0.0 - 2026-08-11

### 新增
- HTTP 文件服务器：基于 Node.js 流式传输，支持 Range 请求，自定义端口与绑定 IP
- 文件/文件夹共享管理：多选文件、多选文件夹、拖拽添加，层级树展示
- 文件夹超过 20 个文件确认提示，防止误操作
- 实时开关/删除共享条目，深度克隆确保响应式更新
- 多网卡自动检测与选择，切换网卡自动重启服务，启动插件自动恢复服务
- 随机访问令牌鉴权，Token 一键刷新，旧令牌即时失效
- IP 白名单：白名单内 IP 无需 Token 即可访问和下载
- 子路径分享：通过 `?path=xxx` 定向分享指定文件或目录，限制访问范围
- 二维码生成：主分享地址及单个文件/目录均可生成二维码，支持复制二维码图片
- 文本分享：粘贴文本直接生成为时间戳命名的 .txt 文件共享
- Ditto 等剪贴板工具拖入文本智能识别，自动切换文本分享
- 下载日志：记录每次下载的 IP、时间、文件路径，持久化存储，3 秒去重
- 下载日志仅记录主动下载（`?dl=1`），预览请求不计入

### Web UI
- 全宽文件列表作为主页面，点击文件弹出预览弹窗
- 单文件下载、目录递归下载、多选下载、全部下载，批量操作栏始终可见
- 文件列表刷新按钮
- 在线预览：文本、代码语法高亮（30+ 语言）、Markdown 渲染 / 源码切换
- 图片直接展示，音视频 HTML5 播放，PDF 内嵌预览
- 二进制文件标记为不可预览
- 文本/代码/Markdown 预览一键复制内容，兼容 HTTP 环境
- 亮色/暗色主题切换，localStorage 记忆
- 关闭弹窗自动销毁媒体元素，防止后台播放
- 全面中文化，自定义 Toast 通知

### 交互
- 文件项在资源管理器中打开
- 单文件/目录分享链接复制，各条目复制反馈独立
- 地址行操作按钮固定成组，空状态居中醒目引导
- 自定义 Toast 通知：复制、刷新、共享等操作统一反馈
- 纯色 SVG 图标，无渐变无 Emoji，简约现代设计
