# Changelog

## 3.0.0 - 2026-11-08

- 新增 AI 配置与指令编辑，可接入多个 OpenAI 兼容服务商并用一句话自动调色
- 新增 PSD 工程文件导入/导出，支持保留图层
- 新增历史记录面板，可查看每一步参数变更并回到该步骤
- 调色新增中间调、色温、棕褐与灰度强度参数
- 新增大量滤镜预设，按基础/复古/黑白分类
- 修复画布缩放或平移后图层对齐与分布位置偏移的问题
- 修复选择滤镜后其他滤镜预览不准确的问题
- 修复连续裁剪或切换工具后图层被裁掉的问题
- 修复保存图片或 ORA 工程文件时默认保存位置可能带出常用目录的问题
- 优化 AI「编辑当前图层」：效果先生成预览，确认后才替换原图

## 2.6.0 - 2026-10-06

- 新增图层复制功能，可通过右键菜单、快捷键或按钮复制
- 图层右键菜单支持复制、重命名与删除
- 新增图层对齐与分布，可多图层排列或对齐画布
- 新增图层混合模式，如正片叠底、滤色、叠加等
- 调色新增自然饱和度参数
- 修复打开插件时初始化失败、面板无法显示的问题

## 2.5.0 - 2026-09-23

- 调色预设改为效果图卡片，直接显示当前图层的调色效果
- 新增贴纸功能，支持从本地添加图片图层
- 橡皮擦新增框选模式，拖拽框选即可一次擦除整片区域
- 修复保存图片或 ORA 工程文件失败时没有任何提示的问题

## 2.4.3 - 2026-08-31

- 图形工具新增五边形
- 修复撤销/重做、打开新图片、导入 ORA 后画笔光标指示丢失的问题
- 修复「保存」格式弹窗在深色模式下显示异常的问题
- 修复文字预设按钮在深色模式下显示过亮的问题
- 画笔光标指示增强对比度，并增加中心点提示落笔位置

## 2.4.2 - 2026-08-29

- 更新图片工具箱至 2.4.2。
