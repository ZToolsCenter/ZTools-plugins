# 更新日志

## 1.0.1 - 2026-10-26

### Changed

- 打开插件不再预置示例金额，输入框默认为空，并显示空状态提示。
- 切换「税前→税后」与「税后→税前」时清空输入，避免把上一模式的金额误当作本模式金额。
- 界面整体重做：科技蓝主题、浅色底白卡、跟随系统深浅色；宽窗口（≥ 660px）两栏布局，窄窗口单栏。
- 新增快捷金额（4000 / 8000 / 1 万 / 2 万 / 5 万），点击后填入，不预置。
- 结果区展示预扣个税、计税收入额、适用预扣率，并高亮当前所处档位。

### Fixed

- 修正劳务报酬预扣率表：原表误用了其他所得类型的档位，导致 3000–10000 元区间漏算税金、30000 元以上多扣。现按国家税务总局公告 2018 年第 56 号预扣率表二计算（≤ 20000 元 20%；20000–50000 元 30%，速算扣除 2000；> 50000 元 40%，速算扣除 7000）。
- 修正 `plugin.json` 中正则指令的字段名（`regex` → `match`），与官方 schema 对齐。
- 移除 `development.main` 本地调试地址，避免发布包携带无效入口。

## 1.0.0 - 2026-10-22

- 首个版本：税前→税后、税后→税前双向计算，支持粘贴金额直达。
