# 更新日志

## 1.0.2 - 2026-10-08

- 单条输入命令改为精确匹配指令，避免各条命令持续占用 ZTools「最近使用」列表。
- 保留原触发词标签、功能 ID 和快捷键目标，刷新时自动转换旧的动态功能。
- 触发词中的正则特殊字符按字面匹配，支持完整触发词搜索。

## 1.0.1 - 2026-10-08

- 快捷输入的动态功能改为 `mainHide` 后台触发，避免快捷键唤起主窗口抢占输入焦点。
- 输入完成后退出本次插件调用，避免 ZTools 跳过同一文本指令的重复进入事件，导致仅首次快捷键能输入。
- 输入前先隐藏主窗口并等待焦点切换，再调用原生模拟输入 API。
- 刷新时更新旧的动态功能配置，并在等待结束后重新检查命令是否仍启用。
- 为全局快捷键输入时序增加回归测试。

## 1.0.0 - 2026-10-08

- 首次发布「快捷输入」，插件 ID 为 `quick-input`。
- 提供空白初始列表，支持添加、编辑、搜索、启停和删除自定义单行命令。
- 为每条命令注册独立触发词，可跳转到 ZTools 快捷键设置。
- 隐藏 ZTools 后向原窗口模拟输入，保留首尾空格，不自动回车。
- 本地保存配置，支持 ZTools 3.2.0 的注册和存储错误返回值。
