# Changelog


## 1.0.2 - 2026-08-25

- 子输入框占位符改为「目标类型 or 新变量名」
- 输入内容会筛选风格；匹配不到时按新变量名转换，且输入框保留刚才输入的文字
- 修复顶部输入框被列表刷新清空或重复写入的问题
- 恢复 ⌘/Ctrl+1…0 快捷选择：输入后焦点回到列表，顶部仍显示刚输入的内容

## 1.0.1 - 2026-08-25

- 将 uTools 插件 [Var-Conv](https://github.com/imdong/Var-Conv) 移植为 ZTools 插件（原作者青石 ImDong）
- 支持输入「变量」进入，或复制变量名后选择「将变量名转换为」
- 自定义列表界面：无图标、空值保留占位高度，macOS 用 ⌘+1…0、Windows 用 Ctrl+1…0 快速选择
- 数字与含数字的标识符（如 `123`、`user2Name`）按命名风格转换；
