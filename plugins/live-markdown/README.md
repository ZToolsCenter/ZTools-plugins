# Live Markdown for ZTools

一款基于 React 19 + TypeScript 纯自研构建的高性能**所见即所得 (Live Preview) Markdown 沉浸式编辑器** ZTools 插件。

告别传统左右双栏预览的视线割裂，Live Markdown 带来优雅自然的纯粹写作体验：**聚焦当前内容即可实时内联编辑 Markdown 源码，光标移开后立即呈现纯净优美的最终排版**；同时支持按 `Cmd + /` (`Ctrl + /`) 秒级无缝切换到带行号的 Markdown 源码模式。

---

## AI 模型配置与首次使用

1. 点击“润色”或在 AI 助手输入框点击模型按钮，打开模型选择页面。
2. 如尚未在 ZTools 中配置模型，可点击“打开 ZTools 模型设置”添加内置供应商或自定义模型，随后回到列表选择并点击“使用此模型”。
3. 有选区时处理精确选区；无选区时处理当前文件全文，包括未保存内容。完成后对照原文确认修改，支持一键撤销。准备或生成期间改动文档，旧任务不会自动覆盖新内容。

插件发布包和解压后的文件分别执行 **15,000,000 字节**上限检查。本地实验性小模型部署入口当前已隐藏，AI 能力统一由 ZTools 宿主已配置的供应商或自定义模型提供。

默认使用薄执行层：固定文本及完整可组成的结构由程序执行；未知的小型指令使用一次模型响应同时返回操作与正文。范围、只读、版本、取消、已知传输失败和体积限制仍会阻止不安全提案。普通自由输出的格式差异会给出审查提示；结构化填充回执缺项、越界或无法完整解析时停止。程序不保证识别全部事实错误或内容遗漏。失败不自动重试，不写入部分结果；原指令仍可修改。明确的固定文本无需模型复制全文，同时修改多个位置时仍需拆成独立指令。

按任务选择内容执行方式：已知标题、围栏、表格、公式等结构由程序生成，模型填写内容；润色和校对只改正文文字槽，代码、表格、公式及其他受保护源码由程序原样拼回。来源问答逐块核验原句，明确字段和 Markdown 基础语法可零调用。全部分片完成后才形成一次可确认提案；任一片失败、停止或文稿版本改变，都不产生部分写入。独立创作不附带无关全文。模型仍可能误解需求、编造事实或遗漏正文，候选结果须核对后确认。

开发验证：`npm run build` 执行单元测试、运行层测试、类型检查、构建校验及集成检查；`npm run test:e2e` 执行真实 Chromium `file://` 端到端回归；`npm run package` 在上述检查全部通过后生成 `release/` 发布包和体积报告。

## AI 助手、Skills 与 MCP

右侧助手的输入框铺满侧栏，模型、设置与发送／停止位于输入框内。平时一行显示带图标的“润色、校对、总结”轻量按钮，续写、图表、学术润色和技术方案收进“更多”；有修改待确认时，快捷任务换成一行复制、取消与确认，减少重复按钮。取消或应用后恢复快捷任务，复制并入同一行。长结果独立滚动；助手空闲且无结果时，插件 Logo 与“AI 助手”在主内容区空白处居中显示，生成和显示结果时隐藏，不占输入框位置。Enter 发送，Shift+Enter 换行，输入法选词不会触发发送；快捷键提示可在发送按钮悬停查看。模型页面仅展示当前宿主配置的供应商与自定义模型。

AI 修改预览复用历史记录的 Diff 组件，默认单栏显示红删绿增、行号和中文句内高亮，自动折叠未改上下文；短窗口首次打开时定位首处改动。插入与追加会对照实际写入位置及块分隔符，避免把整篇原文误标成删除。复制始终得到完整结果，不受上下文折叠影响；历史记录原有双栏、单栏切换与恢复继续保留。

“润色”“校对”等预制功能以内置提示词为基础，同时执行选区／全文定位、预算检查、格式提示和确认写回。它们不需要分别安装模型。Skills 将系统提示词与含 `{{content}}` 的用户模板组合起来，可直接运行：

- 内置技能可查看或复制为自定义技能，不能覆盖或删除。
- 自定义技能可新增、编辑、删除；保存到本机，最多 30 项。保存失败会明确提示。
- 写作、学术、编程类别生成替换提案；总结、图表生成插入提案。所有文稿修改都先预览再确认。

技能库用分类图标、标题、来源和说明展示每个技能，运行与查看／管理操作分层排列；长标题和说明在卡片内最多显示两行，可通过“查看”访问完整内容。新建按钮保持单行，窄侧栏下复制、编辑、删除和运行仍可访问。

MCP 页面可添加、编辑、启停和删除自定义服务。填写服务地址，点击“连接并发现工具”，选择工具、填写参数并运行。工具结果先展示；要放入文稿，仍需确认插入。内置服务不可删除，工作区搜索返回真实匹配，图表工具返回本地模板，网页工具提取公开页面文本。

当前 MCP 支持 **Streamable HTTP 工具调用**，兼容带初始化握手的 2025-11-25、2025-06-18、2025-03-26 协议；不支持 stdio、旧式独立 SSE 地址、OAuth 登录或模型自动挑选工具。Bearer 令牌只保存在当前宿主会话，重新启动后需重新填写；配置中的名称、地址和启用状态持久保存。连接默认有超时和数据量限制，调用失败不会自动重放可能有副作用的工具。外部服务仅收到用户填写的工具参数，不会自动收到整篇文稿。

## ✨ 核心特性

### 1. 沉浸式所见即所得 (Live Preview) 与源码模式
* **内联动态展开与渲染**：点击任意标题、列表、表格、数学公式、图表或代码块，自动展开对应 Markdown 标记；失焦后即时转换回出版级排版。
* **保留源码的段落连排**：普通段落中的单次换行在 CM6 实时预览（含段内编辑）和阅读模式中自动衔接，源码模式保留原始行；空行分段、双空格或反斜杠硬换行、代码及特殊块保持原有边界。
* **双向无缝源码模式 (`Cmd + /`)**：随时在所见即所得与带行号的 Markdown 纯源码编辑器之间双向热切换，光标位置与滚动进度精确同步。
* **智能粘贴与格式清洗**：支持外部富文本与 HTML 智能转换为 Markdown 格式粘贴，支持截图直接粘贴并自动归档至本地 `./assets` 目录。

### 2. 丰富完备的 Markdown 与扩展语法支持
* **结构化块级排版**：
  * **YAML Front Matter**：原生解析文稿元数据、属性与配置标签。
  * **H1–H6 阶梯标题**：聚焦时显示级别标识与锚点定位。
  * **GFM 警告框 (Alerts / Callouts)**：支持 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 与 `[!CAUTION]` 5 类标准提示块。
  * **任务与清单列表**：支持嵌套无序列表、有序数字列表，以及可直接交互打勾的待办清单 (`- [ ]` / `- [x]`)。
  * **自动目录 `[TOC]` 与学术脚注**：动态生成全文档目录树，脚注标记与底部定义无缝联动。
* **交互式可视化表格**：
  * 支持悬浮工具栏快速调整列对齐（左对齐 / 居中 / 右对齐）。
  * 支持键盘快捷键（`Alt + 方向键`）或按钮快速插入、删除与上下左右移动行列。
  * 内置 Markdown 表格源码格式化与自动对齐美化引擎。
* **学术公式与图表引擎**：
  * **LaTeX 数学公式**：支持行内公式 (`$...$`) 与多行复杂公式块 (`$$...$$`) 实时排版。
  * **Mermaid 矢量图表**：内置对流程图 (Flowchart)、时序图 (Sequence)、饼图 (Pie)、甘特图 (Gantt) 与状态图 (State) 的实时矢量渲染。
* **多语言代码块高亮**：
  * 覆盖 TypeScript、JavaScript、Python、Rust、Go、Java、C++、JSON、Bash、SQL 等主流语言语法高亮。
  * 配备一键复制、行号显示与语言快速检索选择器。

### 3. 多功能侧边栏与工作区管理
* **文件树视图 (Tree View)**：完整树状展示本地文件夹目录结构，支持新建文档/目录、重命名、生成副本与删除。
* **文章列表视图 (List View)**：以平铺卡片形式呈现文稿标题、修改时间与正文内容摘要，支持按名称/时间多维度排序。
* **大纲导航 (Outline)**：自动提取文档 H1–H6 标题层级，随正文滚动实时高亮当前章节，支持大纲关键词过滤与平滑滚动跳转。
* **工作区全文检索 (Search)**：支持在当前工作区所有 Markdown 文档中进行跨文件检索，支持区分大小写、全词匹配与正则表达式。

### 4. 专注写作与生产力工具
* **专注模式 (`F8`)**：高亮当前正在编辑的活动段落，其余区域柔和虚化，让注意力百分之百沉浸在当前构思中。
* **打字机模式 (`F9`)**：视口始终将当前光标编辑行保持在屏幕纵向中央，大幅减轻长文输入时的颈椎疲劳。
* **Quick Open 快速跳转 (`Cmd + P`)**：模糊匹配工作区文件与历史打开记录，秒级在不同文稿间穿梭。
* **查找与替换 (`Cmd + F` / `Cmd + H`)**：支持文档内关键字高亮、正则匹配、单步跳转与全部替换。
* **实时字数统计浮层**：实时统计字符数、单词数、行数、选中范围计数以及预估阅读时长。

### 5. 多套精心调优的内置排版主题
内置 6 套精美排版主题，完美适配不同场景与阅读偏好：
* **Classic Light (GitHub)**：清晰干练的现代无衬线文档排版，适合技术笔记与文档编写。
* **Dark Modern (Night)**：低眩光深空配色，专为夜间与弱光环境设计的暗色沉浸主题。
* **Warm Paper (Newsprint)**：温润典雅的复古纸张与衬线字体风格，适合深度阅读与文学长篇写作。
* **Serif Book (Pixyll)**：大字号、舒缓行距的书籍版式，带来舒适的呼吸感与视觉体验。
* **Clean Minimal (Whitey)**：瑞士极简网格与纯粹留白排版，纯净无杂质。
* **Industrial Sans (Gothic)**：现代几何细体设计风格，利落硬朗。

### 6. 数据安全与多样化导出
* **纯本地安全存储**：数据全流程保存在本地磁盘，无第三方云端中转或数据上传，保障个人隐私与文稿资产安全。
* **灵活导出**：
  * 导出带完整排版样式的独立 HTML 文件（可直接离线阅读或分发）。
  * 导出无内联样式的语义化 HTML 代码。
  * 支持调起系统打印面板直接生成高清矢量 PDF。

## 🛠️ 技术架构与工程开发

本项目采用现代前端与桌面技术栈纯自研实现（Clean-room Implementation）：
* **界面与渲染**：React 19 + TypeScript + Vite
* **图标体系**：Lucide React
* **宿主通信**：ZTools Preload Bridge (CommonJS / Node.js 沙盒隔离)
* **解析器架构**：基于轻量状态机与正则流的高性能 AST 行块解析器，无黑盒重型依赖

### 本地构建与验证

```bash
# 安装依赖
npm install

# 运行单元测试、Preload 测试与 E2E 验证
npm test

# 静态类型检查
npm run typecheck

# 生产环境打包构建与产物校验
npm run build
```
