## 已交付

- 自由输入先调用当前模型一次规划意图；快捷按钮与指定 Skills 继续直接执行，无额外规划。
- 明确字面文本由程序生成补丁，不调用内容生成；位置由 Markdown AST、真实选区和源码范围绑定。
- 生成任务保留总结、图表、润色等任务语义，规划在分片前只执行一次；全局插入只产生一个最终补丁。
- 严格 JSON、字面回溯、单操作、标题消歧、选区范围、UTF-16/CRLF、完整候选 AST、过期快照保护。没有自动重试或失败后全文改写。
- 失败后保留可编辑指令；最终 Diff 确认，一次应用和撤销；继续编辑不被锁住。
- 规划与内容生成共享 5 分钟/64 次请求预算，停止、关闭、切模型会取消并隔离旧结果；修复同一请求被取消两次。
