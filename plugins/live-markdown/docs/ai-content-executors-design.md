# B31：按任务分工的内容执行器

目标是减少小模型同时理解位置、复制原文、生成正文和维护 Markdown 结构的负担。范围定位、结构拼装和写回由程序负责；模型承担需要语言判断的部分。格式通过不等于事实或代码行为正确。

## 生产入口

`runPlannedAiTaskCore → runThinAiTaskCore → generateThinTask → executeThinContent`。

先按语义选执行器，再用长度和预算决定是否分批。一个短文问答也必须使用来源路径；一个很长的独立创作也不能因此自动附带私有文稿。`direct` 比较策略跳过内容执行器与编译器，超过其单次预算时停止，不能暗中切换完整流程。

| 任务 | 模型承担 | 程序承担 |
| --- | --- | --- |
| 精确追加、替换、参数完整的标题/代码块 | 无调用 | 验证指令源码跨度，构造一个补丁 |
| 已知代码、JSON、表格、公式、Mermaid、指定章节 | 生成 payload | 固定标题级别/顺序、围栏、列、公式定界符和图节点 ID；有界解析 |
| 润色、校对、学术润色 | 返回正文槽 ID 与改后文字 | AST 划定纯文字槽；槽外源码原样拼回 |
| 来源字段问答 | 必要时按块选择原句 ID | 同主体字段绑定、来源范围核验、答案组装、覆盖和缺依据记录 |
| 摘要 | 选择可选来源原句 ID | 保留决定、负责人、金额、日期和显式状态等关键原句；按预算呈现 |
| Markdown 基础语法问题 | 无调用 | 返回带来源链接的固定 CommonMark 0.31.2 资料 |
| 其他开放任务 | 普通正文生成；不明确操作时用一次操作与正文组合回执 | 保留范围与生命周期保护，显示质量提示 |

不新增通用意图调用、模型裁判或失败重试。未知意图与已知操作仍有不同路径；任意自然语言不能保证都会进入模板路径。长未知任务沿用调用前选择的有界复杂流程，不在一次模型失败后改走第二套方案。

## 结构填充

只有来自原指令或授权来源的明确参数进入 ArtifactSpec。模型生成的数据没有指令证据，不能伪装为带证据字段。

- 代码：payload 是 raw body；程序生成语言围栏和外部标题。Markdown 代码正文可以含内层代码围栏，外围围栏长度由程序选择。函数名检查不能证明函数逻辑正确。
- JSON：payload 用字符串承载完整 JSON 文档，程序解析后重新序列化。限制 32 KiB 输入、32 层、4096 节点和 128 KiB 序列化正文；schema 本身不保证字段语义。
- 表格：payload 是固定列宽的行数据；来源表格还带来源关系 ID。校验关系和值是否有来源，不把“原句存在”当作所有列语义均正确。
- Mermaid：payload 包含节点文字与节点索引边；程序生成 ID、转义和围栏。图的业务关系仍需核对。
- 指定章节：程序按参数顺序输出标题，模型填写正文。未指定级别使用默认 H2；不把默认布局声称为用户的明确参数。

解析失败或超预算时不形成可确认提案，不复制全文作为“修复”，不自动再调用。

## 正文槽与长文

`buildThinProseSlots` 使用 AST、受保护源码范围和纯文字窗口生成稳定槽。代码、表格、公式、链接目标、图片、frontmatter、强调边界及明确要求保留的首尾标记不作为可编辑文字发送。

每批回执要求所有 ID 各出现一次。拒绝缺项、重复/未知 ID、结构注入、换行和事实锚点变化。槽的原有换行由源码拼回，因此不要求模型复制整份 Markdown，也不做整篇 AST 相等比较。

所有批次在调用前计算预算，顺序执行；全部回执核验后才拼装完整候选。取消、后续批失败或版本变化都会丢弃暂存结果。单槽超过模型预算、超过 50 批或调用总预算时预先停止，不能截断来源。不能承诺每个超长单段都可自动处理。

## 来源保真与覆盖

来源候选带准确源码范围、ID 和章节路径。字段只在存在明确同主体关系时绑定；冲突值和未找到的值分别呈现。多词名字不截断为单词，不能把另一项目的金额借给未识别主体。英文与中文显式标签属于有限语法支持，不是通用实体理解保证。

所有来源块均扫描，结果携带总块数、已处理块数、必需/保留事实数及缺字段。模型只能选择本块的来源 ID；没有最后一次自由写答案调用。未找到依据只说明此次扫描材料的结果，不代表完整世界中该事实不存在。

摘要保持摘要任务，不能因问题含“预算”“状态”就偷换成字段问答。明确要求自由转述的短摘要保留普通生成；长文自由转述仍受既有能力与预算限制。选择原句能减少编造，但不能证明所有重点均已理解或所有内容无遗漏。

## 生命周期、性能与包体

保留选区/全文/光标绑定、版本检查、只读保护、主动取消、共享调用/时间/字节预算。结果先展示 Diff；用户确认后一次写回，一次撤销恢复。协议 JSON 不作为半成品正文流展示。

确定性任务与固定知识减少调用；正文和来源任务按必要批次数执行；不并发占满本地推理服务。能力提示只针对精确识别的缓存小模型，不自动换模型、切云或下载模型。

运行时与权重仍在插件包外按需准备。ZIP 与解压体积各须小于 15,000,000 字节；本次没有新增运行依赖。

## 验收口径

生产入口单测和浏览器回归检查协议、范围、结构、取消、Diff 与撤销。模型回测另外记录格式、显式参数、事实关系和内容完整性；可确认、返回 JSON、ID 存在都不能计为语义通过。B30 原始包和证据保留；B31 使用独立目录、冻结源码身份和新包名。

本机 Chromium 与缓存本地模型结果不替代 ZTools 原生窗口、宿主供应商、Windows 或 Linux 本机验收。具体数字及失败见 B31 验收报告。
