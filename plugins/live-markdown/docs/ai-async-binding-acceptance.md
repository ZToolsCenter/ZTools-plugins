## 已确认原因与修复

- 两项英文回退在相同提示下返回了不同 raw，不能归因于 Diff 写回丢失。另八项在既有轮次仍有漏改或内容泛化，不能把一次生成成功当作质量通过。
- TypeScript 的 `async function ...(): string` 虽可解析，却违反异步返回类型规则。程序仅对用户明确要求的唯一目标函数，将显式基础类型包装为 `Promise<T>`，不改参数、函数体、其他函数或用户源码；提示有限修正和未执行完整类型检查，仍需 Diff 确认。
- AST 现在按同一变量声明中的精确绑定判断异步属性。目标同步、另一个绑定异步，不能误算目标满足 async。支持普通 class/object 方法；get/set 访问器、async generator 不伪装成普通可调用函数。
- 无注解、已有 Promise、联合/数组、未知类型、类型谓词和声明签名不猜测。重复同名目标保持歧义，不能择一修复。生成代码从不执行；开发 TypeScript noEmit 检查不进入发行包。
