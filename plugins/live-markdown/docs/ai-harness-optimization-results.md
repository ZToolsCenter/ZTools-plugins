# AI Harness 优化实施与验收记录

日期：2026-10-23。对应[已确认方案](./ai-harness-optimization-plan.md)。交付状态：**候选版本，尚未通过所有真实模型任务及原生宿主验收**。

## 已完成的实现

- UI 与评测共用请求构造，使用实际供应商、角色、自定义系统提示、Action/Skill 和预算；旧 v1 数据只读保留。
- 显式指令形成同一份带 UTF-16 原句证据的约束，schema、解析、计划核验与源码绑定共同消费。补齐中英文位置、序号、引号与否定；无效选区/光标不扩大范围。普通“总结文档”只读回答，有明确写入目标才创建编辑提案。
- 自然语言最多一次意图规划；固定文字由程序按精确补丁执行，**0 次正文生成**，并非零次模型调用。未知或冲突要求保留指令、具体引导，无自动重试。
- 长摘要由原文范围、章节路径及完整关系句构造候选；模型只选择候选 ID，程序保留必需关系、归并及渲染，不再自由 reduce。明确的摘要主题排除无关可选背景；否定的“没有新增决策”不强制当作决定。
- 输出按字面、回答、新片段、改写和摘要分别验证；检查实际 Markdown 节点、完整围栏、原文/指令回声和内部上下文标记。验证失败不自动剥除或编造内容。
- 代码正文、表格单元、URL、简单 YAML 标量和公式仅开放已绑定的精确字面替换，验证完整候选及节点身份；脚注 ID 的原子重命名仍不支持。
- 保留统一调用额度、取消与过期检查，单次 Diff 确认和撤销。64 KiB 指令先检查预算再解析；1 MiB 原文、50 分块、64 次总调用等上限仍生效。明确不需要标题候选时省去一次整文解析。

## 真实模型比较

使用 macOS arm64、Node 24.15.0、已缓存的 `Qwen3-0.6B-Q4_K_M.gguf`，未下载、切换模型或调用云端。模型资源 478,804,470 字节独立于插件包。每条指令无修复重试，80 条全部实际运行，未写回原生编辑器。

比较采用同一份冻结 v2-r4 工具、80 场景与生产默认角色请求；A 是旧产品快照，B6 是最终候选。原 v1 的 30/80 不是此处提升分母。

| 指标 | A：旧版重评 | B6：候选 |
| --- | ---: | ---: |
| 原量表全维度严格通过 | 29/80 | 53/80 |
| 原始意图协议通过 | 43/80 | 72/80 |
| 任务、质量、范围联合通过 | 33/80 | 56/80 |
| 生成内容客观量表 | 6/18 | 9/18 |
| 40 个正向字面任务的精确补丁 | 18/40 | **40/40** |
| 意图调用 / 正文调用总量 | 80 / 56 | 78 / 22 |
| 全部场景耗时合计 | 68.98 秒 | 39.44 秒 |

耗时包含模型启动和系统负载差异，仅为本轮观测，不能归因为纯算法加速。没有采集可比较的模型峰值内存，不报告内存改善。

长文结果单独核验：

| 场景 | A 正文调用 | B6 正文调用 | B6 结果 |
| --- | ---: | ---: | --- |
| G09：只回答三项决定 | 15 | 3 | 三组实体、负责人、金额、日期关系均保留，包含章节出处，无重复背景 |
| G10：文末新增三项决定 | 17 | 3 | 相同三组关系，仅一个 EOF 追加补丁，原文不改 |
| G11：全文逐段润色 | 1 后失败 | 2 后失败 | 模型破坏保护内容，被 AST 拒绝；没有完成所有分块，无部分提案 |
| G15：纯代码保留 | 1 | 0 | 明确保留原文，无提案 |

G09/G10 计划仍有 13/14 个拥有准确原文范围的分块，只有含相关候选的 3 块需要模型调用。其余块不用于自由生成；该优化不代表任意主题的摘要都能只调用 3 次。

原始分数完整保留，没有为候选版修改冻结评分器：

- L25 的合法选区格式替换和 B17–B21 的五类新能力仍被旧保护量表计为失败。应分别核验精确补丁、目标节点和其他字节，不能据旧拒绝规则直接宣布失败或整体加分。
- E15/E16 旧受控断言要求调用一次后拒绝；新版在调用前拒绝非法 emoji/CRLF 中间偏移。因此冻结受控分为 14/16，另有 4 个真实入口测试覆盖零调用拒绝及合法边界。没有把原报告改成 16/16。
- B07/B08 等提前拒绝和部分错误消息身份变化会降低旧量表分数；拒绝与正向编辑完成分开统计。
- G15 已返回 `preservedSource` 且 0 正文调用，旧安全评分未识别这个终态，原失败仍保留。

B2、B3、B5 为不同源码的完整中间实验，均保留所有失败。B2 暴露英文光标错位、摘要背景冗余；B3 暴露普通总结被误当作改写；B5 虽阻止写回，但残留操作约束导致回答也被拒绝，B6 已补正向测试并修正。B4 仅冻结，未运行模型。更早 v2/r2 工具试验作废的原因也保留，不能混入最终分母。

历史 19 项里，15 条字面任务已按精确补丁完成；B07/B13 正确停止，B14 仍误报缺失操作，G13 定位正确但生成内容重复标题。不存在把这些拒绝也计为“19 项全部完成”的结论。摘要诊断字段 `retainedRequiredFacts=0` 指模型漏选后由程序额外补入的数量为零，三条必需关系均已由模型选中并保留。

## 尚未通过的能力

- **长文润色 G11 未达标**：分块机制和保留源码测试通过，真实 0.6B 仍会遗漏或破坏结构。安全拒绝不等于任务完成。
- 代码、表格、Mermaid、公式、富文本校对、续写等生成任务仍有未完成项：原文回声、指令复述、截断、未改错字或规划澄清；失败无自动重试。不能宣称换上 Harness 后小模型能力已全面解决。
- G14 客观量表通过，但人工复核可见复述指令与填充文字，技术方案实用性不合格。G13 仍有重复章节标题。客观格式/关键词通过不能替代质量验收。
- 本轮没有执行生成代码，也没有以真实 Mermaid/LaTeX 渲染器证明所有生成输出可用。Mermaid 检查只覆盖结构子集。
- 脚注 ID 重命名、复杂 YAML 语义修改和自由改写长摘要未开放。

## 性能与交付检查

本机模拟推理的完整程序路径，排除模块加载，2 次预热后 10 次测量；不是界面输入延迟实测：

| 输入 | 非模型 CPU P50 | P95 |
| --- | ---: | ---: |
| 11,752 字符长摘要 | 12.83 ms | 15.03 ms |
| 2,215 字符逐段改写 | 3.53 ms | 5.51 ms |
| 1 MiB 最后一处精确替换 | 311.88 ms | 381.93 ms |

典型文稿满足拟定的 P95≤50ms；**1 MiB 同步 AST 校验仍可能阻塞界面**，没有通过该边界的编辑响应预算。只读 profiling 显示主要开销是重复 AST 解析。不能用典型输入结果掩盖边界问题，也不能声称跨设备性能已经验收。
