## 进程与资源边界

- 只绑定本机回环地址，以随机凭据保护受管服务；外部 Ollama 仅连接，不替它安装、删除或停止模型。
- 正常视图销毁先同步处置自己持有的子进程，再异步释放；其他窗口仍在借用时不停止它。已验证身份的残留进程可由后续实例接管和回收。
- 系统强制结束宿主（例如 SIGKILL）无法运行退出清理；如果之后不再打开插件，残留服务可能继续驻留。本版没有另装永久后台监督服务，不能保证硬崩溃瞬间回收。
- 不绕过系统权限、签名和杀毒限制。无法可靠识别某个进程时不会按 PID 猜测终止；保留明确失败状态。
- 过期锁通过独立回收锁串行处理，防止多窗口同时接管。若程序恰在回收旧锁期间崩溃，遗留回收锁会阻止继续自动接管，需诊断处理；不会通过猜测锁归属强行删除。
- 插件包不含模型和引擎。代码、测试、下载缓存没有写入其他插件目录；未创建 Git 提交、未推送、未发布市场。

## 包体与复现

`npm run package` 先完成全量构建检查，再按发行允许清单生成 ZIP。压缩包和解压总字节分别执行 **15,000,000 字节**硬门禁；精确大小由 `release/size-report.json` 记录。模型、引擎、node_modules、测试、截图和缓存都不进入发行包。

可单独运行：`node scripts/accept-local-ai.cjs light` / `balanced`（真实资源下载）、`node scripts/accept-local-ai-lifecycle.cjs`（已有模型的崩溃接管）、`node scripts/accept-local-ai-ui.cjs`（真实推理与生产 UI）、`node scripts/measure-editor-performance.cjs`（本机浏览器测量）。这些显式验收脚本的输出均保存在插件内 `.cache/acceptance/`，不会随发行包分发。
