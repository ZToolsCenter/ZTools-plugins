# AI 分块与任务运行器验收

## AST 校验与无重试执行（2026-10-22）

本节覆盖当前实现；后续历史记录中的结构修复重试和 384 token 修复预留已移除，历史模型输出与失败结论保留。

- 每个片段只调用一次模型，任一片失败直接结束任务；不暴露部分结果，不自动或手动重试旧任务。输入指令保持可编辑，可修改后明确发起新任务。
- 使用已有 Lezer GFM 解析器检查 Markdown AST；保守编辑保留标题、列表及其嵌套、引用、段落、强调与链接结构，代码、表格、HTML 和链接目标保持原样。补充 frontmatter、公式和脚注的保留检查。AST 只能校验结构，不能证明事实、语义或文稿质量。
- 分块还原后校验，整篇还原与格式整理后再次校验，检查最终将写入的候选内容；限制输入／输出 1 MiB、AST 50,000 节点和 128 层嵌套。
- 明确的文末追加独立生成一次提案，不把同一追加指令分发给每个编辑块。完整引号包围的固定文本及单个 ASCII 文本可直接生成候选修改，不调用模型；其他明确追加需求沿用全文语境或长文摘要归并。混合位置修改必须拆开，不能静默只执行追加。
- 追加校验检查实际插入内容，保留原文全部字节与换行，拒绝与原文末尾未闭合代码、公式、列表、引用产生不安全合并。仍需用户确认，并支持一次撤销。

本轮验收采用真实任务运行器和 Chromium 加受控模型响应，验证结构损坏拦截、零自动重试、输入恢复、追加一次、确认／撤销与源码保真；它不构成真实 Qwen 模型质量或原生 ZTools 实机通过。最终包及检查结果另存 `.cache/acceptance/ai-failure-recovery/final-package.json`。

## 段落处理补充（2026-10-22）

本地润色、校对、学术润色和错字校对自动采用段落粒度，一段一请求；标题随紧邻正文处理，连续列表优先保持完整。超过约 384 个估算正文 token 的单元按句子及 Unicode 安全边界继续切分，不切开保护标记。供应商、自定义重写、扩写、总结和续写保留原来的预算策略，不按模型名称猜测能力。

所有调用串行执行，段落模式不附带邻段原文或标题路径，避免小模型把只读语境抄入结果。系统提示、任务和当前片段仍一起计入完整预算。原有预算模式保留有界语境。50 片、64 次模型调用、5 分钟、单片一次与整项两次结构修复的上限继续生效。逐片通过后才合并完整提案，确认前原文不变；后续片失败、停止或文档变化均不产生可应用的部分结果。增加调用次数用于降低单次处理负担，不保证总耗时减少；保守编辑因独立处理而减少跨段指代信息，不适合需要全文重组的任务。

同时修复 CRLF／CR 表格的保护范围：只在解析视图规范行尾，范围映射回原始源码，保护和恢复保留原始换行。工程与真实模型结果记录在本节后续观察及 `.cache/acceptance/paragraph-mode/`；原始历史失败继续保留，不用新一轮输出覆盖。

本轮最终完整发行检查通过：221 项 unit、71 项 preload、5 项集成、30 项 Chromium file:// E2E，共 327 项，另含类型及发行校验。八段串行、精确拼接、完整提案复制、确认后一次撤销、第二段失败及停止零局部提案均有自动化覆盖。新增标题数量校验：保守编辑不能凭空新增标题，自定义结构重组不受此限制。

## 首轮预算分块记录

日期：2026-10-21（America/Los_Angeles）。以下是此前预算分块阶段的观察；不代表段落处理补充的本轮结果。本轮优化任务运行与确定性护栏，没有更换模型或增加运行依赖。

## 实现范围

- 润色、校对和学术润色按完整段落、标题、连续列表优先分块；超长单元才按句子或 Unicode 安全边界拆开。每块提供有界标题路径和前后只读语境，只取本次选区或全文范围内的内容。
- 按完整系统提示、技能模板、任务指令、语境及输出余量计算预算。按实际本地运行器的 4096 token 上下文规划，单次输出不超过 2048 tokens；完整替换按块大小预留输出，并为校验修复另留 384 tokens。估算不是模型 tokenizer，实际服务仍负责拒绝超限或截断。
- 校验保护标记的顺序、次数和所属分块。保守编辑另检查段落、标题下正文、列表、数字、任务清单状态和图标是否遗漏或异常变化。它们是启发式完整性检查，不能证明事实或语义正确。
- 仅重试校验失败的块，每块最多一次，整项任务最多两次；网络错误和截断不自动重试。整项任务最多 50 块、64 次请求、5 分钟；一次只运行一个模型请求。
- 所有块通过才形成一个完整提案；确认前不写文稿。继续编辑、换模型、关闭或停止后，旧结果不能写回，旧流也不能显示、清空或中断新请求。确认替换后可以一次撤销。
- 短文续写直接一次请求；长文才归纳上下文。纯代码、表格或公式且没有可编辑正文的块保留原样，跳过模型；整篇仅有保护结构时明确提示未调用模型，不生成应用提案。
- token 估算不再建立逐字符数组；保护标记恢复改为单次扫描。保留分块边界的原始空白、CR/LF/CRLF 和 hard break；源码模式菜单正确使用其撤销历史。

## 尚未解决的边界

- 自定义重组、扩写允许改变结构，不能套用保守润色的固定段数和数字规则。0.6B 的定向自定义指令仍可能删段并产生预览，必须检查对照；本轮没有宣称所有自定义修改都能自动验明正确。
- 原有表格、公式、代码等保护区域仍不能通过正文替换任务修改；生成新内容、Mermaid 语义和数学正确性依赖模型，现有轻量渲染器的公式排版限制也仍存在。
- 本轮真实推理验证在 macOS ARM64 的 Chromium 发行页与真实本地服务完成；宿主菜单和存储使用夹具。本轮两次连接 ZTools 窗口超时，最新 Harness 包未重新在原生宿主导入验证。历史原生记录对应旧包，不代表本轮最新包已通过宿主验收。
- Windows、Linux、Intel Mac 和 ATools 原生运行没有新增实机验证。
