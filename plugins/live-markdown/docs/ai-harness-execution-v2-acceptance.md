## 实现范围

| 责任 | 实现与行为 |
| --- | --- |
| 单次意图与范围绑定 | 自然语言沿用一次 planner；按钮/Skill 直接绑定已知任务。最后形成 `ExecutionPlan`，后续不再重新决定写入位置。模型不能提供源码偏移。 |
| 统一产物规格 | `ArtifactSpec` 保存语言、标题级别与文本、函数名、表格列/行、列表条目、公式、简单图关系，以及原句证据。未知值不补猜；模型提示不能覆盖已知字段。 |
| 确定内容构造 | 完整的字面标题、Markdown 标题代码块、JSON、明确表格、图标清单、给定公式和简单有向图由程序渲染，无正文模型调用。真实附加创作要求保留为生成任务。 |
| 任务与上下文 | 保留完整原始指令；使用任务专用提示。自包含新增省略文稿；明确引用、原文转换、选区/光标依赖保留来源。独立解释类回答不再扫描整篇 Welcome。 |
| 明确参数验证 | 检查 H1/H2、标题原样内容、代码语言、函数名、JSON 值、列和行、列表顺序、公式、图节点/边。完整代码块并不自动等于任务完成。 |
| 长文执行 | 复用正文槽位与摘要事实账本；新增长文问答的分片事实选择和一次最终回答。来源必须有 owned range，不通过自由摘要反复归并问题。 |
| 文档保护 | 仍验证范围、AST、来源版本、最终大小。全部成功后形成一个 Diff，用户确认后一次事务写回，一次撤销。失败、取消、过期与部分结果不写回。 |
| 草稿修正 | 完整候选未通过产物验证时保留可编辑草稿。修改后本地回验并生成 Diff，不再调用模型；结构化回执、部分分片、取消或截断响应不能冒充完整草稿。 |
| 正常无变化 | 通过校验的 rewrite 与原文逐字一致时显示“文档保持不变”，无错误、无可应用提案、无修复调用。 |
| 问答与引导 | 摘要与问答默认在侧栏回答。本地规划 schema 不再把已证明的只读操作与范围误当成缺少编辑位置；未知内容、缺少选区和真实多操作冲突仍可澄清。 |

产物内合法来源复用与产物外回声分开处理。来源表格先回验同行、已支持的主体/价格/金额/单位，再允许表格中的引用；手工修正也走同一验证层。普通新增的大量局部重叠提示审阅，未经授权的产物外全文复制仍拒绝。

没有自动重试、隐藏的模型修复调用或静默换模型。测试期间重复执行的固定用例属于独立评测采样，与产品运行时重试无关。

“创建代码块 markdown 格式 标题一 hello”在 v2 的两种模型代表集中均三次形成正确提案，每次只作一次意图规划、零正文生成；旧口语句式也恢复程序构造。不同 Markdown 产物共用字段规格与验证，没有给这句单独增加正文模型重试。

原自动 assessor 对方法回答存在关键词假阳性，对带说明标题的合法表格存在假阴性，保留其原始记录但不采用其聚合分数。人工逐条检查任务、参数、范围与事实关系。Direct 的“最后一处替换”样本还有提示边界污染，不能把多出的范围说明干净归因为模型能力。

不同轮次会绑定各自 source tree；小修后的补测不伪装成所有旧输出均来自最终源码。结构化请求温度为 0，普通生成使用后端默认值，seed 未暴露。因此这里是观察性流程对照，不能推断普遍成功概率、纯模型优劣或严格性能因果。

## 明确边界

- 自由方法回答仍可能编造编辑器步骤；两模型均出现过此问题。语法和 AST 通过不会被表述为答案正确。当前不再增加第二次模型审判来掩盖它。
- 函数名验证不是代码行为或语法编译证明；插件不执行生成代码。公式推导、复杂图语义也不能由通用结构校验证明。
- 来源引用、同句子串可回溯不证明任意谓词的主客体和方向；回源表格会提示在 Diff 中核对列含义与对应关系。
- 问答最终选中的事实超过上下文预算时会停止，不删减证据、不截断文稿或无限归并。保留 1 MiB、64 次调用等边界，不承诺无限长文。
- 生成期间允许编辑；依赖的文档版本、选区或光标失效会停止任务。已完成的分片不会作为可应用的部分结果。
- 模型及运行时在包外；ZIP 与解压资源分别按十进制 15,000,000 字节检查。没有把缓存模型、node_modules、评测记录或浏览器依赖装进插件。
- 当前只验收 macOS 本机服务和 Chromium；ZTools 原生宿主、Gemini、Windows/Linux 实机，以及冷下载/安装全流程均仍未在本轮复验。未强制重启 ZTools，也未恢复用户历史文稿。

这份候选可用于继续试用结构化 Markdown 编辑；自由问答质量与原生跨平台正式验收保留为单独的后续工作，不以大量安全拒绝抬高完成率。
