# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 - 2026-11-17

### 工作区多文件夹支持与默认工作区移除（2026-11-17）

- 移除侧边栏内置「默认工作区」虚拟目录及模板列表，空白状态下直接引导打开或选择本地文件夹（示例文档保留在「帮助」菜单与 Quick Open 中）。
- 支持同时添加与管理多个本地工作区文件夹：提供系统目录多选、`plugin.json` 多目录启动、侧边栏加号与底部「添加文件夹...」入口、菜单栏「打开文件夹...」（替换）与「添加文件夹到工作区...」（追加）以及单文件夹移除能力。
- 统一工作区文件列表视图、全局全文搜索、Quick Open（`Cmd+P`）、懒加载子目录展开、新建/保存刷新及内置 MCP `search_workspace_references` 工具，覆盖全部已添加文件夹。

### 上线前模型入口与发行产物收口

- 隐藏界面中的本地部署与 Ollama 入口，默认使用 ZTools 宿主已配置的供应商或自定义模型，并提供一键跳转「打开 ZTools 模型设置」。
- 兼容历史遗留的未就绪本地模型配置，启动时自动回退至宿主模型选择页；为独立浏览器预览环境提供清晰提示。
- 精简发行包产物：移除 `dist/docs/` 中的内部验收文档，并将需要本地浏览器的 E2E 回归从 CI `build` 脚本中解耦，保留在 `npm test` 与 `npm run package` 中执行。

### AI AST 结构校验与文末追加（2026-10-22）

- 润色、校对通过 Markdown AST 检查标题、列表嵌套、引用和行内格式；还原占位内容与格式整理后再次校验完整结果，保留代码、表格、链接目标、HTML、文档信息、公式和脚注。
- 结构校验失败立即结束，移除自动重试及对应上下文预留；清理旧进度、流式残片和待确认结果，保留指令并提供“修改指令”聚焦入口。
- 明确的文末追加独立执行，固定文本直接生成待确认追加提案，避免逐块重复；保留原文换行、确认写入和一次撤销，复合编辑请求不会静默只执行追加。

### 段落软换行预览（2026-10-22）

- 保留 Markdown 源码中的单次换行，普通段落在实时预览（含段内编辑）和阅读模式中自动连排；中文衔接、英文词间空格分别处理。
- 修正光标进入段落后重新拆开软换行的问题，源码模式保留原始行；空行分段、显式硬换行、代码及特殊块保持边界，超长或未解析完整的段落保留原显示。
- 调整文档信息卡片的窄窗口布局，避免长字段名挤在窄列中。

### CM6 段尾短行与字号修复（2026-10-22）

- 修复上下键越过相邻短文本行，以及进入富文本段落时标记展开后落点偏移的问题；先预展开目标行，再按最终可见行定位，保留横向目标列与源码换行。
- CM6 正文正确继承设置中的字号；补充实际恢复文稿、连续回车、短行与空行往返，以及不同字号和窗口宽度的回归。

### CM6 连续空行导航修复（2026-10-22）

- 修复连续回车后上下方向键跳过相邻可见空行的问题，保留原有列位置和滚动行为；折行段落、选区、输入法及 Slash 菜单保持原生处理。
- 补充完整欢迎文档、中文混排、连续空行和快速往返的浏览器回归；隐藏在公式、目录等块组件内的源码空行不参与强制校正。

### AI 打开状态与方向键修复（2026-10-22）

- `/ai` 仅打开助手；忽略助手和技能页的文字选区，关闭后清理旧反馈，明确停止时仍显示停止提示。已确认的编辑器选区与真实定位失败保护保持有效。
- 旧版编辑器上下键按实际软折行移动，仅在首末视觉行跨段；目标落点按目标块实际字体和宽度计算，兼容草稿、空行和末尾换行。
- 输入法组合输入、Shift 选区和修饰键保持原生行为；跨块列定位采用有界测量，避免逐字符扫描长行。CM6 保留原生方向键行为。

### 快捷目录与 AI 入口修复（2026-10-22）

- 快捷目录与前后正文分开，继续输入时保持渲染；独占一行的 `[toc]` 可在相邻正文中正常显示，保留代码、引用和内嵌标记原文。
- 快捷菜单的回车、Tab 和方向键优先执行菜单操作，普通编辑按键保持原有行为。
- 通用“AI 创作”只打开助手，不发起推理或在启用模型后自动补发；选区“润色”“总结”分别运行普通文稿润色与要点总结技能。
- 重复明确操作独立触发；浮条收起和右键菜单保留选区意图，无法准确定位时拒绝执行，防止扩大到全文。

### Markdown 渲染修复（2026-10-22）

- 普通围栏代码恢复等宽字体、基础语法高亮、语言标识和代码复制；编辑时显示围栏，退出编辑后隐藏围栏。
- 文档头部 YAML 以信息卡片预览，脚注恢复角标、悬停说明、定义排版和点击定位；标题与目录显示已知 Emoji 短代码。
- 修复后台解析完成、编辑器失焦及阅读模式切换后的预览刷新；未解析内容与未知语法保持源码，不改动文稿。
- 增加浅色／深色主题、长文滚动、复制失败回退、只读切换和源码保真回归。引用及列表内的代码围栏保留源码，避免复制容器标记。

### AI 品牌行与技能卡片（2026-10-22）

### AI 底部操作精简（2026-10-22）

### 本地小模型逐段处理（2026-10-22）

- 本地润色、校对和学术润色改为段落级串行调用，超长段落再切分；保留有界只读语境、逐片校验和整篇一次确认／撤销。

### Initial Release (初始版本发布)

专为沉浸式写作设计的纯自研所见即所得 (Live Preview) Markdown 编辑器插件首发上线。

#### ✨ 核心编辑与实时预览 (Editor & Live Preview)
- **所见即所得渲染引擎**：纯 TypeScript 原生构建的块级 AST 解析器与内联渲染流，聚焦段落时展开 Markdown 源码标记，移开焦点后无缝转为排版效果。
- **双向无缝源码模式**：支持通过快捷键 `Cmd+/` (`Ctrl+/`) 或状态栏按钮一键切换至带行号的 Markdown 纯源码编辑器，光标行号与滚动位置精确同步。
- **智能格式清洗与粘贴**：支持外部网页/富文本智能转 Markdown 格式粘贴，支持截图粘贴自动转存至本地 `./assets` 并生成相对路径。

#### 📁 侧边栏与工作区管理 (Workspace & Sidebar)
- **双工作区视图**：支持层次分明的“文件树 (Tree View)”与平铺卡片式的“文章列表 (List View)”双模式自由切换。
- **动态大纲导航**：自动解析提取 H1–H6 标题结构，支持关键词过滤、按章节折叠/展开与随滚动自动高亮当前阅读位置。
- **工作区全局检索**：支持对当前打开文件夹内所有 Markdown 文档进行内容快速检索，支持大小写敏感、全字匹配与正则表达式。
- **文件操作体系**：支持新建 Markdown 文稿、新建文件夹、重命名、复制副本、删除及历史最近访问记录。

#### 📐 扩展语法与富内容支持 (Rich Syntax & Extensions)
- **GFM 警告块 (Alerts / Callouts)**：支持 GitHub Flavored Markdown 规范的 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 与 `[!CAUTION]` 5 种风格化展示。
- **可视化表格编辑器**：支持悬浮网格快速创建表格、一键切换文本对齐（左/中/右）、快捷键（`Alt+方向键`）移动行列、增删行列与 Markdown 表格源码美化排版。
- **LaTeX 数学公式引擎**：支持行内公式 (`$...$`) 与多行复杂公式块 (`$$...$$`) 的实时排版与 LaTeX 语法交互编辑。
- **Mermaid 矢量图表**：内置对流程图 (Flowchart)、时序图 (Sequence)、甘特图 (Gantt)、饼图 (Pie) 与状态图 (State) 的实时矢量图表渲染。
- **多语言代码高亮**：支持 TypeScript、JavaScript、Python、Rust、Go、Java、C++、JSON、Bash、SQL 等主流编程语言代码高亮，提供语言模糊选择器与一键复制代码。
- **排版增强标记**：支持 YAML Front Matter、目录自动生成 (`[TOC]`)、学术脚注、Emoji 短代码自动补全、荧光笔高亮、上标/下标与下划线。

#### 🎯 沉浸式写作效率工具 (Writing Tools & UX)
- **专注模式 (`F8`)**：高亮聚焦当前编辑段落，平滑虚化非编辑区域，极大降低视觉干扰。
- **打字机模式 (`F9`)**：始终将当前光标输入行居中锁定在视口纵向中央，减轻长文输入颈椎负担。
- **Quick Open (`Cmd+P`)**：支持跨工作区和最近打开文件的快速模糊匹配与秒级跳转。
- **文档内查找与替换 (`Cmd+F` / `Cmd+H`)**：提供实时高亮命中项、大小写/全词/正则匹配，支持逐项或全局一键替换。
- **字数统计浮层**：实时统计字符数、单词数、行数、选区统计与预估阅读时长。

#### 🎨 精选排版主题 (Themes)
- 内置 6 套经过严格调谐的排版主题：
  - `Classic Light` (GitHub 风格现代无衬线)
  - `Dark Modern` (护眼深色沉浸)
  - `Warm Paper` (复古暖米色纸张衬线风格)
  - `Serif Book` (大字号书卷风格)
  - `Clean Minimal` (瑞士极简留白风格)
  - `Industrial Sans` (现代几何工整细体风格)
- 支持主题无缝热切换与本地持久化记忆。

#### 💾 安全存储与多格式导出 (Storage & Export)
- **全本地化运行**：数据完全由本地文件系统驱动，保护文稿隐私与知识资产。
- **导出能力**：支持导出带主题排版样式的独立离线 HTML 文件、导出纯语义 HTML 代码，以及调起系统打印面板输出高清矢量 PDF。
