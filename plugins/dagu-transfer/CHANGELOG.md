# Changelog

## 1.0.0 - 2026-11-26

### 新增

- 「分享」：把图片或文件上传到本地目录或 SSH 服务器。下拉列表里选目标，默认选中上次使用的，回车或点击即上传；成功后目标路径复制到剪贴板并自动收起，失败可回车重试。
- 「下载文件」：从 SSH 服务器下载到本机下载目录。在 ZTools 里输入或粘贴远端路径后选「下载远端文件」，选服务器即可下载；也可以先选服务器，再在搜索框里粘贴路径。成功后本机路径复制到剪贴板，可回车打开所在文件夹。下载类指令用向下箭头的图标，与上传区分。
- 「分享本地文件」：在 ZTools 里粘贴或输入本地文件路径，直接上传这个文件。
- 「快传配置」：管理上传目标（本地目录 / SSH 服务器）与下载目录。
- 接收「大古截图」的分享：在截图工具条点「分享」后直接进入上传列表。
- SSH 密码登录：服务器目标可以填写登录密码，上传和下载都按它登录；不填照旧免密登录（密钥 / `~/.ssh/config` / Agent）。密码只交给系统自带的 scp 去用，不写进命令行也不落盘；密码错误只尝试一次。目前只支持 Windows。
- 登录密码的保存与大古截图的密钥一致：默认只保存在本机，打开「同步密钥」后才写入 ZTools 的 `dbStorage` 并随备份同步，关闭开关删除同步副本。
- 跟随 ZTools 的深浅色与主题色：目标列表和配置页在深色下用深色配色。
- 配置页的 SSH 服务器表单新增独立的「用户名（可选）」输入框：填了则以它为准拼成 `用户名@主机`（主机框里已带的账号前缀会被替换），留空时行为与从前完全一样；存储格式不变，老配置照常使用。

### 变更

- 配置页与大古截图的配置面板是同一套卡片样式，底部有「保存设置」：所有改动要点它才生效，有未保存的改动时标题栏提示，不保存就关闭则丢弃。
- SSH 表单字段顺序调整为连接必需信息在上（主机、端口、远端目录），可选凭证在下（用户名、密码）；编辑已有目标时表单在该行正下方展开，改哪条看哪条，行的移动与删除会带着表单一起走。
