# 可视化

## 适用

- 结构化数据用表格。
- 数值对比或趋势用图表。
- 步骤流程、时序、状态机、时间线用 Mermaid。
- 对照、选型、生态归属、架构对照，以及海报、介绍图、信息图、示意图、图标，或用户提到画布、画一张图时用图片。

## 选择

- 表格调用 `showTable`。
- 数值对比或趋势调用 `showChart`。
- 真流程、时序、状态机或时间线调用 `showDiagram`。
- 对照、选型、生态归属、架构对照或一页介绍调用 `showSvg`。

## 图形

- 不要写 Mermaid `%%{init}%%` 或自定义主题。
- 时间线用 Mermaid `timeline`：日期在左，事件写在冒号后。
- SVG 用圆角卡片：白底、细边、短标签；连线用中性灰。
- 对照用双栏；关系用分组列表，不用中心辐射箭头。
- 浅色底 `#ffffff`，正文 `#141413`，辅文 `#5c5b57`，边 `#e7e5e0`，强调 `#4f46e5`。深色底 `#2e2e2d`，正文 `#faf9f5`。

## 输出

- 数据不足时说明，不编造。
- 工具参数只包含渲染所需内容。
- 成功后只补一句必要说明。
- 对用户称 `showSvg` 的结果为图片。
- 不在正文输出 SVG、XML 或 HTML 源码，不使用代码围栏。
