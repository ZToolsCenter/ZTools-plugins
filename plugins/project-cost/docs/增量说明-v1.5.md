# 增量说明 v1.5.0（M3 / M2 / M1 / A2 / A3 / A4）

> 批次定位：v1.4 补齐了「欠款多久了」（A1）与「存储会不会满」（Q3）之后，本批做的是
> **让判断更贴近真实约定**（M3 到期日 / M2 逾期分级 / M1 提醒不烦人）与**让报表能拿去做决定**
> （A2 材料结构 / A3 环比 / A4 单方造价）。六条全部是 P2、全部为 S 规模、全部为只读聚合或
> 项目级元数据，**不动金额链任何一个环节**。

## 0. 一句话结论

- 新增 6 个能力，**0 处改动金额链**：应付 246,055.97 / 已付 188,529.11 / 待付 57,526.86 字面不变，
  B1 派生 231,180.97 / 14,875.00 字面不变，预算 234,688.00 / 结余 −11,367.97 字面不变。
- 数据结构只多两个**项目级**字段：`dueDays`（默认 30）、`area`（0 = 未填），老数据打开自动补齐。
- 测试 **781 例全绿**（v1.2 回归 143 + v1.3 358 + v1.4 99 + v1.5 181）。

## 1. M3 到期日推算可配（`book.dueDays`）

**问题**：统一「下单日 + 30 天」推算到期日；7 天结的工长早就逾期却不提醒，月结 45 天的又提前催。

**实现**
- `core.js`：`DEFAULT_DUE_DAYS = 30`、`bookDueDays(book)`（1–365 夹取，非法回落 30）、
  `effectiveDue(p, dueDays = 30)` —— **签名向后兼容**，不传就是 30 天。
- 全部到期日消费方统一走 `bookDueDays(book)`：`agingRows` / `agingPayees` / `buildAlerts` /
  `cashflow` / `StatementSheet`。**没有任何一处留在旧的硬编码 30 天**。
- `store.js`：`mkBook` 与 `normalizeBook` 补 `dueDays`；新增 `setBookMeta({dueDays, area}, id?)`。
- 设置页新增「到期日推算」卡：数字框 + 当前项目按「下单日 + N 天」推算的说明。

**验收**：设 15 天 → 新建未填到期日的费用项到期日 = 下单日 + 15，逾期与账龄同步变化（测试覆盖
0/负数/非数字/999 的夹取，以及「已填到期日优先」）。

## 2. M2 逾期分级（超 30 天）

**问题**：逾期 1 天和逾期 90 天混在一行，催款顺序排不出来。

**实现**
- `core.js`：`SEVERE_DAYS = 30`、`overdueGroups(book, today)` →
  `{ all, severe, normal, count, amount, severeAmount }`，只收 `dueOf > 0.005` 且已逾期的费用项，
  按逾期天数降序。**口径与 `buildAlerts` 完全一致**（同一个 `effectiveDue` + 账本推算天数）。
- `buildAlerts`：`overdue` 项加 `severe` 标记，文案分级 —— 超 30 天 `超30天 … 42天 · ¥X`，
  普通 `逾期 … 5天 · ¥X`；汇总模式单独给出「超30天 N 笔」；返回值新增 `severeCount`。
- UI：顶部预警 `.alert-chip.overdue.severe` 用**实心 danger**；付款页新增「超 30 天 · 优先催收」
  置顶卡（4 列：天数徽标 / 品名 / 金额 / 收款方，最多 4 行后内部滚动），点行开抽屉。

**踩过的坑（已修）**：`overdueGroups` 首版把 `daysBetween(dd, today)` 的符号搞反
（这是「今天 − 到期日」，> 0 才是逾期），结果筛出了**未到期**的项、severe 恒为空。
测试用「30 天 / 31 天」边界把这条钉住了。

## 3. M1 预警忽略按天持久化

**问题**：点「忽略」只活在本次渲染里，切个分区就回来，被反复打扰后用户开始无视整条横幅。

**实现**：新模块 `src/lib/alertIgnore.js`，独立键 `ztools_alert_ignore_v1` 存 `{date, types[]}`。
- `ignoreTypes(types)` 去重写入；`isIgnored(type)` 按当天判断；`refreshIgnore()` 跨天复位；
  `clearIgnore()` 恢复；`ignoredCount()` 给设置页读数；`reloadIgnore()` 供测试/重置。
- **角标不跟着消失**：`rail-dot` 仍用 `alerts.total` —— 忽略只是「今天不打扰」，不是「清零」。
- App.vue：横幅只渲染 `visibleAlerts`（过滤已忽略的类）；启动与切分区各 `refreshIgnore()` 一次
  （**不在 computed 里写响应式状态**，避免副作用重算）。
- 设置页：「今日已忽略 N 类提醒」+「恢复」按钮。

**健壮性**：坏 JSON、`localStorage` 被拒都 try/catch 兜住（配额满时忽略状态存不下不算错误）。

## 4. A2 材料（明细品名）支出排行

**实现**：`materialRows(book, limit = 10)` → `{ rows, total, topTotal, others, othersCount, names, max }`。
- 同名判定：去首尾空白 + 去内部全部空白 + 英文小写（「瓷砖 胶」≡「瓷砖胶」，`Cement` ≡ `cement`）。
- 每行带 `unit / price / itemId / itemNo / cat`（取该品名**金额最大**的那条明细为代表行）。
- **可对账**：`topTotal + others === total === Σ 明细金额`（247,577.89）；空品名不进排行但计入总额。
- UI：分析页第 5 个页签「材料」，占比条以 Top1 为满格，点行打开费用项抽屉。

## 5. A3 月度环比

**实现**：`monthCompare(book, today)` → `{ cur, prev, payable, paid, count, topCat, hasData }`，
每组含 `{cur, prev, diff, pct}`。
- 应付与新增费用项按**下单日期**归月，已付按**付款日期**归月（无日期付款不计入任何月份，与
  `monthlyPayments` 同口径）；`topCat` 取应付环比增幅最大的品类（可为负）。
- 跨年正确处理：`2026-01` 的上月是 `2025-12`。
- UI：「费用构成」页顶部三格（应付 / 已付 / 新增费用项）+ 上月基准行 + 变化最大品类。

## 6. A4 单方造价（元/㎡）

**实现**：`costPerArea(book)` → `null`（未填面积）或 `{ area, payable, confirmed, perArea, perAreaConfirmed }`。
- `perArea = Math.round(应付 / 面积)`；89㎡ → ¥2,765/㎡（246,055.97 / 89 = 2,764.67）。
- UI：项目管理抽屉每行「面积 __ ㎡」；概览「预算执行」加一行单方造价，分析页命令栏一枚
  `¥X,XXX/㎡` 胶囊。**未填则整项隐藏**，不显示 ¥0/㎡。
- 面积只服务这一个指标，**不进任何金额公式、不进导出表头**。
