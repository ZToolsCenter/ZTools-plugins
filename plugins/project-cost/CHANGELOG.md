# 更新日志

## 1.9.1 - 2026-10-29

- **修复撤销 / 重做按钮原地不刷新**：改一条费用项备注后，盘上撤销栈已有 2 步，界面上「撤销」按钮却仍是灰的、提示还写着「没有可撤销的操作」、点了完全没反应，只有切页或重开抽屉才读到新值。根因是这些判定函数读的是模块内的普通数组，Vue 追踪不到；原代码想借账本对象触发重算，但原地修改时它的依赖一个都没变。现改为由独立的撤销栈信号驱动，撤销 / 重做 / 步数提示实时跟随
- **修复同一分钟内连续导出仍撞名**：文件名原先只带「时分」，30 秒内改个筛选再导一次会一字不差地被浏览器静默改名。现在同名再导会自动追加序号（第二次 `_1430_2`、第三次 `_1430_3`），筛选条件不同的两次互不干扰，文件名也不会退回又长又难看的完整时间戳
- **修复「大字」档下环形图图例没放大**：图例因为选择器写法问题被漏掉，实测紧凑 11px → 大字仍是 11px，大字档「所有文字不小于 12px」的承诺在图例上悄悄破了
- **补齐「大字」档在抽屉正文的覆盖**：抽屉里的字段标签、辅助说明、提示文案、徽章、四宫格金额、批量粘贴区原先仍是小字；现全部抬到 12px 以上，靠底栏换行消化排版，**没有压缩任何字号**，800px 窄窗口下横向溢出由 2 处降为 0
- **修复设置页版本号滞后**：上一版只改了工程里的版本号、漏了页面底部写死的那行，导致界面一直显示旧版本。现改为直接读取工程版本号，单一来源
- 测试基建：8 个界面自验套件的端口改动态分配，并发执行不再互相撞车；套件启动失败时不再被汇总器当成通过

## 1.9.0 - 2026-10-29

- **大字档全场景**：新增「紧凑 / 舒适 / 大字」三档直达切换；大字档下所有文字不小于 12px（付款页列表、抽屉、环形图、柱状图同步放大），紧凑档的单行高度与首屏条数一个像素都没动
- **图表字号下限回退**：柱状图柱顶数值取消 8px 档，恒为 9px（大字档 12px），宁可用省略号也不压字号
- **重做**：撤销之外新增重做，支持撤销 → 重做 → 再撤销；快捷键 ⇧⌘Z；撤销后又做了新操作时重做栈自动清空
- **同日导出不撞名**：CSV / Excel / 三表导出文件名自动带当日时分
- **密度偏好进备份**：密度档随 JSON 备份一起带走，导入后自动恢复
- **撤销入口扩到全场景**：明细单、付款页都能直接撤销，按钮提示显示「可撤销 N 步 / 可重做 N 步」
- **收款方改名 / 合并前先看影响**：改名与合并都会先显示将影响多少条费用项、多少笔付款与合计金额，确认后才执行；预览与实改同一套口径

## 1.8.2 - 2026-10-28

- 全站金额精度统一为「元 + 千分位 + 2 位小数」，取消万位缩写，同一笔金额在任何页面长得都一样
- 撤销栈落盘并计入存储占用；存储占用超 80% 配额时提示导出备份
- 导出表头术语统一为「收款方」，文件名统一为「费用表」，时间戳只保留在备份文件上
- 体检支持对收款方残缺项一键改名 / 合并
