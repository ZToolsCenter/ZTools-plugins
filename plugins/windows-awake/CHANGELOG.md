# Changelog

## 1.0.0 - 2026-09-29

### Added

- 首个版本：通过 Windows `SetThreadExecutionState` 阻止系统自动睡眠，可选是否同时保持屏幕点亮。
- 唤醒时长支持 15 分钟 / 30 分钟 / 1 小时 / 2 小时 / 一直保持，以及 1 - 1440 分钟的自定义时长。
- 息屏策略支持「不允许息屏」与「允许息屏」，运行中可随时切换并保留剩余时间，时长按新值重新计时。
- 时长与息屏策略通过 ZTools 存储保存，插件或宿主重启后仍然保留。
- 后台 PowerShell 守护进程按心跳与进程存在性上报真实状态，退出 ZTools 时自动清理，且不修改系统电源计划。
