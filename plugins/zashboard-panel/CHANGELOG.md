# Changelog
## 2.0.0 - 2026-09-12
- 新增 ShellCrash 可视化管理功能，支持通过 SSH 远程操作路由器上的 ShellCrash
- 侧边栏 ShellCrash 管理入口，支持功能设置、订阅管理、停止服务、启动/重启服务、备份/还原设置
- 功能设置：路由模式切换、DNS模式切换、跳过证书验证、启用域名嗅探、IPv6透明路由、IPv6-DNS解析
- 订阅管理：订阅列表展示、添加订阅、编辑订阅、删除订阅、一键使用订阅
- 备份/还原脚本设置
- 指令步骤编辑：支持自定义各功能的 SSH 指令步骤

## 1.0.0 - 2026-09-03
- 基于开源项目[zashboard](https://github.com/Zephyruso/zashboard)封装的插件
- 本地内置 zashboard v3.23.0（MIT, Zephyruso），打开即用
