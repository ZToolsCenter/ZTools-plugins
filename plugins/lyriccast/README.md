> 手机正在播放的歌，电脑上同步滚动歌词 + 桌面悬浮歌词。

## ✨ 功能

- **实时歌词**：手机一播放，插件立即显示歌名、歌手、封面（氛围模糊背景）和逐行滚动歌词，当前行居中放大高亮，翻译内嵌当前行下方；切歌、暂停、拖进度 1 秒内跟上；
- **歌词全自动匹配**：LRCLIB 主源 + 网易云/酷狗/lrcmux/Better Lyrics 聚合，自动择优；查不到的结果缓存 24 小时，不反复请求；
- **「换一个」手动选词**：匹配不准时打开候选面板，五个来源的候选一览可选；选中的会记住，下次播这首歌还是它；
- **歌词校准**：`±100/±500ms` 微调，按"本曲"或"此应用"记忆；
- **桌面悬浮歌词**：独立置顶悬浮窗，常驻屏幕可拖动，当前句大字 + 翻译/下一句小字平滑滚动；字号、配色、对齐、透明度、翻译行均可调，位置自动记忆；
- **繁体转简体**：繁体歌词逐字转简体显示，日语歌词自动跳过；
- **扫码配对**：设置页展示配对二维码，手机 App 扫一下即完成连接；另有下载二维码，扫码直装最新版手机 App；
- **多设备**：多台手机可同时连接，设置页一键切换活跃设备。

## 🚀 安装

1. 安装 [ZTools](https://github.com/ZToolsCenter/ZTools/releases)（Node.js 16+ 仅构建时需要）；
2. 在本目录执行：

   ```bash
   npm install && npm run build
   cd src-ztools/preload && npm install
   ```

3. **ZTools → 设置 → 插件 → 导入本地插件**，选择 **`src-ztools/`** 目录；
4. 建议开启插件详情里的 **「跟随主程序同时启动运行」**：ZTools 一启动插件就在线，桌面歌词也会随插件常驻。

首次进入插件会自动生成配对密钥并启动服务（端口 18765）。然后在手机 App 里 **扫码配对** 即可。

## 📖 使用

- **歌词页**：播放中自动滚动歌词；顶部可校准 `±100/±500ms`、调字号、开关翻译；点 **换一个** 手动选词；
- **桌面歌词**：设置页打开「悬浮歌词窗口」，鼠标悬停可调字号/翻译/对齐/配色，拖动到喜欢的位置（自动记忆）；
- **设置页**：歌词来源五个开关、繁→简、封面补图、连接状态与配对二维码、手机 App 下载二维码。

> 没有手机也想先看看效果？在 `tools/` 目录执行 `npm install` 后运行
> `node mock-phone.js --token <设置页显示的Token>`，可以模拟一台手机推送完整的播放时间线。

## ⚠️ 已知限制

- 网易云/酷狗为非官方接口，可能随时间失效（失效自动回退其他来源，不影响使用）；
- 封面补图用的 LrcAPI 为公益接口（可能限流），MusicBrainz 有速率约束；都拿不到时保持占位符，点击可重试；
- 繁→简为字表直转，不做词汇级地域用语转换（如「滑鼠/鼠标」），个别生僻字保留原形；
- 悬浮歌词需要较新版本的 ZTools（支持独立透明窗口），过旧时设置页会提示错误；
- ZTools 重启后，未开「跟随主程序同时启动运行」时需要手动进入一次插件。
