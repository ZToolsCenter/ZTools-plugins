# Changelog

## 0.4.0 - 2026-10-12

- 插件更名「词投 LyricCast」，启用全新图标，入口关键词新增「词投」「lyriccast」
- 桌面悬浮歌词改为统一行高的行间轨道平滑滚动，保留 2 行紧凑视图
- 新增封面 API 兜底：手机端未推送封面时按曲目元数据从公开封面 API 取图（设置 → 歌词来源可关闭）
- 歌词支持简繁转换（t2s）：检测到繁体特征字时自动转为简体展示
- 设置页新增「手机端」下载二维码：扫码直接下载 GitHub Releases 最新 Android 安装包
- 开发调试端口统一为 5236，修复 Windows 下 `dev:full` 启动报 ENOENT 的问题
