# Changelog


## 1.0.1 - 2026-04-25

- 完善技能描述展示、搜索提示、分组删除和 Trae CN 目录配置。
- 优化异步文件操作、技能列表缓存、搜索防抖和导出进度，减少界面阻塞。
- 修复批量删除与分发的异步调用问题，支持旧数据迁移及多行 YAML 描述解析。
- 加强 Git 克隆、文件导出、路径和 URL 校验，修复命令注入与路径遍历风险。
- 完善超时、失败重试和代理配置提示。

## 1.0.0 - 2026-04-17

- 初次发布，将插件提交至 ZTools 插件仓库。
- 支持 AI 技能的安装、更新、删除、搜索和批量管理。
- 支持向不同 Agent 分发技能，并修复技能元数据与注册信息。
- 优化按仓库分组的批量操作、GitHub 镜像回退和跨平台文件选择。
