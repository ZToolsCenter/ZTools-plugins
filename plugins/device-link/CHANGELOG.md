# Changelog

## [0.1.8] - 2026-09-01

### Added

- 适配 ZTools 3.2：附件、传输临时文件和本地凭据密钥使用插件专属 `pluginData`；首次启动会校验迁移旧文件、重写数据库路径并删除旧目录。保留附件另存为入口与按消息 ID、附件 ID 打开的精确定位。

### Changed

- 本地加密 fallback 保持旧密钥种子以解密既有 `local:` 凭据，并将 `local:v2` 密钥迁入 `pluginData`。ZTools 2.4–3.1 直接安装仍使用原目录，完成迁移后不保证降级的数据可见性。
- 适配插件内 ESC 直接隐藏：隐藏时只重置瞬态 UI，不停止后台传输服务；Tab 焦点闭环保持有效。
- 低于 ZTools 2.4 或真实宿主无法提供可信版本时，只显示升级提示；preload 保持惰性，不加载状态、不订阅事件，也不启动局域网服务。

## [0.1.7] - 2026-08-28

### Added

- 扫描电脑端二维码后，H5 会展示“识别电脑、读取一次性扫码授权码、建立连接”的进度并直接进入会话，无需手动输入或点击连接。
- 自动连接失败时可切换到原有手动匹配流程；直接打开电脑地址仍保留手动输入方式。

### Changed

- 延长扫码自动连接各阶段的停留时间，让识别、授权码读取、连接校验和成功状态清晰可见；系统开启“减少动态效果”时仍会跳过动画等待。

### Fixed

- 修复手机发送图片或文件后，电脑端附件卡片只有预览入口、无法另存到指定位置的问题。
- 修复慢网络下扫码页面短暂显示手动表单的问题，并让手机与桌面的 12 位数字码按每行最多 6 位换行展示。
- 修复配对已经成功、但消息列表暂时加载失败时错误引导用户重新配对的问题；现在会保留授权并提供“重试进入会话”。
- 修复配对持久化过程中手动刷新二维码时，旧请求仍可能成功并覆盖最新配对信息的竞态。
- 修复可信设备自动恢复、重新扫码及电脑端撤销授权并发时，旧凭据可能覆盖新授权或让已移除设备重新出现的问题。
- 修复停服期间仍有 WebSocket 设备写入时，服务过早退出导致离线删除后授权记录再次出现的问题。

### Security

- 二维码使用与手动匹配码隔离的每代随机一次性扫码码，不会把用户自定义匹配码写入二维码或浏览器历史。
- H5 识别二维码后立即将会话 ID、一次性密钥和扫码码保存到页面内存并清理地址栏，成功配对后服务端立即轮换整代二维码凭据。
- 同一代二维码的并发配对只允许一个请求成功，并拒绝未知配对模式。
- 同一设备的自动恢复、重新配对、WebSocket 注册与显式撤销会串行更新授权，保证最终状态符合用户最后完成的操作。
- 停止接收服务会拒绝新的授权写入并等待在途设备操作安全落盘，避免停服与离线清理之间发生凭据复活。

## [0.1.6] - 2026-08-28

### Fixed

- 修复 ZTools 预加载环境未提供 Electron `safeStorage` 时，H5 完成校验后返回“服务处理请求时发生错误”的问题。
- 本机安全存储不可用时改用独立随机密钥保护设备授权，并兼容读取旧版本机 AES-GCM 密文。
- 修复数据库返回冲突或失败对象时仍可能误报授权保存成功的问题；失败时回滚新会话、保留原有连接并返回可操作的错误提示。
- 自动连接遇到电脑端安全存储暂时不可用时不再按授权失效处理，避免手机误删可信设备凭据。

### Security

- 服务端仅记录脱敏后的请求路径、错误类型与堆栈，不记录匹配码、证明、会话密钥或请求正文。

## [0.1.5] - 2026-08-26

### Added

- 新增可信设备持久化授权；刷新页面或电脑端服务重启后，通过一次性挑战签名自动换取新会话，无需重复输入匹配码。
- 新增手动连接模式；手机可直接打开电脑端地址并输入匹配码，不再必须扫描包含一次性高熵密钥的二维码。

### Security

- 电脑端优先使用系统安全存储加密长期设备凭据，不可用时使用本机独立随机密钥加密；移动端凭据按浏览器站点隔离保存。自动连接挑战两分钟过期、仅可使用一次，并绑定设备与来源地址。
- 保留二维码高熵密钥、匹配码错误锁定与设备撤销能力，并限制待处理自动连接挑战数量。

## [0.1.4] - 2026-08-20

### Fixed

- 修复移动端打开旧版或缺少配对会话标识的二维码时误报“匹配码不正确”的问题，并在二维码过期或缺少 `pairing` 参数时引导用户重新扫描最新二维码。

## [0.1.3] - 2026-08-14

### Added

- 新增多设备会话：每台设备拥有独立私聊，并提供所有已授权设备共同参与的共享会话。
- 电脑端支持从左侧会话列表切换目标；手机端支持在单独会话与共享会话之间切换。

### Fixed

- 修复第二台手机配对时旧二维码状态可能异步覆盖新状态、继而提示匹配码不正确的问题。
- 修复设备间消息、历史记录和附件可能越过单独会话边界的问题，并补充服务端权限校验。
- 修复多设备消息量较大时，全局历史上限可能挤掉其他会话消息和附件的问题，改为每个会话独立保留最近 1000 条。
- 修复 WebDAV 同步完成后电脑端意外跳回第一台设备会话的问题。

### Changed

- 将手机端交互逻辑拆分为受 CSP 约束的同源静态脚本，便于独立审查和维护。

## [0.1.2] - 2026-08-14

### Fixed

- 修复刷新配对信息后手机页面复用旧配对状态，导致新二维码被误判为已过期的问题。
- 修复较矮的 ZTools 窗口中配对弹窗底部内容被裁切的问题，并优化扫码与匹配码的响应式布局。
- 修复配对信息到期后电脑端仍展示旧二维码的问题，到期时自动轮换匹配码与一次性密钥，并兼容休眠唤醒后的惰性刷新。

## [0.1.1] - 2026-08-13

### Added

- 新增电脑端文件与文件夹拖入会话发送，复用加密分块和超大文件传输链路。
- 新增历史消息手动清理与二次确认，清理本地附件并通过 WebDAV 删除墓碑防止消息恢复。

### Fixed

- 修复会话页右上角搜索和更多按钮缺少交互的问题，并补充键盘与焦点行为。
- 将会话搜索改为按钮下方的浮层输入框，并提高标题栏操作菜单的堆叠层级。
- 搜索输入框聚焦时保持边框与阴影样式不变，减少不必要的视觉跳动。
## [0.1.0] - 2026-08-13

### Added

- 新增 macOS、Windows、Linux 与 Android、iOS 浏览器之间的聊天式实时互传。
- 支持文本、链接、图片、任意格式文件及文件夹发送，并提供内容一键复制与附件打开。
- 新增二维码一次性密钥、6–12 位匹配码、错误锁定、设备授权撤销及 AES-256-GCM 会话加密。
- 新增 4 MiB 流式分块、大文件失败重试、SHA-256 完整性校验及最高 1 TB 接收配置。
- 新增加密 WebDAV 离线同步、附件分块同步和删除墓碑，避免离线设备恢复已删消息。
- 新增移动端非安全上下文加密后备与 IndexedDB 超大文件暂存能力。

### Fixed

- 修复通过 ZTools 开发者工具加载 `dist/` 时错误跳转到未启动的 Vite 开发地址，导致插件白屏的问题。
- 修复 ZTools preload 使用浏览器数字计时器句柄时调用 `unref()` 导致服务启动失败的问题。

### Security

- 局域网服务限制为私有地址访问，并提供 CSP、防嵌入、内容类型保护和会话/传输资源限额。
- 配对连续失败 5 次后锁定 10 分钟，成功配对后立即轮换二维码中的一次性密钥。
