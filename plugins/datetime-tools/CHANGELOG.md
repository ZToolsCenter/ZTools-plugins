# Changelog

## 1.0.0 - 2026-08-11

- 首个版本，功能与界面移植自 uTools 插件「时间日期计算」，移除「历史上的今天」「赞赏」页面
- 时间戳转换：实时时间戳（可暂停/复制/毫秒切换）、时间戳 ↔ 北京时间双向转换
- 计算日期差：天数差、时分秒模式（省略为 0 的单位，相同时间提示"时间一致"）
- 推算日期：按天 / 周 / 月往前往后推算
- 推算工作日 / 工作天数：内置 2024-2026 年官方节假日与调休补班数据，纯本地计算，
  结果展示节日放假与调休补班明细
- 日期格式：美式 / 英式英文日期格式表格，点击复制
- 世界时间：37 个城市时区换算（下拉多选），基于系统时区数据库自动处理夏令时
- 在线秒表：计次 / 暂停记录 / 复位，支持 A / S / C 键盘快捷键
- 每页支持"保持输入到下次"（localStorage），适配暗色模式
- 全部功能本地计算，不依赖任何外部接口
