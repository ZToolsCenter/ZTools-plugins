# 图标编辑器使用指南

## 快速开始

### 创建画布
1. 打开编辑器后会自动创建一个默认画布
2. 点击顶部菜单「文件 → 新建文档」可创建新画布
3. 在属性面板可设置画布预设尺寸或自定义宽高

### 添加对象
- **添加形状**：点击顶部菜单「插入」，选择基础形状（矩形、圆形、三角形等）
- **添加文字**：在「插入」面板中选择文字预设，或自定义文字内容
- **导入图片**：点击「文件 → 导入图片」，支持 PNG、JPG、SVG 等格式

## 对象编辑

### 基础变换
- **移动**：选中对象后拖动
- **缩放**：拖动对象四角的控制点
- **旋转**：拖动对象上方的旋转控制点
- **等比缩放**：按住 `Shift` 键拖动角控制点

### 样式设置
在右侧属性面板可调整：
- **填充**：纯色填充、渐变填充（线性/径向）或图案填充（平铺）
- **描边**：颜色、宽度、虚线样式
- **透明度**：0-100% 调节
- **圆角**：可编辑路径对象支持圆角设置

#### 图案填充
1. 在属性面板把填充切换为「图案」模式，无来源时会先以内置默认图案即时生效
2. 点击上传按钮选择本地图片作为图案来源
3. 可调整平铺方式（重复/横向平铺/纵向平铺/不重复）与图案缩放
4. 切回纯色或渐变即恢复原填充，图案不再生效

### 文本编辑
选中文本对象（可框选多个文本批量应用）后，属性面板出现「文本」区：
- **字体**：常见系统字体下拉（思源黑体/微软雅黑/苹方/黑体/宋体/楷体、Arial/Helvetica/Times New Roman/Courier New/Verdana/Georgia/Impact/Comic Sans MS、Inter/Roboto 等）。注意：字体直接使用系统字体名，不做内置 webfont 加载，实际渲染取决于查看端系统的字体安装情况，跨设备可能回退到相近字体；发布图标建议先「文字转曲」把字形固化为路径
- **字号**：数值输入（6-500）
- **样式**：粗体/斜体/下划线/删除线开关
- **字间距**：-200~800（fabric 单位为千分之一 em，默认 0）
- **行高**：0.5-3 倍（默认 1.16）
- **对齐**：左/中/右三态

AI / MCP 侧对应 `update_text` 操作，字段语义与面板一致。

### 高级效果

#### 阴影
1. 在属性面板找到「效果」区域
2. 点击「添加阴影」可添加投影或内阴影
3. 调整阴影的偏移、模糊半径、颜色等参数（模糊半径是阴影自身的扩散参数）

#### 位图滤镜与混合模式
选中位图对象（PNG/JPG 等导入图片）后，属性面板出现「滤镜」与「混合模式」区：
- **滤镜**：7 种——灰度、反色、褐色（无参数）；模糊、亮度、对比度、饱和度（开启后显示参数滑杆）。多种滤镜可叠加，每行一个开关，改动即应用并入撤销栈
- **混合模式**：13 种——正常、正片叠底、滤色、叠加、变暗、变亮、颜色减淡、差值、排除、色相、饱和度、颜色、明度，对所有对象类型可用

#### 位图裁剪
选中位图后在属性面板「裁剪」区：
1. 点击「进入裁剪」，画布上出现可拖拽、可调尺寸的裁剪框
2. 调整出要保留的区域，点击「确认裁剪」应用（一条撤销记录，可对同一张图连续裁剪）
3. 点击「取消」或按 `Esc` 恢复原图，不产生任何改动

#### 渐变填充
1. 在属性面板选择「渐变」填充模式
2. 选择渐变类型：线性渐变或径向渐变
3. 添加、删除或调整渐变色标
4. 调整渐变角度（线性）或中心点（径向）

#### 高级变换
在属性面板「变换」区域：
- **翻转**：点击水平翻转或垂直翻转按钮
- **倾斜**：输入 Skew X/Y 值实现倾斜变换
- **重置**：一键重置所有变换

### 样式复制
1. 选中源对象，按 `Ctrl/Cmd + Shift + C` 复制样式
2. 选中目标对象，按 `Ctrl/Cmd + Shift + V` 粘贴样式
3. 样式包括：填充、描边、渐变、透明度、阴影等

### 对象锁定
在属性面板点击锁定按钮，可选择：
- **无锁定**：对象可自由编辑
- **锁定位置**：可缩放旋转，但不可移动
- **锁定尺寸**：可移动，但不可缩放旋转
- **完全锁定**：可选中查看，但不可编辑

图层面板中会显示对应的锁定状态图标。

## 路径编辑（点位与线段模式）

通过顶部工具栏按钮或快捷键切换编辑模式：`Alt+1` 图形模式、`Alt+2` 点位模式、`Alt+3` 线段模式。

### 插入锚点
1. 通过 `Alt+2` 或顶部工具栏进入点位模式并选中路径对象
2. 双击目标线段即可在该处插入新锚点（曲线段按曲线位置取点），新锚点自动进入选中态，可直接拖拽

### 删除锚点
1. 在点位模式单击选中锚点（按住 `Shift` 可多选）
2. 按 `Delete` 或 `Backspace` 删除，被删锚点两侧的线段自动合并
3. 锚点数量有下限：闭合轮廓最少保留 3 点、开放轮廓最少保留 2 点，不足时无法继续删除
4. 一次删除（含多选）只产生一条撤销记录

### 线段模式
在线段模式下单击选中单条线段，可在直线与曲线之间切换；曲线段可拖拽控制柄调整弧度。

## 钢笔工具

点击顶部工具栏钢笔按钮或按 `Alt+4` 激活：
- **点击**：落下直线角点
- **按下后拖拽**：落下曲线点，拖拽方向与距离决定曲线控制柄，入柄自动镜像对称保持平滑
- **拖拽时按住 `Alt/Option`**：断开对称，该点以角点方式收尾
- **闭合路径**：落点不少于 3 个时，点击起点或按 `Enter` 闭合
- **右键**：撤销上一个落点
- **`Esc`**：退出钢笔工具（已有不少于 2 个落点时按现有落点生成图形）

## 图层管理

### 图层操作
- **上移/下移**：调整图层顺序
- **置顶/置底**：快速移到最上层或最下层
- **显示/隐藏**：点击眼睛图标切换可见性
- **锁定/解锁**：点击锁图标切换锁定状态
- **删除**：点击叉图标删除图层

### 图层搜索
在图层面板顶部输入关键词可快速筛选图层。

### 图层状态图标
- **锁图标**：显示对象的锁定模式
- **符号徽标**：显示实例所属的符号名称

## 分组

### 成组
1. 选中多个对象（按住 `Shift` 点击或框选）
2. 按 `Ctrl/Cmd + G` 或点击属性面板「成组」按钮
3. 组对象可整体移动、缩放、旋转

### 解组
1. 选中组对象
2. 按 `Ctrl/Cmd + Shift + G` 或点击「解组」按钮
3. 对象恢复为独立的图层

## 对齐与分布

在属性面板可快速对齐选中的对象：
- **水平对齐**：左对齐、水平居中、右对齐
- **垂直对齐**：顶对齐、垂直居中、底对齐
- **水平分布**：等间距横向排列
- **垂直分布**：等间距纵向排列

## 布尔运算

### 支持的对象
- 矩形、圆形、三角形、多边形等闭合图形
- 可编辑路径对象
- 直线（通过描边轮廓参与运算）

### 操作步骤
1. 选中至少两个可运算对象
2. 点击顶部工具栏的布尔运算按钮
3. 选择运算类型：
   - **并集**：合并为一个对象
   - **交集**：保留重叠部分
   - **差集**：从底层对象减去上层对象
   - **异或**：保留非重叠部分

### 注意事项
- 文字和图片对象不支持布尔运算
- 成组对象需要先解组
- 差集以最底层对象为基准

## 参考线与标尺

- **显示/隐藏标尺**：顶部菜单「视图 → 标尺」或 `Ctrl/Cmd + R`
- **拖出参考线**：从水平/垂直标尺向画布拖动即可生成对齐参考线
- **调整与删除**：拖动参考线调整位置；右键单击参考线删除该条；右键参考线区域可通过菜单整体隐藏或清除全部
- **对象吸附**：拖动对象时会自动吸附对齐参考线（约 4 屏幕像素的吸附阈值），方便跨对象对齐
- **视图开关**：顶部菜单「视图 → 对齐参考线」可整体显示/隐藏参考线
- 参考线随工程保存，增删改均可撤销

## 组件符号

把常用组合保存为可复用定义，并通过联动实例保持内容同步。

### 创建为符号
1. 选中画布上的一个或多个对象
2. 右键图层（或画布对象）选择「创建为符号」并命名
3. 入库后原对象保持不变，不会自动转换为实例

### 插入与同步
- **插入实例**：在左侧插入面板「符号」标签中点击符号卡片（或「插入」按钮）插入一个联动实例，也可把符号直接拖拽到画布目标位置；实例是一个组，可整体移动、缩放、旋转
- **更新定义**：选中画布对象后点击符号面板中的「更新」，用选中对象重写定义，并把全部实例同步为新的内容与外观（保持各实例的位置、尺寸、角度，一条撤销记录）
- **删除定义**：在符号面板点击「删除」并确认，定义移除，画布上的实例自动解除关联并保留当前外观
- **解除关联**：选中单个实例后右键选择「解除符号关联」，该实例转为普通对象，不再参与同步

### 实例与历史
撤销、重做或重新打开工程后，实例保持保存当时的外观，不会自动按定义重建；内容联动只在显式「更新定义」时发生。

## 颜色替换

1. 在属性面板「画布」区域点击「颜色替换…」按钮，弹窗会自动扫描当前文档全部对象的填充、描边与渐变色标
2. 在文档颜色列表（按使用次数排序，并显示各自次数）中选择来源颜色，再指定替换为目标颜色
3. 颜色按写法简并比较（如 `#FFF` 与 `#ffffff` 视为同一颜色）
4. 确认后一键批量替换，整个过程只产生一条撤销记录

## 导出

### 导出 PNG
1. 点击「文件 → 导出」
2. 选择 PNG 格式
3. 设置导出尺寸和背景选项
4. 点击「导出」保存文件

### 导出 SVG
1. 点击「文件 → 导出」
2. 选择 SVG 格式
3. 点击「导出」保存矢量文件

### 复制为图片
通过顶部菜单「输出」：
- **输出 → 复制 PNG**：把选中对象（未选中时为整张画布）作为 PNG 图片写入系统剪贴板
- **输出 → 复制 SVG**：把选中对象（未选中时为整张画布）作为 SVG 文本写入系统剪贴板

## 撤销与重做

- **撤销**：`Ctrl/Cmd + Z`
- **重做**：`Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y`
- 编辑器会自动保存历史记录，支持多步撤销

## 工程保存

### 保存工程
1. 点击「文件 → 保存工程」
2. 首次保存会创建新工程文件
3. 后续保存会覆盖同一文件

### 打开工程
1. 点击「文件 → 打开工程」
2. 选择之前保存的 `.json` 工程文件
3. 所有图层、样式、效果都会完整恢复

### 多标签与草稿恢复
- 顶部标签栏可新建多个项目标签，每个标签有独立的画布与撤销历史
- 编辑过程会自动保存草稿；重启编辑器后检测到草稿会弹窗询问是否恢复
- 多标签草稿的恢复提示会标明包含的标签数量，确认后一次性恢复全部标签（含非激活标签）与激活状态

## 技巧与窍门

### 精确定位
- 在属性面板直接输入坐标值可精确定位对象
- 输入宽高值可精确调整对象尺寸

### 快速复制
- 按住 `Alt/Option` 拖动对象可快速复制：拖动落定后留下副本并自动选中，原对象留在原地；多选整体 `Alt` 拖动会整组复制，一次拖拽只产生一条撤销记录
- `Ctrl/Cmd + D` 复制副本并偏移粘贴，不覆盖剪贴板内容

### 多选操作
- 按住 `Shift` 点击可添加选择
- 按住 `Shift` 拖动可框选多个对象
- 选中多个对象时可批量修改颜色、描边等样式

### 锁定比例
- 点击宽高输入框之间的锁图标可锁定宽高比
- 锁定后修改宽度或高度会自动调整另一维度

## 常见问题

**Q: 如何取消选择？**  
A: 点击画布空白处即可取消选择。`Esc` 键用于退出钢笔工具或取消进行中的位图裁剪。

**Q: 对象被锁定无法编辑怎么办？**  
A: 在图层面板或属性面板中点击锁定按钮解锁，或选择不同的锁定模式。

**Q: 如何删除不需要的对象？**  
A: 选中对象后按 `Delete` 或 `Backspace` 键，或在图层面板点击删除图标。

**Q: 导出的图片没有透明背景？**  
A: 在导出对话框中取消勾选「包含背景色」选项。

**Q: 如何让对象精确对齐？**  
A: 使用属性面板的对齐按钮、在属性面板直接输入相同的坐标值，或从标尺拖出对齐参考线辅助对齐。

## AI / MCP 集成

本插件通过 `command_dispatcher` 工具向 MCP 客户端（如 ZCode）暴露画布操作，AI 可以在对话中直接驱动编辑器完成「查询 → 绘制 → 调整 → 导出」全流程。所有操作直接作用于当前打开的编辑器窗口，操作契约遵循「只增不改」原则。

### 能力总览

- **查询**：画布概览、对象列表、条件查找（`find_objects` 按名称/类型/填充过滤召回）、选区、画板、历史、色板、快照
- **创建**：基础图形（支持按目标尺寸生成）、文本、SVG 导入（1:1）、Iconify 图标、模板、批量创建并编组；创建类条目可直接携带初始样式字段（fill/stroke/strokeWidth/cornerRadius/opacity/shadow，语义同 `set_object_props`，一步完成创建+赋样式）；创建类操作的 `x/y` 默认为对象包围盒中心点，可用 `anchor: 'top-left'` 改为按包围盒左上角定位
- **编辑**：属性设置（含渐变/阴影/圆角重建）、批量属性（同值/逐对象条目，均一条撤销）、图层管理、语义命名、对齐分布、布尔运算、蒙版裁切、文字转曲、文本编辑（`update_text` 更新文本内容与字号/字体/字重/斜体/字间距/行高/对齐/下划线/删除线等排版属性）、位图滤镜与混合模式（`apply_image_filter` 整体替换位图滤镜列表，可同设混合模式）、位图裁剪（`crop_image` 按显示包围盒坐标裁掉图片外围，支持连续裁剪）、图案填充（`set_pattern_fill` 为对象设置 fabric 图案平铺填充，`source: null` 清除恢复纯色）
- **对齐参考线**：`list_guides` / `set_guides` / `clear_guides` 管理用户从标尺拖出的对齐参考线（与 `set_keyline` 的 Keyline 安全区模板无关），`position` 为画布坐标像素，越界自动夹取
- **组件符号**：`define_symbol` 把画布对象保存为可复用符号定义（原对象保持不变）、`list_symbols` 列出定义、`insert_symbol_instance` 插入联动实例（实例 = 一个 Group，`x/y` 坐标语义同创建类操作）、`update_symbol` 用画布对象重写定义并同步全部实例（保持实例位置/尺寸/角度，一条撤销）、`detach_symbol_instance` 解除单个实例的关联（转普通对象）；定义与实例均随工程保存与撤销历史持久化
- **颜色工具**：`replace_color` 全局颜色替换（写法简并比较，一条撤销）
- **样式系统**：命名色板（`swatch:名字` 引用）、文档级样式预设（含内置预设）
- **历史**：撤销/重做/历史跳转，以及跨撤销栈的命名快照（恢复前自动备份）
- **导出**：SVG/PNG/WebP（文本、dataURL、文件，支持指定输出目录）、多尺寸套件（favicon/pwa/android/ios/electron 预设）、ICO/ICNS 容器、按画板导出
- **AI 自检**：`get_canvas_thumbnail` 低成本缩略图（可选 `outputPath` 直接落盘返回文件路径，省 token），供 AI「画完→看图→修正」闭环

### 典型工作流

```text
1. new_document / apply_icon_template      建立画布
2. add_shape + set_object_props            绘制并调样式（或 create_objects 一步成组）
3. get_canvas_thumbnail                    视觉自检
4. align_objects / boolean_ops             精修
5. export_size_set / export_icon_container 交付全套尺寸
```

### 坐标语义

- **创建类操作（add_shape / insert_svg / create_objects 条目）**：`x/y` 默认为对象**包围盒中心点**（`anchor: 'center'`，与画布对象默认的 center 原点一致）；传 `anchor: 'top-left'` 时 `x/y` 为包围盒**左上角**，适合按边缘摆放或精确铺排。省略 `x/y` 时定位不生效，对象落在画布中心（此时 anchor 无意义）。
- **set_object_props 的 left/top**：与创建默认语义一致，同样是对象包围盒中心点坐标（不做改动）；需要按左上角定位时请先加宽高的一半换算，或改用创建类操作的 `anchor: 'top-left'`。
- **对象摘要（get_object / list_objects / batch_set_props 返回值等）**：`left/top` 为包围盒中心点，另有 `bboxLeft/bboxTop` 字段表示 angle=0 时的包围盒左上角，可直接用它核对创建与定位结果（例如 `anchor: 'top-left'` 创建后，`bboxLeft/bboxTop` 应等于传入的 `x/y`）。
- **crop_image 的 left/top/width/height**：以目标位图**当前显示包围盒**（即 `bboxLeft/bboxTop` 起 `width×height` 的矩形，angle=0 语义）为坐标系，`left/top` 为裁剪矩形**左上角**坐标，矩形必须完整落在显示范围内；实现内部换算为图片源像素的 `cropX/cropY/width/height`，对已裁剪的图可继续传新矩形做连续裁剪。
