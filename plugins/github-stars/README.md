# GitHub 星标管理

在 ZTools 里极速浏览、搜索与管理你的 GitHub Star 仓库。支持**多账号一键切换**、**即写即存的本地备注**与**主搜索框全局直出**。

---

## ✨ 核心功能

- 🔀 **多账号管理**：支持添加多个 GitHub 账号（Token 模式），各账号数据独立本地缓存，下拉框秒级无缝切换。
- 📝 **行内即存备注**：每个仓库卡片下方直接自带备注输入框，随手输入，**回车或失焦自动保存**，清空内容即自动移除备注。
- ⚡ **智能模糊搜索**：支持拼音首字母/字符子序列智能匹配与高亮；按「仓库名 → 备注 → 描述/语言/标签」多重权重排序，可一键勾选「只看有备注」。
- 🏷️ **语言胶囊与多维排序**：
  - 语言胶囊支持多选过滤，直观展示各语言仓库计数；
  - 支持按 ⭐Star 数升降序、按语言分组、**按备注更新时间**、按仓库名称、按最近推送时间排序。
- 🔍 **主搜索框全局直出**：无需进入插件页面，在 ZTools 主搜索框中直接输入关键字，即可搜索星标仓库（备注命中带 📝 前缀），回车直接在浏览器打开。
- 🔒 **隐私与安全**：Token 与备注数据**仅保存在本机 ZTools 数据库（dbStorage）**，仅直连 GitHub 官方 API，零上传、无任何第三方服务。
- 📤 **离线数据导出**：支持一键将当前账号的完整星标数据（包含自定义备注）导出为标准 JSON 文件，方便备份与迁移。
- 🎨 **自适应主题**：原生适配系统及宿主深色模式（Dark Mode），高对比度排版，界面清爽现代。

## 🚀 唤醒与使用

### 1. 唤醒插件
在 ZTools 呼出框中输入以下任意指令回车即可打开：
- `github`
- `ghstar`
- `star`

也可以直接在主搜索框输入想找的仓库关键词，命中星标仓库后回车直接在浏览器中打开。

### 2. 首次配置（添加账号）
1. 首次打开插件会自动弹出「添加账号」窗口；
2. 填写 **GitHub Token**（必填，见下文生成方式）；
3. **GitHub 用户名**（可选）：留空则在保存时通过 Token 自动识别；
4. **账号别名**（可选）：便于在多账号下拉列表中区分（例如“工作账号”、“个人主页”）；
5. 点击「保存」，插件将自动拉取星标仓库数据并建立本地缓存。

## 🔑 GitHub Token 获取指引

本插件通过 GitHub 官方接口（`/user/starred`）同步星标数据，需要生成一个 Personal Access Token：

1. 打开 GitHub [Personal Access Tokens 页面](https://github.com/settings/personal-access-tokens)；
2. 点击 **Generate new token** → 选择 **Generate new token (classic)**；
3. **Note** 随意填写（例如 `ztools-github-stars`）；
4. **权限勾选**：
   - 若只需查看**公开仓库**星标：无需勾选多余敏感权限（默认权限即可，或仅勾选 `read:user`）；
   - 若需要同时拉取**私有仓库**的星标：勾选 `repo` 范围；
5. 点击页面底部 **Generate token**，复制生成的以 `ghp_` 开头的 Token，粘贴到插件中保存即可。

## ⌨️ 常用快捷键

| 按键 | 说明 |
|---|---|
| `/` | 快速聚焦到顶部搜索框（非输入框状态下） |
| `Esc` | 在搜索框时清空搜索；在弹窗时退出关闭；在备注输入框时取消编辑并还原 |
| `Enter` | 在备注输入框内回车：保存当前备注；在搜索结果列表选中链接时：浏览器打开 |
| 点击仓库名 | 在系统默认浏览器中打开该 GitHub 仓库页面 |

## 🛡️ 数据与安全声明

- **本地存储**：所有账号信息（掩码存储）、GitHub Token、仓库缓存以及本地备注，全部存放在本机的 ZTools `dbStorage` 隔离数据库中（键前缀 `ghstar.`）。卸载插件将自动清空所有数据。
- **纯粹网络请求**：插件仅与 GitHub 官方服务器（`api.github.com`）通信，绝不发送任何数据到任何第三方服务器。
- **备注共享**：备注按 `owner/repo` 全局绑定，同一电脑切换不同账号时，相同的仓库能够共享查看并编辑同一份收藏心得。
