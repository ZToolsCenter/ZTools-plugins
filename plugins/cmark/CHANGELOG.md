# Changelog

## 1.2.4 - 2026-11-11

内部结构重构，界面与操作方式不变。这一版把源码重新分层，为后续同时维护多种宿主打底。

- 源码按 `contracts / core / domain / service / adapters / ui` 分层：业务逻辑与宿主平台彻底解耦，平台差异只在 adapters 层出现
- 平台访问统一收敛到 `runtime/legacy-bridge.ts`，新增结构门禁脚本（`npm run check`）：core 或 domain 层一旦直接依赖 Node / Electron 就会被拦下，防止解耦被后续改动侵蚀
- `preload` 拆分为 `panels / ports` 两部分，宿主能力按端口声明，不再散落在各面板脚本里
- 预留桌面端（Tauri）适配层，本轮未启用，不进产物
- README 重写：补上主界面、深色主题、公式弹窗、提交历史、改动对比、设置面板的实际截图

## 1.2.3 - 2026-10-30

搜索模块整体重做，不再靠零散补丁维持；另外修掉一批与「焦点」相关的顽固问题。

- 搜索状态收敛成单一来源：一个搜索词同时驱动目录树过滤、正文高亮和命中计数，高亮词只在一处同步，不再出现「搜到了正文却不亮」
- 修复搜索状态下隐藏面板再唤起、搜索状态丢失：目录树过滤、打开的文档、正文高亮、输入框内容都会原样恢复
- 修复把搜索词逐字删到空时，最后一个字符删不掉（会被判定成宿主重新唤起时的清空而写回输入框）
- 修复在 AI 面板、公式弹窗、重命名输入框里按上下键会切换笔记、按 Esc 会退出搜索
- 修复正文编辑器无法输入：光标被宿主的搜索框反复抢走
- 修复「笔记内查找」对话框从未挂载（按 Ctrl+Shift+F 无反应）
- 新增：没有搜索词时，上下键按目录树顺序切换笔记，切到折叠目录里的笔记会自动展开
- 修复快捷指令打不开对应笔记：动态指令只存在于宿主运行内存，宿主重启即丢失；现在按 near.txt 重建并写入宿主索引
- 修复全文索引只在启动时构建，新写的内容搜不到
- 修复「设为全局搜索」在重新打包后被覆盖
- 命中计数如实显示当前笔记在命中列表中的位置，不再固定显示 1/N
- 移除界面上并不存在的侧栏搜索框与相关死代码

## 1.2.1 - 2026-10-28

- 修复 Gitee 一键建仓 / 同步报 403：HTTPS 的用户名原先写死成 `x-access-token`（只有 GitHub 接受这种占位），Gitee 要求用户名必须等于令牌所有者，否则回 `The token username invalid`。现在按远端推断用户名（`gitee.com/<owner>/` 取 owner，其它保持 `x-access-token`），已用旧版本绑过 Gitee 的用户升级后无需重新授权
- 修复「使用已有仓库」选到空仓库时报「合并远端分支失败」：远端没有任何分支时直接走首次推送，不再先 merge
- 认证类错误（令牌用户名不匹配、401/403）统一归类，提示改为「令牌无效或用户名不匹配」
- 修复「工作区变更记录」面板里混入单个文档状态的问题：状态条被整体覆盖后遗留裸 chip，导致全局的「分支 main / 工作区干净」和文档的「路径 / 与最近提交一致」叠在同一行
- 修复面板已打开时点另一个入口不切换模式，标题、内容与操作按钮停在上一模式

## 1.2.0 - 2026-10-27

同一份产物同时支持 ZTools 与 uTools，宿主自动识别，不再需要分叉维护。

- 新增主题设置：浅色 / 深色 / 跟随系统，主界面、设置面板、Git 面板一起切换
- 新增一键建仓：GitHub 设备码授权、Gitee 私人令牌，自动创建仓库、绑定远程并推送首次提交
- 自动适配宿主：`preload/host.js` 在启动最早期识别 `window.utools` / `window.ztools` 并互为别名，宿主晚注入也不会崩
- 支持 uTools 上架：`plugin.json` 补齐 `homepage` / `platform`，新增 `npm run pack:upx` 产出 uTools 插件包
- AI 生成适配两个宿主：模型字段归一化（ZTools 用 `value`、uTools 用 `id`），模型列表为空时回退默认模型
- 手填远程地址支持私有仓库：先免授权探测，需要授权时引导填访问令牌，令牌只存本机
- 修复 uTools 下 preload 不执行导致设置与 Git 面板打不开（`app/` 就近声明 `type: commonjs`）
- 修复文档里的裸邮箱、裸网址被写成尖括号或 Markdown 链接，源码不再自动插入转义符
- 表格：操作栏只在光标位于表格内时出现，滚动吸附不再闪烁；支持直接编辑表格源码；列对齐可持久化
- 拉取、推送、同步的成败提示改为插件底部浮窗，不再弹 Windows 系统通知
- 版本回溯的确认提示去掉并不存在的“改动前自动备份”说法
- 配色抽成设计令牌，深色下侧边栏、编辑区、面板统一，不再出现半深半浅
- README 补充 npm 与 uTools 安装方式（`@lancc/cmark`）
- 发布改为 GitHub Actions + npm Trusted Publishing，产物带 provenance 签名

## 1.1.0 - 2026-10-26

首个公开发布版本。

- 本地 Markdown 笔记，直接读写 `.md` 文件，无私有格式、无云端账号
- 所见即所得编辑，Markdown 源码始终保持标准语法
- 代码块语法高亮，27 种语言，可切换语言、一键复制
- 表格可视化增删行列与对齐
- mermaid 流程图 / 时序图、echarts 统计图，编辑区直接渲染
- KaTeX 行内与块级公式
- Git 内置：改动 diff、历史版本回溯、单文件撤销
- 自动同步：定时提交并推送到自己的仓库，失败自动暂停
- 导出 Markdown / HTML / PDF / 长图，按编辑区快照生成，所见即所得
- 图片粘贴自动入库并按内容去重，可拖动缩放
- 全文搜索命中高亮、源码模式带行号、只读模式
