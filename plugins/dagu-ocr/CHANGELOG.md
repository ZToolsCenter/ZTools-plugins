# Changelog

## 1.2.0 - 2026-09-15

### 新增

- 「截图」改为沉浸式截图：隐藏主窗口后冻结光标所在显示器，直接在全屏画面上框选与标注，不再放入深色背景容器。
- 框选交互：蓝色边框、八个手柄、`宽 × 高 px` 尺寸标签，选区外加深遮罩；可拖动移动、手柄调整大小。
- 标注工具：形状（矩形/椭圆、描边/填充）、线条（直线/箭头/双向）、画笔、荧光笔、马赛克、文字、橡皮擦，各自带颜色/粗细/字号等子工具条。
- 「固定到屏幕」：把选区结果钉成置顶图片窗口，支持拖动移动、滚轮缩放、双击或 Esc 关闭。
- 图片标题行新增「复制」按钮，识别与翻译结果页都能一键复制当前图片；原文与译文标题行右上角各有一个复制入口，译文复制只复制译文。
- 预览框支持滚轮以光标为锚点放大、按住拖动平移，缩小回原始倍数即复位。
- 截图失败时写入系统临时目录的 `dagu-capture-status.json`，便于排查宿主采集问题。
- 触发截图时立即向宿主申请画面，与覆盖层窗口创建并行；覆盖层取用这一帧后直接进入框选，省掉「先出窗口、再采集」的等待。

### 变更

- 图片标题行右侧整合「预览」与「编辑」入口，删除图片下方整行「编辑图片」按钮。
- 识别与翻译结果页删除底部状态栏：状态提示与「历史」「配置」并入结果操作行右端，减少一行占用。
- 结果页操作栏改到图片容器与 OCR 结果容器下方并横跨整行（与翻译结果页一致），图片容器与 OCR 输入框上下对齐、高度一致。
- 翻译进行中的提示只保留右下浮动进度：状态栏不再显示「正在翻译...」；图片预览不再被原始尺寸撑高把操作栏挤出窗口。
- 主题色收敛到主操作：状态提示语与「历史」「复制」「编辑」等次级入口改用次级字体色，不再占用主题色。
- 工具条贴靠选区浮动：默认在选区下方，空间不足时自动换到上方。
- 快捷键：Enter/Ctrl+C 复制、Ctrl+S 保存、Ctrl+Z/Ctrl+Y 撤销重做、Delete 删除选中标注、Esc 分步回退、滚轮缩放、空格或中键拖动画面。
- 工具条与子工具条图标改用 Lucide（ISC）开源图标。
- 「OCR」「翻译」仍保留在截图工具条上，回传主窗口后走既有识别与翻译链路。
- 宿主不支持桌面捕获源时，回退到 ZTools 系统截图加同一套标注界面。
- 「编辑图片」改用同一个标注界面（图片模式），删除 tui-image-editor 旧编辑器：插件内只保留一处标注实现，旧资源一并移除。
- 识别、翻译、配置等主页面统一窗口高度，底部工具条贴底、长内容在页面内滚动，不再出现「窗口太小」。
- 主页面按钮统一使用 Lucide 图标，并与截图工具条共用圆角、阴影与主色 token，风格一致。
- 识别与翻译结果页保留复制按钮（文案由「复制结果」改为「复制」，删除重复的「复制文本」），复制后仍停留在当前页面继续翻译或重新识别。
- 主页面统一为 800×600（4:3），图片与文字框等宽（1:1），并修复语言选择栏在纵排容器里被拉高、挤压文本对比区的问题。
- 主题跟随修复：自定义主色现在会一并派生 hover/柔光/焦点环，且主题类改挂根元素，避免默认色是自定义色、hover 仍是旧主题色。
- 结果页预览收起时改为紧凑排布（并停止渲染空预览框），减少顶部空白、把高度让给原文/译文。
- 主色解析对齐 ZTools 规则：仅在主题为「自定义」时使用自定义色，命名主题（蓝/紫/绿/橙/红/粉）忽略残留的旧自定义色；并优先采用宿主注入的 `--plugin-primary-color`。
- 插件图标改为非纯色渐变，避免 ZTools 暗色主题下把「单色图标」自动反色（蓝色被反转成黄色）。

## 1.1.0 - 2026-08-27

### 新增

- 截图标注编辑器支持将标注结果下载导出为 PNG 图片。
- 截图标注编辑器支持鼠标滚轮缩放，放大后按住空白处拖动图片。

### 变更

- 界面与指令中的「大古截图配置」改为「配置」。
- 每个指令增加同名英文指令：`Screenshot` / `Image OCR` / `Translate Text` / `Edit Image` / `Settings`。
- 新增面向使用者的 README 与三张界面截图。

## 1.0.0 - 2026-08-19

### 新增

- 支持百度 OCR 和阿里云 OCR。
- 支持截图编辑、图片上传、剪贴板图片识别和文字翻译路由。
- 支持截图后的矩形、箭头、文字和马赛克标注。
- 支持识别结果编辑、复制和历史记录。
- 支持 ZTools Provider 发现、单 Provider 选择和内置 Provider。
- 支持 ZTools dbStorage 偏好存储、可选密钥同步和旧配置迁移。
- MyMemory 改为必须配置用户 key，不再使用默认 key。
