# 更新日志

## 0.0.8 - 2026-10-21

### 界面

- 重构整体视觉：统一设计令牌（明暗双主题配色、圆角、阴影、焦点环），组件交互态与悬浮反馈
- 主页改为工具栏分组 + 变量卡片网格，Path 表格限制高度并支持内部滚动，表头吸附
- 设置页改为卡片网格布局，修复窄窗口下卡片溢出与重叠
- 变量组页工具栏卡片化，空状态居中，图标改为矢量图形
- 重写滚动条样式（透明轨道 + 悬浮胶囊滑块）
- 深色主题背景调整为 `#303133`，与宿主窗口一致

### 新增

- 支持自定义主题色（取色器 + 十六进制输入），悬停色、柔和底色、深色模式提亮自动派生
- 支持自定义字体族，等宽字体（变量名、路径、Diff）保持不变
- 主页四个面板记住上次展开/折叠状态
- 搜索时临时展开面板，不覆盖用户的手动折叠偏好

### 修复

- 修复 `UiTable` 忽略 `scroll` 属性导致表格无法限高的问题
- 清理硬编码颜色与失效的样式选择器，修复深色模式对比度问题
- 修复配置差异页被双列网格挤到左列、右侧留白的问题，长文件名改为省略号
- 主题色与字体族纳入导入/导出配置，跨设备恢复样式
