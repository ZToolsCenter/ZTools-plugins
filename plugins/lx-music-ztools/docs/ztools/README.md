判定口径：**已实现**表示代码接通；**受控 PASS**表示本地合成数据/响应通过；**实际宿主 PASS**表示在指定版本的真实 ZTools app.asar 中运行；**外部 LIVE PASS**只表示当时的指定真实样本通过。四者不能互相替代。`FAIL` 保留已观察失败，`待验`/`BLOCKED` 不计通过。

核心播放/下载检查点已在独立 Electron 41.4.0 通过 30 分钟后台与 50 次进入/隐藏、分离测试：实测 1,807,934 ms，累计播放 1,791.56 秒，业务监听器 34 个、播放实例新增 0、采样进程 9→9，下载前后解码 PCM SHA256 一致。随后主题与歌词窗口修正由最终 ZIP 专项回归覆盖，不把该 ZIP 字节称为已经长测 30 分钟。曾在独立 Electron 42.3.3 上约 695 秒发生插件 WebContents 消失，该次仍为 FAIL。日常 ZTools.exe 全流程、人工听音、物理快捷键和其他操作系统未完成验收。
