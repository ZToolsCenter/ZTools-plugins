# 更新日志

## 0.0.2 - 2026-11-10

- 默认入口切换为原 LX Music 界面，补齐 Webpack 与可读 CommonJS 服务构建。
- 支持 LX API 2.0.0 自定义音源的本地 JS、URL 导入与选择；脚本在隔离 Worker 中运行。
- 接通原播放器、列表和设置，验证受控音源解析播放、暂停/继续、后台播放与下一首。
- 去掉 LX 内部的缩小、关闭按钮及桌面窗口留白、圆角、阴影，内容铺满 ZTools 插件区域。
- 构建时安装插件运行依赖，确保插件中心从源码构建的 ZIP 包含所需模块。
- 当前为 Windows 开发版，不预置音源；下载、同步、开放 API 和系统集成仍在移植，真实用户音源/平台服务未全量验证。

## 0.0.1 - 2026-11-09

- 使用官方 Vue 模板建立插件框架。
- 接入生命周期、preload 诊断与存储探测。
- 增加构建、打包校验与发布演练。
