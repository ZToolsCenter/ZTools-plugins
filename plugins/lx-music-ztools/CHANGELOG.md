## 0.1.0 - 2026-11-10

- 将原 LX 搜索、榜单/歌单、列表、原播放器/DSP、备份、下载、同步、开放 API 和桌面歌词接入 ZTools 原生插件服务；不是 LX 官方发行版。
- 下载保留原 UI，增加流式 Range/validator 校验、有界重试、阶段恢复、同名归属保护及 MP3/FLAC 标签/封面/歌词最终化；所有新下载需要目标文件系统支持 hard link，metadata rename→fingerprint 崩溃窄窗保守保留文件并报错。
- 保留原 LX 同步协议；官方 Desktop 2.12.6 原对端双向 Node 场景通过，实际 ZTools 双角色各19项共38项通过；外网、其他版本、全部策略与长期运行未据此宣称通过。
- 接通原桌面歌词窗口、HTTP/SSE 开放 API 与五项宿主指令/快捷键设置；独立窗口/托盘/更新由宿主管理，任务栏缩略图按钮/电源锁等限制逐项说明。
- 使用设备本地 pluginData SQLite，支持原备份/显式 LX 同步迁移，与 ZTools 账号云数据独立；不附带用户音源。
- 真实去重音源样本23个导入、20个初始化，保留3个失败；指定monster.js样本已实际播放并下载成功，真实五平台搜索返回结果，不扩大为全部源/平台可播。
- 增加独立运行包、文件校验回执、确定性 ZIP 与完整生产依赖许可。Windows x64 / ZTools 3.3.0-beta.2 app.asar + 匹配的独立 Electron 41.4.0 为首验组合。
- 本地0.1.0 ZIP通过14个串行宿主专项、100列表/10,000首强杀恢复及官方LX双向38项互通；用户提供的指定音源在最终包上真实播放和下载完成。核心服务检查点30分钟/50次往返通过，最终包另做50次短回归；保留Electron42.3.3约695秒WebContents消失的历史FAIL。未发布或推送当前版本，物理快捷键、人工听音与日常ZTools.exe全流程未验。

## 0.0.2 - 2026-11-10

以下为0.0.2当时的历史范围，后续补验见0.1.0和当前验证矩阵。

- 默认入口切换为原 LX Music 界面，补齐 Webpack 与可读 CommonJS 服务构建。
- 支持 LX API 2.0.0 自定义音源的本地 JS、URL 导入与选择；脚本在隔离 Worker 中运行。
- 接通原播放器、列表和设置，验证受控音源解析播放、暂停/继续、后台播放与下一首。
- 去掉 LX 内部的缩小、关闭按钮及桌面窗口留白、圆角、阴影，内容铺满 ZTools 插件区域。
- 构建时安装插件运行依赖，确保插件中心从源码构建的 ZIP 包含所需模块。
- 当前为 Windows 开发版，不预置音源；下载、同步、开放 API 和系统集成仍在移植，真实用户音源/平台服务未全量验证。
