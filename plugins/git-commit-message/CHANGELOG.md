# Changelog

## 0.2.0 - 2026-09-19

- 新增输出格式切换，可选择 Gitmoji 在 commit type 前或在摘要前。
- 保存输出格式设置到本地。
- 优化 ZTools 小窗口布局，进入插件时自动聚焦摘要输入框并重置滚动位置。

## 0.1.0 - 2026-09-10

- 首次发布 Git Commit Message 生成器。
- 支持 Gitmoji 常用推荐和关键词搜索。
- 支持生成 Gitmoji + Conventional Commit 格式提交信息。
- 支持 scope、详细说明和关联 issue。
- 支持一键生成并复制到系统剪贴板。
- 支持最近 20 条本地历史记录，可查看、再次复制和清空。
- 优化 ZTools 小窗口布局、滚动区域和复制状态提示。
