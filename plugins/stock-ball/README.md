<h1 align="center">股票管家 · stock-ball</h1>

<p align="center">
  <b>桌面股票监控插件</b><br />
  持仓管理 · 自选行情 · 桌面盈利悬浮球 · K线 · 股价预警
</p>

---

一个跑在 ZTools 里的本地股票助手：录入持仓和交易流水，实时算盈亏；桌面上常驻一颗悬浮球，随时瞟一眼今天赚没赚；自选股、已清仓、K线、预警都在一个面板里。

**所有个人数据只存本机，不上传、无遥测。** 行情数据来自公开接口。

## 功能特性

### 💼 我的持仓
- 录入买入 / 卖出交易，自动核算**持仓成本、总盈亏、今日盈亏**（券商口径：`当日盈亏 = (持股市值 + 当日卖出额) − (昨日市值 + 当日买入额)`）
- 表格行内直接操作：**买/卖 · 流水 · 预警 🔔 · K线 📈**，表头可点选排序
- **自定义显示列**：持仓/金额、当前价/成本、今日涨幅/盈亏、累计涨幅/盈亏 按需勾选
- 交易录入有**风控校验**：
  - 卖出不超过**可卖数量**（含 T+1：今天买入的下一个交易日才能卖，弹窗实时显示「可卖 N 股」）
  - 买卖数量必须是 **100 股整数倍**（失焦自动取整，提交双重把关，数据层兜底）
  - 例外：卖出时恰好把**零股一次性清仓**（A股规则允许）
- 佣金 / 过户费 / 印花税可在设置里调整，录入时自动试算实付金额

### 🗂 已清仓
- 独立标签页，与持仓页同款表格展示：清仓日期、清仓盈亏 / 收益率
- 概览卡：已清仓 N 只 · 累计清仓盈亏 · 最近清仓日期
- 每行可直接打开该股票的 K线

### 📈 自选行情
- 自选列表 + 分组管理（默认 / 核心持仓 / 观察池，可增删改）
- 行情表格支持按现价、涨幅排序；**双击行直接跳转东货行情页**
- 行内操作：买入 🔔预警 📈K线 🗂分组 ✕删除
- 行情表头同步显示大盘四大指数

### 🕯 K线
- **当日分时**（价格线 + 均价线 + 昨收基准）与**历史K线**（日K，前复权，可滚轮/拖动缩放）双页签
- 持仓行、自选行、已清仓行统一入口 📈
- 图表组件（ECharts）按需懒加载，不拖慢插件启动

### 🔔 股价预警
- 四类条件：突破高价 / 跌破低价 / 涨幅超标 / 跌幅超标
- 桌面通知，带**冷却间隔**（同一条件 N 分钟内只提醒一次）
- **股价提醒时段：北京时间 9:25–11:30、13:00–15:00**（盘前、午休、收盘后、周末一律静默；行情获取仍可从 9:10 开始）
- 2026 年节假日按[交易所休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)静默；后续年份需在 `lib/market.js` 补充年度休市日历，未收录年份仅排除周末。
- 多窗口去重：主窗口 / 悬浮球 / 小窗共享冷却表，绝不重复弹

### 🟢 桌面悬浮球
- 常驻桌面显示**今日总盈亏**（红涨绿跌），点顶部「🟢 桌面悬浮球」开关
- 拖动换位置（贴边自动吸附）、**双击唤起主面板**、大小 56–110px / 背景不透明度 0%–100% 可调
- 背景不透明度 ≤30% 时文字红涨绿跌，0% 时仅保留文字；文字不随背景淡化
- 悬停显示当日涨幅 >3% 或跌幅 >3% 的股票名称、代码、现价和涨跌幅，按波动幅度排序；有持仓时看持仓，无持仓时看自选
- 悬浮球直接调用宿主窗口接口完成拖动和位置保存；插件声明后台运行，主界面隐藏后仍可拖动，休眠唤醒保留心跳恢复时间
- 纯圆形透明窗口，不抢焦点、不进任务栏

### 📋 交易明细流水 
- 每只股票的流水弹窗：时间线柱状图（最多15天、可拖动）、**成本均价折线**、悬停看当日明细
- 每日持仓、成本价与**做T盈亏核算**（反T口径与券商一致）

## 使用指南 

| 页面 | 说明 |
|---|---|
| **💼 我的持仓** | 顶部三张概览卡（总市值/总盈亏/今日盈亏）；下方持仓表格；底部「+ 记录买入 / 加仓」「- 记录卖出 / 减仓」；行内 📈 开K线、流水 开交易明细 |
| **🗂 已清仓** | 买入后全部卖出的股票自动进入这里，按清仓日期倒序 |
| **📈 自选行情** | 搜索添加自选股、分组管理、排序；双击行跳转东货行情页 |
| **⚙️ 设置** | 刷新间隔、**开机自动启动**（随 ZTools 启动并自动打开悬浮球）、悬浮球大小/透明度、交易费率、持仓显示列、默认视图等 |
| **悬浮球** | 拖动定位，双击回主面板；球上永远是今天的盈亏 |

## 交易规则口径（重要）

| 规则 | 实现 |
|---|---|
| T+1 | **可卖 = 当前持仓 − 今天买入**，录入弹窗实时显示可卖数 |
| 100 股整数倍 | 买入强制；卖出同样要求，失焦自动取整、提交校验、`store.addTransaction` 数据层最终兜底 |
| 零股 | 唯一例外：卖出数量恰好等于全部零股持仓时放行（清掉历史零股） |
| 费率 | 佣金（默认万2.5，最低5元可开关）、过户费（沪，万分之0.1）、印花税（万分之5，卖出单边），均可在设置调整 |

## 数据与隐私

- 所有持仓、交易、自选、预警数据保存在本机 **`~/.ztools-stock-ball.json`**（即 `C:\Users\<你>\.ztools-stock-ball.json`），纯 JSON，可直接备份 / 手动编辑
- 行情走公开接口，插件本身**不上传任何个人数据**

## 行情数据源

- **主通道**：东方财富 push2 系列（行情/分时/详情），push2his（K线，前复权）
- **兜底**：接口失败自动切换腾讯行情 / 腾讯日K
- 非交易时段东财接口常有超时，插件已按上文「行情闸门」策略规避空转
