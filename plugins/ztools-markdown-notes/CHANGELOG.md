# 更新日志

## 0.1.2

- 新增文本高亮，以及高亮颜色和透明度设置。
- 新增代码块语言选择、过滤和一键复制。
- 新增图片右键调整大小、恢复自动大小和删除功能。
- 优化编辑器正文间距，以及代码块和图片的聚焦体验。
- 修复高亮文本边界连续退格可能破坏 Markdown 标记的问题。

## 0.1.1

- 新增 Markdown 导入、Markdown 导出和 HTML 导出。
- 优化编辑器工具栏、更多操作菜单和内容区域布局。
- 修正生产包清单，移除开发服务器入口。

## 0.1.0

- 支持真实 Markdown 文件与多工作区管理。
- 支持 Vditor 即时渲染和源码编辑，编辑内容自动保存。
- 支持目录管理、搜索、置顶、大纲、图片、附件和内部链接。
- 支持本地回收站、异常草稿恢复与外部修改冲突保护。
- 支持浅色和深色主题，以及可选的 zTools 全局笔记入口。
