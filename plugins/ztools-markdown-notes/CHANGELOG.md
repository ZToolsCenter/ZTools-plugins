# 更新日志

## 0.1.4 - 2026-10-28

- 新增目录树自定义排序，支持在同一目录内拖拽混排文件夹和笔记。
- 优化拖拽反馈，通过条目边缘插入线调整顺序，拖入文件夹中部执行移动。
- 排序按工作区和目录独立保存，并在重命名、移动、刷新后保持一致。
- 排序记录读取或保存失败时显示明确提示，且不影响已经完成的文件操作。

## 0.1.3 - 2026-10-12

- 新增黑色、白色等内置主题，并支持跟随系统切换蓝色主题的明暗配色。
- 新增自定义主题，可配置导航、编辑器、弹窗、强调色、边框及高亮颜色。
- 支持复制、编辑、预览和删除自定义主题，并保留字号、行高与高亮透明度设置。
- 自动迁移旧版背景和高亮颜色设置，避免升级后丢失原有配色。

## 0.1.2 - 2026-09-26

- 新增文本高亮，以及高亮颜色和透明度设置。
- 新增代码块语言选择、过滤和一键复制。
- 新增图片右键调整大小、恢复自动大小和删除功能。
- 优化编辑器正文间距，以及代码块和图片的聚焦体验。
- 修复高亮文本边界连续退格可能破坏 Markdown 标记的问题。

## 0.1.1

- 新增 Markdown 导入、Markdown 导出和 HTML 导出。
- 优化编辑器工具栏、更多操作菜单和内容区域布局。
- 修正生产包清单，移除开发服务器入口。

## 0.1.0

- 支持真实 Markdown 文件与多工作区管理。
- 支持 Vditor 即时渲染和源码编辑，编辑内容自动保存。
- 支持目录管理、搜索、置顶、大纲、图片、附件和内部链接。
- 支持本地回收站、异常草稿恢复与外部修改冲突保护。
- 支持浅色和深色主题，以及可选的 zTools 全局笔记入口。
