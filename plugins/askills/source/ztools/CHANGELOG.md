# Askills ZTools 插件更新记录

## 1.0.2 - 2026-10-19

- 与桌面版统一使用本机字体，默认微软雅黑。
- 个性化设置支持字体列表、搜索、预览、刷新与保存；字体缺失时自动回退。
- 保留旧版主题设置，移除完整 MiSans 字体文件以减小包体积。
- 通过原插件中心 PR #672 提交更新，解决构建包过大的反馈。

## 1.0.1 - 2026-10-19

- 首次提交 ZTools 插件中心，支持 Windows x64。
- 提供本地 skills 库、项目管理、GitHub API／本地 Git 来源和设置页面。
- 支持显示名称、批量操作、固定版本部署、升级回滚和库迁移。
- 内置 MiSans、中英文界面与浅深色主题，使用透明底色和半透明卡片。
- skill 和项目详情紧跟选中卡片展开，支持切换和收起。
- 与桌面版共用本地数据，通过文件锁和插件退出取消机制保护操作。
