# Askills v1.0.0-fix

本次修正 Windows 应用数据目录，继续提供单文件免安装版。

- 设置、项目记录和偏好改为保存在 **`%LOCALAPPDATA%\asklils`**。
- 全新使用时，默认 skills 库位于 **`%LOCALAPPDATA%\asklils\library`**。
- 首次从 1.0.0 升级时，安全继承旧版 SQLite 中的项目、名称、仓库历史及界面偏好。旧数据保留，不覆盖新目录已有记录。
- 已有库与自定义库保持原位置，现有项目链接不变；如需统一到新默认目录，可在设置中迁移到 `%LOCALAPPDATA%\asklils\library`，更新项目链接并保留旧库备份。
- 界面版本更新为 **V1.0.0-fix**，自动构建支持带 `-fix` 的版本号。

## 下载

**`Askills_1.0.0-fix_windows_x64.exe`**：Windows x64 单文件 EXE，下载后双击即可，无需安装或解压。界面、MiSans、图标均内嵌，仍使用系统 WebView2。当前未进行代码签名。

`SHA256SUMS.txt`、`build-info.json` 和 `LICENSE.txt` 是校验、构建信息和许可附件，无需一起放在程序目录。

## 升级

先退出所有旧版或开发版，再启动新 EXE。旧版仍占用数据时会提示 `LibraryBusy`，退出旧版后重新启动即可。不要通过手动移动旧 skills 库来修改路径，以免使项目链接失效；在应用设置中预览并执行库迁移。

原 1.0.0 版本与下载保留。日常 Actions 构建仍只保存产物，不自动发布 Release。
