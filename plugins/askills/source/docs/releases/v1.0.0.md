# Askills v1.0.0

Askills 的首个正式版：使用 Rust + Tauri 2 构建，在本地管理 skills，并为不同 Agent 项目启用所需版本。

## 主要功能

- **本地 skills 库**：导入完整目录、自定义显示名称、搜索、阅读 Markdown 和原文，保留来源、许可证及版本快照。
- **项目管理**：识别 Codex、Cursor、Claude Code 的 skills 路径，从库、本地或云端添加 skills；支持链接、Windows junction、复制、升级、回滚与冲突检查。
- **GitHub 来源**：GitHub API / 本机 Git 两种方式，固定 commit 下载；预览、多选、批量下载、进度通知及最近 10 条仓库历史。
- **库位置迁移**：预览并迁移已有 skills 库，校验内容并更新受管理的项目链接，保留原目录作为备份。
- **中英文界面**：内置 MiSans，支持浅色、深色、跟随系统及自定义主题色；正文保持原文。
- **条目管理**：自定义右键菜单、重命名、批量移除、添加到项目。

## 下载与启动

本次提供 **Windows x64 单文件免安装版**，界面、字体、图标均内嵌：

- **`Askills_1.0.0_windows_x64.exe`**：下载后双击即可，无需安装或解压。
- `SHA256SUMS.txt`：EXE 的 SHA-256 校验值，可按需下载。
- `build-info.json`：对应源码提交和构建信息。
- `LICENSE.txt`：MIT 许可。

需要 Microsoft Edge WebView2；若系统缺少运行时，可从[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)获取。此版本未使用代码签名证书，Windows 可能显示未知发布者提示。

设置、项目记录和默认 skills 库仍保存在 `%LOCALAPPDATA%\io.github.candquarzy.askills`，也可在设置中迁移 skills 库。此版本为免安装分发，个人数据不会随 EXE 自动移动。

首次启动后可在设置中选择 skills 库位置，再导入 skill、登记项目并添加到项目。详见[用户指南](https://github.com/Candquarzy/Askills/blob/v1.0.0/docs/user-guide.md)。

若开发版或其他 Askills 实例正在使用同一 skills 库，请先退出它，再启动正式版；应用会用 `LibraryBusy` 提示阻止多个实例同时写入。

## 持续构建

每次向 GitHub 推送提交，以及 PR、手动运行 CI 时，自动检查代码并构建 Windows 单文件 EXE。构建产物保存在对应 Actions 运行的 Artifacts 中，保留 14 天，附带 commit 和校验值；日常构建不会创建或更新 Release。

macOS / Linux 安装包不在本次发布范围；应用内自动更新和 skill 正文翻译未提供。Askills 使用 MIT 许可，第三方 skills 与内置字体保留各自许可。
