# 轻影截图 snap-capture

> 作者：一个成熟的剪辑猿

把微信截图那一套搬进 ZTools：**框一次 → 就地标注 → 复制 / 另存 / 悬浮 / 抠字 / 翻译**，全程不换工具。

## 核心特点

- **框选完就地出小窗**：截完直接弹出和选区一样大的编辑窗，图片 1:1 像素显示，不放大不糊。
- **高清重抓**：在 125% / 150% 缩放的副屏上截图，按物理像素重新抓取底图，不会拿到被放大的糊图。
- **悬浮置顶**：截图后可以直接「悬浮」，钉在桌面上随时对照。悬浮图可拖动、缩放、裁剪、调节透明度。
- **单窗口替换**：贴图右键开编辑 / 识别 / 翻译时，先关掉这扇置顶贴图窗，再打开目标窗，屏幕上始终只留一扇。
- **延时截图与导出**：可延时 1~30 秒再框选；另存支持 PNG / JPEG / WebP，放大镜里按 `C` 复制 HEX 色值。
- **微信 OCR 抠字**：可调用本机微信 OCR 引擎，把图片里的文字抠出来；也能走 ZTools 官方 OCR provider。
- **图片翻译**：识别后直接把译文贴在原图对应位置上，可切换看原文 / 译文。
- **贴图板与历史**：每次截图自动留档；历史图可二次编辑 / 识别，贴图可一键「恢复上次」，搜索框同时覆盖贴图与历史。

## 常用命令

在 ZTools 搜索框输入以下关键词即可触发：

| 关键词 | 作用 |
| --- | --- |
| `截图` / `截图标注` / `截屏` | 框选并进入标注 |
| `截图并复制` | 框选后直接复制到剪贴板 |
| `截图并保存` | 框选后直接另存为文件 |
| `截图并悬浮` | 框选后直接悬浮到桌面 |
| `延时截图` | 延时数秒再框选，秒数在设置页调 |
| `贴图板` / `截图历史` | 打开贴图板与历史管理 |
| `轻影截图设置` | 打开设置页 |

也可以直接把图片拖进 ZTools，用 `悬浮图片` / `编辑图片` / `OCR 识别` 命令处理。

## 标注工具

矩形、椭圆、箭头、直线、画笔、荧光笔、马赛克、序号、橡皮擦、文字——共 10 种工具，工具条紧贴图片显示，贴近屏幕边缘时自动翻转到另一侧。取色不是工具：全屏框选时放大镜会实时显示光标下的 `#RRGGBB` 和坐标，按 `C` 复制色值。

## OCR 与翻译说明

插件优先使用 **ZTools 官方 provider**（在设置页可选择 OCR / 翻译渠道）。若未配置可用 provider，可回落到**本机微信 OCR 引擎**：

- Windows：需要本机已安装微信，其 OCR 引擎目录可由插件自动探测，也可在设置页手动指定。
- macOS：需要本机已安装微信并完成过一次 OCR 初始化。

> 本插件不携带任何微信二进制文件，所有引擎均来自用户本机已安装的微信。

## 安装

在 ZTools 的插件中心搜索「轻影截图」即可安装。

## 使用建议

- 触发截图后，先用 `Esc` 取消框选；编辑器里 `Enter` 复制、`Ctrl+S` 另存、`Ctrl+Z` 撤销。
- 翻译中英混排或日文短句判错时，在设置页或结果窗把「原文语言」从「自动检测」改成对应语言。
- 悬浮图可以钉在屏幕边缘当作参考图；再次截图不会打断已有悬浮图。
- 若截图后没弹出编辑窗，请检查 ZTools 搜索框结果面板里该插件的「退出后立即结束」开关是否被打开。
