# Changelog

## 1.8.0 - 2026-11-01

- 初次发布，将插件提交至 ZTools 插件仓库。
- 框选后原地弹出与选区等大的编辑窗，图片 1:1 像素显示。
- 高清重抓：按物理像素重新抓取选区底图，兼容 125% / 150% 缩放屏幕。
- 悬浮图支持拖动、缩放、裁剪、透明度调整；点「编辑标注」在原窗口内直接编辑。
- 接入 ZTools 官方 OCR / 翻译 provider，未配置时回落到本机微信 OCR 引擎。
- 图片翻译将译文直接覆盖在原图对应位置，支持原文 / 译文切换。
- 贴图板与截图历史统一管理，支持重新悬浮、编辑、OCR。
- 截图后自动清理过期临时文件。
