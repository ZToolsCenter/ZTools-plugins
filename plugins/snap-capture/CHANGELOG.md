# Changelog

## 1.11.1 - 2026-11-04

- **修复「截完图一按右键整个插件就没了」**：选区编辑器（`overlay.html?mode=window`）的右键原本直接 `cancel()` → `window.close()`。主视图在开窗时已 `outPlugin` 收起，这扇窗是插件唯一可见的窗口，关掉它屏幕上什么都不剩，看起来就是闪退；`cancel()` 先置 `state.finished=true` 还会让 `beforeunload` 提前返回、不发 `closed`，父窗口全程不知情。
- 现在右键只 `abandonInteraction()` + `closePalette()`，放弃当前正在画的笔画 / 关掉色板，编辑窗保留；要结束整次截图仍按 `Esc` 或工具条「取消 (Esc)」。
- 不会引入双窗口：编辑器由 `preload.js` 的 `retireEditor()` 保证单例，新窗上任前会关旧窗；贴图 → 编辑 / 识别 / 翻译仍是 1.10.3 起的「关一扇、开一扇」。
- 这是 1.10.3 第一版曾修好、随后因误判「双窗口」被整份撤销的修复，此处恢复并保留 1.10.3 / 1.11.0 的全部窗口语义。

## 1.11.0 - 2026-11-04

- **窗口管理收口**：新增 `transition()` 单窗口调度，把所有「开新窗」请求按来源统一处理 —— 选区编辑器可原地变结果窗，贴图窗一律先关再开，贴图板作为普通面板保留。1.10.x 连续四版修「双窗口」的根因（每个分支各自决定关不关旧窗）至此消除。
- 补上 `openResult` 的来源守卫：贴图窗即使走 `bridge.openResult` 也不会再被原地接管吃掉，而是 `closePin → 独立结果窗`。
- 编辑器「悬浮」改为父窗口先关编辑窗再开贴图窗，不再短暂两扇。
- **设置项清理**：接上 `sourceLang`（设置页 + 结果窗都能指定原文语言，不再写死 `auto`）、给 `copyAfterSave` 补开关、删掉从未被读取的 `pinAutoClose`。
- **导出格式**：另存支持 PNG / JPEG / WebP，JPEG 自动铺白底；默认仍是 PNG。
- **延时截图**：新增命令「延时截图」，秒数可在设置页调（1~30 秒），触发后先收起主窗、倒计时结束再框选。
- **取色**：放大镜实时显示 HEX，按 `C` 直接复制色值。
- **贴图板**：历史卡片补「编辑标注」「识别文字」；搜索框覆盖贴图页与历史页；新增「恢复上次贴图」（贴图会话存到历史目录，不受临时文件清理影响）。
- **传图兜底**：大图不再整张塞进 localStorage（5MB 配额 + 同步阻塞），改由父窗口写临时文件，localStorage 只留路径标记；桥不可用时自动回退旧路径。
- 文档清理：修掉重复的 `1.9.1` 条目、README 里过期的「原地编辑」与错误工具清单、乱码文件名与失效的安装路径。

## 1.10.3 - 2026-11-04

- 修复「贴图悬浮窗上右键编辑/识别/翻译会变成双窗口」：1.10.2 让识别/翻译另开结果窗而贴图原地不动，实测两扇窗会同时挂在屏幕上。现把三条路统一成「先关掉这扇置顶贴图窗，再打开目标窗」——编辑标注开 1:1 编辑窗，识别/翻译开结果窗，**屏幕上始终只有一扇窗**。
- 贴图窗改由 `closePin()` 统一收尾：不再先 `hide()` 再 `close()`（隐藏态的窗口代理容易关不干净），并归还被「摇一摇」藏起来的其他贴图、同步贴图板。
- 保留选区编辑器里右键 `cancel()` 关窗的原有语义，避免置顶窗常驻累积。

## 1.10.2 - 2026-11-04

- 修复「贴图右键点识别/翻译后贴图直接消失」：1.10.0 把贴图窗原地变身成结果窗，贴图作为长期便签被误吃。现改为识别/翻译另开独立结果窗，贴图原地不动；原地接管只保留给编辑器（编辑器是一次性窗口）。

## 1.10.1 - 2026-11-04

- 修复「贴图→编辑标注」原地变身导致编辑器被塞在贴图尺寸里、不是 1:1 原图编辑的问题：改为直接关掉贴图窗、按贴图位置和尺寸开编辑窗，始终只有一扇窗且尺寸正确。

## 1.10.0 - 2026-11-04

- 文字标注支持双击改字（原位置重开输入框回填原文）和按住拖动移位，点击空白才落新字。
- 修复「贴图上点 OCR / 翻译会同时出现贴图窗和结果窗」：宿主窗口代理白名单没有 loadURL，此前的「原地导航」判断在真机上永远为假，全部走了开新窗兜底。现改用白名单内的 webContents.executeJavaScript 实现真正原地导航，贴图 / 编辑器原地变身结果窗，无双窗口。
- 原地导航失败时自动回退为独立结果窗，行为不劣化。

## 1.9.1 - 2026-11-04

- 修复「图片突然放很大且无法缩小」：拦截 Chromium 默认页面缩放（Ctrl+滚轮 / Ctrl+加减号 / 触摸屏捏合），并用宿主 API 钉死各子窗的视觉缩放级别。
- 修复设置页「闪退」：编辑器原地转结果窗等场景发出的 closed 消息不再被设置页误响应，避免幽灵 outPlugin 把视图收起。
- 拦截到页面缩放时写入 diag 日志，便于回溯。

## 1.9.0 - 2026-11-02

- 面向官方插件仓库的规范化改造（清单、文档、许可）。

## 1.8.0 - 2026-11-01

- 初次发布，将插件提交至 ZTools 插件仓库。
- 框选后原地弹出与选区等大的编辑窗，图片 1:1 像素显示。
- 高清重抓：按物理像素重新抓取选区底图，兼容 125% / 150% 缩放屏幕。
- 悬浮图支持拖动、缩放、裁剪、透明度调整；点「编辑标注」在原窗口内直接编辑。
- 接入 ZTools 官方 OCR / 翻译 provider，未配置时回落到本机微信 OCR 引擎。
- 图片翻译将译文直接覆盖在原图对应位置，支持原文 / 译文切换。
- 贴图板与截图历史统一管理，支持重新悬浮、编辑、OCR。
- 截图后自动清理过期临时文件。
