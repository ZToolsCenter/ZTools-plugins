# Changelog


## 1.0.2 - 2026-08-26

- 网站延迟改为业界常用探针：Google 用 `generate_204`，其余用 favicon；页面侧走 Chromium `fetch`，不再下载整站首页
- 未走代理时「位置」展示国内公网地址，不再留空
- 延迟由页面立刻测探针并出数；curl 仅在页面失败时补测，成功结果不再互相覆盖
- 国外 IP 页面立刻查询并先显示，不必等系统代理检测结束

## 1.0.1 - 2026-08-26

- 公网不再被国外接口抢答；无独立国外出口时位置不再空等；TUN / 系统代理刷新互不覆盖
- 延迟探测不再把 curl 失败 / HTTP 000 当成成功；刷新时清空归属地缓存
- 插件名称：鹅的IP；指令支持「鹅的ip」「ip」「内网」「公网」
- 支持网卡切换与进入插件时自动复制内网 IP
- 探测常用境内 / 境外网站延迟
- 列出系统 DNS 并查询归属地
- 支持填写高德、腾讯、ipgeolocation 密钥；填入后走官方定位接口，位置和国外归属更准
- 风格参考 [eachann](https://github.com/eachann1024/goose-mark)，希望大佬同意理解：若有问题随时反馈给我～
