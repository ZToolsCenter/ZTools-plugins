# UI Polish — Todos

日期：2026-11-24

## 范围

保留现有 “Quiet Paper” 视觉语言，做一次界面 polish，不重做信息架构和品牌方向。

目标：

- 恢复原本设计系统里的字号与间距层级
- 让任务颜色表达真实语义，而不是随机装饰
- 让周 / 月切换与真实行为一致
- 提升月视图和搜索空状态的可读性
- 修正次要文本对比度和窄窗口溢出

## 发现与修正

### 1. 缺失设计变量

大量组件使用 `--text-xs / --text-sm / --text-base / --text-lg`、`--sp-12`、`--emerald`，但 `variables.css` 中没有定义。

结果是：

- Logo、任务标题、任务日期、月视图标题全部落到继承的 14px
- 空状态缺少垂直留白
- 已完成状态点和数字没有颜色

修正：补齐语义别名和缺失 token。现在层级为：

- Logo / 月标题：18px
- 工作空间 tabs：11px
- 任务标题 / 描述 / 分组标题：12px
- 任务日期 / 年 / 图例：11px 或 10px
- 空状态：上下 48px 留白

### 2. 周 / 月切换语义不一致

顶部按钮使用 `Maximize2 / Minimize2` 全屏图标，但点击实际切换的是周 / 月视图。

修正：改成明确的“周”“月”分段控件，带 `aria-pressed`，不再使用全屏图标。

### 3. 任务颜色与数据不匹配

任务左侧色条使用 `getTaskColor(task.id)` 随机生成彩色，和 `priority` 字段无关，导致界面里同时出现大量无意义色相。

修正：

- 高优先级：红色
- 中优先级：橙色
- 低优先级：绿色
- 色条增加 `role="img"` 和“优先级：高/中/低”标签

> 2026-11-26 回退：优先级目前没有编辑入口，新建任务固定为「中」，色条于是全部变成橙色，丢掉了「一条任务一个颜色」的辨识度。现在改为设置项：「按完成状态」用青绿 / 红 / 灰区分钟未完成、逾期、已完成；「按任务配色」按任务 ID 稳定取色。两种模式都能跨重启保留，优先级信息仍保留在色条的 `title` / `aria-label` 中。

### 4. 月视图任务不可读

月视图单元格宽度有限，任务徽章保留完整 border/padding，标题只剩一两个字；超过 3 个任务时也没有稳定的溢出提示。

修正：

- 月视图徽章改为紧凑无边框样式
- 优先条缩窄到 2px
- 每个日期最多显示 2 个任务，其余显示 `+N`
- 为任务 chip 增加 `title`，hover 可以看到完整标题

### 5. 搜索无结果时空白

搜索没有匹配项时，待办池直接空白。

修正：增加“没有找到任务”空状态，说明原因并提供“清空搜索”操作。

### 6. 对比度与窄窗口

- 任务日期、年、底部图例从低对比 `--clay` 调整为 `--graphite`
- 图例字号从 9px 提升到 10px
- 窄窗口隐藏状态快捷筛选，避免状态条和标题挤压
- 640px 以下搜索框收窄到 120px
