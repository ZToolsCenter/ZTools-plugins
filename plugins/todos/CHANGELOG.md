# Changelog

## 1.4.0 - 2026-11-26

### Added

- 支持两层嵌套任务：主任务下可添加若干子任务，子任务就是普通任务——可单独排期（拖到日历某天）、拖拽完成 / 删除、双击编辑、点击跳转；池里嵌套展示，主任务行右侧按情况显示「添加子任务」或「展开 / 收起」，展开后列表底部为「+ 子任务」，主任务行同时显示进度（如 `2/3`）
- 设置中新增「任务颜色」选项：按完成状态取色（青绿未完成 / 红逾期 / 灰已完成，一眼看出进度）或按任务配色（每条任务一个颜色，便于在多任务间总览），选择随快照保存、重启后保留

### Changed

- 任务左侧色条默认改为按任务配色（上一版固定为中优先级橙色，而优先级没有编辑入口，新建任务全是同色）；可在设置里切回按完成状态取色，优先级信息仍保留在悬停提示中
- 日历排期里不再隐藏已完成任务：留在当天、置灰并排在未完成任务之后，方便回看当天完成了什么
- 已完成任务统一归入「已完成」分组，不再重复出现在今天 / 本周 / 未安排列表
- 删除语义按拖拽来源区分：从待办池拖到右下删除整条任务；从日历某一天拖出时只移除当天安排，不再跨天删除整条任务
- 拖拽操作区的图标按语义区分：已完成任务右上为蓝色「取消完成」，日历来源右下为琥珀色「移除当天」，底部图例同步提示
- 拖拽操作区整体缩小到原来的 60%，图标、阴影与命中区域同步缩放
- 仅待办池布局下隐藏头部无意义的周 / 月视图切换
- `Ctrl/Cmd+Enter` 改为两步：任务输入框未聚焦时先聚焦并把光标放到末尾，已聚焦时提交任务；设置 / 操作指引弹层打开时不抢焦点

## 1.3.0 - 2026-11-24

### Added

- 拖拽任务时以光标为圆心展开双扇形操作区：右上扇形完成、右下扇形删除，两块贴合组成整圆 40%（各 72°）的饼形区域，颜色从中心向外做透明度渐变（中心透明、外缘更实），鼠标移入后松手即可执行；触控板用左键拖拽即可完成操作
- 搜索无结果时显示“没有找到任务”空状态，并提供清空搜索操作

### Changed

- 底部图例与操作指引更新为“右上完成 / 右下删除”；鼠标右键滑动保留为备用操作
- 操作区未选中时使用低饱和灰绿 / 灰红，仅在悬停时恢复高饱和色
- 任务拖拽从原生 HTML5 Drag & Drop 改为 Pointer Events 自定义拖拽，保留拖到操作区和拖到日历分配日期
- 数据主存储统一到 ZTools `dbStorage` 单快照，旧 `localStorage` 与 `workspace-configs` 自动迁移；上一版快照自动备份
- 仅持久化字段变化时触发保存，UI 状态变化不再整包重写；开发模式使用独立存储 key
- 补齐 `--text-*`、`--sp-12`、`--emerald` 等缺失设计变量，恢复标题、正文、日期和空状态的排版层级
- 任务左侧色条改用优先级语义色（高红 / 中橙 / 低绿），替代随机彩色
- 周 / 月切换改为明确的“周”“月”分段控件
- 月视图任务密度优化：每个日期最多显示 2 项并显示 +N，任务徽章更紧凑；日期、图例等次要文本对比度提升
- 窄窗口隐藏状态快捷筛选并收窄搜索框，避免头部溢出

### Fixed

- 修复笔记本触控板松手后完成 / 删除不立即执行、操作区不立即消失的问题：松手时直接按指针位置执行，不再依赖浏览器延迟补发的 `drop` / `dragend`
- 修复从周视图 / 月视图拖动任务时操作区不出现的问题
- 修复周 / 月切换按钮使用全屏图标、与真实行为不一致的问题
- 修复搜索无结果时任务池空白、没有任何提示的问题
- 修复布局模式（日历 + 待办 / 仅待办池）与日历任务密度重启后被重置的问题：两者随主快照持久化，旧快照自动补默认值

## 1.2.0 - 2026-09-22

### Added

- 点击待办池中的任务，日历自动跳转到 deadline（安排的最晚日期）；未安排日期的任务不跳转，周视图与月视图均生效

### Changed

- 分组编辑页名称输入框与首页待办输入框统一为共享 `.app-input` 风格（边框、圆角、聚焦态、占位符一致）

### Fixed

- 修复新建分组后选中该分组时页面崩溃的问题（`WeekView` 中 `Cannot read properties of undefined (reading 'filter')`）：新建/删除分组现在会同步初始化与清理对应任务列表
- 修复自定义分组数据在刷新后丢失的问题：本地存储加载时不再只保留内置的 `work/life/study` 分组

## 1.1.0 - 2026-08-29

### Added

- 底部常驻迷你图例，展示核心操作提示（右键滑动、双击编辑、拖拽分配日期）
- 快捷键操作指引面板（按 `?` 或点击图例按钮打开）
- `?` 快捷键注册，输入状态下自动屏蔽

## 1.0.1 - 2026-08-29

### Fixed

- 修复月视图周起始日对齐问题，表头显示周一到周日但网格按周日开始计算，导致日期偏移一列
- 统一月视图中的 `getWeekStart` 实现，改用 `dateUtils` 中的标准函数，避免时区问题
