# Changelog


## 1.1.0 - 2026-08-29

### Added

- 底部常驻迷你图例，展示核心操作提示（右键滑动、双击编辑、拖拽分配日期）
- 快捷键操作指引面板（按 `?` 或点击图例按钮打开）
- `?` 快捷键注册，输入状态下自动屏蔽

## 1.0.1 - 2026-08-29

### Fixed

- 修复月视图周起始日对齐问题，表头显示周一到周日但网格按周日开始计算，导致日期偏移一列
- 统一月视图中的 `getWeekStart` 实现，改用 `dateUtils` 中的标准函数，避免时区问题

## 1.0.0 - 2026-07-22

- 初次发布，将插件提交至 ZTools 插件仓库。
- 实现任务管理、工作区、周/月日历及拖拽分配。
- 支持搜索、快捷键与持久化保存。
- 优化拖拽动画、任务高亮和工作区设置，修复克隆操作背景异常。
