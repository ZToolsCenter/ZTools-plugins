# Changelog


## 1.0.2 - 2026-07-28

- 重构页面为紧凑的左右分栏布局，左侧按连接类型分类，右侧集中展示端口详情。
- 搜索框统一支持进程名、PID、端口、地址、状态和协议，修复切换关键词后仍受旧字段限制的问题。
- 增加数字指令匹配，在 ZTools 主搜索框输入端口号时可直接推荐并打开插件。
- 优化固定窗口高度下的表格列宽、滚动与深浅色视觉，并将插件显示名称简化为“端口占用”。

## 1.0.1 - 2026-06-01

- 更新插件 Logo，视觉上同时表达端口占用、运行状态、服务列表与网络接口。
- 优化 README，补充运行中 Windows 服务详情查询能力和 PowerShell 数据来源说明。

## 1.0.0 - 2026-05-19

- 新增 Windows 端口占用插件。
- 支持按进程名、PID、端口、地址、状态、协议筛选。
- 支持表格展开查看连接详情。
- 支持直接结束对应进程。
