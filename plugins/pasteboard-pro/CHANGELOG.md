# 更新日志

## 1.3.0 - 2026-09-01

- 适配 ZTools 3.2：新增截图入库、原生文件外拖和插件专属 `pluginData` 附件目录；首次启动会校验迁移旧附件、重写数据库路径并删除旧目录。ZTools 2.4–3.1 直接安装仍使用旧目录与浏览器拖拽回退。截图对公开的一参数 wrapper 以第二参数 `false` 作 best-effort 编辑态请求，不能保证 wrapper 会转发；区域尺寸按宿主是否回传而可选。
- ZTools Shelf 截图只写系统剪贴板，由主窗口唯一负责历史镜像与广播，避免双窗口重复入库。
- 插件附件删除改为内容寻址白名单，复核 SHA-256、无符号链接文件句柄、canonical 路径、父链和 inode；无法验证或仍被记录引用时拒绝删除。
- 低于 ZTools 2.4 时只显示升级提示，不初始化剪贴板数据库、同步、窗口或后台监听。
- Windows/Linux 列表快捷键改用 Ctrl，覆盖搜索、新建、复制、暂停、编辑、重命名、全选、多选和数字快捷粘贴。
- 通用设置新增 ZTools 全局快捷键入口，并明确 `Win + V` 为 Windows 系统剪贴板历史快捷键。
- 修复带 Ctrl、Meta 或 Alt 的方向键和 Enter 被误判为裸键、导致搜索框失焦或列表误操作的问题。
- 统一卡片与列表的 Enter/Space 键盘路由，避免事件冒泡造成重复粘贴或绕过修饰键保护。

## 1.2.0 - 2026-08-03

- 插件源码目录与唯一 ID 保持为 `pasteboard-pro`，兼容既有安装、数据和同步协议。
- 新增“文本”“图像”智能分组，并支持列表拖动排序、整卡片拖拽和多选卡片并排 3D 拖拽预览。
- 键盘输入可自动进入搜索框；方向键、Enter 可恢复列表控制，Backspace 可返回搜索编辑。
- 分组右键菜单支持无分组时直接创建，以及从分组管理入口展开编辑操作。
- 外观设置现在持久保存主题色、纯色背景和本地背景图片；启用 WebDAV 后可端到端加密同步到其他设备。
- 设置页新增“清空剪贴板”，可清理全部历史、插件自管附件和当前系统剪贴板，并同步删除状态。
- 扩展 ZTools 插件市场平台支持到 Windows 和 Linux。
- Windows/Linux 使用系统安全存储保存同步凭据，使用 Tesseract OCR 和 ImageMagick 图片旋转。
- 文件拖拽与队列剪贴板格式适配 Windows、Linux；多选队列在非 macOS 上按 Enter 逐项粘贴。
- 文件预览在 Windows 使用资源管理器、Linux 使用系统默认打开器，macOS 继续使用 Quick Look。
- 非 macOS 构建跳过 macOS Vision helper，避免平台构建失败。
- 普通粘贴与复制现在使用历史记录的规范源内容，并保留 HTML 富文本格式，不再读取当前系统剪贴板或易失历史 ID。
- 分组批量变更和删除增加失败补偿，避免部分内容被移出分组或残留同步 tombstone。
- 粘贴队列移除常驻 200ms 数据库轮询，持久化失败改为指数退避；辅助功能权限缺失时等待重新进入或队列变化再尝试。
- 升级 Vite、Vitest 和 Svelte Vite 插件，并锁定已修复的传递依赖；npm 官方审计无已知漏洞。
- 修复双宿主 favicon 缺失导致视觉矩阵首项失败，完整 35 个场景和 72 张截图恢复通过。

## 1.1.1 - 2026-07-28

- 修复宿主剪贴板历史已更新但列表未及时刷新的问题。
- 提升连续粘贴队列可靠性，监听异常退出后可自动恢复，持久化失败时不再复活已消费内容。
- 使用线性时间的正则与通配符匹配，并检查完整文本中的敏感内容。
- 限制宿主文本、预览文件和 WebDAV 响应大小，避免超大内容占用过多内存。
- 保留策略现在会安全清理不再使用的插件附件，同时保护共享文件和插件目录外文件。
- 移除尚未实现的任意文件内容同步设置，并完善分组右键菜单的键盘焦点操作。

## 1.1.0 - 2026-07-24

- Paste剪切板首次运行后自动登记为随 ZTools 启动，并保持后台剪贴板监听。
- 支持在当前分组中新建文本，并通过卡片右键菜单将单项或多选内容加入、移出分组。
- 修复删除确认框导致浮窗提前关闭，以及同步时旧分组数据恢复已删除分组的问题。
- 修复自定义分组内多选与键盘操作越过当前可见范围的问题。
- 加固隐私规则的正则与通配符校验，降低 ReDoS 风险。

## 1.0.0 - 2026-07-20

- 首次发布 Paste剪切板双宿主插件。
- 支持剪贴板历史、搜索、分组、预览、快捷粘贴与连续粘贴队列。
- 支持图片缩略图、PDF、Quick Look、图片旋转和 macOS Vision OCR。
- 支持上、下、左、右贴边、多屏跟随、紧凑布局和失焦关闭。
- 支持历史保留、附件预算单位、隐私规则、屏幕共享保护与暂停捕获。
- 支持端到端加密 WebDAV 同步和跨宿主冲突合并。
- 增加双宿主视觉矩阵、搜索性能门禁、helper 证明和最终 ZIP 校验。
- 品牌名称更新为“Paste剪切板”，启用全新紫蓝渐变图标。
