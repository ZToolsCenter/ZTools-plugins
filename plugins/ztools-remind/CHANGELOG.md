# 更新日志

## 2.2.8 - 2026-10-15

uTools 插件「提醒」（原作者 zivxzf）v2.2.8 的 1:1 移植版：原版页面与逻辑（layui + jQuery + CodeMirror）字节级原样运行，仅新增 ZTools 宿主兼容层。

- 多种定时方式：一次 / 每天 / 每周 / 每月 / 循环间隔（含生效时段）
- 到点独立弹窗提醒：7 种弹出位置（中间、四角、左右居中），支持自动关闭与提醒后删除
- 提示音乐：内置三首提示音或自定义本地音频，支持试听
- 弹窗样式自定义：提示文案、Logo 图片（含默认动图）、背景色/透明/多彩、文字颜色/多彩、字号，支持实时预览
- 全屏烟花提醒模式（Canvas 烟花动画）
- 自定义脚本提醒（到点执行 JavaScript，可调用 ztools 宿主 API）
- 深色模式、系统通知
- 兼容层含旧版数据自动迁移（mode → remindCount、相对路径资源转绝对地址）
