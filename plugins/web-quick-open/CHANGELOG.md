# Changelog

## 1.0.4 - 2026-10-25

- 新增分组功能
- 新增可复用的浏览器配置项，支持三平台预设、自定义路径和启动参数，支持浏览器图标获取、上传和内置图标
- 网页图标改为本地站点与远端图标服务并发获取，整体限时 5 秒，网络请求跟随 ZTools 代理
- 导入改为异步分批处理，修复 Electron 下解析线程不可用导致导入失败的问题
- 增加 Debug 日志，可在 ZTools 调试控制台查看
- 新增 JSON 导出，兼容旧版配置导入

## 1.0.3 - 2026-09-12

- 修复打开缓慢的问题，不在重复创建动态指令

## 1.0.2 - 2026-09-04

- 更新插件版本与发布配置。

## 1.0.0 - 2026-09-03

增加添加网址入口
