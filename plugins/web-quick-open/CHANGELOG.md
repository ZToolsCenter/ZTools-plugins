# Changelog

## 1.0.4 - 2026-10-28

- 新增网页分组功能，旧版本数据改为默认分组
- 新增可复用的浏览器配置项，支持多平台预设、自定义路径和启动参数，支持浏览器图标获取、上传和内置图标
- 网页图标改为本地站点与远端图标服务并发获取，优先采用网页声明和站点结果，整体限时 5 秒，网络请求跟随 ZTools 代理
- 刷新按钮新增批量获取网页图标菜单，跳过手动及未知来源图标，支持进度和取消
- 增加关键节点的 Debug 日志
- 新增配置导出功能，兼容旧版配置导入

## 1.0.3 - 2026-09-12

- 修复打开缓慢的问题，不在重复创建动态指令

## 1.0.2 - 2026-09-04

- 更新插件版本与发布配置。

## 1.0.0 - 2026-09-03
