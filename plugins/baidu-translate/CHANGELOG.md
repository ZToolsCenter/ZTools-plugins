# 更新日志

## 1.1.2 - 2026-11-05

- 修复发布包内端点常量引用错误导致的"网络请求失败"
- 网络请求优先走 Electron net 模块（跟随系统代理），node https 兜底
- 网络错误提示附带真实原因（DNS / 连接 / HTTP 状态），便于排查

## 1.1.1 - 2026-11-05

- 网络请求增加 User-Agent，避免被目标服务误拦截

## 1.1.0 - 2026-11-05

- 布局改为上下结构：顶部语言栏，下方左右分栏（左输入 / 右结果）
- 输入自动翻译（600ms 防抖，中文输入法组合期不触发）
- 单词查询词典卡片：多词性含义、音标、词形变化（复数 / 过去式等）、考试标签、英英释义与例句
- 变形词（claims 等）自动查原形词典择优合并
- 智能方向：中文 → 英文，英文 / 日语 / 韩语等 → 中文
- 最近 50 条翻译历史，点击回看重翻
- 译文逐段 / 整体复制

## 1.0.0 - 2026-11-05

- 初次发布：基于百度翻译开放平台通用翻译 API 的 ZTools 翻译插件
- 密钥本地 AES-256-GCM 加密存储，secretKey 不出 preload，不上传任何第三方服务器
- 源语言自动检测，28 种语言互译，语言方向互换
