# easynote · 简单便签

> 轻量、好用的桌面便签：Markdown 所见即所得、笔记 / 待办双类型、独立桌面便利贴，随取随记。

![便签插件界面](index.png)

easynote 是一个 [ZTools](https://github.com/ztool-center/ztools) 插件，让你随时在桌面贴一张可编辑的便签，随手记录、随时查阅。

## ✨ 产品特点

### 🧱 双栏分区管理

主页面一眼看清全部内容：**笔记**与**待办**左右分栏展示，类型互不混淆；待办栏顶部实时统计「已完成 / 总数」，完成进度一目了然。

### 📝 笔记 / 待办双类型

保存时可选择保存为「笔记」或「待办」。待办在列表中前置勾选框，一键勾选完成即可划掉；笔记则专注记录，互不干扰。

### 📌 桌面便利贴

从 ZTools 唤起后，便签以独立窗口贴在桌面右上角——**无边框、置顶、可拖动**，不占用主窗口，随时都能看到、随手就能改。

### 🎨 Markdown 所见即所得

输入 `# 标题`、`**粗体**` 等语法即时渲染成富文本；也可切换为「双栏」模式（左编辑、右预览），精确打磨排版。

### ✂️ 纯文本复制

一键复制 Markdown 原文，或复制剥离全部标记的纯文本，贴进任何不支持 Markdown 的地方也干净整洁。

### 🖱️ 字号自由调

在主页面设置区调字号，或在便利贴内 `Ctrl + 滚轮` 实时缩放，字号偏好自动记住。

### 💾 草稿与本地存储

新建便签默认为草稿（不落库），点「保存」才正式写入；所有数据保存在本地（ZTools dbStorage），无需联网，随用随取。

### 🌙 暗色模式

跟随系统主题自动适配浅色 / 暗色，夜晚使用不刺眼。

## 📦 安装

将构建产物 `dist/` 目录的内容放入 ZTools 插件目录，或在 ZTools 中安装本插件。

开发调试：

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 🚀 使用

### 1. 唤起便签

在 ZTools 输入以下任一指令：

- `便签`
- `note`
- `bj`

进入主页面（管理面板）。

> 也可以直接在 ZTools 输入 `新建便签` / `new-note`，跳过管理页，打开一张空白便利贴。

### 2. 主页面

主页面是便签的管理中心：

- **设置区**：选择编辑模式（所见即所得 / 双栏），调整字号。
- **新建便签**：点击「新建便签」，在桌面弹出一张空白便利贴。
- **笔记栏**：左栏集中展示所有笔记，点击进入内容页查看 / 编辑。
- **待办栏**：右栏集中展示所有待办，勾选即可标记完成（完成后划线显示，顶部同步完成进度）；点击进入内容页。
- **便利贴按钮**：列表每条右侧的便利贴按钮，将内容以桌面便利贴形式打开。
- **删除**：删除按钮移除对应便签。
- **清空**：笔记栏、待办栏表头各有一个「清空」按钮，二次确认后仅删除对应栏的全部条目（不可恢复）；该栏为空时按钮置灰。

### 3. 桌面便利贴

桌面便利贴是一个独立的置顶小窗口：

- **输入**：所见即所得模式下直接输入 Markdown 语法即时渲染成富文本；双栏模式下左侧编辑、右侧实时预览。
- **保存**：点击「保存」将当前便签写入本地存储。新建的便签保存前会提示选择类型（待办 / 笔记），已保存便签沿用原类型。
- **复制**：点击「复制原文」复制 Markdown 源文本；点击「复制纯文本」复制剥离标记的纯文本。
- **字号**：在便利贴内 `Ctrl + 滚轮` 实时调整字号（与主页面设置同步并持久化）。
- **拖动**：按住便利贴顶部标题栏即可拖动窗口位置。
- **关闭**：点击右上角 × 关闭便利贴，并结束插件进程。

> 桌面便利贴是单例窗口：再次输入「便签」唤起主页面可新建 / 打开其他便签。如需切换到另一张已保存便签，请先关闭当前便利贴再从列表打开。

### 4. 编辑模式

- **所见即所得**：输入即渲染，适合快速书写、注重排版效果的场景。
- **双栏**：左 Markdown 源码、右渲染预览，适合需要对照源码或精修语法的场景。

在主页面设置区切换，选择会持久化，下次打开自动沿用。

## 🗃️ 数据存储

便签保存在 ZTools 的本地存储（dbStorage）中，关闭插件、重启 ZTools 后依旧保留。每条便签包含：

- **标题**：自动取自首个标题或首行非空文本。
- **内容**：Markdown 源文本。
- **类型**：`笔记` 或 `待办`。
- **完成状态**：待办是否已完成（`done`）。
- **完成时间**：待办勾选完成时记录（`doneAt`）。
- **创建时间 / 更新时间**：用于列表排序（待办未完成在上、已完成在下，各组内按更新时间倒序）。
