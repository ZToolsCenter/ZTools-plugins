# 自动化助手

自定义触发指令 + JavaScript 脚本，一条指令完成一串繁琐操作。

## 功能

**创建自己的自动化**

在设置页新建脚本，填写功能说明、配置触发指令、编写 JavaScript，保存后指令即注册到主输入框。

支持六种指令类型：

| 类型 | 触发方式 | 可配置项 |
| --- | --- | --- |
| 功能指令 | 主输入框输入关键字 | 指令名称（可配多个） |
| 【任意文本】匹配 | 输入或选中任意文本 | 排除正则、最少/最多字符数 |
| 【特定文本】匹配 | 输入或选中符合正则的文本 | 正则、最少/最多字符数 |
| 【文件】匹配 | 粘贴或选中文件 | 文件/文件夹类型、名称匹配正则、最少/最多文件数 |
| 【图像】匹配 | 粘贴截图 | — |
| 【系统窗口】匹配 | 在特定窗口下呼出 | 应用名称、标题匹配正则、窗口类 |

**脚本运行环境**

脚本在 Node `vm` 沙箱中隔离执行，可直接使用以下全局对象：

| 全局对象 | 说明 |
| --- | --- |
| `ENTER` | 进入插件的参数：`code` / `type` / `payload` / `option` / `from` |
| `print(msg)` | 输出内容到运行面板 |
| `ztools` | 插件 API：剪贴板、键鼠模拟、屏幕、系统路径、Shell 等 |
| `require` | Node 内置模块，如 `child_process`、`fs`、`os`、`https` |
| `sleep(ms)` | 阻塞等待 |
| `runAppleScript(script)` | 执行 AppleScript（macOS） |

脚本 `return` 的内容会展示在结果面板，并可「再次运行」；抛出异常则展示错误信息。

开启「脚本隐藏后台运行」后，进入时先隐藏主窗口，脚本无返回值则静默退出，有返回值或报错才唤回窗口展示结果。

**分类管理**

新建 / 重命名 / 删除分类，脚本支持移动到其它分类、拷贝创建。

## 内置脚本

开箱即用，可只读查看源码，也可「拷贝创建」为自己的脚本后修改。

| 分类 | 指令 | 说明 | 平台 |
| --- | --- | --- | --- |
| 本地系统 | WiFi 密码 | 获取当前已连接 WiFi 的密码 | Windows / macOS |
| 本地系统 | Ping 一下 | 识别 IP 或域名，打开终端 ping | Windows / macOS |
| 本地系统 | 内网 IP | 获取本机内网 IP，自动避开虚拟网卡 | 全平台 |
| 文本处理 | 今天 | 在光标处输入今天的日期 | 全平台 |
| 文本处理 | 英文大写 / 英文小写 / 首字母大写 | 转换选中的英文文本 | 全平台 |

## 开发

```bash
npm install
npm run dev      # 开发服务，开发模式连 http://localhost:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
npm run release  # 通过 ZTools CLI 发起发布 PR
```

`src/dev-mock.ts` 会在开发环境注入 API 模拟层，便于在普通浏览器中调试；生产构建时自动摇除。
