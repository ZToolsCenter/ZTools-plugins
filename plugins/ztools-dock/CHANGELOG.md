# 更新记录

## 0.1.11 - 2026-11-13

- 外观设置增加“显示菜单栏名称”和“显示入口名称”两个独立开关，默认均开启，旧配置保持原显示效果。
- 隐藏名称后图标沿原布局居中，保留悬停提示、可访问名称、搜索和启动功能；不影响管理页面中的分类和入口名称。
- 新开关支持导入导出、重启恢复及外观重置，保留已有分类、入口和停靠位置。

## 0.1.10 - 2026-11-13

- 增加上、下、左、右四个停靠方向，面板向屏幕内侧展开；侧边分类栏纵向滚动。
- 支持按比例或按距左/右（侧边为上/下）边缘的距离定位，默认仍为顶部居中；越界位置按当前工作区限制。
- 卡通触发图案适配侧边方向；原生承载窗留在目标显示屏内，修复不同 DPI 屏幕边缘触发条坐标偏移。
- 切换方向后保持当前选中分类可见，避免长分类列表改变滚动轴后选中项离屏。
- 旧配置自动补齐定位选项，导入导出与外观重置支持新设置，分类和快捷入口保留。

## 0.1.9 - 2026-11-13

- 触发条增加经典细条、虫仔、蜗牛主题，静态矢量绘制；图案主题使用 32 px 触发区。
- 分类和入口图标支持小、中、大，保留原有卡片高度与列数配置。
- 增加原生云母 Mica、亚克力 Acrylic 与纯色材质，原生材质要求 Windows 11 22H2 或更新版本；其他系统回退纯色。
- 增加背景不透明度，只调整表面着色，文字和图标保持清晰；系统材质模糊强度由 Windows 控制。
- 材质切换保留展开和钉住状态，使用原生圆角区域排除面板空白处的绘制与鼠标命中。
- 旧配置自动补齐外观默认值；外观重置与导入导出支持新增设置，保留分类和快捷入口。

## 0.1.8 - 2026-11-13

首次提交插件市场审核。Windows 顶部分类程序坞：悬停展开、分类卡片启动应用/文件/文件夹/网址/ZTools 插件，支持搜索、排序、自定义图标、显示屏与外观设置、导入导出和导航条钉住。

- “重置外观与行为”位于外观页，仅恢复该页设置，保留分类、入口、图标、顺序和启用/暂停状态。
- 网址可获取网站图标；复制网址或本地文件可匹配“添加到程序坞”，按类型预填分类。
- 应用自动名称去除 exe、lnk、link 等后缀；空分类不出现在悬浮导航中。
- 导航和卡片区统一外侧投影，透明空白不拦截鼠标；设置使用独立窗口。
- 保留置顶维护、增量状态同步、显示器缓存和按需鼠标轮询。
