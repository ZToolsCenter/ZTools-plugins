# 更新记录

## 0.0.2（发布准备中，未提交市场）

作者：lifeek。发布前的修复和试装统一沿用 0.0.2。

- 一个插件同时支持 Windows（Everything）与 macOS（FSearch）。
- Windows：文件名、完整路径、大小写、字符模糊、正则及类型、目录、排除目录、扩展名、修改时间、大小筛选。
- 修复 Everything 1.4 的带单位大小范围与包含边界的筛选兼容性。
- 图片结果显示缩略图；独立大图窗口可最大化，16:9 画布保留图片比例。
- 普通滚轮围绕鼠标缩放；任意比例下可从图片或留白处自由拖动。
- 支持 fs / find、带参入口、预设独立指令、恢复上次条件及默认关闭的主搜索推送。
- 修复点击推送文件后同批“更多结果”失效的问题。
- Windows 不注册 macOS 专属正文和代码定义入口；macOS 首次打开插件后注册。
- 补齐安装、隐私、许可与平台验证范围；公开作者名称统一为 lifeek。
