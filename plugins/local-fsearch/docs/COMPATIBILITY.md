# 系统要求

| 平台 | 需要安装 | 可用功能 |
| --- | --- | --- |
| Windows | Everything 完整客户端、ES 命令行工具 | 名称/路径、分类与筛选、图片预览、预设与主搜索推送 |
| macOS | noahdunnagan/fsearch | 通用功能，以及正文、代码定义、Git 状态、常用优先和 Quick Look |

Everything 与 ES 均从官网下载，插件不捆绑或自动安装。只运行 Everything 系统服务不够，还需启动客户端并等待索引就绪。

Windows 已在 ZTools 3.2.0、Everything 1.4.1.1026 环境试用。macOS 以 Apple Silicon、ZTools 3.3.0-beta.2 和 FSearch 0.2.1 为参考；最新图片窗口的 macOS 实机体验仍待确认。其他环境如遇异常，可提供系统与引擎版本反馈。
