# 兼容范围与验证边界

插件 0.0.2，作者 lifeek；同一插件 ID 为 local-fsearch。

| 平台 | 已验证环境 | 能力与边界 |
| --- | --- | --- |
| Windows | 本机 Windows、ZTools 3.2.0、Everything 1.4.1.1026、ES x64 1.1.0.38 | 名称/路径、分类/筛选/分页、宿主入口、预设、推送、图片预览已测 |
| macOS（历史基线） | arm64、macOS 27.0.1、ZTools 3.3.0-beta.2、FSearch 0.2.1 | 0.0.1 真实引擎及能力探针已测；0.0.2 最新图片窗口和专属指令注册尚需 macOS 实机回归 |
| 其他架构 | 随包 ES ARM64 / x86 | 程序已核对官方签名；未在对应硬件实测，不宣称已全面兼容 |

Windows 需要 Everything 完整客户端运行，不只启动系统服务。插件不自动安装、启动或配置 Everything。索引覆盖以其卷、文件夹和排除设置为准。

macOS 的安装指纹记录见 compatibility.json。指纹仅识别磁盘上的安装文件，不证明守护进程版本。首次或手动重检用临时小文件检测正文、大小写、正则、定义和上下文接口；不会扫描私人文件做能力检查。

Windows 不支持 FSearch 原生模糊评分、全文/代码定义、Git 状态、常用优先及 Quick Look，不在界面和主搜索暴露对应功能。文件名的字符模糊与 FSearch 原生模糊是不同模式。

## 宿主系统动作边界

Windows 隔离实例确认打开、定位、复制路径已传至真实 ZTools 的系统调用层；为避免打扰日常使用，最终的系统默认应用、资源管理器和剪贴板调用被拦截。不能将其描述为完整系统端到端验收。

正式投稿前建议手动补测这三个最终动作及 macOS 最新版本。文件对象复制、向原应用粘贴和真实焦点恢复也需手动验收。未验证项不写成已通过。
