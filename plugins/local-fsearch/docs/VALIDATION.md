# 0.0.2 验证记录

作者 lifeek。发布材料整理日期：2026-11-19。

## 已有证据

- 静态自检覆盖清单、版本一致性、公开作者、平台、512px PNG 图标、运行文件白名单及本地 require 依赖。
- 最近完整回归为 39 项：35 项通过，4 项 macOS 实机集成测试在 Windows 上跳过。最终准备时的实际重跑结果另存于交付目录。
- 真实 Everything 测试使用合成文件，覆盖中文、空格/元字符、精确/字符模糊/正则、大小写、路径、目录、类型、大小、修改时间、排除目录和筛选后分页。
- 隔离 Windows ZTools 3.2.0：ZIP 导入、fs / fs 关键词、主搜索推送与“更多结果”、预设保存及独立指令启动通过。未改变日常 ZTools。
- 大图独立窗口在真实 ZTools 中打开；主插件宽 800px 时，预览画布约 1331×749px。支持 Esc 关闭。
- 最新图片平移在 Windows ZTools 中以 64% 实测：图片上拖动 (120,-65) 和留白处拖动 (-35,40) 均准确。拖动后图片内与留白上四次 64%↔80% 滚轮缩放的锚点测量偏差为 0px。
- 浏览器覆盖 PNG/SVG、缩略图、损坏图片回退、缩放/拖动/适应窗口与布局变化。只作界面证据，不替代宿主系统动作。
