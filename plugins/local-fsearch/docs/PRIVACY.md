# 隐私与本地数据

版本 0.0.2；作者 lifeek。

## 查询与索引

macOS 经本机 Unix Socket 向独立 FSearch 守护进程发送关键词、路径与筛选。Windows 通过参数数组启动随包官方 es.exe（或用户主动选择的其他 ES），使用 Everything 本地 IPC 查询；不拼接 shell、不开放 HTTP 服务。

插件不上传文件名、正文或关键词，不含遥测、广告和账号服务，不建立第二份索引。索引由外部引擎维护，其安装、权限和覆盖设置由用户管理。

选择的 ES 程序路径保存在 ZTools 本地 fsearch-everything-es 设置中，仅用于查询，不上传。

## 图片与内容读取

结果页只保留当前一页（25/50/100 条）。可见图片缩略图按需读取本地文件，最多两个读取任务同时执行，生成小图后释放原图对象 URL。用户预览大图时读取选中图片，32 MB 上限；窗口关闭后释放对象 URL。图片路径在本地预览窗口 URL 的 hash 中传递，可能出现在本机调试信息中，不作为网络请求发送。

macOS 正文由 FSearch 读取，预览有命中数量及文件大小限制。未知或损坏图片显示失败提示，不上传转换。

## 宿主存储

ZTools dbStorage 保存 fsearch-settings 和 fsearch-session：偏好、最多 20 个预设、编辑器、工作目录及可关闭的上次搜索条件、选中路径、滚动位置和有界游标元数据。会话序列化上限 32 KiB，不存结果列表、图片或正文。关闭恢复偏好会清除会话。ZTools 自身备份/同步策略以宿主设置为准。

## 用户操作与外部帮助

只有用户操作才打开、定位、复制、粘贴或打开帮助网站。macOS 成功打开后向 FSearch 写入常用记录。Windows 不维护额外打开历史。帮助链接为固定官网/项目地址，不附带搜索词和本地路径。

## 连接检测

macOS 首次或手动重检创建自己的临时小文件，测试后删除；流式计算安装程序指纹。崩溃可能留下 ztools-fsearch-check-* 临时目录。Windows 读取 Everything 版本确认连接。无后台轮询。
