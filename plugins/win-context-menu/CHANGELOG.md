# 更新日志

## 1.0.0 - 2026-11-27

### Added
- 支持扫描与管理 Windows 10 / 11 四大场景右键菜单（文件夹空白处、文件、文件夹、桌面空白处），覆盖 `shell` 项、`AllFilesystemObjects`、`shellex` COM 扩展与 Win11 现代 `AppX/Sparse Package` 扩展。
- 支持通过 Win32 API 解析本地化中文菜单名、提取真实程序小图标，并按贴近系统真实的顺序排列。
- 支持默认独立任务栏窗口打开、一次 UAC 常驻提权会话（零蓝框闪烁、15 分钟空闲自动退出）以及前端毫秒级局部刷新。
- 支持修改前自动备份 `.reg` 与历史状态，并提供「一键还原全部修改」与「一键重启资源管理器」功能。
