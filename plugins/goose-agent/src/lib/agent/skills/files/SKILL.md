# 本地文件

## 适用

- 列出、读取、写入、搜索、创建目录、删除或重命名工作区（或完整权限下的本机）文件。
- 用户明确要求处理本地路径、改配置、生成文件等。

## 工具

- `listDir`：列目录。
- `readFile`：读文本文件。
- `writeFile`：写入或覆盖文本文件（直写，无审批）。
- `searchFiles`：按名称关键字在目录树中搜索文件。
- `mkdir`：创建目录（直写，无审批）。
- `deletePath`：删除文件或目录；目录非空时需 `recursive: true`。
- `renamePath`：重命名或移动文件/目录（`from`/`to`，亦可用 `path`/`newPath`）。

## 约束

- 遵守当前 Permission Mode：只读工作区 / 工作区读写 / 完整权限。
- 无工作区且非完整权限时，文件工具不可用。
- 路径须落在沙箱允许范围内；越权会失败。
- 只做用户明确要求的写入、删除与移动；完成后停止。
- 大文件或二进制内容先说明限制，不硬读二进制当文本。

## 输出

- 读写结果用简洁摘要回复；需要时可再调用 visual 呈现表格。
