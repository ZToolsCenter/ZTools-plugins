# uTools 真机 E2E 清单（鹅的 Agent）

> 真机项必须在 uTools 插件窗口内执行。浏览器 `bun run dev` 仅作 UI 预览，gooseFs 真机为准。

## 前置

- [ ] 本机构建：仓库根 `bun run build` 通过
- [ ] 无真机冒烟：`bun run smoke:utools`（校验 `dist-utools` 元数据/产物）
- [ ] uTools 开发者模式加载 `dist-utools/`（或项目约定的插件目录）— **必须真机**
- [ ] 准备一个可写测试文件夹（内含 1–2 个文本文件）

## 1. 开插件

- [ ] 主输入框唤起「鹅的 Agent」/ 对应 feature cmds
- [ ] 窗口为左工作区栏 + 右对话主区（无笔记页树 / BlockNote）

## 2. 独立引导 / 首次配置

- [ ] **无 Key 启动**：全屏独立引导页（非主 shell 内嵌）；主界面**不**出现起步清单
- [ ] 引导页两项：Key（必做）/ 工作区（可选）；「打开 AI 设置」可打开设置 → AI
- [ ] 无 Key：「进入工作台」禁用
- [ ] 配好 Key 后可点「进入工作台」进左栏+主区；空会话仅「开始对话」轻空态
- [ ] 有 Key 重启：直接进主 shell，不再挡引导
- [ ] 主 shell 内无 Key：Composer 发送禁用；尝试发送有 toast 且**不**发出消息
- [ ] 有 Key、无工作区：可正常发送对话；侧栏可补加文件夹
- [ ] **自动导览**：有 Key 且 `ga:tour` phase=pending 时，进入工作台后 idle / 非 streaming 约 700ms 自动播 3 步 **1 次**（**不**要求工作区或首条消息）
- [ ] 导览可点「完成」或关闭跳过；之后**重启插件不再**自动弹出（done/skipped）
- [ ] 顶栏**无** Compass「界面导览」常驻入口
- [ ] DEV 设置 →「重置界面导览」后，回到工作台可再自动播 1 次
- [ ] 存储仅 `ga:tour`（phase pending/done/skipped）；清单两项仅实时推导、无完成态键

## 3. 挂目录

- [ ] 左栏「添加文件夹」选中测试目录
- [ ] 列表显示名称；切换选中生效
- [ ] 重启插件后列表/选中记忆（若已实现持久化）

## 4. 配模型

- [ ] 设置 → AI：任选 OpenAI 兼容 **或** OpenAI Responses **或** Claude，填 Key
- [ ] 保存后 Composer 模型选择器可见对应模型
- [ ] **注意**：原生 tool 循环已接 `openai` 与 `openai-responses`；`claude` 仍为文本 + prompt 约定工具

## 5. 读写与 tool 卡

- [ ] 权限切「工作区读写」
- [ ] 发送：「列出当前工作区文件」→ 出现 tool 进度卡（listDir 等）
- [ ] 发送：「在工作区创建目录 demo-ga 并写入 demo-ga/hello.txt」→ mkdir/writeFile 成功，磁盘可见
- [ ] 发送：「把 hello.txt 重命名/移动为 demo-ga/hi.txt」→ renamePath
- [ ] 权限切「只读工作区」后再写 → 工具失败且文案可理解
- [ ] 权限切「完整权限」**无二次确认**；访问工作区外路径（谨慎）按预期
