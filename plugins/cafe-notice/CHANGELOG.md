# Changelog

## 1.0.0 - 2026-10-29

### 新增

- 首次发布：采集 Windows 系统通知（wpndatabase.db 增量轮询），重展示为顶部/中部/底部弹幕与角落卡片两种形态
- 弹幕可配速度、方向（左→右 / 右→左）、位置、跨所有显示器连续飘屏、轨道数、字号、底色/透明度、边框、emoji 挂件
- 卡片可配显示器、四角位置、停留时长、宽度、同时上限（超出排队等位）、底色/透明度；悬停暂停、点击展开完整正文、手动关闭
- 通知内容可配：显示应用名、显示时间、字体颜色（留空按底色自动反色）
- 按应用配置：显示名、颜色、形态（弹幕+卡片/仅弹幕/仅卡片）、静音、接管原生横幅（ShowBanner=0，可恢复）
- 应用名解析：内置表 + 注册表 AppUserModelId DisplayName（覆盖 IDEA 等生成 AUMID）+ 推导兜底
- 历史页：固定条数展示、搜索、按应用过滤、导出 CSV/JSON
- 防刷屏合并：同应用 N 秒内超过 M 条合并为「+N 条」，M=0 关闭
- 测试通知使用独立身份 cafe.notice.test，不占用宿主或真实应用名字
- 常驻采集：backgroundRunning + 多实例 leader 选主（心跳锁），浮层僵尸窗自检自清理
- 仅 Windows：feature 声明 platform=win32；非 Windows 侧载时静默待命不采集
- 性能：外部进程（reg/powershell）全异步不阻塞界面；按应用/历史分页渲染；卡片窗空闲销毁、按需重建（省一个常驻渲染进程）
