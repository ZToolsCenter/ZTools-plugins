# 快捷打开 (quick-open)

在 ZTools 主搜索中按名称、别名或关键字快速打开网址、应用项目目录、浏览器书签、搜索引擎结果与本地文件/目录；并提供统一的配置管理界面。

> 首版仅支持 **macOS**。

## 本地调试

```bash
cd plugins/quick-open && npm install
bash ../../scripts/debug.sh quick-open
```

在 ZTools 中加载 `plugins/quick-open/`。修改 `preload.js` 后需重启插件（仅前端 HMR 不够）。

## 主搜索指令

| 指令 | 说明 |
|------|------|
| `快捷打开` / `quick open` / `quick-open` | 打开配置管理界面 |
| `应用快开` | 选择项目根目录，进入子目录列表 |
| 已保存的网址 / 应用 / 书签 / 搜索 / 文件配置的名称与别名 | 动态注册，命中后直接打开或进入对应流程 |

网址、应用、搜索、文件配置保存后会通过 `setFeature` 实时注册/更新/移除指令；改名、改别名、禁用或删除会立即生效。

## 功能概览

| 分类 | 说明 |
|------|------|
| 网址快开 | 配置名称/别名/关键字/URL/打开方式（系统浏览器或内置窗口），主搜索模糊匹配后直接打开 |
| 应用快开 | 配置应用名称、别名、根目录、启动命令模板（如 `cursor {path}`）；表单内置「应用预设」下拉框，自动发现本机已安装应用（含图标）与常用开发工具（Cursor、VS Code、Xcode 等），未内置应用自动生成 `open -a "<路径>" {path}` 模板；命中后进入项目列表，按命令模板打开目录 |
| 书签快开 | 自动读取 Chrome / Edge / Safari 默认 Profile 收藏夹，支持 HTML/JSON/plist 文件兜底导入；统一「书签」「收藏网址」指令，进入后按标题/别名/URL 搜索并打开 |
| 搜索快开 | 任意非空输入展示已启用的搜索引擎（内置 Google、百度、Bing、头条、搜狗、小红书，支持自定义），`{query}` 占位符自动编码 |
| 文件快开 | 配置命令模板（如 `open {path}`）与可选关键字前缀，输入路径或命中关键字时展示结果并按模板打开 |

配置管理界面分为网址 / 应用 / 书签 / 搜索 / 文件五个一级 Tab，各自维护独立的二级分类；双击二级分类可改名或删除（「全部」除外），不合格名称退出编辑时恢复原名。详情页右上角为启用开关，支持「立即验证」。编辑时可在分类下方配置图标（上传 / 自动获取 / 恢复默认）；未配置时配置列表与主搜索动态指令均使用字母徽章，配置后主搜索命中关键字会显示对应图标。

## 使用方法

1. 呼出 ZTools，输入 `快捷打开` 进入配置界面。
2. 选择对应 Tab（网址 / 应用 / 书签 / 搜索 / 文件），点击「新增」填写配置并保存。
3. 应用类型可在表单的「应用预设」下拉框中搜索并选择已安装应用，自动填充名称/别名/命令模板，也可手动编辑。
4. 书签类型可点击「导入」自动读取浏览器收藏夹，或选择导出文件兜底导入。
5. 保存后回到 ZTools 主搜索，输入对应名称/别名即可直接命中并打开；搜索类型可直接输入任意文本查看可用搜索引擎。
6. 在详情页右上角开关可随时启用/禁用某条配置，禁用项不参与主搜索匹配。

## 技术边界

- 业务逻辑：`lib/quick-open/`（+ 根目录 `tests/quick-open.test.js`）
- 书签读取 / 列目录 / 安全启动进程：`plugins/quick-open/preload.js`（`spawn`，禁止 `shell: true`）
- 持久化：`ztools.db.promises`；主搜索：`onMainPush`；动态指令：`setFeature` / `removeFeature`

详细需求见 `docs/prds/quick-open.md`。
