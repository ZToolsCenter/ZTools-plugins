# Changelog

## 1.0.1 — 2026-07-29

### 二级分类编辑

- 双击二级分类 Tab 进入编辑模式，可直接改名
- 编辑态右上角提供删除按钮；删除后该分类下条目变为无分类
- 点击编辑 Tab 以外区域退出编辑；不合格名称（空名 / 「全部」/ 特殊符号 / 过长 / 重名）退出时恢复原名
- 「全部」为系统分类，不支持改名或删除
- 「新增分类」改为仅展示 + 图标
- 修复编辑态删除按钮顶部被工具条裁切的问题

## 1.0.0 — 2026-07-14

### 正式发布

- 插件正式定名 **快捷打开**（`quick-open`），版本 `1.0.0`
- 五个一级 Tab：网址 / 应用 / 书签 / 搜索 / 文件
- 主搜索模糊匹配与动态指令注册
- 书签支持 Chrome / Edge / Safari 导入与文件兜底
- 配置卡片图标：默认字母徽章 / 上传 / 自动获取
