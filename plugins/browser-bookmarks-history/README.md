# 书签与历史记录搜索

搜索 Chrome / Edge 浏览器的书签与历史记录，支持便携版浏览器。

## 指令

- `书签` — 搜索全部书签 + 历史记录
- `历史记录` — 仅搜索历史记录
- `chrome书签` — 仅搜索 Chrome 书签
- `chrome历史记录` — 仅搜索 Chrome 历史记录
- `Edge书签` — 仅搜索 Edge 书签
- `Edge历史记录` — 仅搜索 Edge 历史记录
- 主窗口直接输入 — 全局联想搜索
- `书签设置` — 配置便携版 Data 目录、chrome.exe 路径

## 特性

- 自动获取网站图标，快速辨别目标网站
- 书签带 ⭐ 标识，历史记录带 🕘 标识，轻松区分类型
- 支持便携版 Chrome / Edge 的目录配置，便携版也能搜索
