# 书签与历史记录搜索

一键搜索 Chrome / Edge 浏览器的书签与历史记录，支持便携版浏览器。

## 特性

- 自动获取网站图标，描述行图标区分书签/历史记录、Chrome / Edge
- 右键菜单：打开网页、复制链接、默认浏览器打开、打开书签管理器/历史记录页、删除
- 设置页「书签与历史记录设置」可管理目录与程序
- 支持日期搜索历史记录，浏览模式逐层查看全部书签

## 使用说明

1. 输入“书签与历史记录设置”进入设置页配置浏览器
2. 安装版浏览器会自动配置，若目录为空则手动配置
3. 配置教程可把鼠标移到标题边上的 ！图标，有详细解释
4. 输入“书签与历史记录搜索”回车输入关键字进行搜索使用
5. 输入关键字匹配推荐选择“书签与历史记录搜索”进行搜索
6. 进入插件后在输入框输入指令进行功能搜索，具体指令见下方

## 指令（在插件搜索框中输入）

- `-ch` — 仅搜索 Chrome 的书签与历史记录
- `-ed` — 仅搜索 Edge 的书签与历史记录
- `-b` — 仅搜索书签
- `-h` — 仅搜索历史记录
- `-t` — 搜索今天的历史记录
- `-w` — 搜索最近 7 天的历史记录
- `-d 20260901-20261001` / `-d 0901` — 搜索指定日期的历史记录
- `-chb` / `-edb` — 书签浏览模式，按文件夹逐层查看全部书签
- 输入 `-` 查看全部指令说明
- 指令可以放在关键词前面或者后面，用空格隔开
- 不同类型指令可组合（除 `-chb` / `-edb`）
- 书签指令组合日期无效，书签没有日期
- 指令都是英文名取首字母，方便记忆，如下
- ch(chrome) ed(edge) h(history) b(bookmark) t(today) w(week) d(day) chb(chrome bookmark) edb(edge bookmark)
