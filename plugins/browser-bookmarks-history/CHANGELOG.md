# Changelog

## 2.5.0 - 2026-11-13

- 删除多余指令，改为插件内后缀指令
- 新增后缀指令说明，输入“-”显示，点击直接填入
- 新增搜索结果右键菜单
- 新增本地书签/历史记录删除功能（右键）
- 搜索结果描述行新增图标，区分 Chrome / Edge
- 新增历史记录访问时间
- 修改优化设置页 UI
- 历史记录去重（同一天同一网址仅一条，跨天保留多条）
- 修复设置页选择目录/浏览器程序后路径不生效的问题（兼容新版 ztools 异步返回的路径数组）
- 修复已知bug

## 2.4.1 - 2026-09-05

- 修复输入框逻辑
- 更新插件图标
- 简化搜索结果描述行，仅保留类型标识（⭐ 书签 / 🕘 历史）与网址

## 2.0.0 - 2026-09-03

- 重写浏览器历史记录搜索功能
- 重写「书签设置」界面，支持便携版 Chrome / Edge 数据目录配置
- 修复便携版 Chrome 书签搜索不到的问题
- 修复点击搜索结果无法打开网页的问题

## 1.0.0 - 2026-09-03

- 「书签与历史记录搜索」初始版本，一键搜索Chrome/Edge的书签与历史记录
- 新增「书签设置」界面，支持便携版 Chrome / Edge 数据目录配置
- 新增网站图标显示（读取浏览器本地 Favicons 数据库）
