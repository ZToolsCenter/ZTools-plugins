# 更新日志

本插件的变更格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

> 说明：以下所有数字都是**在本机真实抓包归档上跑出来的实测结果**（不是估算，不是预期）。
> 涉及具体样本处已脱敏为 `样本-NN`；样本规模口径：50 个 `.saz` 归档、合计 793.4MB。

## 0.2.4 - 2026-10-04

### 新增
- **归档级流式/分块枚举**：`saz_query` 的条件对象新增 `transferEncoding[]`、`chunkedOnly`、`eventStreamOnly`（只读索引期响应头，零正文 IO；`false` 是补集而非关闭）。此前要列出事件流会话只能去读 `66-stream.md`。
- **单事件全文展开**：详情「事件流」页点击任一行即可展开该事件的完整 `data`（复用已有返回体，不二次请求）；被上游截断时明确提示"这里给的不是全文"。
- **拆帧参数正式化**：`maxStreamEventsInFile`(200) / `maxWsFramesInFile`(120) / `streamMaxEvents`(5000) / `streamMaxValues`(2000) / `streamMaxDataChars`(200000) 进入默认配置与导出面板。**上限只控制逐条展开的行数，计数始终是全量**。
- **发布合规自检**：`tools/package-zip.js` 逐条目扫描包内文本文件，拦截真实样本名 / 本机绝对路径 / 凭证形态；红则出不了包。

### 修复
- **声明为 `text/event-stream` 但正文是每行一份裸 JSON（无 `data:` 前缀）的会话，此前只交出"1 个事件、data 为空"**，三份 JSON 全堆在控制字段里，比不拆更难读。现在自动回退为顶层多值拆分（结果带 `fellBackFrom`，并在正文里写明改判理由）。实测全包 21 条声明该头的会话中命中 3 条，3/3 救回。
- **Content-Type 错标的多值 JSON 此前完全不处理**（典型：某 290.8KB 会话被标成 `text/html`，实为 9 份顶层 JSON 拼接）。现在由内容探测命中（带 `detectedBy:'content'`）。实测 3125 条候选中仅命中 1 条，**JS/CSS/HTML 假阳性 0**。
- **兼容层美化器按 Content-Type 分派，导致错标类型的多值 JSON 直接 passthrough**（而非"形态未覆盖"）。现补上按内容兜底：同一批样本的美化 passthrough 由 39 条降到 **0**。

### 变更
- 内容探测的预门收窄为"正文首非空白字符必须是 `{` 或 `[`"。依据实测成本：放宽到任意 JSON 值开头会让扫描从 39 次膨胀到 6271 次（1955 次被硬判据拒绝）而收益为 0 条。
- 回归断言：`verify` 60 → **74**、`verify-legacy` 18 → **24**、`verify-preload` 203 → **210**；当前全量 74 / 56 / 24 / 210 / 20 全绿。

### 新增（测试）
- `verify-legacy.js` 第 7 节：**chunked 会话与原 Python 算法真实历史产物的逐条对拍**。实测 18 条对齐会话中，原算法产物 18/18 开头就是十六进制长度行（`939\r\r\n{...`），我们 18/18 已剥框，且落盘字节 18/18 逐字节等于对归档原始字节做 transfer-decoding 的结果。
- 结论登记：chunked 场景**不能用"逐字节相等"对齐原算法**——它以文本模式写盘，除不剥框外还会把正文内部的 `\n` 改写成 `\r\n`，两种改写叠加使等式必然不成立。
- `tools/probe-stream-cost.js`：内容改判的覆盖面与成本实测探针。
- 修复 `probe-stream-bodies.js` 的 `--diff` 位置参数被静默忽略的问题（曾导致把历史快照的数字当成新结果）。

## [0.2.3]

### 新增
- **`Transfer-Encoding: chunked` 的 transfer-decoding**（缺陷 B11）：按字节逐块剥框架，支持块扩展与 trailer，残尾标记 `partial`；框架不合法时**整块退还原字节**。解码顺序按 RFC 9112 改为"先解框、再解压"。实测影响面 **245 条**（此前口径 36 条只统计了"能解码但带框架"的一类）：未剥框 36 → **0**，另有 **209 条因长度行混在压缩流开头而解压失败（正文整条不可用）→ 0**，可扫描会话 7402 → 7611。
- **流式/多帧正文拆帧（F28）**：新增 `core/stream.js`，SSE 逐事件（多行 `data` 按规范用 `\n` 拼接、`:` 心跳单独计数、字段后单空格不当内容）并逐事件结构化 `data`；顶层多值 JSON 采用硬判据（值间必须纯空白、无残尾）。实测 19 会话 / 5030 事件 / 5023 个 `data` 为合法 JSON，改后 19/19 拆开；单会话最大 2587 事件。
- 分析包新增 **`66-stream.md`**（事件流与 chunked 会话清单），会话正文新增「事件流拆分」段与「传输解码」说明行。
- **第 5 个 MCP 工具 `saz_stream(sid, from, count, limitBytes)`**；`saz_body` 返回值新增 `transferEncoding` 与 `decode.response.dechunk`。
- UI：详情新增「事件流」页，顶栏新增事件流 / chunked 两个标记；索引与摘要层新增 `transferChunked` / `stream` 计数。

### 变更
- `beautify` 支持顶层多值逐份重排与事件流排版（仅影响兼容层导出）。事件流**默认不展开 `data:` 内的 JSON**——按规范展开会改变重放时的字符串，需显式开启。
- 兼容层把"chunked 已解框"登记进 `_导出清单.md` 的有意不一致清单（非静默差异）。

## [0.2.2]

### 变更
- **交互按实际使用习惯定稿**：粘贴 / 拖入 / 输入 `.saz` 路径时给**两条候选**（一键解析直接落盘 / 打开分析界面）；直接搜索只给**一条**（打开分析界面）。
- 删除 `quickMode` 设置项：无界面判定只能由触发指令决定，任何设置开关都不得劫持宿主的行为询问。
- **搜索关键词从 6 个收敛为 1 个且与插件标题全等**（实测搜 `saz` 由 4 行结果 → 1 行）。其他叫法请用宿主自带的「自定义别名」。
- 修复路径正则在大写 `.SAZ` 上漏匹配：宿主的输入框通路会剥掉 regex flags，改为显式字符类。

### 新增
- 真·无界面通路（宿主隐藏主窗 + 插件自报模式 + 方法调用），完成结果进宿主通知、解析历史与诊断留痕。

## [0.2.1]

### 修复
- **粘贴触发解析失败**：确证宿主 `files` 触发的事件负载结构为 `{isFile, isDirectory, name, path}[]`，绝对路径取自 `path`；并禁止把相对路径按当前工作目录补全（插件进程 CWD 是宿主安装目录，会报出误导性的"文件不存在"）。
- Cookie / 响应头跨会话传递链：在 50 个归档 / 7611 会话上做改前基线 → 改后对拍，进账本条目 **1 → 676**（共 1078 个候选），生产者精确率 **676/676 = 100%**，方向污染 **398 → 0**。
- 设置合并顺序缺陷（改一个开关会静默重置其他设置）。

### 新增
- 安装件自动产出 `release/saz-parser-v<version>.zip`；构建最后一步直接替换本机已安装插件目录（无需手动导入）。
- 输出目录默认落在**归档所在目录**下（分析包 `<名>_分析包`、兼容层 `<名>_解析结果`）。

## [0.2.0]

### 新增
- 首版完整链路：自研 ZIP 中央目录解析、秒级索引（3756 条约 1–3s）、按需流式解码正文（33.6MB 单条不卡死）、gzip/deflate/br/zstd 全支持、WebSocket 帧日志解析（原 Python 脚本一条未取，实测 34 会话 / 1984 帧）、隐私字段类型标注但**值完整保留**、JSON/urlencoded/multipart/query 统一 KV 树。
- 分析包（L0–L3 四档 + token 预算 + 自动分卷 + `manifest.json` + 降级留痕 `trimLog`）、业务流程分组与跨会话参数传递摘要、条件对象取数。
- 界面：会话列表 / 三档过滤 / 详情懒加载 / 域名分组与端点 / 关键值看板 / 流程与传递链 / 诊断面板 / 导出面板（双模式 + 估算 + 进度）/ 解析历史。
- 4 个 MCP 工具：`saz_parse`、`saz_query`、`saz_body`、`saz_ws`。
- 兼容层：与原 Python 脚本同构的目录树导出，并通过逐目录对拍（差异全部可归因）。

### 已知限制
- 不调用任何模型，也不联网；分析效果需自行把分析包交给 AI。
- 无 `.proto` 时 protobuf 正文只能保留原始字节（子协议已记录在会话字段）。
- 单次触发处理一个归档；HAR 导出、L3 全量分卷优化在路线图上。
