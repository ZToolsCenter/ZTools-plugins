# 生成书签元信息

## 适用需求

- 为一个网址生成标题和简介。
- 根据已有页面标题与描述补全书签信息。

## 输入检查

- 必须有网址。
- 页面标题和页面描述可以为空。
- `usedNetworkFallback` 仅标记是否走过联网兜底，不单独决定文案。

## 输出

- 返回符合请求 Schema 的对象。
- `source` 只能是 `ai` 或 `network`。

## 质量要求

- 标题自然、准确，不超过 15 个汉字。
- 简介用一句话说明核心功能与价值，不超过 40 个汉字，使用简体中文。
- 删除首页、登录、Sign in、Documentation、官方文档等弱信息。
- 不要输出「请登录」「需要登录」「访问受限」等无法验证产品价值的抽象说明。
- 有可靠页面线索时优先依据线索，不臆造未出现的细节。
- 页面线索为空、仅为登录墙或访问受限文案时：根据网址域名的公开产品定位生成可用标题与简介，说明该站点提供什么服务；`source` 记为 `network`（若输入标记用过联网兜底）否则 `ai`。

## 完成

- 标题、简介和来源均满足 Schema 后结束。
