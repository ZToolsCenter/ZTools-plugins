# 推荐书签分类

## 适用需求

- 从用户已有分组中推荐一个分类。
- 为书签匹配主分组和子分组。

## 输入检查

- 必须有网址。
- 必须有可选分组列表。
- 当前分组仅作为参考，不应形成默认偏好。

## 输出

- 返回符合请求 Schema 的对象。
- 返回 `groupName`、`subGroupName`、`confidence` 和 `reason`。
- `confidence` 取值为 0 到 1。

## 分类规则

- 主分组和子分组必须与输入列表中的名称完全一致。
- 不创建新分组。
- 没有合适分类时将 `groupName` 设为空字符串。
- 优先匹配网址的主要用途，不因当前选中分组降低判断质量。
- 理由简短、具体。

## 完成

- 名称来自输入分组且字段满足 Schema 后结束。
