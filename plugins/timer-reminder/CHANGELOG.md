# Changelog

## 1.2.0 - 2026-10-09

### Changed

- 导入导出改为 Excel（xlsx）格式：零依赖内置 xlsx 读写引擎，兼容真实 Excel 的 sharedStrings 与日期序列号
- 「导入 Excel」按钮移至待提醒页底部，「导出 Excel」按钮移至已完成页底部（导出已完成列表）
- 移除设置页「数据管理」区块

## 1.1.0 - 2026-10-08

### Added

- 待提醒 / 已完成列表支持导出为 JSON（全部 / 待提醒 / 已完成）与导入合并
- 额外提醒通道：邮件（内置 SMTP 客户端，SSL/STARTTLS）、短信（短信宝）、自定义 Webhook
- 密钥（SMTP 密码 / 短信密钥 / 大模型 API Key）改存 ZTools 加密存储 dbCryptoStorage
- 接入大语言模型（OpenAI 兼容接口）：规则解析失败时自动 AI 解析自然语言

## 1.0.0 - 2026-10-08

### Added

- 首个公开版本：一次性 / 周期性定时提醒（间隔、每小时、每天、每周、工作日、每月）
- 自然语言快速创建：如「10分钟后 喝水」「明天9点 开会」「每周一三五 9:00 例会」
- 到点系统通知 + 响铃，可选置顶弹窗强提醒；支持稍后提醒、完成、停用、编辑、删除
- 插件重启自动续期，停机期间错过的提醒启动时补发
- 多窗口心跳锁，避免主窗口与分离窗口重复触发
- 跟随 ZTools 浅色 / 深色主题
