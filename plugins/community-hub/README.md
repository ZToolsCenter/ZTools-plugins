# 社区漫游

在 ZTools 中浏览 **V2EX、LINUX DO、LINUX SB**，用统一的帖子列表、正文和回复界面阅读社区内容。

## 功能

- **三站浏览**：V2EX 最热 / 最新；LINUX DO 最新 / 热门；LINUX SB 最新 / 热议 / 新回复。
- **正文与讨论**：保留段落、链接、代码、引用和表格，支持分批加载回复。
- **作者头像**：帖子列表、正文和回复显示头像，加载失败时显示名字首字。
- **帖子图片**：默认显示正文与回复中的图片，按需加载；支持点击放大、切换原始大小、失败重试和查看原图。
- **可调整社区栏**：拖动左侧社区栏右边缘调整宽度，双击恢复默认；支持隐藏 / 显示并记住设置。
- **收藏与足迹**：收藏喜欢的帖子，保留阅读记录和已读标记；刷新失败时保留此前的列表。
- **关键词筛选**：即时筛选已加载帖子的标题、作者和分类。
- **阅读外观**：浅色、深色或跟随系统；宽窗口分栏阅读，窄窗口切换列表与正文；默认展开高度为 860 px。
- **原站入口**：复制帖子链接，或通过阅读栏右上角的“在原站打开”按钮，在系统默认浏览器中查看原帖。

插件仅提供浏览与本地收藏、阅读记录功能，不提供发帖、回复、点赞等社区写入操作。主界面由插件排版显示帖子内容，没有嵌入整站网页。

## 安装与打开


| 关键词 | 打开内容 |
| --- | --- |
| `社区漫游` / `社区` / `community` | 社区漫游 |
| `v2ex` | V2EX |
| `linux.do` / `linuxdo` | LINUX DO |
| `linux.sb` / `linuxsb` / `烧饼社区` | LINUX SB |

从源码使用时，在 ZTools 插件开发入口导入本目录的 `plugin.json` 即可，无需安装 npm 依赖或编译。普通浏览器无法使用插件的社区数据请求功能。

登录与验证功能需要宿主支持 `zbrowser`，建议使用支持该接口的 ZTools 版本。插件声明支持 Windows、macOS 和 Linux，目前已在 Windows 环境完成验证。

## 阅读操作

选择社区和分类后，点击帖子阅读正文与讨论。较窄窗口会切换为正文页，点击“返回列表”继续浏览。

拖动社区栏右边缘可在 153–360 px 范围内调整宽度，窄窗口会自动限制上限。双击边缘恢复默认宽度，点击顶部社区栏按钮可以隐藏或显示左栏。宽度和显隐状态会自动保存。

正文及回复中的图片默认显示，接近可见区域时开始加载。点击图片可在插件内放大；遇到加载失败，可点击“重试”或“查看原图”。阅读设置中可关闭图片显示，改为保留图片链接。

## 登录与站点验证

插件默认读取公开内容。遇到登录或浏览器验证提示时：

1. 点击对应社区顶部的 **登录 / 验证**。
2. 在弹出的 ZTools 浏览器窗口中手动登录或完成验证。
3. 返回插件，刷新列表或重新读取帖子。

连接后，该社区会通过插件的浏览器会话读取内容。主界面继续显示帖子列表、正文和回复，可在阅读设置中恢复直接请求。

插件浏览器会话与系统默认浏览器的登录状态独立，登录信息由宿主管理。插件不会自动填写账号密码、完成验证码或导出 Cookie。


## 已知限制

- 筛选仅作用于已加载的帖子，不是全站搜索；当前只适配上述三个社区。
- 站点登录、验证码、访问频率与内容权限由原站决定。LINUX DO 可能要求浏览器验证；LINUX SB 部分评论需登录后才能读取。
- V2EX 使用公开 API，列表范围以接口返回内容为准；回复在界面按每批 100 条显示。LINUX DO 按帖子流分批补取回复。
- 图片支持 PNG、JPEG、GIF、WebP 和 AVIF，单张下载上限为 12 MiB。防盗链、登录权限、图片格式或网络限制可能导致部分图片无法在插件中显示，此时可使用原图入口。
- 默认请求支持 Windows / macOS 系统 HTTP / HTTPS 代理及 `HTTPS_PROXY` 环境变量，不直接解析 PAC/WPAD 或 SOCKS 代理。遇到相关限制时可尝试“登录 / 验证”后的浏览器会话读取。
- 原站接口或页面结构变化后，相关站点可能需要更新适配器。

## 本地数据

收藏、阅读足迹、阅读设置和列表摘要优先保存在 ZTools 插件数据库中，缺少宿主存储接口时使用本地存储。收藏最多保留 500 条，阅读足迹最多保留 300 条，可在阅读设置中清空足迹。

正文、回复和图片仅在当前插件会话中缓存，不保存到插件数据库。插件没有独立的中转服务器；数据与图片请求发送至对应社区或图片来源。
