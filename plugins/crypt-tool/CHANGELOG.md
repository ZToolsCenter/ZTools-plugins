# Changelog

## 1.2.0 - 2026-10-22

### 界面重构

- 全新「信号台」界面：顶栏展示分类路径、方向切换与可逆/单向徽标，主区域改为带信号线的滚动工作台
- 新增右侧「边注」面板：聚焦字段时显示说明，并常驻算法简注与类别安全要点；窄窗口下变为可收起的覆盖面板
- 侧栏改为可折叠分类索引并显示算法数量；新增搜索框，支持 `/` 快捷聚焦
- 设置页重新设计：按类别分组、开关式启停、按名称或 ID 筛选、已启用计数与恢复默认
- 全面适配 ZTools 主题色与深浅色模式，自动计算强调色上的文字对比度；新增 1040 / 1000 / 620px 响应式断点
- 字段与操作按钮改用线性图标，复制后显示完成反馈，补充 ARIA 标签与键盘可访问性

### 功能改进

- AES 新增随机密钥与 IV 生成按钮，并移除默认预填的示例密钥/IV
- Base58 / Base58check 支持跟随全局方向编码或解码，Base58check 解码显示校验结果与还原数据
- 可逆算法的「互换输入输出」改为「转入解密 / 转入加密」（编码类为「解码 / 编码」）：仅在有输出时显示，点击后切换方向并带入上一次结果
- bcrypt 的哈希/验证模式切换改为顶部 Tab
- 密钥对与随机值生成入口统一收进对应字段的行内操作（RSA、ECDH、ChaCha20、scrypt 等），scrypt 随机盐改由 preload 的 `randomBytes` 生成
- 进入插件时清空搜索，侧栏搜索与 ZTools 子输入框保持同步

### 修复与优化

- 切换算法时按算法 ID 重建页面宿主，避免不同算法间残留状态
- 新增 AES keygen / ivgen 单元测试
- 同步更新 README、DEVELOP 及界面截图

## 1.1.0 - 2026-09-25

### 首次发布

**编码转换 (10 种)**

- Base64 / Safe Base64 / Base32 / Base58 编解码
- Hex / URL 编码
- Unicode 转义 / HTML 实体 / Punycode 编码
- 摩尔斯电码编解码

**哈希摘要 (8 种)**

- MD5 / SHA-1 / SHA-256 / SHA-384 / SHA-512
- SHA3-256 / SHA3-512 / RIPEMD-160

**对称加密 (4 种)**

- AES (CBC / GCM 模式)
- 3DES
- ChaCha20-Poly1305
- XOR 流密码

**非对称加密 (4 种)**

- RSA 加解密与密钥对生成
- ECDSA 签名与验证
- Ed25519 数字签名
- ECDH 密钥交换

**密钥派生 (5 种)**

- Argon2 / bcrypt / scrypt 密码哈希
- PBKDF2 口令派生
- HKDF 密钥派生

**消息认证 (1 种)**

- HMAC-SHA256 消息认证码

**实用工具 (7 种)**

- JWT 解码
- JSON 格式化与压缩
- UUID / Random Bytes 生成器
- 密码强度分析
- CRC32 / Adler-32 校验和
