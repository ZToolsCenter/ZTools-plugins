# Changelog

## 1.0.0 - 2026-10-21

### 新增

- 系统服务管理：全量服务列表、搜索过滤、状态标签、详情查看（路径/账户/PID/描述）、启动/停止/重启、修改启动类型（自动/延迟/手动/禁用）
- NSSM 服务管理：nssm 路径探测与手动配置（验证后持久化，支持从已注册 nssm 服务的 binPath 反查路径）、nssm 服务识别与列表、行点击查看详情（服务信息 + nssm 全部参数）、表单式安装/编辑/卸载
- 安装/编辑表单分「基础 / 日志 / 高级」三个页签，程序路径、启动目录、日志文件均可通过系统选择对话框浏览选取
- 高级参数带注释：日志重定向与轮转、退出动作、重启延迟、崩溃节流、进程优先级、停止方式、环境变量
- 双轨提权：ZTools 以管理员运行时零弹窗直执行；普通权限时自动降级为 UAC 逐次确认，命令执行前均预览可审计
