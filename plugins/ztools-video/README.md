# 影视搜索

在 ZTools 里搜索片名、选集、看片的一个小插件。

支持搜索 4K 影视的片库，按「电影 / 电视剧 / 动漫」三个频道浏览，也能直接粘贴播放页、MP4 直链或 M3U8 链接来播放。播放、选集、连播和进度记录都在插件里完成，不用跳到浏览器。

打开插件直接进入电影频道。搜索框在右上角，输入片名后回车即可搜索，结果显示在当前频道上方。

![搜索](docs/screenshots/home.png)

## 功能

**搜索与频道**

点顶部切换电影、电视剧、动漫，按原站分组浏览。右上角搜索框输入片名后回车，搜索结果会覆盖当前列表；点「返回电影」或切换频道即可回到频道内容。

**独立播放窗口**

点影片会在单独的窗口里打开播放详情，主窗口保留你当前浏览的列表。再选一部影片时会复用同一个播放窗口，不会越开越多。

![播放窗口](docs/screenshots/player.png)

**选集与连播**

多集剧集在右侧显示选集面板，支持分页。一集播完会自动播放下一集；播放器控制栏里播放按钮右侧还有「下一集」按钮，随时手动切换。最后一集会自动隐藏这个按钮。

不需要连播的话，播放器下方有「自动连播」开关，关掉后会停在当前集。选择会被记住。

**全屏**

双击画面进入全屏，再双击退出。因为播放详情在独立窗口里，全屏不会受主窗口限制。全屏下自动连播也不会退出全屏。

**播放记录**

点右上角的时钟图标进入播放记录页。

![播放记录](docs/screenshots/history.png)

同一部剧只保留一条记录，显示封面、看到第几集、已看多久和剩余时长。点记录会直接回到上次观看的那一集和位置。看完的剧进度会归零，下次从头播放。

记录支持单条删除和整体清空，只保存在你本机，不会上传。

## 使用

在 ZTools 里搜索「影视搜索」或「视频播放」即可打开。

也可以在输入框直接粘贴：

- 4K 影视的播放页链接，例如 `https://www.4kvm.tv/play/xxxxx`
- MP4 直链
- M3U8 播放清单链接

## 注意事项

**关于内容来源**

本插件只做聚合检索与播放，不存储、不制作、不分发任何视频内容。所有影片与播放地址都来自第三方站点，版权归各自权利人所有。请仅用于个人学习与测试，勿作商业用途。

首次打开插件时会展示这份说明，确认后不再弹出。

**播放地址会过期**

站点返回的播放地址带签名和有效期，过一段时间会失效。如果播放失败，点播放器上的「重试播放」会重新获取地址。

**部分线路可能不可用**

片源由第三方站点提供，个别线路可能返回错误页面或加载失败。换一条线路或换一集通常可以解决。插件会在片源返回网页而不是视频时给出明确提示。

**播放记录是本地数据**

记录保存在 ZTools 的本地存储里，卸载插件或清理数据会丢失。
