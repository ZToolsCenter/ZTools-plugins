## 当前功能

### 🚀 主要功能：VSCode 最近项目

**使用方式**：
1. 在 ztools 中输入 "vscode"、"vs"、"最近" 或 "最近项目"
2. 显示最近打开的 VSCode 项目列表
3. 使用 ↑↓ 键选择项目
4. 按 Enter 键打开项目（启动功能待实现）
5. 支持模糊搜索过滤

**数据来源**：
- 自动读取 VSCode 的 state.vscdb 数据库
- 跨平台支持（Windows/macOS/Linux）

### ⚙️ 配置功能：VSCode 启动器配置

**使用方式**：
1. 输入 "vsc配置" 或 "vscode配置"
2. 配置界面包含：
   - Code.exe 路径设置
   - state.vscdb 路径设置
3. 点击"保存配置"保存设置
4. 配置自动应用到主功能

### Preload API

\\\	ypescript
window.services = {
  // VSCode 最近项目

### 数据存储

- **存储方式**：ZTools 数据库 API
- **存储键**：scode-launcher-config
- **数据格式**：JSON

### vscdb 读取

- **库**：sql.js（SQLite in JavaScript）
- **查询**：\SELECT value FROM ItemTable WHERE key = 'history.recentlyOpenedPathsList'\
- **解析**：JSON 解析并映射为项目列表
