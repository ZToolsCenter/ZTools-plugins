# VSCode 启动器 - 配置功能完成 ✅

## 新增功能：配置界面

### 功能概述

新增了配置界面，允许用户自定义 VSCode 启动器的相关路径，包括：
- **Code.exe 路径**：VSCode 可执行文件位置
- **state.vscdb 路径**：VSCode 数据库文件位置

### 使用方法

**触发方式**：
- 在 ztools 中输入 "vsc配置"、"vscode配置" 或 "vsc设置"
- 进入配置页面进行设置

**操作步骤**：
1. 在输入框中直接输入路径
2. 或点击"浏览..."按钮选择文件
3. 点击"保存配置"按钮保存设置
4. 配置会自动存储到 ZTools 数据库

**2. Preload API (src-ztools/preload/services.js)**

\\\javascript
// 配置管理
const CONFIG_KEY = 'vscode-launcher-config';

function getVSCodeConfig() {
  const config = window.ztools.dbStorage.getItem(CONFIG_KEY);
  return config ? JSON.parse(config) : { codeExecutable: '', vscdbPath: '' };
}

function saveVSCodeConfig(config) {
  window.ztools.dbStorage.setItem(CONFIG_KEY, JSON.stringify(config));
}

// 暴露给前端
window.services = {
  // ... 其他服务
  getVSCodeConfig,
  saveVSCodeConfig,
}
\\\

**3. 配置界面组件 (src/VSCodeSettings/index.tsx)**

主要功能：
- 使用 \window.services.getVSCodeConfig()\ 加载配置
- 使用 \window.services.saveVSCodeConfig()\ 保存配置
- 使用 \window.ztools.showOpenDialog()\ 浏览文件
- 使用 \window.ztools.showNotification()\ 显示提示

**4. 配置应用**

在 \loadRecent()\ 函数中会检查用户配置：
\\\javascript
const config = getVSCodeConfig();
const customVscdbPath = config.vscdbPath || '';
