## 技术要点

### Preload 脚本设计

**关键问题**：Node.js 不能直接运行 TypeScript 文件

**解决方案**：将核心逻辑内联到 \services.js\ 中，包括：
- vscdb 读取逻辑
- URI 映射
- 文件存在性检查

这样避免了复杂的构建流程，使 preload 脚本可以直接被 Electron 加载。

### 与目标项目的差异

1. **Preload 实现**：目标项目使用 tsc 编译，本项目采用内联方式
2. **UI 框架**：从原生 DOM 转换为 React
3. **功能简化**：暂未实现 VSCode 启动功能
4. **数据源**：仅使用 state.vscdb
