# Changelog

## 1.0.0 - 2026-09-11

- 首个正式版本，基于 ZTools 插件平台 + Vue 3 + Vite + ssh2 实现一键批量执行服务器命令
- 服务器管理：密码 / 私钥认证，连接测试
- 命令库：可复用命令模板
- 快捷指令：一条命令 + 一组服务器，一键批量执行
- 临时命令：即时输入 + 自定义并发数
- 批量执行引擎：并发池、单台超时、整批取消、高危命令二次确认、失败重试
- 实时四阶段状态反馈：连接中 / SSH 握手 / 登录成功 / 命令执行中
- 终端式结果展示：stdout / stderr 分区着色
- 执行记录：每次独立持久化，默认保留 10 条可自定义
- 三栏布局首页，明暗主题适配
